Desigo Control Point

The integrated graphics editor for ABT Site offers the following functions for offline engineering.

  • Flexible and efficient creation of customized user interfaces such as page layouts, navigation, texts, colors, operating elements (list, buttons, hyperlinks) etc.
  • Efficient reuse of available graphics
  • Simulated preview of graphics in the tool during creation

The graphics engineering in a runtime system can be done over an HTML 5.0 web browser. No additional tool is required.
