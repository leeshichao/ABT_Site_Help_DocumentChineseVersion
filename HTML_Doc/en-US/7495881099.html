Supply chain extract air VAV air volume flow saturation evaluation (SplyVavExSrt11)

Overview

(for future use)

The application function "Supply chain extract air VAV air volume flow saturation evaluation 11" (SplyVavExSrt11) evaluates the extract VAV saturation signal(s) from the room segments for use in fan speed optimization.

Function

(for future use)

Depending on the number of extract saturation signals (NumVavExStrtn) the fan speed can be adjusted.

The signal for damper saturation is a binary value object. It is True when the air flow control loop cannot get enough air to reach setpoint.

The value is True when:

  • Damper position exceeds a configured damper saturation level, AND
  • Air flow error exceeds a configured air flow error level, AND
  • Both conditions stay true for more than a configured delay interval.
