IP network information

Column

Description

Hostname

Dedicated hostname for the device.

UDP Port

Specifies the UDP port in hexadecimal format from BAC0 to BAD4. Default is BAC0.

Local broadcast UDP port

UDP port for Local broadcast setting.
Address defaults

DHCP

If selected DHCP is used to automatically configure the IP addresses.

IP Address

IP address of the device.

Subnet mask

Specifies the subnet within the larger network (IP).

Gateway

Specifies a node on a TCP/IP network that serves as an access point to another network.

Preferred DNS server

The address of the preferred domain name server.

Alternative DNS server

The address of the alternative domain name server.

Domain name

Name of the domain e.g. siemens.net.

MS/TP network information

Column

Description

Network

Number that identifies the network.

Auto addressing

When activated the MAC address settings are obtained automatically.

MAC address

First MAC address for the MS/TP port.

Max. manager address

Set the Max manager address to prevent the passing of the token to unused MAC addresses situated after the manager.

Baud rate

Specifies the rate at which data is sent to the bus.

Max info frames

The maximum number of information requests to other devices. Range 1‑25. Default is 10.

Description

Save

Saves the current changes. The number above the button indicates the number of changes made.

Copies the table data to be pasted in Excel or other spreadsheet software.

Pastes data from the clipboard into the table performing certain checks to work with changed data from Excel or other spreadsheet software.

Check

Performs all mandatory checks and the optional checks selected in Configure checks. The results are indicated in the Details and Log tabs.

Allows you to set optional checks.
