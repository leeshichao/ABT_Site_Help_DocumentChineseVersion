Object naming

Show property on adding objects

The activated check box displays an additional Object name field when a new object is created. Enter an object name text into the field. Keeping the object name empty will result in a standard hierarchical object name. Note: Within the project, the text must be unique.
Modifying object name to user defined object name

In the Properties tab, the Object name rule field changes to User defined.

Note: It is not advisable to use this function together with the user designation, because both functions use the same data source. This may prevent a consistent view of the data point description.

Use build name option for building elements

The activated check box defines how the parent elements in the building structure (i.e, buildings, floors, sections) are used in the object names of the individual plants.
