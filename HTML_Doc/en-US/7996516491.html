Common settings tab

Common settings define project-specific rules for access and operating.

① Settings

Setting

Description

Block time on failed login

Specified time a user is not able to log in after a number of failed login attempts. The number of failed login attempts can be set in Failed login attempts.

Failed login attempts

Number of login attempts before a user account is blocked for a specific time. The time can be set in Block time on failed login.

Min password length

The minimum number of characters to be used for passwords.

Password policy

Select rules for creating new passwords. The following rules are available. Set at least 3 of the following values.

Use uppercase characters

Use lowercase characters

Use digits

Use special characters

For a best practice guideline on setting strong passwords, see our Password policy section.
Password policy

Note
Minimum password length and password policies cannot be changed if conflicting with already defined passwords.

Room operation priority

Command priority of returned BACnet values for room operation.

Technical operation priority

Command priority of returned BACnet values for technical operation.

Save encrypted password with the project data

Only visible if set by your local tool manager.

Clearing the checkbox will delete all saved password recovery data. Once you clear the check box, you cannot select it again. The option will be grayed out.

Enable N-step configuration

Activate to enable role-based backup and restore.

Enable engineering data on device

Activate to load the engineering data into the device. The Load > Engineering data menu becomes visible.
Note: Within a region, the settings should be the same to avoid confusion if engineering data on the device exists or not. To have this menu available, the tool manager must enables this function in the ABT Site installer.

 

NOTICE

Weak passwords can be deciphered. As a result system malfunctions or automation stations failures can be set off.

High fixing costs and a loss of reputation.

  1. Use different passwords for different users.
  2. Use strong passwords.

 

② Toolbar

Command

Description

Verify profiles

Checks if the user profiles settings are consistent:

  • At least one valid and not expired user must be present.
  • All users must have a valid password.
