Importing an external web certificate

This procedure describes how to install a certificate on a device. It is required if the device is used to connect to a web server, for example by using a web browser.

 

Import a certificate in MS Windows
  1. ABT Site is the certification authority.
  2. You have exported the root certificate from ABT Site.
    Exporting the web root certificate
  1. Open the root certificate file (*.crt)
  2. Click Install certificate.
  3. The Certificate Import Wizard dialog box opens.
  4. Click Next.
  5. Select Place all certificates in the following store.
  6. Click Browse.
  7. Select Trusted Root Certification Authorities.
  8. Click Next.
  9. A warning is displayed.
  10. Confirm the warning with Yes.
  11. Click Finish.
  1. You have imported a certificate. The certificate is now trusted.
Import a certificate on an Android device
  1. ABT Site is the certification authority.
  2. You exported the root certificate from ABT Site.
    Exporting the web root certificate
  1. Send the root certificate to a mobile device (e.g. by signed email or shared repository). Note that some email clients do not work with certificate attachments. Use an E-Mail web client instead.
  2. Open the certificate.
  3. Provide a name for the certificate when requested. For example: <Project Name> Root CA.
  4. The root certificate is visible under “USER CERTIFICATES”

The root certificate is only available for the default Chrome browser.

Import a certificate on an Apple IOS device
  1. ABT Site is the certification authority.
  2. You exported the root certificate from ABT Site.
    Exporting the web root certificate
  1. Send the root certificate to a mobile device (e.g. by signed email or shared repository). Note that some email clients do not work with certificate attachments. Use an E-Mail web client instead.
  2. Open the certificate
  3. Click Accept.
  4. Install "Test project root CA EC" where Test is the name of the ABT Site project.
  5. Enter the PIN of your IOS device.
  6. Click Install.
  7. Now the "private CA root certificate" is validated.
  8. To activate this root certificate go to Settings.
  9. Go to Settings > General > About > Certificate Trust Settings.
  10. Under Enable full trust for root certificates, turn on trust for the certificate.
