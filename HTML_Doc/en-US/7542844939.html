Configuring application templates

Application templates available in the library can be selected in the Add devices window when adding devices.
For further information on specific application types, click Application help to open the help for the selected application type.

1

To add a project-specific application template select Building > Building structure > Add application template

Building structure

Application selection

2

Select an application template from your project or an application type from your library.

Click Add template to project.

Adding project-specific application templates

3

The template opens in Configuration > Application configuration.

Application configuration

4

Select I/O's and features of the template.

Configuring features (template)

5

Open Configuration > Default values. Configure parameters and modify default values.

Configuring default values (template)

6

Open Configuration > I/O assignment.
