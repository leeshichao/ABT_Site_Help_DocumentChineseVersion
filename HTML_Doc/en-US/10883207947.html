Membrane pressure measuring properties (AI - subsystem-specific extension)

The Analog Input (AI) object supports following properties of the subsystem-specific extension Membrane pressure measuring.

CAUTION

Important!

Do not alter a value unless the consequences are understood. Some of these properties must not be changed.

✳ Indicates a Siemens proprietary property.

Auto-zero mode ✳

 

 

"Auto-zero mode" defines how calibration will be handled.

1

Disabled

2

On demand

3

Time based (see "Auto-zero mode, timer")

Disable auto-zero mode ✳

 

 

"Disable auto-zero mode" defines whether calibration is temporarily disabled while the application reads large airflow changes.

Auto-zero mode, timer ✳

 

 

"Auto-zero mode, timer" defines the time value for calibration frequency.

Pressure deviation ✳

 

 

"Pressure deviation" defines the dead band offset within which the measured airflow must be for a length of time before calibration is allowed. (see also "Pressure deviation hold time")

Infinite impulse resp.filter time ✳

 

 

"Infinite impulse resp.filter time" defines an RMS value for internal system response time.

In use objects list ✳

 

 

"In use objects list" includes a list of all object identifiers of BA-Objects which are currently “in-use”.

Samples for average sensors calculation ✳

 

 

"Samples for average sensors calculation" defines the number of samples taken continuously in a rolling sample average.

Supported signal types ✳

 

 

"Supported signal types" defines which signal types are supported by the hardware.

Signal type

 

 

'Signal type' defines the signal type for its I/O channel. The available signal types depend on the specific hardware, e.g. I/O module type or Onboard-I/O type.

Property ID: 4968

Pressure deviation hold time ✳

 

 

"Pressure deviation hold time" defines how long the measured airflow must remain stable before calibration is allowed.

Calibration command ✳

 

 

"Calibration command" triggers the calibration of the device.

Ready

The device is ready for a new request.

Calibrate

Starts the calibration of the device.

Auto-zero mode, zero value ✳

 

 

"Auto-zero mode, zero value" defines the "counts value" recorded during the last calibration cycle that is used to calculate the zero offset of the sensor.
