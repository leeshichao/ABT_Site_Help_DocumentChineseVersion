Monitoring BACnet objects

When you go online and select a target object to monitor, the monitoring column displays to the left of the Type column, and you can select an object or multiple objects to monitor.

When the object is being monitored, the BACnet objects editor frame changes to orange, eye glasses display in the monitor column, and the Object properties in the Inspector window are deactivated until you click Object Properties in the Inspector window. To reactivate the Object properties fields in the Inspector window, double-click the eye glasses in the monitoring column, right-click the object and select Stop Monitoring Point(s), or click the Stop Monitoring Point(s) icon in the BACnet objects editor toolbar.

Note

Physical inputs must be out of service before Present Value is writable. Physical outputs are commanded with a Command Priority.

When the BACnet objects editor is in online mode, the copy, paste, add, and delete functions are not allowed. When the BACnet objects editor is in offline mode, these functions are restored.

For more information see: Going online/offline with an automation station

Prerequisites

  • A project must be open with a room automation station selected.
  • The BACnet objects editor is open.

Procedure

Monitoring can be turned on in three ways:

  • Double-click the cell to the left of the desired object(s) in the monitor column.
  1. Monitoring is turned on for all selected data points and subordinate properties.

OR

  • Click the Monitor Target icon and click the Start Monitoring Point(s) icon in the BACnet objects editor toolbar.
  1. Monitoring is turned on for all selected data points and subordinate properties.

OR

  1. Right-click the object(s) and select Monitor Target.
  2. Select Start Monitoring Point(s) from the context menu.
  1. Monitoring is turned on for all selected data points and subordinate properties.
