Fan operation (FanOp11)

Overview

The application function "Fan operation 11" (FanOp11) handles the manual operation of fan speed. FanOp11 reads the manual fan speed and determines the impact on plant mode and the fan. It also provides the current fan speed to the room operator unit for display purposes.

Function

This AF has several commandable BACnet objects for monitoring and also for operating via room operator unit. All common fan types are supported. If an object does not correspond with the type of fan being used, that object is automatically set to "unused" and is no longer considered.

Manual commands
When a manual fan speed command is detected (priority 13 active), plant op mode and fan speed are set according to current configuration and the fan device(s) in the room segments are commanded at priority 13 via the grouping function.

Manual fan speed configuration for open window contact shutoff:

Parameter FanOpManCmd must be set to Semiautomatic control to ensure that the fan will turn OFF when a window contact senses an open window, regardless of a manual fan speed command. See Configuration.

Green Leaf interaction
If the GreenLeaf button is pressed, the last manual fan speed command is evaluated for efficiency and will be reset if deemed inefficient.

Fan operation at manual command
▶ How manual fan commands affect fan speed operation and the HVAC control function.

1:Semiautomatic control
▶ Manual fan speed commands affect PltOpMod and fan speed operation:

  • If manual fan speed = OFF, PltOpMod goes to Protection (Prio13)
  • If manual fan speed = ON, fan is commanded ON unless window contact senses open window.

2:Direct control
▶ Manual fan speed commands to the fan affect fan speed operation only:

  • If manual fan speed = OFF, fan is commanded OFF
  • If manual fan speed = ON, fan is commanded ON
