Configuring the properties of a data point

You can select a single data point in the BACnet objects editor. This will allow you to verify all properties and attributes of the data point object in the Inspector window. You can then change the values of the properties as needed. For more information, see: BACnet objects editor Inspector window properties tab

You can edit existing data points by changing the contents in the corresponding row. File, Device, Field Bus Management, and Network View objects that are loaded with a given device may not be deleted.

Each row allows the following actions:

  • Clicking a cell in the row:
    • Selects the row.
    • Displays the Property tab for the associated BACnet object in the Inspector window
    • Sets the focus of the row cell and activates the cell control (for example, textbox, drop-down menu).
  • Typing in editable text cells.
  • Right-clicking a row displays a context menu with the following menu items:
    • Cut–Cuts the selected row(s).
    • Copy–Copies the selected row(s).
    • Paste–Adds copied BACnet object(s) or data point(s) to new row(s).
    • Delete–Deletes the selected row(s).
    • Rename–Sets the focus to the Description cell to rename the item.
    • Monitor Target–Specifies a BACnet object to be monitored and goes online with the device.
    • Start Monitoring Point(s)–Starts/stops monitoring specified BACnet objects in a device.
    • Command–Changes the Present Value of a data point to the value specified in the Command Value field.
    • Release–Releases the data point from the commanded value and restores the default present value.
    • Cross-reference information–Currently not enabled.
