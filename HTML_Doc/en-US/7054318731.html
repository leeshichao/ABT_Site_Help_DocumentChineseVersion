Rapid ventilation operation (RpdVntOp11)

Overview

The application function "Rapid ventilation operation 11" (RpdVntOp11) sends a request for AF HvacPltModxx to start/stop the function "rapid ventilation" used to improve the room air quality.
The request is either entered manually on a room operator unit, or is generated automatically by a trigger signal (if configured).

Function

Request to start rapid ventilation

  • By room occupant, using a room operator unit
    • The room operator unit writes to data point RpdVnt
  • By the application, based on CmfCndTrg/EefCndTrg and supplied by AF ROpMod11
    The response can be configured for each trigger signal.
    • Upon Comfort Condition Trigger (CmfCndTrg), activated by automatic
    • Upon Comfort Condition Trigger (CmfCndTrg), activated manually by room occupant
    • Upon Energy Efficiency Condition Trigger (EefCndTrg), activated by automatic
    • Upon Energy Efficiency Condition Trigger (EefCndTrg), activated manually by room occupant


Request to stop rapid ventilation

  • By room occupant, using a room operator unit
    • The room operator unit writes to data point RpdVnt.
  • By the application
    • Rapid ventilation timer (TiRnRpdVnt) has elapsed.
    • Conditions for manual operation (see below) no longer apply (this stops the timer).


Conditions which prevent rapid ventilation

  • Present priority of PltOpMod is 1..12
  • Manual operation is locked (ManOpCnd = Locked), supplied by AF ROpMod11.
