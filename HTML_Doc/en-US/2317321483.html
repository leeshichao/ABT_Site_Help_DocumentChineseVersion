BACnet objects editor procedures

This section contains a list of procedures related to this editor. Procedures are small steps that belong to a task. Project tasks

Tasks are part of a workflow. Workflows

BACnet objects represent fundamental building automation data; either physical data (such as data associated with I/O) or virtual data (such as network and/or program visible data variables).

Data point type BACnet objects are added to the engineering system through the BACnet objects editor. The BACnet objects editor allows you to create, delete, edit, move, or copy data point type objects.

A default set of BACnet objects are assigned to devices based on the type of device. The properties of these objects may be viewed in the Inspector window. Like data point type objects, some of the properties are fixed and some may be edited.

For a list of data points, see: Point Type Catalog
