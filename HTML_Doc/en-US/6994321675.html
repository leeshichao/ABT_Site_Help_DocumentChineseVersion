AO without subsystem-specific extensions

The following tables show the properties for the channel configuration of analog outputs (AO) without any subsystem-specific extension.

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point is selected in the Device view tab.

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Slope

"Slope" defines the slope of linear function used to calculate the measured value or the positioning value.

Intercept

"Intercept" defines the intercept of the linear function used to calculate the measured value or the positioning value.

Calculate slope and intercept

"Calculate slope and intercept" opens the dialog to calculate slope and intercept from process and signal values.

Note
Calculation is not required for relay and triac signal types.

Unit

"Unit" defines the physical unit of the input or the output.

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.
