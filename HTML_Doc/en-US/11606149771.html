Configure: GxB111.9E/KN (PrphDev - subsystem-specific extension)

The Peripheral device (PrphDev) object supports following properties of the subsystem-specific extension Configure: GxB111.9E/KN.

✳ Indicates a Siemens proprietary property.

Heating valve position maximum ✳

 

 

"Heating valve position maximum" allows configuring the damper’s maximum angle position for the heating sequence.

Range: 0..100 [%]

Heating valve position minimum ✳

 

 

"Heating valve position minimum" allows configuring the damper’s minimum angle position for the heating sequence.

Range: 0..100 [%]

Closed valve position ✳

 

 

"Closed valve position" allows configuring the damper’s closed angle position for neither heating or cooling is active sequence.

Range: 0...100 %

Cooling valve position minimum ✳

 

 

"Cooling valve position minimum" allows configuring the damper’s minimum angle position for the cooling sequence.

Range: 0...100 %

Cooling valve position maximum ✳

 

 

"Cooling valve position maximum" allows configuring the damper’s maximum angle position for the cooling sequence.

Range: 0...100 %
