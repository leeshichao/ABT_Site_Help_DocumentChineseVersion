User designation

The user designation definition organizes the assigned BACnet objects with the new user designation. The BACnet name is replaced with the new user designation. Using a BACnet browser you can only see the user designation as a BACnet object name.

Use the User designation task to create project-specific user designations. User designation trees that have no data points assigned are displayed in Italic. ABT Pro: Previously created user designations are lost when copying automation stations or rooms.
Creating project-specific user designations

You have to define the User designation settings before you can use the User designation task. Go to Settings > Naming defaults > User designation settings and define the User designation settings.
User designation settings tab

Changes to the User designation settings are also applied to user designations you have already created.
