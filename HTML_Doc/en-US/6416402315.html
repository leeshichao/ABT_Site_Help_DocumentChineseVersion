Lighting local manual operation (LgtLocManOp11)

Overview

The application function "Lighting local manual operation 11" (LgtLocManOp11) controls local manual switching and dimming of lights.

It is optimized for a short response time between the event on a pushbutton and the lighting actuator response.

Function

The user can switch or dim light(s) using local pushbuttons.

The AF checks the priority of the lighting output and writes at appropriate priorities, see tables below.

Specially configured pushbuttons (commands "User defined 1...3") can be used to change the priority of the Lighting output (LgtOut):

  • Automatic mode 6 (Prio 15, "Enable control"), available only with a lighting control AF (LgtBrgtSwi11 or LgtConstCtl11).
  • Manual mode 3 (Prio 13).
  • Manual mode 1 (Prio 7), prioritized operation, excludes intervention from central AFs and system operator.

Enable external switch-on value

This configuration changes a Switch-on to a Go to level command. The level is provided by the SwiOnVal input pin of the chart. The lighting output is updated as long as the Go to level command is active.
This feature is not supported by the automatic switch-off function of the lighting output. The SwiOnVal input is disabled in this case.

Indication on the KNX PL-Link light pushbuttons

The AF reads the present state of the lighting output and sends the following information to the lighting pushbuttons (for indication purposes):

  • The Present state of the lighting output.
  • Manual operation locked is set:
    • if ManM1 (Prio 7) is not active and present priority < ManM3 (Prio 13)
      This means: Locked is set at priorities 1…12
    • if ManM1 (Prio 7) is active and present priority < ManM1 (Prio 7)
      This means: Locked is set at priorities 1…6.

The LED indication behavior of the PL-Link pushbuttons must be set via device configuration.


Staircase timer
The staircase functionality (automatic switch-off) is provided by the lighting output BACnet objects LgtAOut and LgtBOut. See the properties "automatic switch-off function" and "automatic switch-off time".

Configure the corresponding lighting input object LgtIn to always send a switch-on command. This restarts the switch-off timer whenever the lighting button is pushed.

Engineering and commissioning

Configuration
Except from EnBrgtCtlSwiOn, no configuration in the AF itself.

  • TX-I/O: The channels for the pushbuttons can be configured to send the required commands to the AF.
  • KNX PL-Link devices: Devices have a predefined functionality for blinds pushbuttons. The device can be selected, but not configured.
    KNX PL-Link can only send scenes (this can be used as a workaround).
  • The LED indication behavior of the PL-Link pushbuttons must be set via device configuration.


S-Mode devices

S-Mode devices do not support burn-in. Other functions may not be supported as well. See the device documentation.


Location of AF

  • The AF must be located on the same room automation station as the connected lighting actuators.
  • To reach a short response time it is recommended to connect the pushbuttons to the same room automation station, as well.


Technical hints
The AF LgtLocManOp11 is assigned to OB40 for performance. This is necessary to reach a short response time when operating the lighting manually by means of the local pushbuttons. The event of pressing a local pushbutton triggers the performance in the AF.

Additionally to triggering the AF when pressing a pushbutton, the AF is performed every 20 OB1 cycles.
