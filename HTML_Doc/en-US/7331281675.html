Central room operation distribution (CenROpDstr01)

Overview

The application function "Central room operation distribution 01, Desigo TRA V5.1" (CenROpDstr01) handles distribution of the reset functions for manual operator interventions in the room for rooms with Desigo V5.1 / V5.1SP functionality.

The commands are distributed either to subordinate AFs CenROpDstr01 or directly to the connected rooms.

Function

In Desigo V6 and higher, the reset for manual operator interventions in the room takes place in the room. In Desigo V5.1 / V5.1SP, it is implemented as central reset in CenOpMod01.

CenROpDstr01 is used in cases where CenOpMod11 works with V5.1 rooms as a supplement to the reset function in CenOpMod11.

The following operator interventions can be centrally reset:

  • Presence button
  • Setpoint shift
  • Room climate operating mode
  • Fan speed
