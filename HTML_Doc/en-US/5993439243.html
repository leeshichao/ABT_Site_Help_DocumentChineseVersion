Defining a central functions hierarchy

The central functions hierarchy table organizes group managers and group members of a building in a logical manner.
The central functions hierarchy is created using the following structure elements: central hierarchy (default is F_1) and hierarchy element (default is H_1).

The automatically generated names and descriptions are defined in Settings > Naming defaults.
Naming defaults
Central functions are dragged from the Unplaced central functions folder to a central hierarchy.
Moving central functions

Add a hierarchy
  • Right-click in the work area and select Add hierarchy.
  1. A new central hierarchy is added below.
Add a hierarchy element
  • Right-click the central hierarchy or hierarchy element and select Add hierarchy element.
  1. A new hierarchy element is added below.
Copy a hierarchy
  1. Select a hierarchy or a part of it.
  2. Press CTRL and drag the hierarchy or a part of it to another hierarchy.
  1. The selected hierarchy is copied. The central functions and group managers contained in the hierarchy are not copied with the hierarchy.

You can also drag and drop between split views.

Rename a hierarchy or hierarchy element
  1. Click the corresponding field.
  2. Press F2.
  3. Type a new name.

Alternatively, slowly double-click in the Name or Description fields to edit the designation.

Delete a central hierarchy or hierarchy element
  • Right-click the central hierarchy or hierarchy element and select Delete.
  1. The hierarchy with all hierarchy elements is deleted.
  2. All central functions contained in the deleted element are moved to the Unplaced central functions folder.

Special folders cannot be deleted.
Special folders are only visible if they contain objects.

Delete a central function
  • Right-click the central function and select Delete.
  1. The central function and the contained group managers are moved to the Unplaced central functions folder.

Group managers cannot be removed from central functions.
