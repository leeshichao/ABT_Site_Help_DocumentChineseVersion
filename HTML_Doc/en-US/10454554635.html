Central operating mode extended function (CenOpModExtd11)

Overview

The application function "Central operating mode extended functions 11, for presence mode and operating strategy" (CenOpModExtd11) permits detailed, central operation of presence operating mode for HVAC, lighting, and shading as well as an operating strategy for lighting and shading. The AF distributes these commands either to subordinate AFs CenOpModExtd11 or directly to the connected rooms.

Function

The existing standard concept for Operating mode (local, each room) allows for defining discipline-specific presence operating modes and strategies for each room operating mode.

This extended, central AF is used when different presence operating modes or strategies are required within the same room operating mode.


Example:

Lighting presence mode at Economy from 6 pm to 8 pm should be "Consider present & absent" and "Consider absent" from 8 pm to 7 am.

The central AF prepares the BACnet objects to control discipline-specific presence operating mode and operating strategy from the management station in manual mode 3 (Prio 13) and manual mode 2 (Prio 8).

Operation in Auto mode (Prio 15) is possible via a scheduler or project-specific program. As it commands at prio 14 within the room, this operation also overrides the local operating mode concept.

The locally preset operating mode concept is performed if no variants for these operating modes is selected.
