Emergency lamps

This section describes maintained and non-maintained emergency luminaires. For the description of properties see DALI Devices.

List of maintained emergency luminaires

This list contains the maintained emergency luminaires in the library.

Device

Description

LgtDev_Dali_Emergency_Luminare_Dimmable_Lamp_Maintained_1xDimOut

Maintained dimmable emergency luminaire

Maintained dimmable emergency luminaires contain one control gear that always operates the lamp no matter if normal mains is present or not. The control gear operates the lamp in the emergency mode or the test mode and supports switching on/off and dimming using DALI commands.

LgtDev_Dali_Emergency_Luminare_Maintained

Maintained stand-alone emergency luminaire

The control gear of a maintained stand-alone emergency luminaire operates the lamp in the emergency mode or the test mode no matter if normal mains is present or not. The control gear does not support switching on/off and dimming using DALI commands.

Maintained stand-alone emergency luminaires are always on.

LgtDev_Dali_Emergency_Luminare_Switched_Lamp_Maintained_1xSwiOut

Maintained switchable emergency luminaire

Maintained switchable emergency luminaires contain one control gear that always operates the lamp no matter if normal mains is present or not. The control gear operates the lamp in the emergency mode or the test mode and supports switching on/off and dimming using DALI commands.

List of non-maintained emergency luminaires

This list contains the non-maintained emergency luminaires in the library.

Device

Description

LgtDev_Dali_Emergency_Luminare_Dimmable_Lamp_Non-Maintained_1xDimOut

Non-maintained dimmable emergency luminaire

Non-maintained dimmable emergency luminaires contain two control gears. The emergency control gear operates the lamp in the test mode and if the normal mains fails. The second control gear operates the lamp if the normal mains is present and supports DALI commands for switching and dimming.

LgtDev_Dali_Emergency_Luminare_Non-Maintained

Non-maintained stand-alone emergency luminaire

The control gear of a non-maintained stand-alone emergency luminaire operates the lamp in the emergency mode or the test mode only if the normal mains fails. The control gear does not support switching on/off and dimming using DALI commands.

Non-maintained stand-alone emergency luminaires are only on if the normal mains fails.

LgtDev_Dali_Emergency_Luminare_Switched_Lamp_Non-Maintained_1xSwiOut

Non-maintained switchable emergency luminaire

Non-maintained switchable emergency luminaires contain two control gears. The emergency control gear operates the lamp in the test mode and if the normal mains fails. The second control gear operates the lamp if the normal mains is present and supports DALI commands for switching.
