Creating Pack & Return files

Use this procedure to create a Pack & Return file.

Freely programmable devices are not supported for Read back or Pack & Return from ABT Site. Use ABT Pro for reading back parameter changes.

 

Create a Pack & Return file

  1. A Pack & Go file has been imported.
    Creating a Pack & Go file
  1. Open the Pack & Go project.
  2. Open Startup > Export.
  3. Select the Pack & Return tab.
  4. In Work package, select the desired work package.
  5. Select the desired building elements or devices.
  6. Click Create Pack & Return.
  7. The Create Pack & Return dialog box displays.
  1. ABT Site stores the file in the Exports folder.
