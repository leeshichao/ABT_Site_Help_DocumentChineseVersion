XFBs

In the XFB (eXchange Function Block) comparison table, A and B denote property restrictions:

  • A – The XFB ignores the "Priority array" and "Update count" properties in the referenced data point(s).
  • B – The XFB ignores the "Priority array" property in the referenced data point(s).

Command

CLB_VNTR

Allows access to BACnet object property of datatype Unsigned for calculated multistate value object.

Read Property

Single

Real

RP_REAL

Allows access to any BACnet object property of datatype Real.

Boolean

RP_BOOL

Allows access to any BACnet object property of datatype Boolean or BACnetBinaryPV.

Unsigned

RP_UNSG

Allows access to any BACnet object property of datatype Unsigned (includes Multistate, Enumerated, and non-negative Integer*).

*Limited to range 0...231 -1 (0...2,147,483,647).

Write Property

Single

Real

WP_REAL

Allows access to any writable BACnet object property of datatype Real.

Boolean

WP_BOOL

Allows access to any writable BACnet object property of datatype of Boolean or BACnetBinaryPV.

Unsigned

WP_UNSG

Allows access to any writable BACnet object property of datatype Unsigned (includes Multistate, Enumerated, and non-negative Integer*).

The control program—not the XFB—must limit Multistate property write values to that property’s correct range (1 to maximum allowed states) to prevent a reject of the write command.

*Integer property write values are limited to range 0...231 -1 (0...2,147,483,647).
