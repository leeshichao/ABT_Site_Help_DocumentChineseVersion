Central emergency command lighting (CenEmgCmd11)

Overview

The application function "Central emergency command for lighting 11" (CenEmgCmdLgt11) handles emergency operation using a multistate BACnet object.

1)

CenEmgCmdLgt11 either acts on AFs Lgt11 as group member or direct on lighting zones (BACnet objects) as group members.
In the second case, ABT Pro is required for engineering.

Function

The staged emergency operation of group members in CenEmgCmdLgt11 occurs via BACnet using a multistate object and can accept the following values: Off/12.5%/25%/37.5%/50%/62.5%/75%/100%. The value is written cyclically (default is 15 minutes).

An emergency operator can use a switch (fire service switch) with the positions enable/off/on. AF CenEmgSwiLgt11 is also required in this case.

An Emergency detector automatically switches lighting of group members to on. AF CenEmgSwDet11 is also required in this case. Manual operation can override automatic switching.

Nested groups are possible, e.g. a superordinate group for the building and subordinate groups for individual hallways.

Secure communication: Group managers and group members monitor communication.
Lighting switches on if the group manager is unavailable.
Lighting switches on even if the DALI bus is unavailable.

Hierarchical grouping

This AF supports hierarchical grouping. For detailed information, see Hierarchical grouping.
