✳ Indicates a Siemens proprietary property.

Present value

 

 

'Present value' indicates the present value of the virtual variable.

Property ID: 85

DALI device number ✳

 

 

"DALI device number" identifies a possible attached DALI device. The property value represents a possible dependency between an emergency unit and a lighting unit.

0

No dependency between an emergency unit and a lighting unit

Dali device number

Dependency between a coupled emergency unit and a lighting unit

  • "DALI device number" represents a forward reference from the emergency control gear to the device number of the control gear that is coupled with the emergency control gear.
  • If emergency mode or test procedure is active, then:
    • the emergency control gear will disconnect the coupled lighting control gear , i.e. the coupled lighting control gear will no more communicate on DALI.
    • data acquisition will suppress reliability errors of the corresponding Peripheral-Device-Object.
    • the running of control commands received from the respective BA-Lighting-Output-Object will stop.
    • the Status-Flag will be set to Overridden of the Lighting Output Object to indicate that the actuator is locally overridden by an emergency mode or test procedure.

Attached-To-Dali-Device = 0: No dependency between an emergency unit and a lighting unit

Attached-To-Dali-Device = Dali device number

-Dependency between a coupled emergency unit and a lighting unit

-Dali device number represents a forward reference from the emergency control gear to the device number of the Control Gear that is coupled with the emergency control gear.

-The emergency control gear will disconnect the coupled lighting control gear if emergency mode or test procedure is active, i.e. the coupled lighting control gear will no more communicate on DALI.

-In the case the data acquisition will suppress Reliability errors of the corresponding Peripheral-Device-Object, will stop the running of control commands received from the respective BA-Lighting-Output-Object and set the Status-Flag Overridden of the Lighting Output Object to indicate that the actuator is locally overridden by an emergency mode or test procedure.

Short test time ✳

 

 

"Short test time" defines the short duration test period in seconds.

Test period ✳

 

 

"Test period" defines the start and frequency of test periods in days. Tests can be started automatically or manually. The following tests are available.

  1. "Test period" [1] = Function test
  2. "Test period" [2] = Duration test
  3. "Test period" [3] = Short duration test

Setting the value to 0, will start the tests manually.
Example: "Test period" [2] = 0 defines a manual start of the duration test.

If the duration test and short duration test are set to start automatically (> 0), the lower value will be used as the primary test type.

Control command ✳

 

 

"Control command" allows triggering and canceling tests, as well as changing the mode of emergency lights.

  • A test may take some time during which a switchable/dimmable emergency light may not be controlled. In this case the data acquisition will set the overridden flag of the respective associated BA-Lighting-Output-Mode to indicate that the actuator will be controlled by the local test procedure.
  • Property Control-Command may not be written when a Control-Command is active, i.e. when the property value <> Ready
  • If Out-of-Service, Control-Command will not be notified to the Data Acquisition

Ready

Default value

Start-Function-Test

Triggers a function test.

Start-Duration-Test

Triggers a duration test. Present-Value indicates whether a duration test is active.

Start-Short-Duration-Tests

Triggers a short duration test. Present-Value indicates whether a duration test is active.

Stop-Test

Cancels an active test.

Goto-Rest-Mode

Sets the emergency light to rest mode.

Goto-Inhibit-Mode

Sets the emergency light to inhibit mode.

Re-Light

Cancels the inhibit mode and the Control Gear will revert to emergency mode unless further inhibited by the hardwired inhibit.

Reset-Inhibit

Cancels the inhibit mode and the Control Gear will revert to normal mode.

Reset-Lamp-Time

Clears the lamp operation time information in case of replacement of the lamp. The control gear counters Lamp EMERGENCY TIME and LAMP TOTAL OPERATION TIME and the properties Lamp-Emergency-Time and Lamp-Total-Operation-Time will be reset.

Switch-on delay for mains supply ✳

 

 

"Switch-on delay for mains supply" defines an extension of an emergency period in seconds before returning to normal mode.

The property can be modified online.

Emergency lighting level ✳

 

 

"Emergency lighting level" defines the emergency lighting level in percent. Only use the property during commissioning. Do not modify the property during normal operation. It has a high write access level.

If the "Emergency lighting level" value is -1%, the value can only be used with peripheral devices which support a configurable emergency level.

I/O address ✳

 

 

"I/O address" identifies and documents the data source, and facilitates configuring, modifying, and querying the assignment in a standardized way.

The content of "I/O address" is technology-specific and includes:

  • Unique selector to identify and document the respective data acquisition. For example, TX-I/O or KNX PL-Link.
  • Unique address to identify the peripheral data source. For example, TX-I/O 3.4.
  • Blank until assigned to a Module.

State text

 

 

'State text' specifies the enumeration of the multistate value. Preconfigured enumerations can be selected or set to a project-specific enumeration.

Out of service

 

 

"Out of service" allows decoupling the object from being modified by a control program, system program or peripheral device.

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

Property ID: 81

State flag ✳

 

 

"State flag" represents four boolean flags ("Out of service", "Overridden", "Fault", "In-Alarm") that indicate the general status of an object.

Reliability

 

 

'Reliability' indicates whether the property value 'Present value' is reliable. If the 'Present value' is not reliable, the property 'Reliability' indicates the cause of the fault and the bit "Fault" of the state indication is set to 'True'. In a normal case, the property 'Reliability' is set to "No fault".

Property ID: 103

Tracking value

 

 

'Tracking value' represents the uncorrected value as measured by the subsystem. It has the same data type as the 'Present value'.

  • It is not limited by 'Present minimum value' and 'Present maximum value'.
  • It is not corrected by the correction factor and offset.
  • It is updated, even if "Out of service" = 'True' applies.

Object access level ✳

 

 

"Object access level" defines the instance-specific object access level. "Object access level" is used for generic filtering and processing an object by a client application.

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" indicates whether the object is used or unused. The "Object usage" property can hide or display respective objects and their functionality in a client. For example, room functionality can be marked for flexible room arrangements as used/unused. An object that is marked as unused behaves as if the object does not exist.

Property ID: 4930

Description

 

 

"Description" is a string of printable characters whose content is not restricted.

Object name

 

 

"Object name" represents a name for the object that is unique internetwork-wide. The minimum length of the string is one character. The set of characters used in the "Object name" are restricted to printable characters.

Comment

 

 

A string of printable characters whose content is not restricted.
