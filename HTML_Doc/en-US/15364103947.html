Watch table

A watch table is a table that represents the current value of the signal.

Column

Description

Tag name

Pin name.

Value

Offline value of the pin.

Online value

Online value of the pin.

Comment

Comment field.

Create and configure a watch table

Use the Watch table to monitor pin data.

  1. Go to the Programming editor.
  2. Click or on the toolbar.
    Programming
  3. In the Project tree view, expand the Diagnostic folder.
    Plants navigation view
  4. Double-click Add object.
  5. The Add Diagnostic Object dialog box displays.
  6. In the Type field, select Watch table.
  7. Enter the name for the watch table in the Name field and click OK.
  8. A watch table displays in the second space of the Programming editor.
  9. Drag the pins from the chart to the watch table. The pin name, offline value, and online value displays in a tabular form. Add/update the Comment field to give a description to the pin.
  1. You have created a watch table.

You can add a maximum of 16 watch tables only.

If you are offline, you can see the last used value in the Online value column of the watch table.
