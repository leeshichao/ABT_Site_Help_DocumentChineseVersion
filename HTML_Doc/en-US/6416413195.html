Lighting brightness manager control (LgtCtlMst11)

Overview

The application function "Lighting brightness manager control 11" (LgtCtlMst11 ) calculates the theoretical daylight component of brightness at the window, starting from the brightness sensor measurement in the room. This calculated daylight value is provided to the subordinate lighting control AFs under a manager subordinate configuration.

Function

The daylight component of brightness (LgtDlgtcWnd) is calculated using the brightness sensor measurement and the sensor's mounting distance from the window.

The attenuation of daylight is influenced by the height of the room, window dimensions, colors in the room, and other conditions. Parameter daylight factor (DlgtFac) is used to adapt control: The less daylight decreases in the room, the lower the factor, see diagram below.

The default value is 2.5 (the equivalent of a standard room).

Change DlgtFac, if decrease in daylight deviates from the default curve. Use a lux-meter to measure the characteristics for your room and adapt DlgtFac accordingly.
