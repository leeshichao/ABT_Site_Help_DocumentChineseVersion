[DMUX8_BO] Demultiplexer 1 of 8 boolean values

Function block DMUX8_BO switches the Boolean input to one of the 8 outputs in dependence of a selector.

DMUX8_BO switches the Boolean input to one of the 8 outputs in dependence of a selector.

Functioning

DMUX8_BO switches the input [In] to the output [Out0] ... [Out7] defined by selector [K]. All other outputs are set to default value [DefVal].

If the value of input [K] is smaller than 0 or greater than 7, all outputs [Out0]...[Out7] are set to [DefVal].

Cascading

DMUX8_BO can be cascaded, e.g. to demultiplex 16 outputs. Instead, multiple DMUX8_BO are switched in parallel with the same input value [In]. Selector [K] is adapted by subtraction.

Application

DMUX8_BO normally is used to reset signals interconnected via a multiplexer.

For example, a communication path featuring an integer and Boolean pin only can be used to transmit up to 8 different values in sequence.
