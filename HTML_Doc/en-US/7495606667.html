Central smoke extraction for exhaust air (CenSmextEh11)

Overview

The application function "Central smoke extraction by exhaust air 11" (CenSmextEh11) distributes a request for extract air smoke extraction to the rooms.

Function

As an option to the central HVAC emergency function (CenEmgHvac11), this AF is required if smoke extraction or purge via extract VAV box or extract fan is used.

None.
