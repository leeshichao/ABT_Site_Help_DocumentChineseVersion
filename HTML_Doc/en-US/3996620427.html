QMX3.P36

This section describes room operator units QMX3.P36 for specific applications.

For the description of properties see chapter "KNX PL-Link devices" in the Hardware catalog.

Devices in the library

The devices in the library represent layouts with settings for specific applications. The name of the device in the library refers to its application.

The unit system of the library and the selected Page layout determine the unit for the display of the temperature.

The device names are independent of the unit system of the library. If units are part of the device name, only SI units are used.
