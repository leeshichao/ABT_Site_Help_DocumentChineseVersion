Venturi valve (MCalcVal - subsystem-specific extension)

The Multi-state Calculated Value (MCalcVal) object supports following properties of the subsystem-specific extension Venturi valve.

✳ Indicates a Siemens proprietary property.

Inactive air flow ✳

 

 

"Inactive air flow" characterizes the air flow data sets of the inactive calibration data table.

Inactive valve position ✳

 

 

"Inactive valve position" characterizes the valve position data sets of the inactive calibration data table.

Search attempts ✳

 

 

"Search attempts" allows limiting the number of attempts for searching valve position corresponding to minimum air flow.

Holding time ✳

 

 

"Holding time" defines the time for air flow settling after valve position change.

Measuring period ✳

 

 

"Measuring period" defines the time for measuring the air flow.

Number of valid calibration points ✳

 

 

"Number of valid calibration points" indicates the number of valid pairs in the active table.

Remaining calibration time ✳

 

 

"Remaining calibration time" indicates the estimated calculated time left until the calibration process is expected to be completed.

Calibration error ✳

 

 

"Calibration error" indicates additional information for the valve in case of error.

Air volume flow units (SI) ✳

 

 

"Air volume flow units (SI)" defines the SI units used when displaying airflow values. This field is not active if US units are selected for the overall device (ActiveUnitSet).

m3/h

cubic meters per hour

l/s

liters per second

Active air flow ✳

 

 

"Active air flow" characterizes the air flow data sets of the active calibration data table.

Active valve position ✳

 

 

"Active valve position" characterizes the valve position data sets of the active calibration data table.
