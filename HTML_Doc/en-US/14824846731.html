[CYCLEGEN] Cycle pulse generator

Function block CYCLEGEN (FB101) generates a cycle with adjustable pulse and pause length.

CYCLEGEN (FB101) generates a cycle with adjustable pulse and pause length.

Functioning

Time-related process

Time-related process of the output signal [Out] in general and upon reset.

Key

1.

Pulse length [TiOn]

2.

Pause length [TiOff]

Reset

  • If the input value [Reset] = 1, all times are reset and [Out] = 0 is switched.
  • If the input value [Reset] changes from 1 to 0, pause time resumes.

Application

CYCLEGEN is used to generate pulses that repeat regularly. This is true e.g. for blinking lights or when switching on a pump every 24 hours for 1 minute.

Process response

After startup, CYCLEGEN starts in the start phase.
