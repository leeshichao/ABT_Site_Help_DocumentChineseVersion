Lighting operating strategy (LgtOpStrgy11)

Overview

The application function "Lighting operating strategy 11" (LgtOpStrgy11) controls the lighting operating strategy for automatic mode based on the room operating mode.

Function

The operating strategy (LgtOpStrgy) supports the following values:

  • Energy efficiency: In automatic mode the lights are set to reduced consumption of electrical energy.
  • Comfort optimization: In automatic mode the lights are set to visual comfort.

The strategy can be configured for each room operating mode.


Output
The response (LgtOpStrgy) is distributed via grouping to the lighting applications (Lgt11) in the room segments.
A BACnet client can also operate the response to a presence detector.
