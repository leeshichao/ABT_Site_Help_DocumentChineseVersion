Application selection

The Application selection task contains all application types and application templates available in the project and in the library.

Only types and templates for the selected engineering unit are displayed. You can change the engineering unit of a project in Settings > Localization> Engineering unit.

② Toolbar

Command

Description

Open template

Opens Configuration > Application configuration where you can reconfigure the selected application template.
Changing application parameters

A project template must be selected to activate the command.

Note

In case of changing an already downloaded template: All configured and commissioned data in the online system are overwritten. To prevent data loss, read back the online system data to ABT Site before making offline changes in the template.

Add template to project

Opens a dialog box to create a new application template. A template or type and device type must be selected.
Adding project-specific application templates

Import application type

Opens a dialog box to import project-specific application types (e.g. *.s1ca file from ABT Pro).
Importing project-specific types

Refresh

Refreshes the view.

Application help

Opens the online help for the selected application template or application type. The button is only active if a corresponding help is available.

 

③ Source selection tabs

A source selection tab separates available application templates and application types from the current project or installed libraries.

Tab

Description

Templates in project

Displays all application templates for this project (project data).

Templates in library

Displays all application templates from the installed HQ and RC libraries.

Types in library

Displays only application types from the installed HQ and RC libraries.
Installing HQ or RC libraries

Application types are delivered with the application library. Application templates are fully configured application types.

④ Application selection table

The Application selection table lists all available application templates and application types for the selected tab. Selecting a row updates the Device type selection table.
