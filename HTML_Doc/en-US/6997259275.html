Central operating mode delay (CenOpModDly11...13)

Overview

Application function "Central operating mode delay 11...13" (CenOpModDly11...13) distributes the central operating mode along with teh related data with a time delay to distribute the electrical startup load (HVAC plants, blinds, lighting) to multiple, phased startup groups when changing the operating mode for an entire group.

Delayed distribution comprises all elements of grouping "Central operating mode", i.e. all outputs of AF CenOpMod11 and the included AFs CenOssc11, CenOpModExtd11, CenROpDstr01.

The delayed AFs are used to distribute tot he rooms, but cannot be used for distribution to subordinate AFs CenOpModDly11...13.

Function

The first start-up group (CenOpMod11) starts up immediately upon change in operating mode. The start groups for central operating mode delay 11 to 13 (CenOpModDly11...13) have an adjustable delay time and start as soon the delay expires.

Hierarchical grouping

This AF supports hierarchical grouping. For detailed information, see Hierarchical grouping.


Interface to local and superordinate functions

There are no additional BACnet objects for delayed distribution. The subordinate AFs CenOpModDly11...13 receive their input via internal communication from the AFs CenOssc11, CenOpModExtd11, CenROpDstr01 contained in the superordinate AF CenOpModDly11...13.

Engineering and commissioning

The AFs receive the values (Chart interface) from CenOpMod11. Each change is saved in a buffer. The AFs read back the values from the buffer after the delay time expires and decodes and distributes them to the connected group members.
