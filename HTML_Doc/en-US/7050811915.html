Downloading device configurations

You can configure and download devices in two ways. You can either map engineered devices with discovered devices or map the devices directly to the engineered devices that have been configured with a serial number.

Each load process is a full load process. All configured and commissioned data in the online system are overwritten. Consider, any timers and priority array settings are reset and all manual actions via push button (Prio 7 and Prio 13) are lost. To prevent data loss, read back the online system data to ABT Site before making offline changes in the template. In order to read back data, always select the option merge online data.

Mind that the merge function is object based and not parameter based. To be sure that offline changes are not overwritten, always make a full upload before making offline changes to a device.

For U.S. only, NGAA supports downloading signed licenses from ABT Site to devices.

Download the complete configuration to the device before performing an online import of devices to Desigo CC. Changes issued with a delta load are not imported automatically.

When multiple devices are selected for download and/or upload, one or more devices may fail to load due to network conditions, such as excessive network traffic. In these cases, select the devices that failed to load and repeat the download/upload command.

Configure and load discovered devices
  1. A USB or Ethernet connection is established.
    If connected through the room unit, the connection will be dropped. If a connection is needed, wait for the device to restart, and re-establish the connection.
    Connecting to devices
  1. Go to Startup.
    Configure and download
  2. Open the Configure and download task.
  3. In the Discovered devices tab, click Discover and select a Discovery filter from the list box.
  4. Click OK.
  5. The discovered devices display in the table.
  6. Select the engineered device and the discovered device.
  7. Click Assign.
  8. Click Load > Application configuration.
  1. The application configuration is downloaded and the device is restarted.
Configure and load devices by serial number

The serial number can be pre-engineered, entered manually, or by using a barcode scanner. It can be entered in the Serial number field of the Engineered devices tab.

Adding the serial number

  1. A USB or Ethernet connection is established.
    If connected through the room unit, the connection will be dropped. If a connection is needed, wait for the device to restart, and re-establish the connection.
    Connecting to devices
  1. In the Engineered devices tab, select one or more pre-engineered devices with a serial number.
    INFO: Multi-selection of automation stations is not supported for the device type PXC3. If you select several automation stations, ABT Site will try to open the same ABT Pro project several times in the background, which is impossible.
  2. In the Engineered devices tab toolbar, click Load > Device network configuration.
  3. The devices are configured and restarted.
  4. In the Engineered devices tab toolbar, click Load > Application configuration.
  1. All devices with a matching serial number are loaded and restarted. There is no need to discover and match a discovered device with a pre-engineered device.

Properties for device configuration

The following properties are set with Assign or Load > Device network configuration only:

These properties are not covered with Full load and Play function only.

BACnet properties

  • Device object name
  • Device instance number
  • APDU retries
  • APDU segment timeout
  • APDU timeout
  • Max APDU length

IP properties

  • Host name
  • UDP port
  • Web access
  • Use DHCP
  • IP Address
  • IP Subnet mask
  • IP Default gateway
  • IP Domain name
  • Local broadcast UDP port
  • Network number (for IP network routing)

MS/TP properties

  • Baud rate
  • Network number
  • MAC address
  • Max manager address
  • Max info frames

Application configuration and default value changes can be loaded over any connection type. The load times will vary based on the connection type. However, the time to load is quite quick (on the order of minutes).
