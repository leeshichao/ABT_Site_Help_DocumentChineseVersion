Number ranges

The Number ranges task allows you to define the number ranges for room IDs, central functions and device instance numbers, and provides an overview of the used and defined number ranges.

Room IDs and central function numbers must be unique within the BACnet system.
Setting group number ranges

You can check the ranges of room IDs, central function and device instance numbers against the defined number ranges in Building > Device list.

② Range settings tab

Allows you to set the limits of the number ranges for group numbers, room IDs and central functions.

Common settings for group numbers

Setting

Description

Group number start

The first group number to be used. Numbers between 1 and 3'999'999'999 are allowed within the BACnet system. Default is 1.

Group number end

The last group number to be used. Numbers between 1 and 3'999'999'999 are allowed within the BACnet system. Default is 100000.

Room IDs

Setting

Description

Number range per template

Define a range per template. Numbers between 1 and 3'999'999'999 are allowed within the BACnet system. Default is 200.

Central functions

Setting

Description

Offset for type based

The first number for tape based central functions. Numbers between 0 and 3'999'999'999 - x are allowed. x is the number of Group number start defined for this project. Default is 1.

Number range per unit

Define a range per template. Numbers between 1 and 3'999'999'999 are allowed. Default is 200.

Common settings for device instance numbers

Setting

Description

Start device instance number

The first device instance number to be used. Numbers between 1 and 4'194'302 are allowed. Default is 1.

End device instance number

The last device instance number to be used. Numbers between 1 and 4'194'302 are allowed. Default is 100000.

Apogee integration

Setting

Description

Show application number

Select to show the Apogee application number within ABT Site. By default the application number is hidden.

Room ID follows device instance

Room IDs are managed by device instance numbers. Use with care, conflicts can be checked in the Device list task.

Common settings for device instance numbers can be set manually. Make sure that the entered values are accurate.

Device instance numbers

Setting

Description

Number range per unit

Define a range per unit. Numbers between 1 and 4'194'302 are allowed. Default is 200.

Manually entering or changing device instance number values and device instance number ranges can result in duplicate device instance numbers, when application templates or ABT Pro projects have already been created. Make sure that the entered values are accurate.

You can check for duplicate device instance numbers in Building > Device list.

③ Room ID overview tab

Lists all available information concerning room IDs in a customer project. For each application template, the first and the last used room ID, and the defined room ID end is listed. The data is read-only.

Setting

Description

Usage

The name of the application template or ABT Pro project.

Room ID start

The first used room ID of the application template or ABT Pro project.

Last used room ID

The last used room ID of the application template or ABT Pro project.

Room ID end

The last usable room ID of the application template or ABT Pro project

Get new range

You can get new ranges for room IDs, group numbers and device instances by clicking Get new range. The system will extend the end number by the number range per unit set in the Range settings tab.

Once you have created devices and used up ID ranges, the system does not release the used ranges after you delete the devices. In case you have used up a range, you need to get a new range in order to be able to add new devices. To get new ranges, open Settings > Number ranges, select the corresponding overview, and click Get new range.

 

④ Central function overview tab

Lists all available information concerning central functions in a customer projects. For each usage, the group category, the first and the last used group number, and the group number end is listed. The data is read-only.

Setting

Description

Usage

The name of the ABT Pro project or type based central function. The same name can be listed several times for multiple group categories.

Group category

The name of a group category e.g. Central weather station. The same category can be listed several times in different application templates or ABT Pro projects.

group no. start

The first used group number of the group category in this application template or ABT Pro project.

Last used group no.

The last used group number of the group category in this application template or ABT Pro project.

Group no. end

The last usable group number of the group category in this application template or ABT Pro project.

 

⑤ Device instance number overview tab

Lists all available information concerning device instance numbers in a customer projects. For each usage, the start number, the end number and the last used device instance number is listed. Device instance numbers of ABT Pro projects are not available. The data is read-only.

Setting

Description

Usage

The name of the application template or ABT Pro project.

Device instance no. start

The first used device instance number of the application template.

Last used device instance no.

The last used device instance number of the application template.
Note
The last used device instance number of ABT Pro projects are not displayed. They are managed by ABT Pro.

End device instance no.

The last usable device instance number of the application template.
