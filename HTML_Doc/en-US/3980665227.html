SWI_2P: On/off switch with adjustable switch-on and switch-off point

The SWI_2P (FB411) block generates a binary output signal after a comparison between the input signal and the switch-on and switch-off point.

Functionality

The block generates the binary output signal [Out] after a comparison between the input signal [In] and the switch-on point [SwiOnPt] and the switch-off point [SwiOffPt].

The relative mutual position of the switch-on point [SwiOnPt] and the switch-off point [SwiOffPt] defines the direction of control action.

The block function can be fully enabled or disabled via pin [EnFnct].

Application

  • In air conditioning and heating to control (disable and enable) components and aggregates.
  • General: Performance of switching functions with known and settable switch-on and switch-off point.

If a setpoint with settable position relative to the switch-on and switch-off point for On/Off switches/On/Off controllers represents a known or adjustable variable, block SWI_2PH (FB432) is to be used.

Process response

The block is processed with the values at the inputs, starting from the first cycle in the process. During start-up, if the value [In] is between the switch-on and switch-off point, the output is set to [Out] = 0 (Off).
