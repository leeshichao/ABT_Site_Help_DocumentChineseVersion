SHD_PAR2: Shading parameter 2, anti-glare protection

Block SHD_PAR2 (FB801) includes a set of parameter values. These parameter values are used in the charts for automating anti-glare applications, e.g. {ShdGlrPrt01}.

Functioning

The block can be parameterized and provide parameter values.
