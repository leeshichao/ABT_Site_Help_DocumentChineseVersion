Uploading report data

Use this procedure to upload data for selected devices.

When multiple devices are selected for download and/or upload, one or more devices may fail to load due to network conditions, such as excessive network traffic. In these cases, select the devices that failed to load and repeat the download/upload command.

Upload report data

  1. Open Startup > Global functions.
  2. Select the Report tab.
  3. Select a report list.
  4. Parameters display as read only by description, units, and value field. The parameter list provides units, range checking, default value, and state text.
  5. Select devices, either individually or by selecting building elements, for reporting.
  6. Click Upload report data.
  1. The data collection request is issued only for the selected devices. When the data is received, a file is created (DeviceName.TagListName) and saved to the Upload Data folder.
