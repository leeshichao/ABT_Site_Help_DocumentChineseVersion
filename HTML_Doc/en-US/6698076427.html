Lighting life cycle (LgtLifeCyc11)

Overview

The application function "Lighting life cycle 11, lifetime phase, operating hours, maintenance" (LgtLifeCyc11) calculates the Operating hours state of the lamp connected to the lighting output (Burn-in phase, Operation phase, Lifetime expired).

If configured, the following functions are supported:

  • Burn-in of fluorescent lamps.
  • Maintenance factor (MntnFac).
  • Adaptation of the lighting power to the illuminance of neighboring lamps.

 

Function Operating hours state

The BACnet object for each lighting output stores the following values:

  • Operating hours ▶ Counter
  • Burn-in operating hours ▶ Information specific to the lamp type
  • Expected operating hours ▶ Information specific to the lamp type
  • Operating hours state (Burn-in phase, Operation phase, Lifetime expired) ▶ Information calculated by the AF.


The AF sets the Operating hours state based on operating hours:

  • Burn-in phase (Operating hours < Burn-in operating hours).
    Certain types of lamps require a burn-in period before achieving optimum operation. Lamps cannot be dimmed during the burn-in period, but rather may only be switched off or on. The AF overrides permissible dimming values (properties) OpMinVal and OpMaxVal using a configured burn-in value BrninMinVal.
  • Operation phase (Burn-in operating hours < Operating hours < Expected operating hours)
    Dimming permissible within configurable limits OpMinVal and OpMaxVal.
  • Lifetime expired (Operating hours > Expected operating hours)
    Lamps must be replaced and the operating hours reset (usually via the management station).

Function Maintenance factor

The AF considers the Maintenance factor (MntnFac) based on the operating hours and expected operating hours. It provides the necessary information to the other involved application functions.

The function is disabled if (MntnFac = 1) or (expected operating hours = 0).

Function Adaptation of illuminance

The AF adapts the power of the lighting output

  • If the illuminance it is too high and glares. (ImncAda < 1)
  • if the illuminance is too low because of the maintenance factor. (ImncAda > 1)

It provides the necessary information to the other involved application functions.

The function is disabled if ImncAda = 1.

Note: The lighting output object forms the basis for service and maintenance information.

Operating hours are saved as a property of the BACnet object for each lighting output. The value is saved for each save cycle on the room automation station, e.g. approximately every 15 minutes. The operating hours counter can be reset online, after changing the lamp. The management station directly accesses the BACnet object to visualize service and maintenance information.

Engineering and commissioning

Disable functionality
Burn-in functionality and lifetime supervision can be disabled by setting burn-in operating hours and/or expected operating hours to 0.


Burn-in
Newly installed fluorescent lamps must be burned in to achieve their maximum brightness and life cycle:

  • T5 fluorescent lamps require a burn-in time of 100 hours.
  • T8 fluorescent lamps require a burn-in time of 20 hours.

Refer to manufacturer data for more detailed information.

The burn-in function ensures that new fluorescent lights are not dimmed during the required burn-in period, either by a control algorithm or manual dimming. Only states Off or BrninMinVal are permitted. BrninMinVal must be configured.

As soon as the hours of operation counter reaches the required number of hours for burn-in, dimming is permitted between limits OpMinVal and OpMaxVal. They must be configured.

Note: S-Mode devices do not support Burn-in.


Operation phase
The operation phase depends on type of light. Whereas halogen bulbs have an average service life of approx. 2,000 hours; LEDs have up to 50,000 hours. This period is referred to as expected operating hours. Refer to manufacturer data for more detailed information.


Operating hours reset
The operating hours must be reset online.

The operating hours are stored with the room automation station's store cycle.


Maintenance factor
The maintenance factor is normally provided by a lighting designer.
It considers

  • the lamp's aging (depends on the operating hours and the number of switching cycles)
  • pollution (depends on the environment and the time since the lamp has been installed)

A normal office environement has a value of 0.67.
