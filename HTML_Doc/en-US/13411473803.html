HVAC actuators extension properties

These devices support following subsystem-specific extensions:

  • Flow pressure measuring properties (AI - subsystem-specific extension)
  • VAV setpoint (AO - subsystem-specific extension)
  • Network-ADA (AO - subsystem-specific extension)
  • Networked valve actuator (AO - subsystem-specific extension)
  • Progress value (AO - subsystem-specific extension)
  • Configure: GxB111.9E/KN (PrphDev - subsystem-specific extension)
  • Pulse width modulation: thermal (AO - subsystem-specific extension)
