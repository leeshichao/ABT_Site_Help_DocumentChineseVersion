DALI rail properties

Room automation stations named PXC3..A support DALI control gears.

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the DALI rail is selected in the Device view tab.

Note
The number of slots on the DALI rail represents the number of allowed devices on the rail.

Network settings

Property

Description

Default value

Update time lighting level

For DALI I/O objects, Update time lighting level defines the time before they query the actual light level and information about the status of the control gear.

For DALI emergency objects, Update time lighting level defines the time before they query the emergency mode, emergency status, failure status, battery charge, lamp emergency time and total lamp operation time.

Range: 1…30 [min]

5

Device check time

Device check time defines the time before the DALI device list queries the actual status of the device, information about the status of the control gear and error information.

Range: 1…30 [min]

5

Test Query Period

Test Query Period defines the time before the DALI emergency objects query the emergency mode, emergency status and failure status while a function or duration test is performed.

A short Test Query Period improves the accuracy of the emergency test timing and the test status information but increases the bus traffic.

Range: 10…120 [s]

30

Notify Limit Error

Notify Limit Error defines if a limit error is notified as reliability error.

A limit error occurs if the values for the minimum or maximum level are inconsistent between the DALI I/O object and the control gear.

enabled: A limit error is notified as reliability error.

disabled: A limit error is not notified as reliability error.

Bus power supply

Property text

Description

Default value

Bus power supply 1)

The internal bus power supply has to be configured using one of the following settings.

: Manual off: Internal bus power supply is permanently off.

: Auto detection depending on connected devices: Internal bus power supply is automatically turned off if no DALI devices are connected to the DALI rail.

Auto detection depending on connected devices

1) If the subsystem-specific extension DALI (FldBusMgmt - subsystem-specific extension) of the BACnet object Field bus management object (FldBusMgmt) is enabled, you have to configure this property in the BACnet objects editor or in Web interface.
