Users tab

Define User name, Password, and other settings for each project user. Each user is assigned to a Role.
Roles tab

NOTICE

Account lockout on the device.

Using the Administrator account to access the QMX7 can lead to an account lockout on the device.

  1. Only use the predefined StandardOperator account to log on to the room operating unit QMX7.
  2. Do not use the Administrator account to log on to the room operating unit QMX7.

① User list

The default user list contains predefined users. You can add and delete users from the user list.

② Settings

You need to be logged in as Administrator to set or change passwords for other users. The Administrator password is set when creating a project.

Adding projects

Setting

Description

User name

Type a user name.

Password

Click Set password if no password has been assigned for the selected user yet.

Click Reset password to change the Administrator password for the project.

Click Change password to enter a new password for a user

Type and confirm the password according to the password policy defined in Settings > User profiles > Common settings.
Common settings tab

If the entered password does not match the password policy, the password is not saved.
Password policy

QMX7 (role Room optrs.): The password for the room operating unit QMX7 must be compatible with the keyboard layout on the device.

Expiration date

If you want to create a temporary user account, type a date for the user account to expire, or select a date using the calendar button .

Operation function

Set the default view for the Operation function.

Auto-logoff delay

Idle time before the system logs out the user automatically. The set time also has an effect in simulation mode. When the time has expired, the simulation mode also stops (settings between 5 to 60 minutes).

Navigation bar timeout

Setting for QMX 7: Idle time before the navigation bar is reactivated, when more than one navigation element is present.

Screensaver timeout

Setting for QMX 7: Idle time before the screen saver is activated.

NOTICE

Weak passwords can be deciphered. As a result system malfunctions or automation stations failures can be set off.

High fixing costs and a loss of reputation.

  1. Use different passwords for different users.
  2. Use strong passwords.

③ Toolbar

Command

Description

Verify profiles

Checks if the user profiles settings are consistent:

  • At least one valid and not expired user must be present.
  • All users must have a valid password.

Add user

Adds a new user to the users list.

Note
To add a user, you must provide an Administrator password.

Delete

Deletes the selected list element.

 

ABT Site comes with a number of predefined users, user roles, and user settings.

Only use the predefined user StandardOperator to log on to the room operating unit QMX7. Do not use the Administrator account to log on to the room operating unit QMX7. Using the Administrator to access the QMX7 can lead to an account lockout on the device.

In older project versions the user StandardOperator corresponds to the user RoomOperation.
