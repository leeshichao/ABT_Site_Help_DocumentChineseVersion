Uploading a device configuration

Use this procedure to upload the device configuration data bundle from a device.

When editing user profiles or adding new users online, it takes at least 1 minute for the changes to take effect.

Wait for 1 minute after editing user profiles or adding new users online before uploading.

 

For U.S. only, NGAA supports uploading signed licenses to device data in ABT Site.

When multiple devices are selected for download and/or upload, one or more devices may fail to load due to network conditions, such as excessive network traffic. In these cases, select the devices that failed to load and repeat the download/upload command.

Read back data
  1. The device is connected.
    Connecting to devices
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select the Discovered devices tab.
  4. Right-click the device and select Upload.
  1. The device runtime instance data is uploaded to the project.
