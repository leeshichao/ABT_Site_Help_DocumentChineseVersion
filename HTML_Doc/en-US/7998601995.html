User designation settings tab

A user designation is made up of individual structure items which are defined in the User designation settings tab.

You can create user designations in Advanced > User designation.
User designation
Creating project-specific user designations

 

You can only import a user designation file (exported from XWP), if the User designation settings table is empty. If you need to import a user designation file, remove the existing structure first.

If you have an XWP project, you must import the user designation from an XWP export file (*.xwpuds). Otherwise you cannot use the user designation in Desigo CC without import errors.

You can update 15 levels of user designation structure.

① User designation settings table

Column

Description

Name

Name of the user designation level.

Description

Description of each user designation level. Not used in the user designation.

Separator

Separator character next to the user designation level. A space as separator is allowed as well.

With separator:
Location'Building'Floor'Wing'Room'Segment

Without separator:
Location Building Floor Wing Room Segment

Mixed:
Location'Building Floor Wing'Room'Segment

INFO: Do not use the characters : and * for Desigo CC. The Alias field in Desigo CC cannot handle these characters.

Min. length

Minimum character length of the user designation level.

Max. length

Maximum character length of the user designation level.

Predefined

Predefined name of the user designation level.

Data point

One specific structure item must be marked as the data point. The data point can be any kind of BACnet object.

 

② Toolbar

Command

Description

Add level

Adds a new user designation level.

Delete

Deletes the selected user designation level.

Up

Shift the selected level one level up.

Down

Shift the selected level one level down.

Remove structure

Deletes the whole structure from the table. This operation cannot be undone.

Import user designation

Opens a file browser where you can select and import a user designation file (*.xwpuds) from a XWP project. The imported file is stored in the ABT Site project and overwrites all user designation definitions in the project.
