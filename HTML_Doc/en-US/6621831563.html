Lighting inputs

This section describes light input objects (LgtIn) for specific applications.

For the description of properties see chapter "TX-I/O modules" in the Hardware catalog.

List of generic I/Os

This list contains the generic light input objects in the library.

Data point

Description

LgtIn_LgtBtn_Dimming_NO

Two light buttons, dimming, normally open

LgtIn_LgtBtn_Switching_NO

Two light buttons, switching, normally open

LgtIn_LgtBtn_Toggle_NO

One light button, toggle, normally open
