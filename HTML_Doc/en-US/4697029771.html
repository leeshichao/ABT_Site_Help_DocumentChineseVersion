CK_COV: Check change of value for 2 MS & 2 Real

Block CK_COV (FB885) checks 2 multistate values and 2 real values for a change of value. The results are pending on the output.

Application: Displays in chart {CenGlrThPrt01} for a change to blinds positioning value.

Functioning

The block compares all input values with their value for the last cycle. For change a value, [PlsCovInd] is set to = 1 (one cycle in length).

The input values are switched directly to the outputs.
