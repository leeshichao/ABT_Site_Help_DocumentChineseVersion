Configuring features (template)

Changes made to a template configuration are applied to all devices associated with this template (existing and future).

Locked templates cannot be configured.

Changing the template configuration will, in most cases, change the object list. Therefore a new application number is required.
Unlocking application templates

For further information on specific application types, click Application help to open the help for the selected application type.

Select on-board I/O's
  1. Go to Configuration.
  2. Open the Application configuration task.
  3. Open the template.
  4. Select the On-board output or On-board input configuration section.
  5. Select an I/O for each feature.
  6. The discipline feature is activated automatically (i.e., the Supply air VAV position Y10; 0...10 V may activate the HVAC feature Supply air VAV 11, external air flow ctr.).
  7. Selecting an I/O locks it for further use (dimmed).
  8. Continue until I/O selection is complete.
  1. On-board I/O's are now selected.
Assign network peripheral devices
  1. Select the KNX PL-Link device configuration section.
  2. Select the network peripheral device.
  3. The corresponding discipline feature is activated automatically (i.e., the Lighting device 1 feature UP 525/03 may activate the Lighting feature Lighting device 1).
  4. Continue until all planned network peripheral devices are assigned.
  1. The network peripheral devices are now assigned.
Configure disciplines and coordination functions
  1. Select a discipline, e.g., Lighting.
  2. Check the activated features against your plans and configure as needed.
  3. Select additional features in the corresponding discipline.
  4. Continue until all disciplines are configured.
  1. The features for this template are configured.
  • Selecting an I/O or network peripheral device automatically activates the corresponding discipline feature.
    Dependencies
  • Releasing an I/O configuration or network peripheral device may deactivate the corresponding feature configuration.
  • Changing a specific feature configuration may change a feature configuration in another tab (as per application type specific rules).
  • Changing a feature configuration after setting default values may delete the corresponding parameter setting (Additional parameters).
