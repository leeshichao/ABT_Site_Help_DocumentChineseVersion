Configure: QMX3.P88 (PrphDev - subsystem-specific extension)

""Configure: QMX3.P88" is a subsystem-specific extension of "Peripheral device" (PrphDev) objects.

✳ Indicates a Siemens proprietary property.

Backlight timeout ✳

 

 

"Backlight timeout" defines the amount of time that the backlight stays on after an operation. If there is no activity for the defined amount of time, the backlight turns off.

Range: 00:03...120:00 mm:ss

Backlight brightness ✳

 

 

"Backlight brightness" defines the brightness of the backlight during active use.

Range: 0...100 %

Timeout to default page ✳

 

 

"Timeout to default page" defines the amount of time a page displays after a button press. If there is no activity for the defined amount of time, the screen switches to the default page.

Units: mm:ss

Range: 3 through 300

Timeout user operation ✳

 

 

"Timeout user operation" defines the amount of time a page displays after a button press. If there is no activity for the defined amount of time, the screen switches to the default page.

Units: 1/10 of a second

Range: 2 through 100, default 30 (3 sec.)

Alarm display time ✳

 

 

"Alarm display time" defines the alternation period that the display will switch between an alarm icon and the fume hood mode.

If this parameter is set to 0, the display does not alternate between the alarm icon and the fume hood mode. In this case, the user must press the i-Button to view an alarm.

Units: 1/10 of a second

Range: 5 through 3600, default 100 (10 sec.)

Setpoint display time ✳

 

 

"Setpoint display time" defines the amount of time that the setpoint value displays. After the display time has elapsed, an average value displays.

Units: 1/10 of a second

Range: 5 through 3600, default 100 (10 sec.)

Air volume flow units (SI) ✳

 

 

"Air volume flow units (SI)" defines the SI units used when displaying airflow values. This field is not active if US units are selected for the overall device (ActiveUnitSet).

Enable pushbutton, mode manual ✳

 

 

"Enable pushbutton, mode manual" defines:

Yes

Enables Key_1 (hand button) to be used to override a scheduled occupancy change.

No

Key_1 (hand button) has no function.

Enable fume hood integrated light ✳

 

 

"Enable fume hood integrated light" defines:

Yes

Enables Key_4 to be used as a light switch. The 'light bulb' icon appears next to Key_4.

No

Key_4 has no function. The 'light bulb' icon is not displayed next to Key_4.

Enable operation: Green leaf ✳

 

 

"Enable operation: Green leaf" defines if the "Green leaf" LED indicates if the conditions for the energy efficiency state are fulfilled and if the user can reset the application to energy efficient parameter values.

Yes

The "Green leaf" LED indicates if the conditions for the energy efficiency state are fulfilled and the user can reset the application to energy efficient parameter values.

No

The "Green leaf" LED does not indicate if the conditions for the energy efficiency state are fulfilled and the user cannot reset the application to energy efficient parameter values.

No
