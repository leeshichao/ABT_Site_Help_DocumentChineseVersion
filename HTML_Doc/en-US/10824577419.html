KNX PL-Link: FSA (APrcVal - subsystem-specific extension)

The Analog Process Value (APrcVal) object supports following properties of the subsystem-specific extension KNX PL-Link: FSA.

✳ Indicates a Siemens proprietary property.

Number of fan speeds ✳

 

 

"Number of fan speeds" defines the type of speed control of the connected fan.

1-stage

Staged speed control with 1 stage

2-stages

Staged speed control with 2 stages

3-stages

Staged speed control with 3 stages

Variable fan speed

Variable speed control

Rapid ventilation ✳

 

 

"Rapid ventilation" defines if the user can start rapid ventilation.

On

The user can start rapid ventilation.

Off

The user cannot start rapid ventilation.
