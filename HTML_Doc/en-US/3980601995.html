SELMS_4V: Multistate selector for four values

The SELM_4V (FC443) blocks switches multistate inputs to the outputs in dependence of a selector and a corresponding input selector condition. The multiple inputs have two multistate values and two real values available.

Functionality

The block switches that input [In0xx]-[In7xx] whose selector condition [KCnd0]-[KCnd7] matches selector [K] to output [Outxx]. If there is no match, 'default value' [Defxx] is output at outputs [Outxx].

If several input selector conditions [KCnd0]...[KCnd7] are the same and selector [K] corresponds to a condition, input [In0xx]-[In7xx] of the lowest selector condition [KCnd0xx]-[KCnd7xx] is switched to output [Outxx].
