What are function blocks and nested charts?

Function blocks assume a specific function within the plant.

Function blocks can be sub-divided by complexity into the following groups:

  • Function blocks for simple instructions, e.g., logical operations such as AND and OR.
  • Function blocks for more detailed instructions. The function blocks have internal logic and calculate the corresponding output signals based on the input signals.
  • Function blocks with a link to a BACnet object. The function blocks have internal logic and calculate the corresponding output signals based on the input signals. They also communicate their signals over BACnet.
  • Nested charts. The function blocks have internal logic and calculate the corresponding output signals based on the input signals. Additional settings can be edited within the block.

Function blocks can be dragged from the library to the workspace.

Function blocks are available in the library for all common functions on an HVAC plant.

Nested charts are not included in the function block library, but can be copied from existing plant examples.
