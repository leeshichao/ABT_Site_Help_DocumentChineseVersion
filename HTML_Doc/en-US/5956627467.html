Power return mode

Power return mode defines the behavior of the actuator when power returns after a power failure or when the application is restarted.

up: The actuator moves the blind up.

down: The actuator moves the blind down.

no change: The actuator returns to the state before the power failed.

value according additional parameter PowerReturnValue: The actuator is set to the value defined in PowerReturnValue.

stop: The actuator is stopped.

no change

Power failure mode

Power failure mode defines the behavior of the actuator if the power fails.

up: The actuator moves the blind up.

down: The actuator moves the blind down.

no change: The actuator keeps the current state.

stop: The actuator is stopped.

no change

Enable blinds mode

Enable blinds mode defines if the actuator functions as a blinds actuator or as a shutter actuator.

: Actuator functions as blinds actuator.

: Actuator functions as shutter actuator. The actuator interprets a step command as a stop command.

: Actuator functions as blinds actuator.

End position dead time

End position dead time defines the time before the state of the end position switch is read after the blind has left the end position.

The delay is needed because the end position switch does not close immediately when the blind leaves the end position.

Range: 500...5000 [ms]

500

Slat position at end position down

Slat position at end position down defines the angle of the slats at the lower end position if the blind moved without interruption from the upper to the lower end position.

Range: 0...100 [%]

0: slats are completely opened.

100: slats are completely closed.

100

Range: 1...16

6

Predefined positions1)

Values for the predefined positions P0 through P4 are configured using the positioning table.

Each position is defined by 2 values:

  • HeightPos: Blind position, range 0 – 100 [%]
  • SlatPos: Slat angle, range 0 – 100 [%]

P0: Closed:
Normal lower end position, slats closed. HeightPos: 100 %, SlatPos: 100 %.

P1: Visual protection
Slats are in a position that protects the privacy of people in the room, but still allows as much light into the room as possible.
HeightPos: 100 %, SlatPos: variable

P2: Anti-glare, sun position low
Slats are in the shading position for low altitude of the sun.
HeightPos: 100 %, SlatPos: variable

P3: Anti-glare, sun position high
Slats are in the shading position for high altitude of the sun.
HeightPos: 100 %, SlatPos: variable

P4: Open
Slats are in the position that constricts the view trough the blinds as little as possible.
HeightPos: 100 %, SlatPos: variable

100
