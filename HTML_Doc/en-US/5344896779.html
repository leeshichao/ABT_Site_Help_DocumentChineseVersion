Accessories properties

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the device with KNX PL-Link is selected in the Device view tab.

General and Catalog information

The General and Catalog Information group provides information about the device.

Property

Description

Default value

Name

Name is a text field to enter the name of the device. The name is used to identify the device in the device view.

Depends on other settings.

Comment

Comment is a free text field to enter any helpful information on the device.

-

Power supply

Power supply shows the output current of the power supply.

Unit: [mA]

The value is used to calculate the remaining power of the KNX rail.

See also power consumption and supply on KNX rail of PXC3 or KNX rail of DXR2.

Depends on the device type.

Short designation

Short designation shows a short description of the designation of the device. Read only.

Depends on the device type.

Order number

Order number shows the order number of the device. Read only

Depends on the device type.

Version

Version shows an internal version of the device. Read only.

-

Description

Description shows a short description of the device. Read only.

Depends on the device type.
