Component selector with common tools

The component selector is a part of the ABT Site user interface that is always visible. The common toolbar contains the component selector on the left and common tools on the right.

① Component selector

The component selector lists all components needed for a certain job.

Some of the components, e.g. Configuration or Web interface, can be started several times with different contexts.

The open instances of a component are displayed in the collapsible task selector on the left.

The following components are only active, if an instance is available. Otherwise, the component names are grayed out. As soon as the first instance of the component is open, the component is active and can be selected.

  • Startup
  • Web interface
  • Configuration
  • Engineering
  • Reports
