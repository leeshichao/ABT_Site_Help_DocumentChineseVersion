Room temperature setpoint determination (SpTR11)

Overview

The application function "Room temperature setpoint determination 11, for HVAC with heating & cooling setpoint for comfort, room temperature setpoint shift" (SpTR11) provides the Comfort heating/cooling setpoints for room temperature controllers.

Function

Input:

  • Absolute setpoint (SpTR) from room operator unit.
  • Setpoint shift (SpTRShft) from room operator unit or from central seasonal compensation (CenSsnCmp11, via grouping).
  • Room temperature (TR, via internal connection).
  • Present operating mode (PrOpMod, from ROpMod11).


Output:

  • The AF overrides the Comfort heating/cooling setpoints (SpHCmf, SpCCmf) in the room temperature controllers, if setpoint shift is commanded by a room operator unit.
    If PrOpMod = Eco or Protection, the setpoint can't be shifted.
  • TR, as well as SpTR or SpTRShft are displayed on a room operator unit.
  • SpTR display:
    • Cooling only: Cooling setpoint is displayed.
    • Heating only: Heating setpoint is displayed.
    • If heating and cooling are available, the displayed value can be selected using parameter SpTRAbsDspy:
      Average value or Present value.


Note: The heating/cooling setpoints for Economy and Protection, as well as the delta heating/cooling setpoints for Pre-comfort are owned by the room temperature controllers and configured there using BACnet Configuration data points.
