Updating firmware of engineered devices

Use this procedure to update the firmware from the library or by browsing to a firmware file. All firmware versions are distributed in the official "Desigo Firmware Library". Download the Desigo Firmware Library to your computer, and set the path to the folder in Project Manager > Settings > Project and paths > Local firmware folder.
Settings

This task supports mass loads. It does not allow firmware and application type loads over a room unit. Checks are performed to ensure that all selected devices are of the same type and to determine file compatibility. Additional language files (text groups) can only be loaded to controllers running non-preloaded applications. The device performs a backup of device instance data (as needed) and restores it after update except for Application type (user must reload configuration).

The RDG2 firmware may only be updated by an authorized Siemens employee. It is not possible to update the firmware via Desigo PXC4/5/7.

 

For operating and monitoring devices, make sure to first upload the device configuration and then update the device before performing a firmware update.

Update firmware from library

  1. Desigo V6 firmware is required. The Discovery and Node Setup Tool (DNT) must be used for Desigo V5 and V5.1 firmware.
  2. Update files (Desigo Firmware Library) are available on the computer.
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select the Engineered devices or Discovered devices tab.
    • In the Engineered devices tab, right-click the building or device to be updated and select Load > Firmware.
    • In the Discovered devices tab, right-click the device to be updated and select Firmware.
  4. Select the Library tab.
  5. Select the device type and the firmware version from the corresponding drop-down list.
  6. (Optional) Click View Release Notes for more information about the selected firmware version.
  7. Click OK.
  1. The device firmware is updated. The update process might take a while. Wait for the device to restart.

Update firmware from file

Please update the device configuration and re-load the device in ABT Site (load in Startup or Play in the editor)! With a firmware update, a clear device no longer needs to be performed for the PXM40.E, PXG3.W100-2 and PXG3.W200-2 devices. The device must also be updated in ABT Site after the update.
The behavior of all devices is the same during a firmware update.

  1. Update files are available on the computer.
  2. Firmware of WAN device must be updated from the LAN port.
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select the Engineered devices or Discovered devices tab.
    • In the Engineered devices tab, right-click the building or device to be updated and select Load > Firmware.
    • In the Discovered devices tab, right-click the device to be updated and select Firmware.
  4. Select the Browse tab.
  5. Click Browse to locate the firmware source files manually.
  6. Select a firmware bundle file (.fmwz) and click Open.
  7. Click OK.
  8. The Firmware update dialog box displays.

    Due to major system changes for a new BACnet revision in the chosen firmware version, the device must be updated in ABT Site after the firmware load has finished.
    Update the device configuration and re-load the device in ABT Site (load in Startup or Play in the editor)!
  9. Click OK.
  1. The device firmware is updated. The update process might take a while. Wait for the device to restart.
  2. A full load is required.
