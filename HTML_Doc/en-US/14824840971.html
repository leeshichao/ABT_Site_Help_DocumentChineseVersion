[SEQ_DIR] Direct sequence linker

Function block SEQ_DIR helps interconnect CTR function blocks in a programmable sequence, i.e., each controller can be assigned to a sequence based on the related input value.

SEQ_DIR helps interconnect CTR function blocks in a programmable sequence, i.e., each controller can be assigned to a sequence based on the related input value. The direct acting function block is used for cooling or dehumidification.

Functioning

Sequential interconnection of CTR function blocks occurs via SEQ_DIR. The sequence is configured via inputs [SeqNr1]...[SeqNr8].

Multiple CTR controllers are interconnected in a sequence (based on load, modulating sequence) for temperature control, humidity control, and eventually other types of control.

A portion of the sequence can be responsible for heating or humidification, the other portion for cooling or dehumidification. Each CTR controller can command a specific plant element, e.g. radiator, heating coil, fan, etc.

In the control program, the CTR controllers for heating or humidification, and those for cooling or dehumidification are grouped to improve understanding and increase flexibility.

  • The sequence for the CTR controllers is determined by a value.
  • To connect SEQ_DIR to SEQ_REV, specific inputs and outputs are reserved.

The following function blocks are used for cooling and heating sequences:

  • Cooling: SEQ_DIR (Direct Sequence Linker)
  • Heating: SEQ_REV (Reverse Sequence Linker)

SEQ_DIR and SEQ_REV are connected via [SeqCnctIn] and [SeqCnctOut].

Application

SEQ_DIR is used to interconnect CTR function blocks to cooling or dehumidification.

Troubleshooting

The following errors may occur related to SEQ_DIR:

  • SeqNr > 0 and is used multiple times.
  • SeqNr > 0 and the related inputs are not connected or the structural elements have default values.
  • SeqNr = 0 and the corresponding inputs are connected.

In the event of error, output [ErrSta] is set to the corresponding vlaue and the function block stops the processing response. All controllers are commanded to stop control.

The new sequence numbers are valid immediately and do not require a restart.
