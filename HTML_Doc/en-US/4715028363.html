CHO_EEI: Changeover of energy efficiency indicator

Block CHO_EEI (FB886) maps a binary value with delay to a multistate value.

Functioning

Block changes [EeiVal] in the following workflow:

  1. If [In] changes, the block waits until [InPrgs] = 0 (False).
  2. Block [TiDly] starts for [InPrgs] = 0 (False).
  3. If [TiDly] is expired, the block maps the input [In] using the following rules to the energy efficiency indicator value [EeiVal]:

IF

THEN

[In] = 1 (True)

[EeiVal] = 2 (Poor)

[In] = 0 (False)

[EeiVal] = 5 (Excellent)
