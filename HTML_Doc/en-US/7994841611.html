MO with Boost function

The following sections show the properties of multistate outputs (MO) with the subsystem-specific extension "Boost function". Multistate outputs with the subsystem-specific extension "Boost function" are not supported in Desigo 5.x.

Channel configuration properties

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point is selected in the Device view tab.

Mapping kind

"Mapping kind" defines how the process value is mapped to the outputs.

1 to n mapping: The mapping table defines one output for each multistate process value.

Up-down mapping: The mapping table defines one or more outputs for each multistate process value. It is possible to have several outputs, but only in a fixed combination.

Binary mapping: The mapping table defines one or more outputs for each multistate process value. It is possible to have several outputs.

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Mapping (table)

Mapping parameters:

  • Active channel number: Number of active channels
  • MO value: Multistate process value mapped to the active channel

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.

Subsystem-specific extension properties

The listed properties are displayed in the BACnet objects editor > Inspector window > Properties > Configuration tab when the data point is selected in the editor table.

✳ Indicates a Siemens proprietary property.

Boost time ✳

 

 

'Boost time' sets the time in 1/10 [s] during which the motor operates at the highest stage at startup before switching back to the desired stage.

Motors on some small fans with stages have too low a torque to operate the fan at the lowest stage. As a consequence, multistage fans can be started at the highest stage and only then switched back to the desired stage.

Property ID: 4969
