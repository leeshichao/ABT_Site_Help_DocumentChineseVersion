Importing project-specific types

Project-specific application types from ABT Pro (*.s1ca-file) can be imported to ABT Site.

The selection of a unit will also restrict the access to libraries of the selected unit. For example, if you have selected HQ SI, you will only see libraries with the SI unit, even if you have imported libraries that use other units.

Import project-specific types

  1. Copy the *.s1ca file to the PC.
  2. Double-click the *.s1ca file.
  3. The types are copied to the default library folder.
  4. Click Refresh.
  1. The types are now available in Configuration > Application selection > Types in library.

HQ or RC libraries are installed using a dedicated setup and are copied to the corresponding library folder.
