Reporting

Use the following workflow to report the status of objects and devices:

Connecting

  1. You have connected via the room unit.
    Connecting directly to a room operator unit
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Set up the connection.
    Connect and disconnect
  3. Click Connect.

Discovering devices

  1. Open Startup > Global functions.
  2. Select the Discovered devices tab.
  3. The locally connected device displays in the Discovered devices table.
  4. Click Discover.
  5. From the Discovery drop-down menu, select All.

Organizing the discovered devices data fields

  1. Scroll to the left.
  2. Select the Tag heading and drag-and-drop it to the right of the Name heading.
  3. Select the Value heading and drag-and-drop it to the right of the Tag heading.
  4. Select the Units heading and drag-and-drop it to the right of the Value heading.

Selecting the command list and parameters

  1. Select the Command tab.
  2. In the Command list, select Air Balancer Commanding List.
  3. Select the checkbox for the desired parameters.

Uploading report data

  1. Select the Report tab
  2. In the Report list, select Air Balancer Reporting List.
  3. From the right side pane, select all three devices.
  4. Click Upload report data.
  1. The log history indicates the status of each parameter uploaded.
    Log viewer and status bar (Log and Jobs)

Generating the balancing report

This task can be performed either online or offline. It can be performed either in Startup > Global functions or Startup > Export.
Global functions
Export

  1. Click Create uploaded data reports.
  2. Select the devices you wish to create a report for.
  3. Click OK.

Viewing/printing/exporting the balancing report

From the report engine you can:

  • View the report
  • Print the report
  • Export the report
