Modifying a calendar entry in an existing calendar manager

  1. The current configuration of the project settings must be uploaded first to avoid losing recent changes.
    Uploading runtime instance data
  1. Go to Building > Building structure.
  2. Select the device where the calendar manager is stored.
  3. Select a calendar entry.
  4. Click Change.
  5. The Modify calendar manager mapping dialog opens.
  6. Modify the data:
    • In the Primary calendar name field.
    • In the Primary calendar device ID field.
    • In the Primary calendar object ID field.
    • In the Subordinate calendar name field.
    • In the Subordinate calendar device ID field.
    • In the Subordinate calendar object ID field.
  7. Click OK.
  1. The modified calendar entries are changed and replaced in the existing calendar manager table.
