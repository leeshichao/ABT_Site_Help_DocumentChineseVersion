Converting projects

Projects created with older tool versions have to be converted. A single conversion can be done directly in Project Manager > Projects.The single conversion of customer projects which are managed by the Branch Office Server (XWP-BOS) is not supported. Please contact your local tool manager to get support for converting the project.

Programming devices are converted on first opening of the device in the Programming editor (right-click and Go to Programming).

Projects based on Pack & Go or Pack & Return data cannot be converted.

Projects containing ABT Pro data can only be converted via batch conversion. The batch conversion utility needs a separate license.

 

Convert a project

  1. The project is marked with the symbol.
  2. The project does not contain ABT Pro project data.
  3. The project is not managed by the Branch Office Server (XWP-BOS).
  1. Double-click the project and click OK.
  2. Enter User name and Password and click OK.
  3. The project is converted. The symbol is no longer displayed.
