Shading operating strategy (ShdOpStrgy11)

Overview

The application function "Shading operating strategy 11" (ShdOpStrgy11) controls the shading operating strategy for automatic mode based on room operating mode.

Function

The operating strategy (ShdOpStrgy) can be configured for each room operating mode. The configuration supports the following values:

  • Energy efficiency: In automatic mode the blinds are set for minimal consumption of thermal energy by controlling solar radiation. This requires central AF CenFcdShd11 with a solar radiation sensor.
  • Anti-glare protection: In automatic mode the blinds are set for maximum use of outside light while avoiding glare.
    This requires central AF CenFcdShd11 with a brightness sensor.
  • Move up: In automatic mode the blinds are raised (move up)
  • Move down: In automatic mode the blinds are lowered (move down).
  • Presence-dependent: In automatic mode, the blinds are controlled for Energy efficiency when absent, and for Anti-glare protection when present. This requires Central AF CenFcdShd11 with a solar radiation sensor and a brightness sensor, and AF ShdPscMod11 with a presence detector.


Output
The resulting shading operating strategy is distributed via grouping to the shading applications (Shd11) in all room segments.

Note: A BACnet client can also operate the shading operation strategy.
