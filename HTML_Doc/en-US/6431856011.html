Setting

Description

Time zone

Defines the project time zone of the project. The default time zone is defined in the ABT Site settings.
Default time zone

Engineering unit

Select the unit system to be used from the drop-down list. The default unit system is International system (SI).

  • International system (SI)
  • US system of units
  • Imperial system of units
  • Canadian system of units

Note

  • All engineering units are listed. The system does not check the selected Engineering unit against the installed application types.
  • Only application types of the selected Engineering unit can be edited. Application types of other unit systems are not displayed in Configuration > Application selection > Types in library.
    Application selection

Reports

Select the default language for generated reports from the drop-down list.

Active system language

Select the default project language from the drop-down list. This is the language in which project data is generated. The project language is automatically set as a runtime language.

Note
The project language can be different from the Application engineering language so that the user can engineer in a language he understands, but generate the data for customers which speak a different language.
The Application engineering language is set in Project Manager > Settings.

Runtime languages

List of languages for download to the devices. English is displayed as fallback for any text which is not available in the text database of a selected language.

The number of languages which can be selected is restricted to 4. The project language is automatically set as a runtime language.

Updating text databases of devices

ABT Pro checks for values in the Runtime languages field and compiles the project in the specified languages. You can set multiple languages.
