Transmit a plant operating mode to CMDSEQ_B

Up to 16 different plant operating modes can be transmitted to function block CMDSEQ_B.

Often, only plant operating modes 1 = 'Off' and 2 = 'On' are needed.
They are normally controlled by input blocks such as a manual switch, software switch, and scheduler.

Other plant operating modes are transmitted as needed using function block ENSEL_MS.

Function block ENSEL_MS receives the signal to trigger the plant operating mode (e.g. from a manual switch) via inputs [En] and [Val] and forwards the desired plant operating mode to function block CMDSEQ_B.

Function block CMDSEQ_B determines which plant components are used in this plant operating mode as well as the switch-on and switch-off sequence.
