Roles tab

Roles define access settings to monitor and to operate the web interface functions of the device.

① Role list

The default role list contains predefined roles. You can add and delete roles from the role list.

The predefined Administrators role is undeletable.

Web interface

Shows whether the view functions in the web interface are active. The check box is changed automatically:

  • It is selected if one of the view functions or installation access is set.
  • Cleared if no view function is set and installation access is set to "No".

Reset: Clears the check box and all set view functions, and sets Installation access to "No". Removes access right to the web interface.

  • Application view

Select the items to be displayed in the web interface within the Application view.

  • Device view

Select the items to be displayed in the web interface within the Device view.

  • Generic Viewer
  • Favorites
  • Events
  • Field bus view

Select the items to be displayed in the web interface within the Field bus view.

  • Assigned device view

Select the items to be displayed in the web interface within the Assigned Device view.

  • Installation access

Select whether the user role includes rights install the device. Default is "No".

Enable view all properties

Select whether the user role includes rights to view all properties of a selected item in the web interface.

Room operation access

Select whether the user role includes rights for using Room Unit Touch (RUT).

Configuration operation

Select whether the user role includes rights for configuring the device.

  • Load files: authorization for load configuration
  • Backup files: authorization for backup configuration

BACnet access

Select whether the user role includes access rights to BACnet settings.

Operation access

Select which views of the operation menu the user role has access to.

User profile access

Select whether the user role includes rights to create, update, and delete users.

BACnet data edit

Select whether the user role includes rights to edit view node functions in online mode, for example adding operating and monitoring devices online, or integrating automation stations online.

Automatic logout

Select whether the user role is logged out automatically. Default is "Yes".

Precedent role

Only visible if role-based backup and restore is enabled. Allows you restore a device from a precedent role backup.

③ Toolbar

Command

Description

Verify profiles

Checks if the user profiles settings are consistent:

  • At least one valid and not expired user must be present.
  • All users must have a valid password.

Add role

Adds a new role to the Roles list.

Delete

Deletes the selected list element.
