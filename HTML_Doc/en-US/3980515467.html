MAX8_R: Maximum of 8 real values

The MAX8_R (FC374) block calculates the maximum value of up to 8 valid, real values.

Functionality

The block calculates the maximum value for inputs [In1]...[In8] and issues it at output [Out]. Only unlocked input values are considered. Inputs are unlocked if [EnIn1]...[EnIn8] = 1 (Yes).

The input that presently determines the output value is available in [PrInNr] = 1..8.

Unused inputs [In1]...[In8] are disabled by setting the corresponding parameters [EnIn1]...[EnIn8] = 0 (No).

If all inputs are locked [EnIn1 ]...[ EnIn8] = 0 (No), then [DefVal] is issued.
