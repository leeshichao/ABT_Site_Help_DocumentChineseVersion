Shading local manual operation (ShdLocManOp11)

Overview

The application function "Shading local manual operation 11" (ShdLocManOp11) processes local manual control of blinds and awnings via pushbuttons.

Function

The AF controls the position of one actuator for blinds or awnings by manual intervention on one or more pushbuttons.

The following pushbutton functions are supported on TX-IO / on KNX PL-Link buttons:

Engineering and commissioning

No configuration in the AF itself, but on the I/Os:

  • TX-I/O: The channels for the pushbuttons can be configured to send the required commands to the AF.
  • KNX PL-Link devices: Devices have a predefined functionality for blinds pushbuttons. The device can be selected, but not configured.
  • The AF is required if pushbuttons are used for blinds operation.
  • The AF must be located on the room automation station where the shading actuators are connected. To achieve a short response time we recommend connecting the pushbuttons to the same room automation station, as well.

 

Troubleshooting
Verifying the function of the chart in CFC: The output UpdCount should increment with each pressing of a pushbutton.


Technical hints
The complete chart ShdLocManOp11 is assigned to OB41 for performance. This is necessary to reach a short response time when operating local pushbuttons. The event of pressing a local pushbutton triggers the performance of the chart.

In addition to triggering the chart when pressing a pushbutton, the chart is performed every 20 OB1 cycles.
