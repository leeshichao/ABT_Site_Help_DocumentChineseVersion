BO for DXP2 and DXR2

The following tables show the properties for the channel configuration of binary outputs (BO) with the signal type "BO Relay" and "BO Triac" and "BO Pulse On-Off" without any subsystem-specific extension.

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point is selected in the Device view tab.

BO Relay and BO Triac

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.

BO Pulse On-Off

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Switch-on time

"Switch-on time" defines the duration of the pulse.

Range: 0.1...25.5 [s]

Switch-off time

"Switch-off time" defines the length of the pause between an ON pulse and an OFF pulse.

Range: 0.0...25.5 [s]

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.
