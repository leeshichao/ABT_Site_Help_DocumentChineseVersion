Application configuration

The Application configuration task allows you to configure the selected application template by selecting features and I/O's. A progress bar illustrates the number of data points in use and the actual data point limits.

③ Configuration sections

Each configuration section shows a set of configurable features. The configuration section is divided into three main sections.

  • Configuration sections for on-board I/O's
    Configuration sections like On-board output or On-board input assign an on-board I/O to a feature. The actual assignment is listed in the Assigned I/O table.
  • Configuration sections for network peripheral devices
    The KNX PL-Link device configuration section assigns a networked field device to a feature. The assigned KNX PL-Link devices are listed in the Network peripheral devices table.
  • Configuration sections for discipline and coordination functions
    Configuration sections for discipline functions or coordination functions activate the required project functions. You can subsequently configure specific features (application functions).

⑤ Overview, I/Os and Devices

  • Overview
    Displays a graphical overview of configuration parameters depending on the selection of the feature made in the configuration section. Note that the feature has to be activated to display the corresponding graphic.
    You can select an item in the graphic to show the corresponding configuration parameters underneath the graphic overview.
  • I/Os
    The Assigned I/O's table shows the current assignment of I/O signals to on-board I/O's and the data point limits.
    Assigning I/O's (template)
  • Devices
    The Network field devices table shows the current assignment of features to the networked field devices and the data point limits.

 

⑥ Configuration parameters

Shows the configuration parameters of the feature selected in the Configuration sections (3).
