Moving devices

Rooms and devices can be moved from one building structure to another, or from a special folder such as the Unplaced devices folder into a building structure.

In Settings > Naming defaults > Object names tab, select Move rooms with automation station, if you want to move the corresponding rooms to be moved together with automation stations.
Object names tab

 

Move a room

  1. Select a room.
  2. Drag and drop the room to a building structure.

Move a device

  1. Select a device.
  2. Drag and drop the device to a building structure.

When you move a device from the Unplaced devices folder to a building structure, the device updates the location information automatically, but the device keeps its properties. You might need to change, e.g., the BACnet properties to fit your project.
