SAVE_4V: Save 4 values (2 multistate, 2 real)

The block SAVE_4V (FB433) saves two multistate values and two real values dependent on a control signal.

Inputs

Pin

E

Description

Save

pa

Save.

Boolean

Switch to hold the existing output values.

0 (No)

Default

The block ignores the input value. The block issues the last stored value to the output.

1 (Yes)

The block issues the input value to the output. The block saves (stores) the value.

InMs1

pa

Multistate input 1.

Multistate (Default value = 1).

InMs2

pa

Multistate input 2.

Multistate (Default value = 1).

InR1

pa

Real input 1.

Real (Default value= 0.0)

InR2

pa

Real input 2.

Real (Default value= 0.0)

Outputs

Pin

E

Description

OutMs1

a

Multistate output 1.

Multistate (Default value = 1).

OutMs2

a

Multistate output 2.

Multistate (Default value = 1).

OutR1

a

Real output 1.

Real (Default value= 0.0)

OutR2

a

Real output 2.

Real (Default value= 0.0)

Application

The block is used for continuous calculations such as saving an operating mode, measured value or setpoint.

Process response

The block is processed with the values at the inputs from the second process cycle onward, as the values at the inputs are considered valid only then. The default value is issued during the first process cycle.
