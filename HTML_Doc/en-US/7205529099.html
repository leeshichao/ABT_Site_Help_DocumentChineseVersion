Orientation light (LgtOrnt11)

Overview

The application function "Orientation light 11" (LgtOrnt11) calculates the state of an orientation light depending on the configured functionality and provides it via grouping to the related orientation light outputs.

Function

The AF supports the following indication functions (IndFnct) based on the room operating mode and/or brightness:

  • None: The orientation light is switched off.
  • Room operating mode:
    The orientation light is switched on based on room operating mode. Room operating modes where the light is switched on can be configured (IndOnCnf).
  • Brightness:
    The orientation light is switched on if brightness is less than the switch-on point (SwiOnPt); it switches off if brightness is greater than the switch-off point (SwiOnPt + HysBrgt).
  • Room operating mode & brightness: Both descriptions above.
