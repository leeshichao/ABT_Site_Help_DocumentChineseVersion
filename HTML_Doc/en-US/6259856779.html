Manually configuring devices

Use this procedure to manually configure automation stations.

Manually configure devices

  1. Connect a device.
    Connecting to devices
  2. Open the Startup > Configure and download task.
  3. In the Discovered devices tab, click Discover.
  4. Select All or Unconfigured in the Discovery list and click OK.
  5. Select the DXR2 device to be configured.
  6. Select Manually configure in the context menu (or Ctrl-M).
  7. The Manually configure dialog box opens.
  8. Complete the configuration details and click Configure.
  9. The configuration is applied to the device and the Message column in the Discovered devices editor is updated.
  10. Select Go to web interface.
    Web interface
  11. Select and activate the Application type.
  12. Configure the parameters (temperature setpoints, flow setpoints, etc.).

Not all devices support manual configuration.
