Assigning I/O's (areas)

You can change I/O assignments of rooms in Building > Building structure > Room and segment details > I/O assignment.

Assign I/O's of a type-based automation station

  1. Areas (rooms, room segments) are defined in the type-based automation station.
  2. The room view is activated, i.e., Show rooms .
  1. Select the room.
  2. In the Details pane, select the I/O assignment tab.
  3. Click Custom.
  4. The available buttons are displayed on the left, and the button collections on the right.
  5. Select the button on the left, e.g. Brightness (Brgt).
  6. Select the corresponding button collection on the right, e.g. Collection of lighting brightness (LgtBrgtCol).
  7. Click Assign.
  8. The button is assigned to the button collection, and the I/O is assigned. Manual assignments are marked by the icon.
  9. A Remove button is displayed, when an I/O is assigned. The Remove button is located in the Description column of the target table next to assigned I/O.
  10. Repeat steps 4 to 6, until all I/O's are assigned.
  11. Optionally, click Save as template to save the I/O assignment for future use.
  12. If you save the I/O assignment, you can later select it in the Template view.
    Applying saved I/O assignments

Uploading of online assigned I/Os

You can upload the I/O configuration that was assigned online to actuators (e.g. in Desigo CC).

  1. Upload a device configuration.
    Uploading a device configuration
  2. Go to Building tab.
  3. In the Details pane, select the I/O assignment tab.
  4. Online assigned I/Os are indicated by the device ID and object ID.
  5. Uploaded and online assigned I/Os are marked by the icon.
