User profiles

ABT Site comes with a number of predefined users, user roles, and user settings.

Only use the predefined user StandardOperator to log on to the room operating unit QMX7. Do not use the Administrator account to log on to the room operating unit QMX7. Using the Administrator to access the QMX7 can lead to an account lockout on the device.

In older project versions the user StandardOperator corresponds to the user RoomOperation.
Only use following characters for the user name and password on the QMX7:
