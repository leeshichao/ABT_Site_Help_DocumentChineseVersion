② Project table

If the Show recently used projects option is activated, there are 2 tabs displayed, the Recent projects tab and the All projects tab.

Activating the Show recently used projects option increases performance if there is a large number of products in your folder.
Settings

The Pack & Go tab is only visible if there is a Pack & Go package.

There are 3 ways to remove projects from the Recent projects list:

  • Select Remove from the context menu
  • Click the x icon beside the list item
  • Press the [Del] key

The projects are not deleted, they are only removed from the list.

③ Context menu

Command

Description

Edit

Highlights the selected element for renaming.

Open

Opens the selected project.

Go to data location

Opens the directory where the selected item is stored.

Duplicate project structure

Duplicates the building structure of the project. The following data is accepted:

  • Building hierarchy
  • Central functions
  • Project information
  • User profiles

Note: No automation station or device information is duplicated.
Duplicating project structure

Archive project

Creates an archive of the selected projects.
Archiving projects

The target directory for archives is defined in Project Manager > Settings > Projects and paths.

Restoring projects

Add project

Adds a new ABT Site project.

Add folder

Adds a new folder.

Delete

Deletes the selected project or folder.

Create Pack & Return

Only for Pack & Go packages. Displays the Create Pack & Return dialog box. Allows you to specify a work package name. Upon completion a message box displays with the file name and the option to open the folder it was created in.

④ Toolbar

Command

Description

Open project

Opens the selected project. Projects are password-protected. You have to enter user name and password first.

Projects created with older tool versions have to be converted, these projects are indicated with a symbol.
Converting projects

Add project

Opens a dialog box to add a new ABT Site project.

Enter and confirm a password. The password will be used as Administrator password in your project.
Users tab

Select Root folder to add a new ABT Site project on the top level even if a lower level folder is selected.
Adding projects

Browse project

Select a folder to browse for projects. ABT Site will not only search for projects in the selected folder but also in the subfolders, and list all found projects in the Recent projects tab.

Only available in the Recent projects tab.

Add folder

Opens a dialog box to add a new folder. Select Root folder to add a top level project folder.

Delete

Deletes the selected project or folder.

Import

Opens a dropdown menu with two options to open and import configuration data which can be used in ABT Site.
The following file types are supported:

  • Pack & Go: *.ABTGo
  • Pack & Return: *.ABTReturn
