Shading basic, for integration (ShdBsc11)

Overview

The application function "Shading 11, basic, for integration, for shading and daylight use with venetian blinds or awnings" (ShdBsc11) is used for monitoring and operation of blinds by management systems that do not recognize BACnet blinds output objects (Apogee or 3rd Party systems).

Function

The AF provides an interface with basic information.


Operating
The AF supports writing a blinds output (BlsCmd) via a multistate process value (BlsCmdBsc).

When commanding BlsCmdBsc, the multistate value is converted to height and angle. Height and angle are then commanded by the blinds output object BlsCmd.

BlsCmdBsc supports the standard use cases for operation:

  • ManMod3 (Prio 13) = allow parallel operation in the room (for example with push buttons).
  • ManMod2 (Prio 8) = override all operations except emergency and protection.
  • Release ManMod3 (Prio 13) = set the blinds to automatic mode (Prio 16).
  • Release ManMod2 (Prio 8) = cancel a previous operation in ManMod2.

Setting BlsCmdBsc to 9:Undefined does not carry out any operation on the blinds. This serves as a workaround for clients which are not able to command the same value twice. The user first commands 9:Undefined (which does not move the blinds), and then the requested value.


Monitoring
For monitoring, the AF shows blinds height (BlsHgtBsc), slat angle (SlatAglBsc) and actual priority (BlsPrioBsc).

Configuration

None.
