Flow pressure measuring properties (AI - subsystem-specific extension)

The Analog Input (AI) object supports following properties of the subsystem-specific extension Flow pressure measuring.

✳ Indicates a Siemens proprietary property.

Index, BACnet objects editor > Properties > Configuration

Altitude ✳

 

 

"Altitude" defines the position of the device above sea level.

Range: -50...15000

Units for altitude, over sea level ✳

 

 

"Units for altitude, over sea level" defines the unit for the property "Altitude".
