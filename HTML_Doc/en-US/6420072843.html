HVAC green leaf (HvacGrnLf11)

Overview

The application function "HVAC green leaf 11, energy efficiency" (HvacGrnLf11) determines if manual user operations influence HVAC energy efficiency, and handles return to normal (energy efficient) state after receiving the reset request.

Function

Inputs:
The main inputs for HVAC determining energy efficiency are:

  • Setpoint shift (configurable limit), heating/cooling status (via internal connection).
    The leaf symbol on the room operator unit turns red if the user increases the setpoint while the application is heating (decreases while cooling) by more than a configurable delta (TolMaxSpTRShft).
  • Fan speed operation, fan speed control values (via internal connection).
    The leaf symbol on the room operator unit turns red if the user sets a higher fan speed than is required by the automatic control.


Output:
The AF provides the Energy efficiency indication HVAC (HvacEei) to the room operator unit (via RGrnLf11).
The AF releases manual settings (via internal connection) if a reset request is received from the room operator unit (REeiRst, via RGrnLf11), and the settings are inappropriate for energy efficient HVAC operation.
