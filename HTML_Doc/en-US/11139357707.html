Engineering > Device assignment allows you to open a maximum of 5 tabs (instances) at a time.

Command

Description

Engineering in browser

Only for devices supporting operating and monitoring devices. Opens a new browser window where you can engineer the devices.

Note

  • For Engineering in an external browser, Java runtime environment needs to be installed. We recommend the Adopt Java runtime environment. The Zulu environment from Azul is supported as well.
  • You can change which browser to use for engineering in Project Manager > Settings > User interface > Browser selection.
    Settings

Assign devices

Opens the Integrate devices window where you can select automation stations to be assigned to an operating and monitoring device.
Assigning devices
Note: If central functions are used in the project, a corresponding hierarchy must exist. Without a hierarchy, the devices are not visible in the Integrate devices dialog.
Defining a central functions hierarchy

Show/hide parameter

Opens a dialog box to add or remove parameters to the Default values table.
Show/hide parameter (dialog box)
Configuring default values (template)

Refresh

Checks for changes in the project, for example room or segment name changes, and refreshes the view.

To update an operating and monitoring device after project data changes, click Refresh.

Note
If you unassign and reassign an operating and monitoring device, your unique ID (baUniqueID) changes.
