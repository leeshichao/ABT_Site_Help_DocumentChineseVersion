ABT Site user interface

The ABT Site user interface provides a frame which collects all ABT components (e.g., Building, Startup, etc.) in one window. The frame also provides common functionalities such as Undo, Redo, Help, and a split view of different tasks (e.g., Building structure, Application selection) within the same window.

① Common toolbar

The common toolbar contains a window title and the standard Windows state icons to minimize, resize, maximize and close the window. The window title is built up like this:

SIEMENS - ABT Site - <Project name>

② Component selector with common tools

The following components are only active, if an instance is available. Otherwise, the component names are grayed out. As soon as the first instance of the component is open, the component is active and can be selected.

  • Startup
  • Web interface
  • Configuration
  • Engineering
  • Reports

③ Component toolbar

Each component may contain different tools depending on the tasks.

④ Work area

The outlook of the work area depends on the active task. Work areas that contain tables with columns can be filtered and sorted.
