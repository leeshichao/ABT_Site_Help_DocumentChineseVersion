MS/TP settings

Property text

Description

Default value

Baudrate

Baudrate defines the transmission rate. The baudrate needs to correspond to the baudrate set in ABT Site > Projects > Settings because only devices with the same baudrate can communicate with each other.

Auto: The baudrate of the network is used.

9600…115200

The default value depends on ABT project settings.

MAC address

MAC address defines the MAC address assigned to the automation station. The MAC address needs to be unique within the network.

Auto: The MAC address is assigned automatically during start up.

0...127

0...127

Max. manager

Max. manager defines the highest value that can be assigned as MAC address.

Range: 1...127

127

Max info frames

Max info frames defines the number of frames the automation station sends if it receives a token.

Range: 0...65535

10

BACnet settings

Property text

Description

Default value

Device name

Name is a text field to enter the name of the automation station. The name is displayed in the project tree.

The default value depends on ABT project settings.

Device instance number

Device instance number is assigned automatically but can be changed manually. It has to be unique within the network.

Note: If you change the value manually, there is no check if the number is already used or will be used by automatic assigning within a range.

The default value depends on ABT project settings.

Serial number

The device serial number that is associated with the BA Device object.

Serial number is assigned during installation and commissioning.

∼

UDP port [Hex]
(IP only)

UPD port [Hex] defines the UDP port used for communication in the hexadecimal format. Use the UDP port specified in ABT Site > Projects > Settings.

Only devices with the same UDP port can communicate.

BAC0...BAD4

BAC0

APDU retries

APDU retries defines how many times the automation station tries to send an APDU.

Range: 0...10

3

APDU timeout [mm:ss:ms]

APDU timeout [mm:ss:ms] defines the time before the automation station will resend an APDU if the APDU is not acknowledged by the receiver.

Range: 00:01:000...00:12:000 [min:ss:ms]

00:03:000 (IP)
00:10:000 (MS/TP)

Max APDU length

Max APDU length defines the maximum length of the APDU.

206: BACnet/LonTalk

480: BACnet MS/TP

1024: BACnet/IP, no fragmentation

1476: BACnet/IP

1476: BACnet/IP
480: BACnet MS/TP

Time zone

Defines the time zone assigned to the BACnet device. This value can be changed by using the drop-down menu of time zone choices. Setting the time zone for automation stations

GMT+01:00 Berlin, Rome

(MS/TP only)

Range: 1...65534
