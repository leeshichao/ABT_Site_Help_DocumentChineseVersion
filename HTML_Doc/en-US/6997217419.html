Central precipitation protection (CenPcpPrt11)

Overview

The application function "Central precipitation protection 11" (CenPcpPrt11) handles one precipitation sensor.

Use

Precipitation protection is typically used for

  • Awnings: To protect against the weight of the water and the elements
  • Shading products made of cloth: Protect against the elements
  • Motorized windows: Protect against rain

The products go to a configured, safe position during rain or in the event of a faulty sensor.
Protection is not possible, AF CenFrPrtShd11 cannot be disabled.

Other shading products: The AF serves as well as a component of the frost protection function. The products only react together with rain and outside temperature. Configure the position for precipitation and sensor fault on "None" and enable AF CenFrPrtShd11.


Function

The AF reads the precipitation warning from one central precipitation sensor and attenuates the result with switch on and off delays. The result (PcpDet) is provided for monitoring.

The precipitation warning is automatically reset if the delay has expired, or the warning is manually reset.

A BACnet configuration object is used for manual reset over BACnet.


The AF transfers the following to CenPrtShd11:

  • A configurable blinds setting (CmdLmExc) in the event the limit value is exceeded.
  • A configurable blinds position (CmdSenFlt) in case of a sensor fault (precipitation sensor reports "unreliable").

 

Hierarchical grouping

This AF supports hierarchical grouping. For detailed information, see Hierarchical grouping.


Interface to local and superordinate functions

Local inputs and superordinate AFs access the same BACnet objects. Evaluation by priority. The local protection input has higher priority than the shading command of the superordinate central functions.

Engineering and commissioning

Precipitation sensor selection and configuration is oriented on the application: High sensitivity for skylights or more tolerance for awnings and frost protection.

The standard settings are designed for frost protection.
