Discovery configuration (NwkView - subsystem-specific extension)

 

Discovery scope ✳

 

 

"Discovery scope" specifies the network’s scope for the device-discovery process.

Range: local-network, remote-network

Default: local-network

Network number ✳

 

 

"Network number" indicates the BACnet network number associated with this network.

0

The number is not known or cannot be determined. Default value

0..65534

Value range

Max. device instance number ✳

 

 

"Max. device instance number" specifies the maximum range for the device-discovery process.

Default: 4194302

Min. device instance number ✳

 

 

"Min. device instance number" specifies the minimum range for the device-discovery process.

Default: 1

Include 3rd party devices ✳

 

 

"Include 3rd party devices" specifies whether 3rd-Party devices are retrieved in the device-discovery process.

Default: false

Command ✳

 

 

"Command" allows triggering the device-discovery process.

Ready

Ready for a new command, default value

Discover

A discover command 'Who is' will be triggered by the BA-Framework using the current configuration property settings.
