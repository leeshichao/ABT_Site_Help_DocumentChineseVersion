Onboard I/O module properties

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the on-board module is selected in the Device view tab.

General properties

Name

"Name" defines the name of the I/O module.

Comment

"Comment" is a text field to enter any helpful information on the selected object or device.

Address

"Address" defines the bus address of the onboard I/O module. The address is assigned automatically.

Automation station

"Automation station" shows the name of the automation station where the I/O module is positioned. Read only.

Catalog information

Short designation

"Short designation" shows a short description of the designation of the device.

Order number

"Order number" shows the device type. Read only.

Description

"Description" shows a short description of the device. Read-only.
