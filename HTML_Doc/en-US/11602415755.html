Network-ADA (AO - subsystem-specific extension)

The Analog Output (AO) object supports following properties of the subsystem-specific extension Network-ADA.

✳ Indicates a Siemens proprietary property.

Enable angle adaptation ✳

 

 

"Enable angle adaptation" defines how the opening angle is mapped to the 0...100 [%] opening range.

Angle adaptation is needed if VAV boxes with a damper opening range other than 0..90° are used.

No

0..100 [%] is mapped to 0..90°

Yes

The actuator determines the actual opening angle during startup. The actual range (e.g. 15...75°) is then mapped to the 0..100 [%] positioning signal.

Control action

 

 

"Control action" defines the logic for the rise and fall command.

Direct

Normal logic: Is opened for a command from 0 to 100 %.

Reverse

Inverted logic: Is closed for a command from 0 to 100 %. Can be used, for example, to match the valve rotation to the mounting position of the actuator.

Property ID: 4988

Process value 1 and Process value 2 ✳

 

 

"Process value 1" (X1), "Process value 2" (X2), "Output level 1" (Y1) and "Output level 2" (Y2) are used to calculate the linear function (f). The linear function is needed to calculate the output level out of the process value.

Range: -3.40282204661662 E+38...3.40282204661662 E+38 [%]

Output level 1 and Output level 2 ✳

 

 

"Process value 1" (X1), "Process value 2" (X2), "Output level 1" (Y1) and "Output level 2" (Y2) are used to calculate the linear function (f). The linear function is needed to calculate the output level out of the process value.

Range: 0...100 [%]

Progress value

 

 

"Progress value" displays the current valve position. Read only.

Unit: [%]

Property ID: 5083
