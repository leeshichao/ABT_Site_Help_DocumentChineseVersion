Lighting brightness subordinate control (LgtCtlSlv11)

Overview

The application function "Lighting brightness subordinate control 11" (LgtCtlSlv11) calculates the daylight value for subordinate lighting control AFs. It uses the theoretical daylight value calculated by the AF lighting manager (LgtCtlMst11).

Function

The daylight value of the subordinate is calculated using the daylight value calculated by the AF lighting manager (LgtCtlMst11), the mounting distance from the window to the subordinate lamp, and the parameter daylight factor (DlgtFac), see description in LgtCtlMst11. The daylight value is then provided to the lighting control AF.
