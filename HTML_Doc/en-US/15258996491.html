Project tree

Description

State

Device state aggregation

State: Shows the states Program running or Not connected.

Device state aggregation: Aggregates all the states on device level of primary devices, can be used in control program logic.
Note: The device state aggregation is applicable only for primary devices of version 1.5 and above.

<Name of the plant>

Shows the plant and its components.

The icons indicate if a chart is mapped to BACnet and if a chart is locked.

Control program and Plant state aggregation

Plant state aggregation: Aggregates all the states on plant level of primary devices, can be used in control program logic.
Note: The plant state aggregation is applicable only for primary devices of version 1.5 and above.

Control program: Shows the control program with its used chart and subchart names.
