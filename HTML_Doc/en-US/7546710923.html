Installing an ABT project (with subcontracting)

The project is shared by a project owner and a subcontractor (installer). The installation procedure is divided, and data is exchanged between the project owner and the installer.

Prepare and handover working package for installer

1

Open Building > Building structure.

Building structure

2

Create a Pack & Go file.

Creating a Pack & Go file

3

Handover the following data to the installer (subcontractor):

-- Pack & Go files (*.txt, *.ABTGo)

-- User name and password

-- ABT Site installation package
