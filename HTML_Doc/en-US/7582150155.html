UP 255 properties

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the device with KNX PL-Link is selected in the Device view tab.

UP 255

General and Catalog information

The General and Catalog Information group provides information about the device.

Property

Description

Default value

Mode

Mode shows the network mode of the device. Read only.

KNX PL-Link

Name

Name is a text field to enter the name of the device. The name is used to identify the device in the device view.

Comment

Comment is a free text field to enter any helpful information on the device.

Indoor brightness sensor (IBS)

Property

Description

Default value

Heartbeat

Heartbeat defines the time interval to send the value for indoor brightness if the value for indoor brightness did not change or the change was smaller than the value of the COV characteristic. See property COV lux.

Range: 1...32767 [s]

900

Change of value, COV

Change of value, COV is used to calculate the actual COV from the measured indoor brightness. The actual COV and the COV lux are used to calculate the COV characteristic.

Range: 1...100 [%]

Example for Change of value, COV: 1 %

Indoor brightness: 100 [lux] -> actual COV: 1 [lux]

1

COV lux

COV lux defines the lower limit of the COV for sending an update of the indoor brightness. COV lux and Change of value, COV define the COV characteristic. COV lux can be used to avoid frequent updates of the indoor brightness at low light levels because of noise of the sensor.

Range: 1...1000 [lx]

Example of COV characteristic (COVchar.) with Change of value, COV: 1 and COV lux: 5

5

Minimum repetition time

Minimum repetition time defines the minimal time interval before the next value for indoor brightness can be sent.

Range: 2...60 [s]

10

Light switching sensor basic (LSSB)

Property

Description

Default value

Rising edge

Rising edge defines the switching behavior if a rising edge is detected.

Inactive: No message is sent. The light is neither switched on nor switched off.

Switch off: The light is switched off.

Switch on: The light is switched on.

Switchover: If the light is on, it is switched off. If the light is off, it is switched on.

Switchover

Falling edge

Falling edge defines the switching behavior of the pushbutton if a falling edge is detected.

Inactive: No message is sent. The light is neither switched on nor switched off.

Switch off: The light is switched off.

Switch on: The light is switched on.

Switchover: If the light is on, it is switched off. If the light is off, it is switched on.

Inactive

Light dimming sensor basic (LDSB)

Property

Description

Default value

Dimming direction

Dimming direction defines how dimming up and dimming down are assigned to the buttons.

: Left or lower button: dimming up, right or upper button: dimming down.

: Left or lower button: dimming down, right or upper button: dimming up.

: Left or lower button: dimming down, right or upper button: dimming up.

Property

Description

: Left or lower button: moving up, right or upper button: moving down.
