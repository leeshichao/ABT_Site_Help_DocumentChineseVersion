SELT_8MS: Table value selection for 8 MS values

Block SELT_8MS (FB881) provides 8 parameterized Multistate values based on one input value (selector).

Principle of operation

The block is parameterized in the value table containing rows [ValRow1..24] at max. 8 Multistate values to be output [ValOut1..8] each.

At runtime, input value [Row] determines row [ValRow1..24] whose parameterized Multistate values are output to outputs [Out1..8].
