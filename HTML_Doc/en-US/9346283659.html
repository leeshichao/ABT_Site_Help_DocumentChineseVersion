Lighting basic, for integration (LgtBsc11)

Overview

The application function "Lighting 11, basic, for integration " (LgtBsc11) is used for monitoring and operation of lighting by management systems that do not recognize BACnet lighting output objects (Apogee or 3rd Party systems).

Function

The AF provides an interface with basic information.


Operating
The AF supports writing of a lighting output (LgtCmd) via an analog process value. (LgtCmdBsc).

In order to write/release the lighting output with a priority, the analog value is mapped to a target state of the lighting command output object.

Priorities EmgMod1-ManMod2 (Prio 1-8) are mapped to ManMod2 (Prio 8) of the lighting command object. The priorities AutoMod1-AutoMod7 (Prio 9-16) are mapped to ManMod3 (Prio 13) of the lighting command object.

The value -1% is introduced for re-commanding or re-releasing the lighting output. Example: The user commands 50%, writes -1% and then commands 50% again.

Note: For ABT 6.0 and above, it is no longer necessary to command to -1% prior to re-commanding the same value or re-releasing the lighting output. The previous "command to -1" behavior will still work, but the user can now re-command the same value without the intermediate step of commanding to -1%. For example: command 50%, then command 50% again. Because both methods of re-commanding are allowed, applications developed prior to ABT 6.0 are not affected.


Monitoring
The AF provides the present value and priority in the form of an analog and a multistate calculated value object. (LgtStaBsc, LgtPrioBsc).
