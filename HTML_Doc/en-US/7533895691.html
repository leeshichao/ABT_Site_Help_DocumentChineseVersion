Installing HQ or RC libraries

HQ and RC libraries use a dedicated setup for installation. The libraries are copied to the standard library folders (C:\ProgramData\Siemens\Desigo\ABT\Libraries\HQ and ...\RC).

 

Install a HQ or RC library

  1. Double-click setup.exe.
  2. The templates and types are copied to the standard library folders (C:\ProgramData\Siemens\Desigo\ABT\Libraries\HQ and ..\RC).
  3. Existing templates and types remain.
  4. New template and types are added.
  5. Click Refresh.
  1. The templates and types are now available in Configuration > Application selection.

Project-specific application templates and application types from ABT Pro (*.s1ca-file) use a different installation process and are copied to their standard library folder (C:\ProgramData\Siemens\Desigo\ABT\Libraries\ProjectSpecific).
