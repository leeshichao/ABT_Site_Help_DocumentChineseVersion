Creating engineering data reports

Use this procedure to create an engineering data report.

Create an engineering data report

  1. Open Startup > Export.
  2. Select the Engineering data reports tab.
  3. In Work package, select the desired work package.
  4. Select the desired building elements or devices.
  5. Click Create engineering data report.
  6. The Select report dialog box displays.
    Types of reports
  7. Chose either:
    Selected devices (rooms)
    or
    Include all devices from project
  8. Select the type of report desired and click OK.
  1. The report displays in the Reports component.

You may print, copy, export the report, etc.
