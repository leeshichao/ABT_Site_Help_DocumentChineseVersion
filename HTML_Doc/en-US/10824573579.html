Room unit LED (KNX) (LgtIn - subsystem-specific extension)

The Light Input (LgtIn) object supports following properties of the subsystem-specific extension Room unit LED (KNX).

✳ Indicates a Siemens proprietary property.

Room operator unit, LED indication ✳

 

 

"Room operator unit, LED indication" defines when the status LEDs are on.

Always off

The status LEDs are always off.

Lighting on

The status LEDs are on if the light is on.

Lighting off

The status LEDs are on if the light is off.

Manual operation locked

The status LEDs are on if the device is locked for manual operation.

Lighting on, or manual operation locked

The status LEDs are on if the light is on or if the device is locked for manual operation.

Lighting off, or manual operation locked

The status LEDs are on if the light is off or if the device is locked for manual operation.

Room operator unit, manual operation locked ✳

 

 

"Room operator unit, manual operation locked" defines whether the status LED can be used to indicate that the device is locked for manual operation.

Note: Manual configuration is only relevant if the device is used without an application function.

Yes

The status LED can be used to indicate manual operation lock.

No

The status LED cannot be used to indicate manual operation lock.
