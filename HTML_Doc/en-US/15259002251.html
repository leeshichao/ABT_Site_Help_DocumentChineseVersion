Library

The Library contains plants, program blocks, functions blocks, field devices, and a custom library with your own content.
Working with the library

Command

Description

Show all versions

Shows older versions of all elements.

By default, the library shows only the latest version of each element.

Filter

Filters all elements according to your input.

Plants

Shows all plants in the library.

The plant examples are a starting point for creating project-specific plants.

Program blocks

Shows all program blocks in the library.

The program blocks are a proven, standardized solution from the HQ library.

Function blocks

Shows all function blocks in the library.

Field devices

Shows all field devices in the library.

Custom library

Contains elements you dragged or imported into the custom library.
Working with the custom library

User library

Contains content from your local computer.
