CNT_BO: Counter of 8 Boolean values

The CNT_BO (FC408) block has a number of inputs with value 1 (Yes). If the parameterized minimum number is reached or exceeded, a flag is set.

Functionality

The block calculates the number of inputs [In1]...[In8] having value 1 (Yes) and issues it at output [Out].

If the output [Out] reaches or exceeds the parameterized limit [CntValLm], output "Limit reached" [LmRd] is set to 1 (Yes).
