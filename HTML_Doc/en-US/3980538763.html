MUX2_R: Multiplexer 1 of 2 real values

The MUX2_R (FC375) blocks switches one of the 2 real inputs to the output in dependence of a selector.

Functionality

The block switches the inputs [In0], [In1] defined by selector [K] to the output [Out].

If the value of selector [K] is smaller than 0 or greater than 1, the output [Out] is set to 0.
