Defining the BACnet/SC project properties for the root certificate

  1. Go to Settings.
  2. Open the Certificates task.
    Default
  3. Select the Default tab.
  4. Go to BACnet/SC certificates.
  5. Enter the root certificate details for:
    • From the Certificate type drop-down list, select one of the options Internal or External.
    • From the Certificate validity drop-down list, define the certificate validity in months (default is 60 months).
    • From the Expiration warning period drop-down list, define the warning time prior to expiration in days (default is 90 days).
