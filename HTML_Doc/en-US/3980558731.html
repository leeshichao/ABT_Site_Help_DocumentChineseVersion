PRIO_CNV: Priority converter to 4 boolean

The block PRIO_CNV (FC440) converts the incoming integer value to four binary outputs.

The block breaks down the incoming integer value [K] to a maximum of four binary output values.

The block is typically used for evaluating present priority from the BACnet priority range. Freely assignable is, for example,

  • binary output 1 is set via Prio 1 and Prio 2,
  • binary output 2 is set via Prio 4 and Prio 5,
  • binary output 3 is set via Prio 7 and Prio 8,
  • as well as Prio 14 and Prio 16 for binary output 4.
