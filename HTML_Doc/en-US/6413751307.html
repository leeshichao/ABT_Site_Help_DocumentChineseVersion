④ Engineered devices tab

The Engineered devices tab contains information that is similar to the Engineered devices pane in the Configure and download task. It contains all or a subset of engineered devices (placed, unplaced, and unused) based on the work package selected.

Tab toolbar

Command

Description

Select work package

Allows you to select from a list of devices organized by Pack & Go files received or All Devices

Engineered devices table

Column

Description

Authentication

Displays the authentication state.
Entering authentication credentials

Name

Lists the building element or device name. An expander to the left of building elements allows you to view the building structure.

Location

Lists the location of the device.

Equip-ID

Reference to mechanical plans and prints.

Serial number

Lists the serial number of the associated device.
Adding the serial number

Address

Lists the IP address and UDP port for IP devices, or network number and MAC address for MS/TP devices (e.g., 7001-23. Where the network number is 7001 and the MAC address is 23).

Object

Lists the name of the parameter.

Value

The value of the command to be sent to the selected device(s).

Units

Unit of measurement.

⑤ Discovered devices tab

The Discovered devices tab contains information that is similar to the editor table in the Engineered devices tab.

Tab toolbar

Command

Description

Discover

Opens the Discovery dialog box.

You can choose to discover devices in the Local network or the Remote network.

Selecting Locally connected devices displays only connected devices based on the network specified. Default is All devices.

Clear table

Clears the contents of the Discovered devices table.

Context menu

To display the context menu, right-click in a row with a device.

Command

Description

Preview

Performs the command(s) selected in the command editor table. Displays the current value state for all selected parameters below each selected device. You can choose to perform the command values or cancel. This button is enabled when:

  • The command tab is selected
  • At least one parameter is selected
  • At least one device or building element is selected

Release

Returns values to original state. This button is enabled when the Command tab is selected.

Upload report data

Issues read requests to the selected devices based on the parameters contained in the selected tag list. The button is enabled when:

  • The Report tab selected.
  • At least one configured device is selected (objects are ignored in the editor) in either the Engineered devices or Discovered devices tabs.

Create uploaded data reports

Opens a dialog box for the selection of a report type and the devices to be contained in the report. You can create a series of reports that display device status, device instance data, etc., in the Reports component viewing area.

Go to web interface

Opens the web interface of the selected device in the Web interface component window. A device must be configured.
Connecting to the web interface of the device
Note
You can only go to the web interface when the device is configured and reachable as indicated by blue highlighting.

Provide authentication

Opens the Authentication dialog box. You must enter your User name and Password to login to the device.
Entering authentication credentials
