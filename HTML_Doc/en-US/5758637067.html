Emergency lamp properties

The DALI device Emergency lamp has the type number 1.

Maintained emergency luminaires

Short designation

Description

Identification in Web interface

Emergency luminaire

The control gear of a maintained stand-alone emergency luminaire operates the lamp in the emergency mode or the test mode no matter if normal mains is present or not.

The control gear does not support switching on/off and dimming using DALI commands.

Maintained stand-alone emergency luminaires are always on.

EML-C

Emerg.luminaire & dimm.lamp

Maintained dimmable emergency luminaires contain one control gear that always operates the lamp no matter if normal mains is present or not.

The control gear operates the lamp in the emergency mode or the test mode and supports switching on/off and dimming using DALI commands.

EML-A

Emerg.luminaire & swi.lamp

Maintained switchable emergency luminaires contain one control gear that always operates the lamp no matter if normal mains is present or not.

The control gear operates the lamp in the emergency mode or the test mode and supports switching on/off and dimming using DALI commands.

EML-B

Non-maintained emergency luminaires

Short designation

Description

Identification in Web interface

Emergency luminaire

The control gear of a non-maintained stand-alone emergency luminaire operates the lamp in the emergency mode or the test mode only if the normal mains fails.

The control gear does not support switching on/off and dimming using DALI commands.

Non-maintained stand-alone emergency luminaires are only on if the normal mains fails.

EML-D

Comb.emerg.lum.&dimm.lamp

Non-maintained dimmable emergency luminaires contain two control gears.

  • The emergency control gear operates the lamp in the test mode and if the normal mains fails.

EML-D

  • The second control gear operates the lamp if the normal mains is present and supports DALI commands for switching and dimming.

G-FL

Comb.emerg.lum.&swi.lamp

Non-maintained switchable emergency luminaires contain two control gears.

  • The emergency control gear operates the lamp in the test mode and if the normal mains fails.

EML-D

  • The second control gear operates the lamp if the normal mains is present and supports DALI commands for switching.

Power-on level

Power-on level defines the level of light the device goes to after a power-return.

The device reacts to DALI commands 0.5 s after power-on. If no command affecting power level is received within 0.6 s after mains power-on, the device will go to Power-on level immediately without fading.

Range: 0…255

0: light is off.

1: light is on.

254: brightest value

255: keeps the current level of light.

Maximum emergency level

Maximum emergency level defines the highest allowed dimming value of the Control Gear in emergency mode.

Range: 0...255

The value is product specific and defined by the manufacturer of the control gear. The control gear will return 255 as unknown, invalid value, if the setting is not supported.

Minimum emergency level defines the lowest allowed dimming value of the Control Gear in emergency mode.

Range: 0...255
