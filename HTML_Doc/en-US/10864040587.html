Configure: UP 258 (PrphDev - subsystem-specific extension)

The Peripheral Device (PrphDev) object supports following properties of the subsystem-specific extension Configure: UP 258.

✳ Indicates a Siemens proprietary property.

Enable LED state indication ✳

 

 

"Enable LED state indication" defines if the programming mode LED flashes when the sensor detects motion.

Yes

The programming LED flashes briefly if the sensor detects motion.

No

The programming LED is not used to indicate if the sensor detects motion.

[6178.351] ✳

 

 

"[6178.351]" defines the property that configures the sensitivity of PIR sensor.

Auto

The presence detector normally senses in low sensitivity mode which is the idle state until the first movement occurs. After the first movement, the sensing mode changes to high sensitivity. The sensor responds in a highly sensitive manner in accordance with the configured high sensitivity time extension by subsystem.

High

The presence detector responds in a highly sensitive manner to the movements.

Medium

The presence detector responds in a medium sensitive manner to the movements.

Low

The presence detector responds in a low sensitive manner to the movements.

[1025.4758]✳

 

 

"[1025.4758]" defines the property that configures the sensitivity of PIR sensor for a particular duration of time as highly sensitive.
