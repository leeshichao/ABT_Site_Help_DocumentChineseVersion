Three-phase stepper motor (AO - subsystem-specific extension)

The Analog Output (AO) object supports following properties of the subsystem-specific extension Three-phase stepper motor.

Motor direction ✳

 

 

"Motor direction" defines the rotation direction of the motor.

Range: clockwise, counterclockwise

Default: counterclockwise

Maximum speed ✳

 

 

"Maximum speed" defines the Maximum-Speed:
Maximum-Speed >= Motor-Curve-Point-Y-Axis [16]

Range: 0...1000 rpm

Default: 150 rpm

Minimum speed ✳

 

 

"Minimum speed" defines the Minimum-Speed:
Minimum-Speed <= Motor-Curve-Point-Y-Axis [1]

Range: 0...1000 rpm

Default: 0 rpm

Coil maximum current ✳

 

 

"Coil maximum current" defines the limit for the max. allowed coil current.

Range: 0...30000 mA

Default: 5800 mA

Coil frequency base ✳

 

 

"Coil frequency base" allows fine tuning the micro-stepping control.

  • "Coil frequency base" shall be suitable for "Coil impedance".
  • "Coil frequency base" should be higher than 20 kHz (out of human hearing range).

Range: 20...100 kHz

Default: 20 kHz

Coil impedance ✳

 

 

"Coil impedance" defines the coil impedance to be used for the coil current calculation.

Range: 0.01...1000.00 Ω

Default: 0.72 Ω

Stepping mode ✳

 

 

"Stepping mode" defines the basic stepping mode.

Range: full-stepping, half-stepping, micro-stepping

Default: micro-stepping

Stepping angle ✳

 

 

"Stepping angle" defines the stepping angle to be used for the stepping frequency calculation.

Example: switching freq (Hz) = required speed (rpm) * (360 / stepping angle)

Range: 0.1...90.0 degrees

Default: 1.2 degrees

Micro step ✳

 

 

"Micro step" defines the number of elements to be read from the subsystem.

Range: 1/4, 1/8, 1/16, 1/32, 1/64, 1/128, 1/256

Default: 1/32

Acceleration time ✳

 

 

"Acceleration time" defines the time in seconds needed to accelerate from stopped to maximum speed.

Range: 15...60 s

Default: 30 s

Deceleration time ✳

 

 

"Deceleration time" defines the time in sec needed to decelerate from maximum speed to stopped.

Range: 15...60 s

Default: 30 s

Decay mode ✳

 

 

"Decay mode" defines how the controller circuit handles the current flow when the motor coil gets turned off.

Range: fast-decay, slow-decay, mixed-decay

Default: fast-decay

Motor characteristics in % (X-Axis) ✳

 

 

"Motor characteristics in % (X-Axis)" defines the x values of a value pair table representing a curve.

Range: 0...100% rpm

Motor characteristics in rpm (Y-Axis) ✳

 

 

"Motor characteristics in rpm (Y-Axis)" defines the y values of a value pair table representing a curve.

Range: 0...1000 rpm

Motor stuck, retry number ✳

 

 

"Motor stuck, retry number" defines the maximum number of unsuccessful retries to move stuck motor.

Range: 1...10

Default: 3

Motor stuck, retry interval ✳

 

 

"Motor stuck, retry interval" defines the wait time in seconds between two attempts to move stuck motor.

Range: 1...1800 s

Default: 900 s

Motor state ✳

 

 

"Motor state" indicates the status of the motor.

Range: running, stopped, retry, failure

Present speed ✳

 

 

"Present speed" indicates the current speed of the motor.

Range: 0...1000 rpm

Motor operating hours ✳

 

 

"Motor operating hours" indicates the accumulated time in seconds during which the motor was running.
