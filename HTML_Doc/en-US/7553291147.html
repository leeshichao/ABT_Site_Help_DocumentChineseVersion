Modifying template properties

The Template properties dialog box is available in the following tasks when changing an application template:

  • Configuration > Application configuration
  • Configuration > Default values
  • Configuration > I/O assignment

Manually entering or changing device instance number values and device instance number ranges can result in duplicate device instance numbers, when application templates or ABT Pro projects have already been created. Make sure that the entered values are accurate.

You can check for duplicate device instance numbers in Building > Device list.
Checking for duplicate device properties

Modify properties in the Configuration component
  1. A project-specific template exists.
  1. Select the Configuration component.
  2. The component opens with the Application selection task.
  3. Select the Templates in project tab.
  4. All project-specific templates are displayed.
  5. Select a template.
  6. Click Open template.
  7. The Application configuration task opens.
  8. Click Template properties.
  9. Change the template properties as needed.
  10. Click OK.
Modify properties in the Building component

The Name, Description, Room ID start and Room ID end properties can also be modified in the Details pane of an application template.
Application template details

  1. A project-specific template exists.
  1. Go to Building .
  2. Open the Application & device overview task.
  3. Select the template.
  4. Open the Details pane.
  5. Select Naming.
  6. Change the template properties as needed.
