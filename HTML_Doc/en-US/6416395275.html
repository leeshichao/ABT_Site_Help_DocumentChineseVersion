Shading presence operation (ShdPscOp11)

Overview

The application function "Shading presence operation 11" (ShdPscOp11) processes the response to one or more presence detectors.

Function

This AF processes presence detector response for one actuator for blinds or awnings based on the room-wide Shading presence mode (ShdPscMod) which is configured in AF ShdPscMod11.

Engineering and commissioning

  • Configuration: Note that ShdPscMod is configured for the entire room in AF RShdCoo11 > ShdPscMod11.
  • The AF is required if presence detectors are used to operate blinds.
  • ShdPscMod is received from RShdCoo11 via grouping. The group member object RFnct (owned by RSegm) distributes the value to all shading AFs in the segment.


Troubleshooting
Verify the function on the chart in CFC: The output PscDet$ indicates the current presence detector state.
