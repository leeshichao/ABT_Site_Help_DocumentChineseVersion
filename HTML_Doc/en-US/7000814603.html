BA object

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point is selected in the Device view tab.

Name

"Name" shows the name of the data point. Read only.

Description

"Description" is a text field to enter a of the data point.

BA object type

"BA object type" shows the data point type. Read only.

BA object ID

"BA object ID" shows the ID of the data point.

Module/Channel

"Module/Channel" shows the position of the data point on the rail.

Syntax: [module address].[channel number].

Device type

"Device type" defines the signal type.
