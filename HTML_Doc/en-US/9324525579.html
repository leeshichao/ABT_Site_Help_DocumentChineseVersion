Show/hide parameter (dialog box)

The Show/hide parameter dialog box adds or removes parameters from the Default values table.
Configuring default values (template)

 

Upper table

The upper table displays all objects that can be selected for the application template.

Column

Description

Name

Displays all parameters that can be selected for the application template.

Object description

Displays a detailed description of the object.

Add

Adds the selected parameter to the selection list (lower pane).

Remove

Removes the selected parameter from the selection list (lower pane).

 

Lower table

The lower table displays currently selected parameters.

The Avail. on AS column can be filtered by using T or True to show only the checked rows and F or False to show only the unchecked rows.

Filtering table columns

Avail. on AS

If selected, the parameter value is visible and can be changed in ABT Site.

You can only view and change parameter values in ABT Site if the Avail. on AS check box for the selected parameter is selected. The Avail. on AS check box is set in Configuration > Default values.
Configuring default values (template)
If selected, the corresponding object parameters are available in the following areas:

  1. Device details > Instance parameter page
  2. Application template details > Instance parameter tab
  3. Building > Device list > Load instance parameter
  4. Checkout report
