Adding devices

Once the building structure is defined, you can create multiple devices in the building structure.

1

Open Building > Building structure.

Building structure

2

Add devices:

-- Select the location in the building structure where new devices have to be created.

-- Click Add devices.

-- Select the device type and an application template.

-- Define properties (names, network addresses).

Adding devices

3

Modify instance-specific values of each device as needed.

Details pane

4

Check the following values over the whole project:

-- Unique IP address

-- Unique automation station names

-- Unique BACnet device IDs

-- Unique equipment IDs (Equip-ID)

-- Unique Hostname

Checking for duplicate device properties
