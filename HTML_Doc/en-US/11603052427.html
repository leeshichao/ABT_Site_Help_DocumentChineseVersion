OSSC (MCalVal - subsystem-specific extension)

The Multistate calculated value (MCalcVal) object supports following properties of the subsystem-specific extension OSSC.

✳ Indicates a Siemens proprietary property.

Enable adaptation ✳

 

 

"Enable adaptation" allows enabling/disabling start stop time optimization.

Start time for design conditions ✳

 

 

"Start time for design conditions" characterizes the start time at design outside air temperature [TOaDsgn].

Start time for low load conditions ✳

 

 

"Start time for low load conditions" characterizes the start time at low load.

Start time for weekend conditions ✳

 

 

"Start time for weekend conditions" characterizes the start time after a weekend.

Start time if no temperature change ✳

 

 

"Start time if no temperature change" characterizes the start time if there is no temperature difference between setpoint and measured value.

Time constant of room temperature during stop time ✳

 

 

"Time constant of room temperature during stop time" characterizes the time constant of room temperature during stop process.
