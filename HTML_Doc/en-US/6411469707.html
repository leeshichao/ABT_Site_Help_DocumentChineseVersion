② User interface tab

Setting

Description

Tool language

Select the ABT Site tool language from the installed languages. The tool language defines in which language the UI is displayed. A restart is required for the changes to take effect.

UDP port number

Configure the UDP port format used in ABT Site:

  • Show hexadecimal (e.g. 0xBAC0)
  • Show decimal (e.g. 47808)

Show splash screen on start

Deactivate the splash screen on program start, if it causes performance issues.

Show workflow help on start

Select the check box to show the workflow help topic every time ABT Site starts.

Confirm closing projects

Selected check box shows a confirm dialog box when you close the project.

Show recently used projects

You can choose to display an additional tab in the Projects task and the number of recently used projects to be dsplayed.

Activating the Show recently used projects function increases performance if there is a large number of products in your folder.

Note
Not all functions are available in the Recent projects tab.

③ Project and paths tab

Setting

Description

Default project settings

Determines which engineering unit is used for new projects by default. If you select HQ -US, only US application types are available. You can change the used unit system for each project in Settings > Localization.
Localization

  • HQ - SI
    Uses the international system of units
  • HQ - US
    Uses the US system of units
  • HQ - CA
    Uses the CA system of units

Note
The selection of a unit will also restrict the access to libraries of the selected unit. For example, if you have selected HQ SI you will only see libraries with the SI unit, even if you have installed libraries that use other units.

Default time zone

Determines which Default time zone is used for new projects by default. The time zones for the project can be customized if required.
Time zone of the project

Local project folder

Select the directory where projects are saved. The path cannot be entered manually. Click the button next to the field to browse the directory.

Note

ABT Site does not support working with engineering data on shared folders (for example, on networks or cloud services).
Adding projects

Local archive folder

Select the directory where archived projects are saved. The path cannot be entered manually. Click the button next to the field to browse the directory.
Archiving projects

Local firmware folder

Select the directory where firmware versions are saved. The path cannot be entered manually. Click the button next to the field to browse the directory.

All firmware versions are distributed in the official "Desigo Firmware Library".

Work package folder

Select the directory where work package projects are stored after opening the ABT Go file. The path cannot be entered manually. Click the button next to the field to browse the directory.

Use absolute path

Click this option button to define one export path for all projects. Each time you export data the results will be saved in the specified folder.
Click the button next to the field to browse the directory.

Use relative path

Click this option button to save exported data relative to the project folder you are working in. Each time you export data the results will be saved in the folder ...\Exports under the project folder you are working in.
