Default Notification class: 8

 

Operating state for an automation station [AsSta] and a room / room segment [RSta]:

1=Normal
2=Intervention active
3=Fault
4=Alarm
5=Fault & Alarm

Operating state for a bus [FldBusMgmt]:

1=Operational
2=Stopped
3=Initializing
4=Missing or wrong configuration
5=Communication error

Operating state for a device [PrphDev]:

1=Operational
2=Device stopped
3=Device not assigned
4=Device missing
5=Configuring device
6=Device not assignable
7=Missing or wrong configuration

Monitoring the operating state of buses does not include acquiring the operating state of individual devices on the bus. But the device's operating state is monitored indirectly if the reliability of a device's data point is monitored by common alarm "CmnEvtEnr" (i.e. is engineered accordingly).
