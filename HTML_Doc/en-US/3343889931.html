Device object (DevObj)

The Device (DevObj) object type defines a standardized object whose properties represent the externally visible characteristics of a BACnet device. There is only one Device object in each BACnet device. A Device object is referenced by its Object_Identifier property, which is both unique to the BACnet device that maintains this object and unique throughout the BACnet internetwork. The DevObj object properties are:

✳ Indicates a Siemens proprietary property.

"System state" indicates the status of the BA-Device.

Location

 

 

"Location" indicates the physical location of the BACnet device.

Local date

 

 

"Local date" indicates the current local date.

Local time

 

 

"Local time" indicates the current local time.

Time zone ✳

 

 

"Time zone" identifies the time zone assigned to the BACnet device. This value can be changed by using the drop-down menu of time zone choices.

The default value from the factory is: GMT+01:00 Berlin, Rome

Time slot for date and time synchronization ✳

 

 

"Time slot for date and time synchronization" defines the time period in seconds to wait for a time synchronization message after a power failure. If the correct time is available by a RTC after a power failure, the "Time slot for date and time synchronization" property has no effect.

If the controller receives a time synchronization message within the time period set in "Time slot for date and time synchronization", the received date and time will be used as the new date and time.

If the controller does not receive a time synchronization message within the time period set in "Time slot for date and time synchronization", the last saved time and date plus waiting time is used as the new date and time.

Default: 300 sec
Range: 0...7200 sec

Active system language ✳

 

 

"Active system language" indicates the language to be used as system language.

Synchronization request ✳

 

 

"Synchronization request" allows an HMI or configuration tool to specify whether, by default, an alarm server device shall send alert notifications to enrolled event notification clients after notifications are purged from the event cache.

If "Synchronization request" is TRUE, alert notifications are sent to relevant enrolled event notification clients after event cache purge.
Set the property to TRUE, when event notification clients are Siemens devices that support alert notifications.

If "Synchronization request" is FALSE, alert notifications are never issued.
Set the property to FALSE, when event notification clients are third-party devices or Siemens devices that do not support proprietary alert notifications and there is a specific reason not to send the alert notifications e.g. the client crashes on receipt of the notification.

Equipment identifier ✳

 

 

"Equipment identifier" indicates the technical equipment identifier associated to the BACnet-device. The Equipment ID serves as a cross reference between the mechanical equipment and the BACnet device.

The property value is included in the Device info property when a device is discovered by a tool.

Supported system languages ✳

 

 

"Supported system languages" indicates the languages supported by the current active application.

System of units ✳

 

 

"System of units" indicates the engineering unit system used by the current active application.

Object naming convention ✳

 

 

"Object naming convention" indicates the object naming conventions used by the current active application.

Time of device restart

 

 

"Time of device restart" indicates time and date of the last restart of the BA-Device.

Restart notification recipients ✳

 

 

"Restart notification recipients" defines which devices, if any, are notified when a restart occurs. The property contains a list of BACnet devices which receive a restart notification.

If the Restart notification recipients = 0 . no device restart notification is sent.

Daylight saving time status ✳

 

 

"Daylight saving time status" indicates whether daylight savings time is active or not.

Object access level ✳

 

 

"Object access level" defines the instance-specific object access level. "Object access level" is used for generic filtering and processing an object by a client application.

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Timeout for backup ✳

 

 

"Timeout for backup" indicates the maximum time of inactivity in seconds before the BACnet-device being backed up or restored unilaterally ends the backup or restore procedure.

Object list

 

 

"Object list" includes an array of object identifiers of all accessible BA-Objects of the BA-Device.

Structured object list

 

 

"Structured object list" includes an array of object identifiers of BA-View-Node-Objects representing root objects of object hierarchies.

Maximum info frames

 

 

"Maximum info frames" specifies the maximum number of information frames the node may send before it must pass the token.

If this property is modified, the property Changes-Pending will be set to true.

The new value of Max-Info-Frames will be activated when a value of activate is written to the property Command.

Max. number of managers

 

 

"Max. number of managers" specifies the highest possible address for manager nodes. The same information will also be modeled as property of a network port object.

Range: 1..127

If this property is modified, the property Changes-Pending will be set to true.

The new value of Max-Manager will be activated when a value of activate is written to the property Command.

Description

 

 

"Description" is a string of printable characters whose content is not restricted.

Object name

 

 

"Object name" represents a name for the object that is unique internetwork-wide. The minimum length of the string is one character. The set of characters used in the "Object name" are restricted to printable characters.

Comment

 

 

A string of printable characters whose content is not restricted.

Active COV subscriptions

 

 

"Active COV subscriptions" indicates a list active COV Subscriptions that are active at any given time.

  • Whenever a COV Subscription is created with the SubscribeCOV or SubscribeCOVProperty service, a new entry is added to the Active-COV-Subscriptions list.
  • Whenever a COV Subscription is canceled, the corresponding entry will be removed from the Active-COV-Subscriptions list.

APDU segment timeout

 

 

"APDU segment timeout" indicates the amount of time in milliseconds between retransmission of an APDU segment. A suggested value for this property is 5000 milliseconds. This value is non-zero if "Number of APDU retries" is non-zero.

To achieve reliable communication, it is recommended that the values of the "APDU segment timeout" properties of the device objects of all intercommunicating devices should contain the same value.

APDU timeout

 

 

"APDU timeout" indicates the amount of time in milliseconds between retransmissions of an APDU requiring acknowledgment for which no acknowledgment has been received. A suggested value for this property is 10,000 milliseconds for devices that permit modification of this parameter. Otherwise, the default value is 60,000 milliseconds. This value is non-zero if "Number of APDU retries" is non-zero.

Application SW version

 

 

"Application SW version" identifies the version of application software installed in the machine. The content of this string is a local matter, but it could be a date-and-time stamp, a programmer's name, a host file version number, etc.

Access object list ✳

 

 

"Access object list" includes an array 1...7 of object identifiers of BA-Objects. The individual BA-Objects of the BA-Devices will be assigned to the array entries 1...7 according to their individual object access levels.

Available Flash-memory ✳

 

 

"Available Flash-memory" indicates the size of available flash.

Available RAM memory ✳

 

 

"Available RAM memory" indicates the size of available memory.

Backup preparation time

 

 

"Backup preparation time" indicates the amount of time in seconds that the device might remain unresponsive after the sending of a ReinitializeDevice-ACK at the start of a backup procedure.

Building automation profile ✳

 

 

"Building automation profile" is an enumeration that indicates a particular type of Siemens proprietary object. Siemens objects are based on standard BACnet objects. For example, Siemens Analog Input, Analog Output, Analog Calculated Value, and Analog Configuration Value are based on standard Analog Input, Analog Output, and Analog Value BACnet objects.

Configuration files

 

 

"Configuration files" indicates an array of file object identifiers within the BA-Device which defines the file images that can be backed up.

Configuration files (S1) ✳

 

 

"Configuration files (S1)" indicates a list of file object identifiers within the BA-Device.

Configured device address binding ✳

 

 

"Configured device address binding" indicates a list of static address bindings.

  • A value of zero is used for the network-number portion of address entries for other devices residing on the same network as this device.
  • The list is empty if no static device bindings are forseen.

Database revision

 

 

"Database revision" indicates a logical revision number for the database of the BA-Device.

Device address binding

 

 

"Device address binding" indicates a list of address bindings. Entries in the list identify the actual device addresses that will be used when the remote device must be accessed via a BACnet service request.

  • A value of zero is used for the network-number portion of address entries for other devices residing on the same network as this device.
  • The list is empty if no device identifier-device address bindings are currently known to the device.

Engineering load context ✳

 

 

"Engineering load context" identifies the engineering context (e.g. a GUID) of the loaded configuration.

Firmware revision

 

 

"Firmware revision" identifies the firmware installed on the BA-Device.

In use objects list ✳

 

 

"In use objects list" includes a list of all object identifiers of BA-Objects which are currently “in-use”.

Last restore time

 

 

"Last restore time" indicates the time at which the BA-Device was last restored.

Local ping interval ✳

 

 

"Local ping interval" defines the interval in seconds used to test the reachability of a communication host on a local BA-Network.

Range: 10...600 s

Default: 180 s

Max APDU length accepted

 

 

"Max APDU length accepted" indicates the maximum number of octets that can be contained in a single, indivisible application layer protocol data unit. The value of this property is greater than or equal to 50. The value of this property is also constrained by the underlying data link technology.

Max segments accepted

 

 

"Max segments accepted" indicates the maximum number of octets that can be contained in a single, indivisible application layer protocol data unit. The value of this property is greater than or equal to 50. The value of this property is also constrained by the underlying data link technology.

Model information ✳

 

 

"Model information" represents the standardized characteristics of device-related information.

Model name

 

 

"Model name" indicates the model of the BA-Device and defines the role of a particular device type in the system. It includes the controller type and market significant HW-Version, but no additional information such production location, preloaded application group identifier or hardware revision.

Number of APDU retries

 

 

"Number of APDU retries" indicates the maximum number of times that an APDU is retransmitted. If this device does not perform retries, then this property is set to zero. If the value of this property is greater than zero, a non-zero value is placed in the "Device" object "APDU timeout" property.

Object identifier

 

 

"Object identifier" is a numeric code that is used to identify the object. It must be unique internetwork-wide.

Object type

 

 

"Object type " indicates membership in a particular object type class. E.g. "Analog input", "Binary output", "Event enrollment", "Trend log", etc.

Operation URL ✳

 

 

"Operation URL" indicates the Web address of the device. For example: http://192.168.251.1

Profile name

 

 

"Profile name" indicates the name of an object profile to which this object conforms. To ensure uniqueness, a profile name must begin with a vendor identifier code followed by a dash. All subsequent characters are administered by the organization registered with that vendor identifier code. The vendor identifier code that prefixes the profile name indicates the organization that publishes and maintains the profile document named by the remainder of the profile name.

Proprietary device features ✳

 

 

"Proprietary device features" indicates the device features supported by the BA-Device.

Protocol object types supp.

 

 

"Protocol object types supp." indicates the object types services supported by the BA-Device.

Protocol revision

 

 

"Protocol revision" identifies the revision of the BACnet protocol supported by the BA-Device.

Indicates the minor revision level of the BACnet standard. This value shall start at 1 and be incremented for any substantive change(s) to the BACnet standard that affect device communication or behavior. This value will revert to zero upon each change to the "Protocol version" property. Changes to the values for "Protocol version" and "Protocol revision" are recorded in the history of revisions at the end of the BACnet standard.

Protocol services supported

 

 

"Protocol services supported" indicates the protocol services supported by the BA-Device.

Protocol version

 

 

"Protocol version" represents the version of the BACnet protocol supported by this BACnet device. Every major revision of BACnet increases this version number by one. The initial release of BACnet is version 1.

Remote ping interval ✳

 

 

"Remote ping interval" defines the interval in seconds used to test the reachability of a communication host on a remote BA-Network.

Range: 10...600 s

Default: 360 s

Restore completion time

 

 

"Restore completion time" indicates the amount of time in seconds that the device is allowed to remain unresponsive after the sending of a ReinitializeDevice-ACK at the end of a restore procedure.

Restore preparation time

 

 

"Restore preparation time" indicates the amount of time in seconds that the device might remain unresponsive after the sending of a ReinitializeDevice-ACK at the start of a restore procedure.

Segmentation supported

 

 

"Segmentation supported" indicates whether the BA-Device supports segmentation of messages.

Segmentation-Supported = enumeration (segmented-both, segmented-transmit, segmented-receive, no-segmentation)

Serial number ✳

 

 

"Serial number" shows the unique serial number of the device as shipped from the factory.

  • Data acquisition will read "Serial number" from the device and set the respective property value.
  • If "Out of service" is TRUE, "Serial number" will not be setup by the data acquisition.
  • "Serial number" will be modeled as a string because it depends on a particular technology:
    KNX PL-Link (KNX Serial Number) 48-bit,
    DALI (CIN as used by Osram devices) 128 bit
  • "Serial number" can be empty if not available.

Server communication buffer ✳

 

 

"Server communication buffer" is dedicated to central-function/supply-chain capabilities configuration.

This is an optimization property for large systems.

Range: 150, 300, 450, 600

Default: 150

Reason for system state ✳

 

 

"Reason for system state" indicates the reason for a System-Status = non-operational.

UTC (Universal time) offset

 

 

"UTC (Universal time) offset" indicates the number of minutes (-780 to +780) offset between local standard time and Universal Time Coordinated. The time zones to the west of the zero degree meridian are positive values, and those to the east are negative values. The value of the "UTC (Universal time) offset" property is subtracted from the UTC time received in UTC time synchronization service requests to calculate the correct local standard time.

Vendor identifier

 

 

"Vendor identifier" is a unique vendor identification code, assigned by ASHRAE, which is used to distinguish proprietary extensions to the protocol.

Vendor name

 

 

"Vendor name" identifies the manufacturer of the BACnet device.
