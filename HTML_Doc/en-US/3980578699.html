SELBO_2M: Boolean selector for 2 multistate values

The SELBO_2M (FC436) block switches a multistate input pair to an output pair in dependence of a selector.

Functionality

The block switches the input pair [In1at0] and [In2at0] or [In1at1] and [In2at1] to the outputs [Out1] and [Out2] defined by the Boolean selector [K].

If...

then...

K = 0 (No)

Out1 = In1at0

Out2 = In2at0

K = 1 (Yes)

Out1 = In1at1

Out2 = In2at1
