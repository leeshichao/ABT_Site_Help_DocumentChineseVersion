④ Toolbar

Command

Description

Split view

Splits the work area vertically to get two views of the same building, allowing you to move elements from one view to another.

Remove split

Resets the view to one work area.

Go to configuration

Opens Configuration > Application configuration where you can reconfigure the selected application template.

Note
In case of changing an already downloaded template: All configured and commissioned data in the online system are overwritten. To prevent data loss, read back the online system data to ABT Site before making offline changes in the template.

Go to engineering

Opens the Engineering component. Only available for operating and monitoring devices, or bus interface modules.

Note
Default action: Double-click a device to open the Engineering component.
Engineering

Change device

If an existing device type PXC4 or PXC5 is no longer sufficient, it can be changed to a larger device type.

Changing the device type (network or size)

Note

Changing a device type with onboard I/Os requires a new assignment if a device type with I/O modules is used.

Delete

Deletes the selected element and its children.

Check for updates

Compares the used application templates against the installed templates from the library. This check is performed for each application template, based on the application type name, version, and the system of units.
Updating application templates and graphics libraries

Export application template

Opens a dialog box where you can select a folder to save the application template, so you can share it with other projects and users.
When exporting a template, a *.s1ct file is created.
Exporting application templates

Create program

Creates a new project in ABT Pro with the name of the selected application template. Enables the user to reengineer the application template in ABT Pro.

Duplicate application template and go to Programming

Opens the dialog Duplicate application template. Enter the properties of the new application template and click OK to start room programming.
