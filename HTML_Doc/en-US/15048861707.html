What are program blocks?

Program blocks are always nested charts and are self-contained.

Program blocks can be dragged from the library to the workspace.

Program blocks can be adapted to the required functionality by adding or deleting function blocks.

There are program blocks for the following disciplines:

  • Cooling and refrigeration equipment
  • Coordination
  • Heating equipment
  • Heating functions
  • Universal equipment
  • Universal functions
  • Ventilation and air conditioning equipment
  • Ventilation and air conditioning functions
