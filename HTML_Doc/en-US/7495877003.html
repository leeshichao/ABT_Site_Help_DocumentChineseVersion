Supply chain dew point temperature evaluation (SplyTDwpEvl11)

Overview

The application function "Supply chain dewpoint temperature evaluation 11" (SplyTDwpEvl11) can be used to dehumidify at the primary air handling unit to avoid condensation.

Function

The application function collects and evaluates the dew point temperature from the room segments in the supply air group. It also counts the number of active condensation monitors in a chilled ceiling application.

The results of the evaluations can be used at the primary air handling unit to dehumidify, but this must be done in a project (dehumidification is project specific).
