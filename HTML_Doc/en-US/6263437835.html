Units of measure, engineering units

Desigo Room Automation uses the units as defined under the BACnet standard for room applications.

Three identical libraries are supplied with the same functionality, but using different units:

  • The International System of Units SI
  • US system of units
  • Canadian system of units

The library (and with it the system of units) is selected as follows:

  • ABT Site: Engineering Units are a customized setting parameter (Settings > Localization > Engineering units). The user is only provided the application types with the selected system of units.
  • ABT Pro: The ABT Pro project is created from ABT Site and the project receives the fundamental settings, including the system of units. A separate ABT Pro library is available for each system of units. The user needs to use the correct library.
