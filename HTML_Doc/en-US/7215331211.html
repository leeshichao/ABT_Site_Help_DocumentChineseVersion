Creating project-specific user designations

A user designation is made up of individual structure items which are defined in Settings > Naming defaults > User designation settings.
User designation settings tab

A user designation may have a minimum and a maximum character length. Consecutive structure items may be delimited by separators. One specific structure item must be marked as data point. The data point can be any kind of BACnet object. The data point marks the structure item that separates the hierarchy from the data point-specific part. The data point is not necessarily the last item of the user designation defined in Settings > Naming defaults > User designation settings.
User designation settings tab

Always define a data point in the User designation settings. If the data point is not defined, you cannot create user designations in the User designation task.
User designation

 

Create a user designation

  1. In Settings > Naming defaults > User designation settings, click Add level to create the structure items of your user designation.
  2. Select the created structure items and enter the project-specific names.
  3. Click the option button in the Data point column to select which of the structure item will be the data point.
    INFO: Do not use the characters : and * for Desigo CC. The Alias field in Desigo CC cannot handle these characters.
  4. You have defined the project-specific user designation settings.
  5. Go to Advanced > User designation.
  6. In the User designation view, click Add root.
    User designation
  7. Select the created root element and click Add element to add the defined structure items.
  8. Select a device from the Building structure view.
  9. The BACnet objects of the selected device are displayed in the I/Os and devices view.
  10. Drag and drop the BACnet objects to the User designation view on the left.
    INFO: You can assign several BACnet objects provided that the objects are children of the same node.
  11. Click Save.
  1. You have created a project-specific user designation.
