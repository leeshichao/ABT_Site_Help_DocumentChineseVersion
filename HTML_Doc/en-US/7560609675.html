Configuring default values (template)

Parameters and their values can be configured as a default in the application template. Use this editor to make changes to default values for all devices associated with this template within ABT Site.

Configure default values

  1. Select an application template.
  2. Click Building > Application & device overview > Go to configuration or Configuration > Application selection > Open template.
  3. The Application configuration dialog opens.
  4. Select the Default values task.
  5. Click Show/hide parameter to open the dialog box.
    Show/hide parameter (dialog box)
    • Select the parameters in the upper table. Click Add.
    • Select the parameters in the lower table. Click Remove.
  6. Click OK.
  7. The parameters are added to or removed from the Default values table.
  8. Set the access property for each parameter value in the Avail. on AS column.
    : Parameter and value are visible and can be edited in ABT Site.
    : Parameter and value are hidden and fixed as per the Default values table for the application template.

  9. This column can be filtered by using T or True to show only the checked rows and F or False to show only the unchecked rows.

  10. Modify the default values in the Value column.
  1. All new and all previously created automation stations with this template adapt the configured default values.

You can only view and change parameter values in ABT Site if the Avail. on AS check box for the selected parameter is selected. The Avail. on AS check box is set in Configuration > Default values.
Configuring default values (template)
If selected, the corresponding object parameters are available in the following areas:

  1. Device details > Instance parameter page
  2. Application template details > Instance parameter tab
  3. Building > Device list > Load instance parameter
  4. Checkout report
