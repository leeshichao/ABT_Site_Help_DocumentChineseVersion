Lighting presence mode (LgtPscMod11)

Overview

The application function "Lighting presence mode 11" (LgtPscMod11) controls lighting respoonse to a presence detector on room operating mode.

Function

Lighting response to a presence detector (LgtPscMod) can be configured for each operating mode.


The configuration supports the following values:

  • None: The presence detector is ignored.
  • Consider present: The AF reacts to a change from absent to present.
  • Consider absent: The AF reacts to a change from present to absent.
  • Consider present & absent: The AF reacts to a change from absent to present and vice-versa.


Output
The response (LgtPscMod) is distributed via grouping to the lighting applications (Lgt11) in the room segments.

A BACnet client can also operate response to a presence detector.


Usage

Lighting operating modes

LgtOpMod

Description

Typical usage

None

The presence detectors state does not influence lighting.

No automatic function available

Consider present

When the first person enters the room, lighting switches on and remains on.

Public places
Typical configuration when Room operating mode is Comfort. Switching off is done centrally.

Consider absent

When no more persons are in the room, the lighting switches off.
Manual switch-on is possible.

Typical configuration when Room operating mode is NOT Comfort.

Consider present & absent

When a person enters the room, lighting switches on. When no more persons are in the room, the lighting switches off.

Typical configuration when Room operating mode is Comfort.
