CYCLEGEN: Cycle pulse generator

The CYCLEGEN (FB401) block generates a cycle with adjustable pulse and pause length.

Functionality

Time-related process of the output signal [Out] in general and upon reset.

1. = Pulse length TiOn

2. = Pause length TiOff

Reset

The input value is [Reset] = 1 (Yes).

  • Resets all times.
  • Switches [Out] = 0 (Off).

The change of the input value [Reset] from 1 (Yes) to 0 (No).

  • Restarts the switch-off time.

Application

The block is used to generate pulse repeated at regular intervals, for example, for blinking lights, or to turn on a pump for one minute every 24 hours.
