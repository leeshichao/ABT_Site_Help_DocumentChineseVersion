[DW_TIDAY] Conversion double word value to time of day

Function block DW_TIDAY converts an input value of data type Double Word to an output value of data type TimeOfDay.

DW_TIDAY converts an input value of data type Double Word to an output value of data type TimeOfDay. The input value corresponds to the number of milliseconds as of midnight.

Troubleshooting

The output value is set to the highest permissible value 23:59:59.999, if the input value is greater than the highest permissible input value 86399999.
