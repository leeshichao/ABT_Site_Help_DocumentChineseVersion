Shading green leaf (ShdGrnLf11)

Overview

The application function "Shading green leaf 11, impact on shading energy efficiency" (ShdGrnLf11) handles the green leaf functionality for the room segment.

Function

The AF compares the current blinds position in manual mode against the solar radiation condition and the room thermal load to detect situations where energy may be saved if the blinds were in another position. The result is indicated in ShdEei and provided to room coordination (RHvacCooxx > RGrnLf11) for further evaluation.

RGrnLf11 sends a reset request (REeiRst) if a user presses the green leaf button on a room operator unit and the blinds are in an unsuitable position. In this case, the response of the AF depends on parameter SetAutoEmgPrtM, set in AF Shd11:

  • "0" moves the blinds to the automatic position, but leaves them in manual mode 3.
  • "1" releases the manual mode, so that automatic is active.

Configuration

None.
