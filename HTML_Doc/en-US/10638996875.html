Dehumidification control, maximum of deviation heating (DhuCtl12)

Overview

The application function "Dehumidification control 12, maximum of deviation heating for dehumidify" (DhuCtl12) lowers room relative humidity in heat pump applications by overriding the heating/cooling coil valve position for cooling and setting the fan to the correct speed for dehumidification.

Function

The PID controller compares the room relative humidity to the setpoint that corresponds to the active plant mode. The PID-Control mode is set to 2-Pos (Off/Dehumidify) to enable max power to quickly lower the temperature for dehumidification.

In addition, the room temperature is monitored. Dehumidification control is disabled if the room temperature falls below the present heating setpoint minus a configurable differential (Max.deviation heating for dehumidify, HDvnMaxDhu).
