Upgrading alarming

Devices which have been engineered with Desigo V6.0 or V6.1 need to be upgraded in order to use the full alarming functionality. Devices older than Desigo V6.0 do not support alarming.

Following BACnet objects need to be adjusted to use all alarming features in the project.

  • Common Event Enrollment object (CmnEvtEnr)
  • Alarm history object (AlmHistory)
  • Priority of notification classes

 

Upgrade alarming workflow

 

Update application templates
  1. A newer version of the ABT Site library has been installed.
  1. Go to Building.
  2. Open the Application & device overview task.
  3. Click Check for updates.
  4. The system checks for new versions of all application templates and graphics libraries. If a new version is found, Update displays in the Version column of the list.
  5. Click Update for each item you want to update.
  6. A message displays details about the update, e.g. the type version numbers. An info might display telling you that a firmware update is required.
  7. For operating and monitoring devices select Library content update.
  8. Select the new version from the New type version drop-down list.
  9. Click Update.
  1. The application templates or graphics are updated to the selected library version.

Update firmware from library

  1. Desigo V6 firmware is required. The Discovery and Node Setup Tool (DNT) must be used for Desigo V5 and V5.1 firmware.
  2. Update files (Desigo Firmware Library) are available on the computer.
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select the Engineered devices or Discovered devices tab.
    • In the Engineered devices tab, right-click the building or device to be updated and select Load > Firmware.
    • In the Discovered devices tab, right-click the device to be updated and select Firmware.
  4. Select the Library tab.
  5. Select the device type and the firmware version from the corresponding drop-down list.
  6. (Optional) Click View Release Notes for more information about the selected firmware version.
  7. Click OK.
  1. The device firmware is updated. The update process might take a while. Wait for the device to restart.
Configure and load discovered devices
  1. A USB or Ethernet connection is established.
    If connected through the room unit, the connection will be dropped. If a connection is needed, wait for the device to restart, and re-establish the connection.
    Connecting to devices
  1. Go to Startup.
    Configure and download
  2. Open the Configure and download task.
  3. In the Discovered devices tab, click Discover and select a Discovery filter from the list box.
  4. Click OK.
  5. The discovered devices display in the table.
  6. Select the engineered device and the discovered device.
  7. Click Assign.
  8. Click Load > Application configuration.
  1. The application configuration is downloaded and the device is restarted.
Command parameters
  1. Go to Startup.
  2. Open the Global functions task.
  3. Select the Command tab.
  4. From the Command list drop-down list, select Alarm management.
  5. A list of parameters displays by description, units, and value field. The list provides units, range checking, default value, and state text.
  6. Select the parameter Update Alarming for 6.2.
  7. Select the device to be updated.
  8. Click Preview.
  9. The parameter settings are read and the results display below the device.
  10. Some errors display in the Jobs log depending on your configuration. You can ignore these errors.
  11. Click Commit.

The same errors display in the Jobs log depending on your configuration. You can ignore these errors. The parameters are updated for the selected device.

Read back data
  1. The device is connected.
    Connecting to devices
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select the Discovered devices tab.
  4. Right-click the device and select Upload.
  1. The device runtime instance data is uploaded to the project.
