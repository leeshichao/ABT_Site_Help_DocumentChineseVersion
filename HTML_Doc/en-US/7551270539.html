Password policy

Passwords are set in Settings > User profiles > Users.
Users tab

NOTICE

Weak passwords can be deciphered. As a result system malfunctions or automation stations failures can be set off.

High fixing costs and a loss of reputation.

  1. Use different passwords for different users.
  2. Use strong passwords.
  • Set a different set of passwords in every project (no country-wide passwords).
  • Use strong passwords:
    • Use uppercase characters
    • Use lowercase characters
    • Use digits
    • Use special characters
    • Use a minimum of 8 characters for each password

Access Control Profile (ACP)

ABT projects use Access Control Profiles (ACP). Comply with the following rules to set password security levels with ACP.

  • Define strong password rules for the ABT project.
    Settings > User profiles > Common settings > Min. password length
    Settings > User profiles > Common settings > Password policy
    Common settings tab
  • Use different passwords for different users.
    Settings > User profiles > Users > Password
    Users tab
  • Use an expiration date for users according to the project task duration (i.e., passwords for subcontractors).
    Settings > User profiles > Users > Expiration date
    Users tab
  • Use the blocking mechanism for computerized logging attempts.
    Settings > User profiles > Common settings > Block time on failed login
    Settings > User profiles > Common settings > Failed login attempts
    Common settings tab
  • Change passwords after finishing the project (i.e., via mass load).
    Startup > Update > Update user profile
    Updating user profiles for engineered devices

V5.x and converted V5.x ABT Pro projects keep the V5.x password concept (no ACP).
