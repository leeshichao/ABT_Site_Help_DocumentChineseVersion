[TIDAY_DW] Conversion time of day to double word value

Function block TIDAY_DW converts an input value of data type TimeOfDay to an output value of data type Double Word.

TIDAY_DW converts an input value of data type TimeOfDay to an output value of data type Double Word. The output value corresponds to the number of milliseconds as of midnight.
