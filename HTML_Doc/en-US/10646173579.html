Fume hood sash positioner (FhSashPsnr11)

Overview

The application function "Fume hood sash positioner 11" (FhSashPsnr11) applies to a Fume Hood Sash Positioner that automatically closes a vertical fume hood sash when triggered by specific conditions. Safeties, to avoid closing on an obstruction, must be supplied by others.

The output device is a sash closer provided by a third party. There is no function to drive the vertical sash to any other position. Regardless of the number of sashes on the hood, there is only one sash closer AF in the application and only one sash closer BO (FhSashPsnrCls). In a complex installation, the BO may be wired to more than one closer.

Main features:

  • Programmable sash closer

Function

The application supports several closing criteria. When any closing criterion is true, the sash closure object (FhSashPsnrCls) is pulsed on for the time set in PulseLngtCls, closing the sash. It repeats the pulse regularly while the sash closing criteria remains true.

The duration of FhSashPsnrCls pulse and the repeat interval command for closing DlyRptCls are configurable.

 

Command or request (or related)

Notification of condition or status, or availability

Device mode

Interlock (internal signal, not a BACnet object; see Interlocks section for additional information)

Criteria to close sash

The application can be configured to close the sash in response to these criteria:

  • user pressed ‘Green Leaf’ button on ODP (if enabled in CE) - EeiRstIn = 1 (BACnet object resides in ODP)
  • user pressed ‘close’ button on ODP - SashClsIn = 1 (BACnet object resides in ODP)
  • fume hood user is absent (Presence sensor) – FhOcc = Unocc = 1
  • fume hood mode is Off, Fire, or Emergency - FhOpMod = 1, 4, or 5
  • manual command to Sash Closure multistate trigger value object - FhSashPsnrCmd = Close = 2
