MS/TP addressing

The following properties must be unique in the project for all devices:

  • Device name
  • Device instance number
  • IP address
  • MS/TP address (combination of MAC address and network number)
  • Serial number (must be unique or empty)

When defining MS/TP settings in ABT Site consider the following:

  • MAC address range
    You can set a MAC address start and a MAC address end in Settings > Address defaults. You can narrow down the default address range in the details of a building or building element. Narrowing down the address range is not limited by the defined project settings, only the initial values are derived from the project settings.
    The network address ranges of a building or building element override the network address ranges defined in Settings> Address defaults.
  • MAC address and Auto addressing
    In Settings > Address defaults > MS/TP the Auto addressing settingcan be used to let the computer manage MAC addresses and provide them to the devices automatically. You can override Auto addressing in the details of a building or building element by entering a network range in the MAC address start and MAC address end fields. You can also override all generic settings in the details of a device by entering an individual MAC addressin the MAC address field.
  • Max manager address
    The MS/TP Max Manager address defaults to 127. There is no issue with leaving all devices at this value. To improve network performance it is recommended to reduce this value to be equal to or one greater than the highest MAC address of a device on each network. All MS/TP devices on a network should have the MAX Manager address set to the same value.
  • Note
    No device with a MAC address greater than Max manager address will be discovered.
  • Network number
    You can set the network number in Settings > Address defaults. You can set the network number for each device in the details of a building, building element or device.
  • Baud rate
    You can set a default baud rate for the whole project in Settings > Address defaults. All devices on the data bus must be set to the same baud rate. Therefore, the chosen baud rate must be supported by all devices connected to the data bus. You can override the set value in the details of a building, building element or device.

If you copy a device from one building element to another, the system does not check if the given network address is within the default range.
