Working with the custom library

The Custom library contains your own content. You can import content from your computer or you can copy elements or entire plants from the Project tree and the Programming editor to the Custom library. The Custom library is empty by default.
Plants navigation view
Programming editor

 

Copy an element from the Plants navigation view to the custom library

  • Drag one or more elements from the Project tree to the Custom library.
  1. The elements are copied to the Custom library.

Copy an element from the Programming editor to the custom library

  • Do one of the following:
    • Select one or more elements in the Programming editor and drag them to the Custom library.
    • Select one or more elements and right-click in the Programming editor and select Copy to custom library.
  1. The elements (including their properties, the connections between the elements, their relative positions to each other, their referenced BA objects and their properties) are copied to the Custom library.

Add a folder to the custom library

  1. Right-click the Custom library and select Add folder.
  2. A new folder is created.
  3. (Optional) Click the folder to rename it.

Rename an element in the custom library

  1. Select an element in the Custom library.
  2. The Properties pane at the bottom of the Library opens.
  3. In the Properties pane, select Compact or Advanced and change the name and description of the element in the Custom library.

Add tags to an element in the custom library

  1. Select an element in the Custom library.
  2. The Properties pane at the bottom of the Library opens.
  3. In the Properties pane, select Advanced.
  4. In the Tags field, add one or more tags to the element.
  1. The tags are assigned to the element. You can now use the Filter field to filter the Custom library contents according to the tags you created.

Import data to the custom library

  1. Right-click a folder in the Custom library and select Import.
  2. Select the file that you want to import into the Custom library and click OK.
  1. The content is imported into the Custom library.

Export data from the Custom library

  1. Right-click a folder or element in the custom library and select Export.
  2. Select the folder where you want to save the content of the Custom library and click Save.
  1. The content of the Custom library is saved.
