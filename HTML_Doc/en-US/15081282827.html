[MRG_DATI] Merge to date and time of day

Function block MRG_DATI combines the input values of data type Date and TimeOfDay in one output value of data type DateAndTime.

MRG_DATI combines the inputs values of data type Date and TimeOfDay in one output value of data type DateAndTime. The output value corresponds to the date and time formed from the input values.
