DMUX8_I: Demultiplexer 1 of 8 integer values

The DMUX8_I (FC413) block switches the integer input to one of the 8 outputs in dependence of a selector.

Functionality

The block switches the input [In] to the output [Out0] ... [Out7] defined by selector [K]. All other outputs are set to default value [DefVal].

If the value of input [K] is smaller than 0 or greater than 7, all outputs [Out0]...[Out7] are set to [DefVal].

The block can be cascaded e.g. to demultiplex 16 outputs. To do this, several DMUX8_I blocks can be switched in parallel to the same input value [In] and the input selector [K] is adjusted via subtraction.

Application

The block normally is used to reset signals interconnected via a multiplexer.

For example, a communication path featuring only two integer variables can be used to transmit up to 8 different values in sequence.
