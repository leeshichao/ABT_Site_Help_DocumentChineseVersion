BlsIn

The following tables show the properties for the channel configuration of blinds inputs (BlsIn) without any subsystem-specific extension.

The listed properties are displayed in the Hardware and network editor > Inspector window > Properties tab when the data point "BIB" is selected in the Device view tab.

Number of channels

"Number of channels" defines how many channels are used by the data point.

If more than one channel is used by the I/O data point, all properties are stored in the first channel.

Signal type

"Signal type" defines the DRA signal type. Available signal types depend on I/O module type. The signal type can be edited.

Pulse length

"Pulse length" defines how long a pushbutton has to be pressed to be detected as a long pulse.

Range 0.1…25.5 [s]

Repetition time

"Repetition time" defines the required additional time for a very long pulse as compared to a long pulse.

Range: 0.1…25.5 [s]

Press time twice

"Press time twice" defines the maximum pause time in a double-click.

Range 0.1…25.5 [s]

Pushbutton events (list)

Enable or disable pushbutton events in the list: The assortment of options depends on the number of channels.

Rising edge

Falling edge, press long

Falling edge, press 2x, long

Repeat cyclic

Press 2x, briefly

Press 2x, long

Press two-buttons

Pushbutton events (table)

Defines pushbutton events.

  • Pushbutton event (from list)
  • Action: Operation associated to the pushbutton event: Stop, Move up, Move down, Step up, Step down, Go to height, Go to angle, Go to height & angle, Go to position, Unser defined 1...5, No action
  • Height (%): Height of slat position. Range: 0.00...100.00 [%]
  • Angle (%): Slat angle. Range: 0.00...100.00 [%]
  • Position number: Range: 0...4

Save as

"Save as" saves the set parameters of the I/O data point as an xml-file.
