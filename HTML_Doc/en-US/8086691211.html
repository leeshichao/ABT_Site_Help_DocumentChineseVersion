Device list

The Device list task lists all devices and its properties. You can change individual properties efficiently and perform uniqueness checks on a number of device properties.
Checking for duplicate device properties

Use this editor to make changes to default values for all devices associated with this template (export from ABT Site).

Devices can be added and or removed from the exported editor (i.e. Excel).

  • Switching to the Device list task closes and reopens the current project in the background. Open Report or Configuration tabs will be closed.
  • In the Device list task the component selector, the task selector, and the split buttons are disabled.

① Toolbar

Command

Description

Save

Saves the current changes. The number above the button indicates the number of changes made.

Close

Closes the Device list task. If you close the Device list task without saving, all changes are lost.

Load instance parameter

The instance parameters are hidden by default to save load time. To view instance parameters in the devices table, click Load instance parameter in the toolbar.

Note
For certain checks, e.g. the IP address range check, the instance parameters must be loaded.

Smart copy

Copies the table data to be pasted in Excel or other spreadsheet software.

Smart paste

Pastes data from the clipboard into the table performing certain checks to work with changed data from Excel or other spreadsheet software.

Load data for extended checks

Only the most important checks are done with the initially loaded data. Use this button to load data for extended checks, in order to perform all checks (takes more time).
Extended checks

Check

Performs all mandatory checks and the optional checks selected in Configure checks. The results are indicated in the Details and Log tabs.

Configure checks

Allows you to set optional checks.

Names

  • Unique room names. Selected by default.
  • Unique room segment names. Selected by default.
  • Unique central function names. Selected by default.
  • Unique plant names. Selected by default.
  • Unique equipment IDs. Cleared by default.
    • Empty equipment IDs allowed. Disabled, if Equipment ID check is disabled.

Advanced

  • Check room segment assignment to rooms. Selected by default.
  • Check room segment context in building. Selected by default.
  • Check integrity of I/O assignment. Selected by default.
  • Allow only one local broadcast UDP port. Selected by default.
  • Allow only two DNS servers. Selected by default.

Note
The instance parameters are hidden by default to save load time. To view instance parameters in the device table, click Load instance parameter in the toolbar.

Each column contains one property. The caption is built from the object description, property description, and the unit.

Example:
Brightness
Process value 2
[lx]

Only instance parameters of pre-loaded devices are listed.

You can only view and change parameter values in ABT Site if the Avail. on AS check box for the selected parameter is selected. The Avail. on AS check box is set in Configuration > Default values.
Configuring default values (template)
If selected, the corresponding object parameters are available in the following areas:

  1. Device details > Instance parameter page
  2. Application template details > Instance parameter tab
  3. Building > Device list > Load instance parameter
  4. Checkout report

  • If the hierarchy of an area is changed, the area will be moved automatically to the new location.

  • If under Settings > Naming defaults in the Object names tab Move rooms with automation station is selected, the rooms follow the automation station in the building structure.
