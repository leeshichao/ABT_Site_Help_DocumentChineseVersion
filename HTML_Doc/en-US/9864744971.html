QMX3.P02, P34, P37, P44, P74 template properties

The listed properties are displayed in the QMX3 templates editor > Inspector window > Properties tab when the templates is selected in the Project tree.

Marked properties ( 1) , 2) ) belong to a subsystem-specific extension. If the corresponding subsystem-specific extension is enabled, it overwrites the selected QMX3 template properties. As a precondition the property in the QMX3 template must be enabled.

Light dimming sensor basic (LDSB)

Property

Description

Default value

Light dimming sensor basic (LDSB)

Light Dimming Sensor Basic (LDSB) enables the configuration of the pushbuttons for dimming and switching lights. Read only.

: The pushbuttons can be configured for dimming and switching lights.

: The pushbuttons cannot be configured for dimming and switching lights.

: The pushbuttons can be configured for dimming and switching lights.

Pushbutton function

Pushbutton function defines if 1 or 2 pushbuttons are used for switching or dimming and defines the behavior of the pushbuttons.

1 button, switching & dimming: A short key press toggles between switching the light on or off. A long key press toggles between dimming the lights up or down.

1 button, on & dimming up: A short key press switches the light on and a long key press dims the light up.

1 button, off & dimming down: A short key press switches the light off and a long key press dims the light down.

2 buttons, switching & dimming: One of the buttons switches the light on or dims the light up the other switches the light off or dims the light down.

Depends on the number of function keys assigned to the application block.

Pulse length

Pulse length defines how long a pushbutton has to be pressed to be detected as a long key press.

Unit: 5...60 [1/10 s]

5

Invert pushbutton assignment

Invert pushbutton assignment defines how dimming up and dimming down are assigned to the buttons.

: Left button: dimming up, right button: dimming down.

: Left button: dimming down, right button: dimming up.

: Left button: dimming up, right button: dimming down.
