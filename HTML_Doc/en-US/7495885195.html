Supply chain VAV overridden value (SplyVavOvrr11)

Overview

The application function "Supply chain VAV overridden value 11" (SplyVavOvrr11) allows a technician / balancer to override the VAV applications for balancing and commissioning of the ductwork.

Function

The technician overrides VAV damper position and VAV flow setpoints via SplyAir group distribution to the destination object. See Engineering and commissioning.
