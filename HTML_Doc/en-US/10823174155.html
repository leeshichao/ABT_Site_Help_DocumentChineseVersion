Room unit LED (KNX) (BlsIn - subsystem-specific extension)

The Blinds Input (BlsIn) object supports following properties of the subsystem-specific extension Room unit LED (KNX).

Room operator unit, LED indication ✳

 

 

"Room operator unit, LED indication" defines when the status LEDs are on.

Always off

The status LEDs are always off.

Manual operation locked

The status LEDs are on if the device is locked for manual operation.

Room operator unit, manual operation locked ✳

 

 

"Room operator unit, manual operation locked" defines whether the status LED can be used to indicate that the device is locked for manual operation.

Note: Manual configuration is only relevant if the device is used without an application function.

Yes

The status LED can be used to indicate if the device is locked for manual operation.

No

The status LED cannot be used to indicate if the device is locked for manual operation.
