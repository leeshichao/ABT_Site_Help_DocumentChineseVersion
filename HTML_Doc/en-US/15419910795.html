Importing ioopt files

Ioopt (I/O Open Point Template) is a file format which contains preconfigured 3rd party Modbus devices. The file comes from Desigo TX Open and can be imported into ABT Site where most of the properties of the device are mapped. The result is a configurable 3rd party Modbus device in ABT Site. Not all properties can be mapped in ABT Site. The import operation does not stop when certain properties are not mapped. Check the log for unmapped properties and adapt the corresponding properties manually.
Log viewer and status bar (Log and Jobs)

 

Import an ioopt file

  1. You have an ioopt file available.
  2. A Modbus network is available.
  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the Modbus task.
  4. In the Modbus area, right-click a Modbus network and select Import.
  5. Select the ioopt file to import and click Open.
  6. Click OK.
  1. The ioopt file is imported, and the 3rd party Modbus device is created.
  2. The bulk reader objects are automatically created for optimizing the network load.
