Lighting green leaf (LgtGrnLf11)

Overview

The application function "Lighting green leaf 11, impact on lighting energy efficiency" (LgtGrnLf11) calculates lighting specific energy efficiency indications (EEI) and provides the result to room coordination (RCoo11 > RGrnLf11) for further evaluation.

It is designed to work together with a lighting control AF (LgtBrgtSwi11 or LgtConstCtl11).

Function

The AF monitors brightness state and present lighting setpoint when the setpoint shift function is enabled. It detects whether automatic mode saves energy versus manual operation. The result is written at LgtEei and provided to room coordination (RCoo11 > RGrnLf11) for further evaluation.

RGrnLf11 sends a reset request (REeiRst) if a user presses the green leaf button on a room operator unit and the lighting state is unsuitable. In this case, the AF activates automatic mode by releasing manual operation (Prio 13) on the lighting output.

None.
