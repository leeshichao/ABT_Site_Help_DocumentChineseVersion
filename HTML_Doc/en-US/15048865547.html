What are plants?

A plant in the Programming editor consists of all required program blocks and function blocks to control plant components for an HVAC plant or partial plant.

Plants are programmed as flat plants and as nested plants.

Closed and open-loop control of an HVAC plant or partial plant consists of the following components:

  • All required input blocks to connect, e.g., sensor, switches, schedulers, fire detectors.
  • All required function blocks with programming function to calculate the values for the output blocks based on the values on the input blocks.
  • All required output blocks to connect plant components, e.g., air dampers, fans, heating coils, pumps, mixing valves.
  • All required interconnections between the function blocks.
  • All required program blocks as coordinators for demand signals from the various zones.

Predefined plants exist in the library for the most common applications, e.g., air handling, heat generation, domestic hot water (DHW), or heating circuit.

Plants can be dragged from the library to project navigation (to line "Add plant").

The plants can be combined and extended with function blocks and program blocks.
