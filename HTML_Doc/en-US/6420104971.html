Shading presence mode (ShdPscMod11)

Overview

The application function "Shading presence mode 11" (ShdPscMod11) controls blinds response to a presence detector based on room operating mode.

Function

Blind's response to a presence detector is considered room-wide for energy aspects and individually per blinds actuator for comfort aspects.

Energy aspects (requires AF RHvacCooxx):
Collaboration with RHvacCooxx allows running the operating strategy "Presence dependent" in ShdOpStrgy11. Presence dependent means that glare protection is performed when someone is in the room, and energy efficiency is performed when no one is in the room. An adjustable off-delay (ShdDlyOfPscDet) and a fixed on-delay (3 minutes) prevent frequent changes.

Comfort aspects:
Room-wide, Shading presence mode defines a balance between maximum automatic functionality and minimum number of automatic blinds movements. For each shading zone (AF Shd11) you can configure, which presence detector(s) and which delay times apply to the blinds.

Shading presence mode (ShdPscMod) can be configured for each room operating mode.
The configuration supports the following values:

  • None: The presence detector is ignored
  • Consider present: The AF responds to a change from absent to present. The response depends on the configuration of the comfort trigger in ShdCoo11:
    • One comfort trigger configuration is "None" or "Hold": The blinds are held in the actual position until moved manually.
    • Both comfort trigger configurations are "Automatic": The blinds are set to automatic.
  • Consider absent: The AF responds to a change from present to absent. The blinds are set to automatic.
  • Consider present & absent: The AF responds to a change from absent to present and vice-versa.


Output
The response (ShdPscMod) is distributed via grouping to shading applications (Shd11) in the room segments.

A BACnet client can also operate ShdPscMod.

Usage

Shading operating modes

ShdOpMod

Description

Typical usage

None

The state of the presence detectors does not influence shading.

No automatic function available.

Consider present

A person enters the room: Change from absent to present. Freeze the current blinds position (automatic control inactive) in order to prevent distracting movements while someone is in the room.

Strictly user oriented. The user is not distracted by movements of the blinds or awnings, even when he leaves the room. Used for example for residential rooms during day time.

Consider absent

No more persons in the room: Change from present to absent. Automatic control is activated. Typically this is done only after a delay. The blinds have the same position if someone leaves the room briefly and returns.

Automatic oriented. Automatic is active until the user manually moves the blinds. Automatic is reactivated, when the user leaves the room. Example: open space office or meeting room

Consider present & absent

Both functions described above.

User oriented. Users are not distracted by movements as long as they are in the room. Automatic is activated when the user leaves the room. Example: individual office or meeting room.
