TI_DW: Conversion time to DWord value

The TI_DW (FC370) block converts time into double word and outputs the value.

Inputs

Pin

E

Description

In

pa

Input

Value range: T#0d_0h_0m_0s_0ms

Time (Default value =0ms)

Outputs

Pin

E

Description

Out

a

Output
Unit: Seconds

Double Word (Default value = 0s)

 

Process response

Standard (see General rules and information).

Troubleshooting

Note

This block reduces the resolution of the converted value. Information about milliseconds will be lost.

If using real numbers to store time values then the resolution of the real number (24 bit mantissa => 8 digits) is limited and can thus not be displayed exactly by a number from 16 000 000.
