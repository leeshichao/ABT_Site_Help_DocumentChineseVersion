Certificate workflows

ABT Site supports certificate management for web browser, IEEE 802.1X, and BACnet/SC. Below are various workflows (BACnet/SC certification management in the projects) and assume that ABT Site is the CA ( certification authority).

  • ABT Site is the CA.
    • Each ABT Site project creates its own root certificate.
  • Export a root certificate (the certificate from the CA) to install the root certificate to a client.
    • Web certificate
    • Exporting the web root certificate
    • Importing an external web certificate
    • BACnet/SC certificate
    • Exporting the BACnet/SC root certificate
    • Importing a BACnet/SC operational certificate from an external CA
    • IEEE 802.1X certificate
    • Exporting the IEEE 802.1X root certificate
    • Importing an external IEEE 802.1X certificate
  • There is at least one external CA for a device.
    Export a certificate signing request for an individual device, then import an externally signed certificate to the device in ABT Site. The CA is changed from internal to external after import.
    • Web certificate
    • Exporting a web operational certificate signing request
    • Importing a web operational certificate from an external CA
    • BACnet/SC certificate
    • Exporting a BACnet/SC operational certificate signing request
    • Importing a BACnet/SC operational certificate from an external CA
    • IEEE 802.1X certificate
    • Exporting a IEEE 802.1X operational certificate signing request
    • Importing a IEEE 802.1X operational certificate from an external CA
  • Download a operational or root certificate to a device.
    Note: A full download with an operational certificate is already performed.
    • Web certificate
    • BACnet/SC
    • IEEE802.1X
    • Downloading an updated certificate to a device
  • Replace an operational certificate because, for example, the certificate has expired, or is close to expiration.
    • Web certificate
      Renewing web internal operational certificate
    • BACnet/SC certificate
    • Renewing BACnet/SC internal operational certificate
    • IEEE 802.1X certificate
    • Renewing IEEE 802.1X internal operational certificate
