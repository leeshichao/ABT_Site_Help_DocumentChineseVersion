Discovering unaddressed MS/TP devices

Only configured devices can be discovered. Based on the type of connection selected, use the associated procedure to discover unaddressed MS/TP devices.

Before a new query is made, a Clear table must be performed. This is the only way to ensure that only the corresponding devices are listed.

Room unit connection

By default, the Discovered devices tab displays the locally connected device. The Discover button provides you with the option to select either All or Locally connected device from the Discovery dialog box. If All is selected, the discovered devices are listed in the table.

  1. A Room unit connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Room unit connection tab.
  3. Click Connect.
  4. Select Startup > Configure and download.
  5. In the Discovered devices tab, click Discover and select the Locally connected device from the drop-down list box and enter the Network number in the Discovery dialog box.
    OR
    Select All from the drop-down list box in the Discovery dialog box.
  6. Click OK.
  7. All connected devices on the selected network display in the Discovered devices table.

  8. PXC3 devices do not support connection through a Room unit.

  9. Select a configured device, right-click, and select Discover all unaddressed devices on network.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. All the unconfigured devices display in the Discovered devices table. They can now be configured and loaded.

This process can take up to 3 minutes.

USB connection

By default, the Discovered devices tab displays the locally connected device. The Discover button provides you with the option to select either All or Locally connected device from the Discovery dialog box. If All is selected, only the configured devices are listed in the table. If Locally connected device is selected, only the locally connected devices are listed in the table (configured or unconfigured).

  1. A USB connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the USB tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Select Startup > Configure and download.
  7. In the Discovered devices tab, click Discover and select the Locally connected device from the drop-down list box
    OR
    Select All from the drop-down list box and enter the Network number in the Discovery dialog box.
  8. Click OK.
  9. All connected devices on the selected network display in the Discovered devices table.

  10. PXC3 devices do not support connection through a Room unit.

  11. Select a configured device, right-click, and select Discover all unaddressed devices on network.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. All the unconfigured devices display in the Discovered devices table. They can now be configured and loaded.

This process can take up to 3 minutes.

Ethernet connection

By default, no devices display in the Discovered devices tab. The Discover button provides you with the option to select All from the Discovery dialog box. As a result, the discovered devices are listed in the table.

  1. An Ethernet connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Ethernet tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Select Startup > Configure and download.
  7. In the Discovered devices tab, click Discover.
  8. The Discovery dialog box displays.
  9. Select All from the drop-down list box and enter the Network number.
  10. Click OK.
  11. All configured devices on the selected network display in the Discovered devices table.

  12. PXC3 devices do not support connection through a Room unit.

  13. Select a configured device, right-click, and select Discover all unaddressed devices on network.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. All the unconfigured devices display in the Discovered devices table. They can now be configured and loaded.

This process can take up to 3 minutes.
