Properties of functions/channels

The listed properties appear in Properties tab when the device with KNX S-Mode is selected in the Device view. The assortment of visible properties depends on the program version of the automation station.

Properties are configured in the Hardware and network editor. The list of properties is sorted alphabetically.

Property

Description

Default Value

Blink off time1)

"Blink off time" and "Blink on time" define the blinking frequency for the blink warning function.

"Blink off time" defines how long the light will be switched off or dimmed to the dimming level defined by "Prewarning minimum level".

Range: 0...50 [0.1 s]

0 [0.1 s]: The blink warning function is disabled.

Depends on the application block.

Blink on time1)

"Blink off time" and "Blink on time" define the blinking frequency for the blink warning function.

"Blink on time"defines how long the light will be switched on.

Range: 0...50 [0.1 s]

0 [0.1 s]: The blink warning function is disabled.

Depends on the application block.

Config. communication flags
GPDI

"Config. communication flags" defines the behavior of the KNX S-Mode receiving group object (DigitalInputValue) after a restart of the automation station.

Activated: read after reset.

Deactivated: do not read after reset.

Activated

Config. DPT subnumber

"Config. DTP subnumber" defines the DPT (data point type) subnumber or enumeration depending on the application block. See also Application blocks.

Depends on the application block.

EnableInfoMUD2)
Sunblind actuator basic (SAB)

"EnableInfoMUD" defines if the blinds actuator can send information about the direction of movement of the blind.

: The blinds actuator supports the communication object "InfoMoveUpDown". The actuator sends the direction of movement when the movement starts or the direction of movement changes. The direction of movement will not be sent if the blind is in the state Stepping.

: The blinds actuator does not support the communication object "InfoMoveUpDown". The direction of movement is not sent.

Note
The communication object "InfoMoveUPDown" is mainly used for realizing the toggle mode in a control panel.

: The blinds actuator does not support the communication object "InfoMoveUpDown".

EnableInfoOnOff2)
Light switching actuator basic (LSAB)

"EnableInfoOnOff" defines if the connected actuator can send information about its current state.

: The actuator can send information about being on or off.

: The actuator cannot send information about being on or off.

: The actuator can send information about being on or off.

EnableLockDevice
Light dimming actuator basic (LDAB)

Function not implemented.

 

EnableVCAP2)
Sunblind actuator basic (SAB)

"EnableVCAP" defines if a connected actuator can send information about the reliability of the following values:

  • Current height of the sunblind in percentage
  • Current angle of the slats in percentage

: The actuator can send information about the reliability of the values.

: The actuator cannot send information about the reliability of the values.

Note
"EnableVCAP" should be disabled if "Map0x00ToVoidPos" is enabled.

: The actuator cannot send information about the reliability of the values.

Fade time absolute dimming1)
Light dimming actuator basic (LDAB)

"Fade time absolute dimming" defines the time the actuator takes to dim down or up the set dimming value after receiving an absolute dimming command.

Range: 0...2400 [0.1 s]

0: the actuator changes to the set dimming value without dimming.

10

Fade time switch on/off1)
Light dimming actuator basic (LDAB)

"Fade time switch on/off" defines the time the actuator takes to dim down or up the entire range after receiving a switch-on or switch-off command.

Range: 0...2400 [0.1 s]

0: The light is switched on or off without dimming.

0

Input communication configuration
GPDO

"Input communication configuration" defines if the automation station reads the state of the general purpose digital output of the device with KNX S-Mode (communication object "DigitalOutSetp") after a restart of the automation station.

Activated: The automation station reads the state of the general purpose digital output after a restart.

Deactivated: The automation station does not read the state of the general purpose digital output after a restart.

Activated

Map0x00ToVoidPos2)
Sunblind actuator basic (SAB)

"Map0x00ToVoidPos" defines how a value of 0 % for the current height position of the sunblind and the current angle position of the slats is interpreted.

: 0 % indicates that at least one of the following values is invalid:
- Current height position of the blind in percentage
- Current angle position of the slats in percentage

: 0 % does not indicate invalid values.

Note
"EnableVCAP" should be disabled if "Map0x00ToVoidPos" is enabled.

: 0 % does not indicate invalid values.

Mapping Table

"Mapping table" defines how enumeration values defined in KNX are mapped to the values of multistate inputs or multistate outputs.

Offset 1: The enumeration value is shifted up by 1 for inputs and down by 1 for outputs.

Offset 0: The enumeration value remains unchanged.

HVACModeUser: Activates the modes for room operating mode including Automatic mode. Only supported by MIN8 and MON 8.

HVACModeEff: Activates the modes for room operating mode, but not Automatic mode. Only supported by MIN8 and MON 8.

Offset 1

Move up/down1)
Sunblind actuator basic (SAB)

"Move up/down" defines the maximum time needed to move the shutter or blind from the upper to the lower end position or from the lower to the upper end position.

If the automations station receives no signal from the actuator about its moving state within the specified time, it assumes that the blind has stopped moving and sets the property In-Process to false.

Range: 3...300 [s]

180

Positioning table2)
Sunblind actuator basic (SAB)

The positioning table contains the values for the predefined positions P0 through P4.

Each predefined position is defined by 2 values:

  • Position, height: Range 0 – 100 [%]
  • Slat position: Range 0 – 100 [%]

P0: Closed:
Normal lower end position, slats closed. Position, height: 100, slat position: 100.

P1: Visual protection
Slats are in a position that protects the privacy of people in the room, but still allows as much light into the room as possible.
Position, height: 100, slat position: variable

P2: Anti-glare, sun position low
Slats are in the shading position for a low altitude of the sun.
Position, height: 100, slat position: variable

P3: Anti-glare, sun position high
Slats are in the shading position for a high altitude of the sun.
Position, height: 100, slat position: variable

P4: Open
Slats are in the position that constricts the view trough the blinds as little as possible.
Position, height: 100 %, slat position: variable

100

Physical input

"Physical input" defines if the input receives a measured value or a calculated value.

: The input receives a measured value. The value is mapped to a "Binary Input" object.

: The input receives a calculated value. The value is mapped to a "Binary Calculated Value" object.

: The input receives a calculated value. The value is mapped to a "Binary Calculated Value" object.

Physical output

"Physical output" defines if the output is mapped to a "Binary Output" object or to a "Binary Calculated Value" object.

: The value is mapped to a "Binary Output" object.

: The value is mapped to a "Binary Calculated Value" object.

Depends on the application block.

Prewarning minimum level1)

"Prewarning minimum level" defines the dimming level for the blink off time of the blink warning function.

"Prewarning minimum level" is only meaningful if the blink warning function is enabled.

Range: 0...100 [%]

0 Is backwards compatible with former on/off blinking.

1

: The actuator can only be dimmed down to the minimum dimming level using dimming.

SceneTeachingEnable
Scene sensor (SCS)

"SceneTeachingEnable" defines if scenes can be saved using teach-in.

: Teach-in is activated. With a long key press the user can save the current states of the actuators to a scene.

: Teach-in is not activated. The user cannot save the current states of the actuators to a scene.

: Teach-in is activated. With a long key press the user can save the current states of the actuators to a scene.

SlatsMoveTimeout1)
Sunblind actuator basic (SAB)

"SlatsMoveTimeout" defines the maximum time needed to move the slats from any position to the open or closed position.

Range: 1...10 [s]

If the automations station receives no signal from the actuator about the moving state of the slats within the specified time, it assumes that the blind has stopped moving and sets the property "In-Process" to false.

Note:
"SlatsMoveTimeout" is only meaningful for products with slats. For shutters or sunblinds it should be set to 0.

10

Transmission change of value

"Transmission change of value" defines the change in the process value that triggers the sending of the process value.

Unit: depends on the application block.

Range: 0…100

Depends on the application block.

Transmission heartbeat

"Transmission heartbeat" defines the time interval to report the process value if the value did not change or the change was smaller than the "Transmission change of value".

Range: 0…900 [s]

0

Transmission min.repetition time

"Transmission min.repetition time" defines the minimal time interval before the next process value can be sent.

Range: 0…120 [s]

10

Transmission timeout

"Transmission timeout" defines the time before the automation station detects a timeout if it does not receive a signal from the device with KNX S-Mode.

Range: 0…65535 [s]

0
