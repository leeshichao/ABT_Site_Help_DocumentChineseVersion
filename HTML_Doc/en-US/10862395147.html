TX-I/O (FldBusMgmt - subsystem-specific extension)

The Field bus management (FldBusMgmt) object supports following properties of the subsystem-specific extension TX-I/O.

✳ Indicates a Siemens proprietary property.

Mains frequency ✳

 

 

"Mains frequency" defines the filter used for hum suppression.

Unit: [Hz]

Note: "Mains frequency" corresponds to ABT Pro > Project settings > I/O modules > Mains Frequency and has to be configured for each automation station individually.

50Hz

A filter optimized for alternating current with 50 Hz is used.

60Hz

A filter optimized for alternating current with 60 Hz is used.

Reserved

No filter is used. This option is meaningful if the automation station uses DC 24 V.

Enable local bus power supply ✳

 

 

"Enable local bus power supply" defines if the internal power supply of the rail is on or off.

Yes

The internal bus power supply is permanently on.

No

The internal bus power supply is permanently off.
