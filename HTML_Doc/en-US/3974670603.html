Safety instructions

Modifications to functions and function blocks

We assume that persons using or modifying functions and function blocks are authorized and trained appropriately and have the technical knowledge required to use or modify the functions and function blocks as intended.

Alterations in predefined functions or function blocks can lead to safety critical situations.

Alteration of functions or function blocks is in responsibility of the engineer.
