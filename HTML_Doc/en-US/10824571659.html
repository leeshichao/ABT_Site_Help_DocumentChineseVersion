KNX PL-Link: SAB (BlsOut - subsystem-specific extension)

The Blinds Output (BlsOut) object supports following properties of the subsystem-specific extension KNX PL-Link: SAB.

End position detection ✳

 

 

"End position detection" defines how the runtime is determined.

Manual

Runtimes must be measured and configured. See properties "Move down time" and "Move up time".

Note: Add a buffer for aging and temperature dependency.

Auto

The module permanently detects the "Move down time" and the "Move up time" and reports significant changes. Auto is not recommended for actuators with integrated electronics for disconnection at the limit positions.

Once at startup

The module detects the "Move down time" time and the "Move up time" one single time at start-up and saves the values internally. Once at startup is not recommended for actuators with integrated electronics for disconnection at the limit positions.

Move up time ✳

 

 

"Move up time" defines the time the actuator takes to move the blind from the lower to the upper end position.

Range: 00:03:000...05:00:000 [min:s:ms]

Move down time ✳

 

 

"Move down time" defines the time the actuator takes to move the blind from the upper to the lower end position.

Range: 00:03:000...05:00:000 [min:s:ms]

Move completion time ✳

 

 

"Move completion time" defines a time that is added to the "Move up time" or the "Move down time" when the blind moves towards one of the end positions. "Move completion time" ensures that moving will be stopped by the end contact.

Range: 00:000...20:000 [s:ms]

Slat rotation maximum time ✳

 

 

"Slat rotation maximum time" defines the time the actuator takes to move the slats from the closed to the open position.

Range: 00:00:000...01:40:000 [min:s:ms]

Number of slat steps ✳

 

 

"Number of slat steps" defines the number of steps needed to move the slats of the blind from the closed position to the open position.

Range: 2...255

Blinds position 0, closed ✳

 

 

"Blinds position 0, closed" defines the height of the blind and the angle of the slats for the predefined position P0.

Range: 0...100 %

Blinds position 1, visual protection ✳

 

 

"Blinds position 1, visual protection" defines the height of the blind and the angle of the slats for the predefined position P1.

Range: 0...100 %

Blinds position 2, sun altitude low ✳

 

 

"Blinds position 2, sun altitude low" defines the height of the blind and the angle of the slats for the predefined position P2.

Range: 0...100 %

Blinds position 3, sun altitude high ✳

 

 

"Blinds position 3, sun altitude high" defines the height of the blind and the angle of the slats for the predefined position P3.

Range: 0...100 %

Blinds position 4, open ✳

 

 

"Blinds position 4, open" defines the height of the blind and the angle of the slats for the predefined position P4.

Range: 0...100 %

Calibration command ✳

 

 

"Calibration command" triggers the calibration of the device.

Ready

The device is ready for a new request.

Calibrate

Starts the calibration of the device.

Calibration status ✳

 

 

"Calibration status" shows the status of the calibration.

Pending

In process

Manually calibrated

Automatically calibrated
