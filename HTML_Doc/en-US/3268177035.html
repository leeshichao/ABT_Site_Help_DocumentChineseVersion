BACnet objects (Room Automation)

The content in this section is intended for advanced users who are familiar with BACnet. The following categories of BACnet building automation objects associated with the room automation station populate the BACnet objects editor.

Note
The entire set of properties is listed for each BACnet object in these categories. However, the Inspector window displays only a subset of properties. The properties that are not displayed are used internally by the automation station.

For further information regarding standard BACnet object properties, see the current BACnet ANSI/ASHRAE Standard at: http://www.ashrae.org
