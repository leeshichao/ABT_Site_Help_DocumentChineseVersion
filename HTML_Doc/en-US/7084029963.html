Creating ABT Pro projects

You can create ABT Pro projects from ABT Site in Advanced > ABT Pro.

 

Create an ABT Pro project

  1. Click Add project.
  2. A dialog box opens where you can enter properties for the new project.
  3. Enter the data according to your project specifications. See table below.
  1. The project is created.

Command

Description

Project name

Name of the project to be used.

Note
Once a project name is entered, the project cannot be renamed.

Path

Read-only information. The project is saved in the directory of the current ABT Site project. You can change the ABT Site project path in Project Manager > Settings.
Settings

Author

Author name. By default the name of the user currently logged in.

Comment

Free comment for the project. The comment will display in Advanced > ABT Pro, in the Description field.
