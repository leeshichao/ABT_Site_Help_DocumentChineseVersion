移动设备

房间和设备可以从一个建筑结构移动到另一个建筑结构，或者从一个特殊的文件夹（例如Unplaced devices文件夹到建筑结构中。

InSettings > Naming defaults > Object names tab, selectMove rooms with automation station，如果您想将相应的房间与自动化站一起移动。
Object names tab

 

Move a room

  1. Select a room.
  2. Drag and drop the room to a building structure.

Move a device

  1. Select a device.
  2. Drag and drop the device to a building structure.

当您将设备从Unplaced devices文件夹到建筑结构后，设备会自动更新位置信息，但设备会保留其属性。例如，您可能需要更改 BACnet 属性以适合您的项目。
