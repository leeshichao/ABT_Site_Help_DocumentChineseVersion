创建事件注册对象 - 项目选项卡

在中创建事件注册对象Projects选项卡。

  1. Go to Engineering > BACnet references.
  2. Click Projects tab.
    See Create a BACnet reference from ABT Site projects.
  3. Select the required project in the Selected project field.
  4. The respective data points of the project is displayed below in the form of a table.
  5. Right-click the required data point in the table and click Add event enrollment.
  2. The event enrollment object is created in the Plants navigation view.
