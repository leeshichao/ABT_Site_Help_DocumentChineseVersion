AI 带测量

以下部分显示具有子系统特定扩展“测量”的模拟输入 (AI) 的属性。 Desigo 5.x 不支持具有子系统特定扩展“测量”的模拟输入。

Channel configuration properties

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

COV limit

“COV limit”定义触发过程值发送的过程值变化。

范围：0...32767（标准化原始值）

单元

“单位”定义输入或输出的物理单位。

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。

Signal type

 

 

'Signal type' 定义其 I/O 通道的信号类型。可用的信号类型取决于特定的硬件，例如I/O 模块类型或板载-I/O 类型。

财产ID：4968

Process value 1和Process value 2 ✳

 

 

"Signal value 1“（X1），”Signal value 2“（X2），”Process value 1“（Y1）和”Process value 2" (Y2) 用于计算线性函数 (f)。需要线性函数来根据测量信号值计算当前值。

单位：取决于过程值。

范围：

如果从测量信号值计算当前值所需的函数完全由所选信号类型定义，则为 -1。示例：Ni1000

如果从测量信号值计算当前值所需的函数未完全由所选信号类型定义，则任何值 ≠-1。

 

Signal value 1和Signal value 2 ✳

范围：

如果从测量信号值计算当前值所需的函数完全由所选信号类型定义，则为 -1。示例：Ni1000

如果从测量信号值计算当前值所需的函数未完全由所选信号类型定义，则任何值 ≠-1。
