[ROT_8] 8 个输出的旋转开关

功能块 ROT_8 根据运行时间或定义的顺序打开或关闭最多 8 个设备组件。

ROT_8 根据定义的顺序或基于运行时间打开或关闭最多八个工厂组件。根据请求的工厂组件的数量、其运行时间、待处理的错误消息或基于外部信号进行切换。

Functioning

输入 [SpNrFun] 上的值定义要打开的设备组件的数量。例如，如果需要四个锅炉来满足热需求，则为 4。因此，工厂组件控制需要四个输出。

设备组件也会根据输入 [SpNrFun] 处的值的增加或减少而打开或关闭。

ROT_8 根据设备组件的设置和运行时间确定要使用的输出 [Cmd1]...[Cmd8]。

可以根据有效输出信号 [Cmd1]...[Cmd8] 或设备组件反馈 [OpSta1]...[OpSta8] 的持续时间在内部计算运行时间。作为替代方案，可以通过外部运行时间计数器将运行时间传输到输入 [ValExtOph1]...[ValExtOph8]。

如果设备组件发出故障信号，则会根据新的设备组件关闭和打开。

Switching on and off

工厂组件根据输入 [SpNrFun] 处请求的值进行命令。

无法切换但可运行的工厂组件（[Avl1]...[Avl8] = 0 和 [OpSta1]...[OpSta8] = 1 被视为可运行并添加到所需工厂组件数量的计算中。

切换标准在输入 [NxRotMod] 上选择。

Time-based

在基于时间的模式下，工厂组件根据当前运行时间进行命令。

  • On switch on, the plant component with the lowest operating hours is switched on.
  • On switch off, the plant component with the most operating hours is switched off.

Oph = 营业时间

Time-based with overlap

“基于时间且重叠”使用与“基于时间”相同的逻辑。
0 - __VAR_000__ 元素未积分。

Oph = 营业时间

Time-based with interruption

“基于时间且重叠”使用与“基于时间”相同的逻辑，
然而，[TiOvrlp] 延迟了植物组件的启动。

Oph = 营业时间

Last in first out

“后进先出”按升序打开设备组件，并按降序关闭它们。换句话说，第一个打开的设备组件是最后一个关闭的。

输入 [BlFun] 定义开启序列的起点。

例子：

如果选择输出 [Cmd7] 上的设备组件作为起始点，则 8 个可用设备组件上的 4 个请求的设备组件的开启顺序如下：

[Cmd7], [Cmd8], [Cmd1], [Cmd2]

禁用顺序相反：

[命令2]、[命令1]、[命令8]、[Cmd7]

[BlFun] = 开关序列的起始点

First in first out

“先进先出”按循环顺序打开和关闭设备组件。换句话说，第一个打开的设备组件也是第一个被关闭的。

例子：

八个可用设备组件上四个所需设备组件的开启顺序：
[命令1]、[命令2]、[命令3]、[命令4]

关闭顺序：
[命令1]、[命令2]、[命令3]、[命令4]

开关序列的起始点由内部指针定义。
如果工厂组件关闭，指针将移至下一个组件。
如果指针指向无法切换的工厂组件，它将移至下一个。
如果设备组件打开，指针将保持静止。

在 4 个设备组件打开和关闭后，指示灯位于 Cmd5 上。

如果再次打开，则打开序列从 Cmd5 开始，因为内部指示器在第一个关闭序列之后位于此位置。

First in first out with overlap

“先进先出重叠”使用与“先进先出”相同的逻辑。
0 - __VAR_000__ 元素未积分。

First in first out with interruption

“带中断的先进先出”使用与“先进先出”相同的逻辑。
然而，[TiOvrlp] 延迟了植物组件的启动。

Changeover by operating hours

输出可在运行期间根据运行时间自动切换。必须允许 [EnNxRot] = 1 进行转换。否则，只有出现故障或设备组件不再可用时才会进行切换。

自动切换仅适用于基于时间的旋转类型（输入 [NxRotMod]，设置为“基于时间”、“基于重叠的时间”和“基于时间的中断”）。

设备组件在达到最大运行时间 [TiRnMax] 后立即关闭，并且运行时间最短的未开关设备组件将打开。

仅更改可切换的设备组件（输入 [Avl1…Avl8] = 1 且输入 [Dstb1…Dstb8] = 0）。

TB = 基于时间的转换
TB+OL= 基于时间的重叠切换
1 - 输入已启用。
[TiRnMax] = 植物组件，最大数量。运行时间达到

Changeover by external command

运行期间可通过外部信号切换输出。必须允许 [EnNxRot] = 1 进行转换。否则，只有出现故障或设备组件不再可用时才会进行切换。

一旦输入 [FrcNxRot] 处有外部命令待处理（上升沿），就会触发强制旋转。

对于基于时间的切换，运行时间最长的活动设备组件将被关闭；运行时间最少的设备组件被关闭。

第一个打开的输出在 FIFO 期间关闭，下一个输出按照开关顺序打开。

LIFO 不支持强制旋转。

仅更改可切换的设备组件（输入 [Avl1…Avl8] = 1 且输入 [Dstb1…Dstb8] = 0）。

TB = 基于时间的转换
FIFO = 先进先出
[FrcNxRot] = 接收外部切换命令

Changeover for faults

如果某个设备组件报告故障 ([Dstb1]...[Dstb8] = 1)，则会关闭该设备组件，并由另一个设备组件根据切换顺序接替它。

I___VAR_000__ 根据整数输入值将布尔输出设置为 1。

切换序列中的下一个设备组件用于 LIFO 和 FIFO。

如果故障已解决，则响应基于所选的切换标准：

  • For time-based changeover and FIFO, the plant component remains switched off. It is considered, however, at the next regular switching process.
  • For LIFO, the plant component is switched on again, as long as it is still within the plant component to be activated. The last plant component that was switched on is switched off again.

TB = 基于时间的转换
FIFO = 先进先出
LIFO = 后进先出
[Dstb1]...[Dstb8] = 输出之一出现故障 [Cmd1]...[Cmd8]

在基于时间的模式中，当设备组件在达到最大运行时间时切换时，可能并不总是能够达到相同的运行时间（如果只有两个可用，则需要运行组件）。在这些情况下，[PrfrMod] 可以定义最大运行时间或相等运行时间的切换首选项。

Process response

ROT_8 从第二个处理周期开始使用输入处待处理的值进行处理。

在第一个处理周期中，ROT_8 将默认值发送到其输出，因为输入上待处理的值不被视为用于计算目的的值。

启动时，ROT_8 从 BACnet 对象中读取组件运行时间的最后保存值，并将这些值用作计算运行时间的初始值。如果发生故障，组件的运行时间计数从 0 开始。

属性“总计运行时间”的值必须在 BACnet 对象上作为扩展可用（“通过持久性扩展”=“具有 8 个输出的旋转开关”）。

Troubleshooting

输入 [NxRotMod] 旋转模式上不可接受的值将被最后一个有效值替换。

如果设备启动时已出现不可接受的值，ROT_8 会设置 [NxRotMod] = 1（“基于时间”）的值。

Application example

ROT_8可以根据运行时间和/或故障来切换制冷机、锅炉、风扇或泵等。

如果设备组件允许手动操作，请使用基于运行状态 [OpSta1]...[OpSta8] ([RnMod] = 1) 反馈的运行时间计数器。这还考虑了手动模式下的运行时间。

在所有其他情况下，基于输出命令 [Cmd1]...[Cmd8] 的运行时间计数器是合适的 ([RnMod] = 0)。
