[F_TRIG] 识别下降沿和触发脉冲

功能块 F_TRIG 识别下降沿。

F_TRIG 识别下降沿。

Functioning

对于输入 [In] 的下降沿，输出 [Out] 在程序周期内设置为 [Out] = 1。

Application

功能块 F_TRIG 用于各种控制任务，例如识别按钮的初始使用。

Process response
  • The old state of input value [In] is initialized with 0.

从第三个处理周期开始，F_TRIG 使用输入处的值进行处理，因为只有在识别出下降沿后才识别初始化类型。默认值在前两个处理周期内发出。

连续信号 [In] = 0 在处理时不会被识别为负斜率。输出 [Out] 保持 = 0。
