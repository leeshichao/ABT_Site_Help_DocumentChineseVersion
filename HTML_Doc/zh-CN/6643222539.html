W_MG：写入多状态组

W_MG 支持将现值和可靠性属性（“value/reliability 对”）分配给共享特定组数据标签的一组多状态计算值对象。当前值必须是无符号数据类型。 W_MG 还支持将值分配给数据类型 Unsigned 的特定属性，分配给共享特定组数据标记的一组对象。

Compatible data points:

  • Multistate calculated value [MCalcVal]
  • BACnet object with a specified property of data type Unsigned

参考data point objects有关 BACnet 数据点的详细说明。

 

Required properties:

  • Present value
  • Tracking value
  • State flag
  • Reliability

 

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

GrpTag

Group data tag

双字（默认值：0）

[GrpTag]定义了由XFB集中分发的特定组数据（当前值、优先级）。

系统提供预定义的标签以及用户可定义的标签。 [GrpTag] 通常由应用程序开发人员在 CFC 中设置，并且在运行时不得更改。必须将其设置为与 XFB 的数据类型匹配的标记。

EnWrit

Enable write

布尔值（默认值：True）

当为 True 时，[EnWrit] 允许将输入 Val 和 SetValid 写入计算值对象。

瓦尔

Value

整数（默认值：1）

由控制程序计算和分配的虚拟值，用于更新当前值。

[Val] 用于更新 Tracking value 属性，之后 BACnet 对象在内部用写入的 Tracking 值更新 Present value。

如果 [EnWrit] 为 True，则在以下情况下将写入 [Val]：

  • [Val] changes
  • [SetValid] changes
  • [RptWrit] is True

SetValid

Set valid value indication

布尔值（默认值：True）

由控制程序计算并分配的值，指示[Val]是否可靠。

如果 [EnWrit] 为 True 且满足以下任一条件，[SetValid] 映射到更新可靠性的错误代码：

  • [SetValid] changes.
  • [Val] changes.
  • [RptWrit] is True.

1（正确）

可靠性错误代码0（无故障）

0（假）

可靠性错误代码 7（不可靠 - 其他）

RptWrit

Repeat write

布尔值（默认值：False）

[RptWrit] 强制将输入 [Val] 和 [SetValid] 写入数据点。只要 [RptWrit] 为 True，每个程序周期都会重复写入操作。

[RptWrit]通常由控制程序计算和设置。

Note:
不得通过连接到始终为 True 的块输出来强制将 [RptWrit] 永久设置为 True。这样做会导致高水平的通信流量。

1（正确）

如果 [EnWrit] 为 True，只要 [RptWrit] 为 True，[Val] 和 [SetValid] 就会在每个程序周期写入数据点。

0（假）
默认

无动作

 

Pin description (outputs)

ErrWrit

Error while writing

整数（默认值：20）

访问或写入组管理器对象期间遇到的错误的错误代码值。

无法指示向组成员成功分发命令。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.
