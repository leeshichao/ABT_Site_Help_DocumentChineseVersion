为上传的数据创建报告

使用此过程为上传的数据创建报告。

Create a report for uploaded date

  1. Open Startup > Export.
  2. Select the Uploaded data reports tab.
  3. In Select report, select the desired report.
  4. Select the desired device.
  5. Click Create uploaded data reports.
  6. The report displays in the Reports component.

您可以打印、复印、导出报告等。
