PID_CTR: PID controller

PID_CTR (FB414) 块是通用的PID controller（P、PI、PD 或 PID），具有外部跟踪。它提供调节操纵变量。 PID_CTR_SiUn (FB414)、PID_CTRUsUn (FB792)

块 PID_CTR 还有助于创建顺序控制器和顺序级联控制器。

  • Sequence controller: One PID-CTR per sequence controller element; possibly one SEQLINK block.
  • Sequence cascade controller: One PID-CTR per sequence controller element; additional CAS_CTR and possibly one SEQLINK block.

顺序控制器的控制响应对于每个顺序控制器元件是不同的或者对于所有顺序控制器元件是相同的。 PID_CTR_SiUn (FB414)、PID_CTR_UsUn (FB792)

 

的功能P, PI, PD, PID controllers

该块具有以下集成功能：

  • Adjustable P, PI, PID, PD, or 2-point controller response.
  • Adjustable gain, integral action time, and derivative action time.
  • The gain factor for controller gain can be interconnected.
  • Adjustable neutral zone.
  • Selectable direction of control action (direct acting/reverse acting).
  • Adjustable runtime for the manipulated variable (0 100%, 100 0%).
  • Manipulated variable can be limited to min/max.
  • Invertible manipulated variable.
  • Adjustable offset (for P and PD controllers).

该块控制任何受控变量，例如：

  • Temperature, temperature difference.
  • Pressure, pressure difference.
  • Velocity.
  • Absolute humidity, relative humidity.

通用 PID 控制器按如下方式控制操作变量。

如果该块用作顺序控制器中的顺序控制器元件，则它以相同的方式控制控制顺序。

Derivative action time [Tv]

Neutral zone [Nz]

中性区 [Nz] 代表控制器在设定点周围的不敏感区域。

如果控制差值的绝对和小于中性区 [Sp]-[Xctr]<[Nz]/2 的一半，则 (t1) 在控制器输出 [Yctr] 处的 7 个过程循环期间跟踪调节变量。此后 (t2)，控制器输出保持恒定，直到控制差值超出中性区。控制器输出再次接管计算的调节变量 (t3)。

Control action [Actg]

[Actg] 确定操纵变量和控制变量之间的关系。

直接作用：如果实际值[Xctr]increases，控制器输出值[Yctr]increases，例如降温、除湿。

反向作用：如果实际值[Xctr]increases，控制器输出值[Yctr]decreases，例如加热、加湿。

Inversion [Inv]

[Inv] 根据以下公式反转控制器输出信号 [Yctr]： [Yctr]Inv = 100% - [Yctr]Old。

 

Limitation of the rise time [Ti0to100] or fall time [Ti100to0]

[Ti0to100]、[Ti100to0]限制操作变量[Yctr]的最大信号增加或信号减少。

 

Limitation of the controller output [YctrMin], [YctrMax]

[YctrMin]、[YctrMax] 限制控制器输出[Yctr]。对于启用的 [EnFnct] = 1 (Yes) 和非命令 [OoServ] = 0 (Off) 控制器，如果控制器 [YctrMin] ≥[YctrMax]，并且设置 [Yctr] = YctrMax 和 [CtrSta] = CntrCmd，则 [OoServ] = 1 (On) 无效。

 

External tracking [Track]

返回有效操纵变量可以提高 PI 或 PID 控制器的控制质量（例如抗饱和）。应用：跟踪。

[EnTrack] = 1 (Yes)

[Track] 作为跟踪信号进行处理。

示例：如果限制控制器直接作用于执行装置（例如最小或最大选择），则控制器的定位信号不再影响控制路径。将有效定位信号返回到跟踪输入可使控制器保持当前值，并保证在限制控制器不再干预时持续进行调制控制。

[EnTrack] = 0 (No)

[Yctr]被处理为跟踪信号。

如果为序列的控制器元件设置了外部跟踪，则必须确保可以达到设置的极限值 [YctrMin] 和 [YctrMax]。否则，只有在发生高控制错误时，顺序控制器才能切换到下一个顺序控制器元件。作为外部跟踪的替代方案，在限制应用的情况下可以直接影响限制值 [YctrMin] 和 [YctrMax]。

Two-point controller (CtrMod=2-position, Hys).

如果 CtrMod = 2 位，则控制器表现出两点行为。

开关差等于迟滞 [Hys]。

控制动作[Actg]的方向决定切换过程。

下一个较低或下一个较高的序列控制器元件在[Sp]+/-[Hys]处切换。

 

P/PD controllers

如果 [Tn] = 0，控制器表现出 P 或 PD 控制行为。

Controller output offset [YctrOfs].

[YctrOfs] 添加到控制器输出 [Yctr]。这会移动 P/PD 控制器的 P 范围，以便控制器在设定点 [Sp] 处输出 [Yctr] = [YctrOfs]。因此，在工作点处控制恒定负载。

 

PID 顺序控制器的功能

如果使用多个聚合来根据预定义的控制序列来控制受控值，则使用序列控制器。序列控制器根据控制序列切换各个序列控制器元件，并在跨所有序列控制器元件或集合体的相互关联的控制行为中协调对各个控制器元件的控制。

顺序控制器的功能包括所有相互影响的过程：

  • Enabling or disabling a sequence controller
  • Control process of the sequence controller
  • Enabling/disabling/commanding an individual sequence controller element
  • Control process of the individual sequence controller elements. The control process corresponds to that of a universal PID controller. Functioning of P, PI, PD, PID controllers

Enabling or disabling a sequence controller

通过禁用 [EnFnct] = 0（否）或命令 [OoServ] = 1（打开）所有顺序控制器元件来禁用顺序控制器。如果随后通过正确参数化的控制操作（[EnFnct] = 1（是）和 [OoServ] = 0（关闭））启用顺序控制器元件的选择，则在该选择中启动顺序控制器元件：控制过程从启用的选择中最接近控制操作转换的顺序控制器元件开始，并且包含由当前实际值和设定点确定的相应情况的控制操作。

如果顺序控制过程由特定的顺序控制器元件启动，则相应的顺序控制器元件必须先于所有其他元件启动；否则，使用上述过程。

Control process of the sequence controller

顺序控制器通过控制器令牌切换各个顺序控制器元件的控制。除了控制器令牌之外，还需要协调序列控制器元件的控制的其他信号。相关信号通过引脚 [ToLower] 和 [FmHigher] 以及引脚 [FmLower] 和 [ToHigher] 进行交换。

工程 – PID 顺序控制器

顺序控制器是通过互连 PID_CTR 块（顺序控制器元件）并对其进行参数化而形成的。顺序控制器的功能是自动生成的（通过信息通道）。各个聚合的顺序由 PID_CTR 块的互连顺序确定。

工程包括以下步骤：

Step

Procedure

1

确定顺序控制器元件的顺序

2

互连顺序控制器元件

3

对顺序控制器元件进行参数化

  • Parameterizing the control behavior (analogous to the PID controller).
  • If all sequence controller elements are parameterized the same, the entire sequence controller responds like one single controller.
  • Parameterizing the sequence controller element' control action
  • Parameterizing setpoints and an energy-free zone

4

设置/tuning顺序控制器

Determining the order of the sequence controller elements

通常，顺序控制器由单独的 PID_CTR 块组成。每个 PID_CTR 充当聚合的序列控制器元素。

PID_CTR 块的互连顺序（从低到高）对应于顺序控制器的控制顺序 (1..n) 的顺序。在互连 [PID_CTR] 时，必须相应地考虑计划的操作范围（例如加热）和开关顺序。

例如聚合：1 = 风门、2 = 预热器、3 = 再热器、4 = 冷却器。

加热控制顺序：1 ---> 2 ---> 3。

冷却控制顺序：4 ---> ....

  • The lowest sequence controller element corresponds to control sequence 1, the highest to control sequence n.
  • The lowest sequence controller element controls an aggregate using reverse action (if available).

Interconnecting sequence controller elements

有两种方法可以将 PID_CTR 块与顺序控制器互连：

1.) Direct interconnection

各个 PID_CTR 块彼此互连。

在引脚 [ToLower] 和 [FmHigher] 以及引脚 [FmLower] 和 [ToHigher] 之间进行互连。

如果 PID_CTR 块位于同一图表上，则使用这种类型的互连。

2.) Interconnection to SEQLINK

各个 PID_CTR 块通过 SEQLINK 块互连。

互连发生在 PID_CTR 块的引脚和 SEQLINK 块上的某个位置之间。 PID_CTR 的序列必须与位置的顺序匹配。但是，SEQLINK 上可能有免费位置。多个 SEQLINKs 可以串联互连。

如果 PID_CTR 块位于不同的图表上，或者单个顺序控制器元件或聚合可能无法互连（CAS 库），则使用这种类型的互连。

Important:顺序控制器元件必须根据互连进行参数化。

引脚 [ToLower] 和 [FmHigher]、[FmLower] 和 [ToHigher] 仅在顺序控制器上互连。在这种情况下，传输以下信息：

Parameterizing the sequence controller element' control action

设定的操作范围（例如加热、冷却）决定了顺序控制器元件的控制动作 [Actg] 的方向。运行期间可以切换控制动作方向（例如能量回收）。如果聚合控制需要反转信号，控制器输出 [Yctr] 的反转 [Inv] 有助于解决此问题。

在顺序控制器中，控制动作的方向必须具有以下响应：

  • The first or lowest sequence controller elements have reverse direction for control action [Actg] = 1 (Reverse).
  • The last or highest sequence controller elements have direct direction of control action [Actg] = Direct.
  • A sequence controller element with changing direction of control action (e.g. energy recovery) can only be in between.

偏差会产生误差信号 [ErSta] = 1（是）。故障排除

Parameterizing setpoints and an energy-free zone

在顺序控制器中，顺序控制器元件 (1...n) 的设定值 [Sp] 必须单调增加：

[Sp]1≤ [Sp]2≤ [Sp]3≤ ... ≤ [Sp]n

如果具有相同控制作用方向的控制序列具有相同的设定点，则可以确保从一个控制序列转换到另一控制序列时的调节控制。

无能量区域由控制动作方向转换时的设定点（例如加热设定点、冷却设定点）定义。

 

应用

应用 PID_CTR 块的各个功能的注意事项：

  • PID controller, PID sequence controller
  • Neutral zone [Nz]
  • Gain factor [GainFac]
  • Positioning time of the plant
  • Tracking [Track]
  • Inverting the controller output [Inv]
  • Controller output offset [YctrOfs].
  • Reset PID controller, PID sequence controller

PID controller.

带跟踪输入的 PID 控制器代表用于通风、供暖和空调设备的通用控制器。它用于控制任何受控变量，例如用于以下应用：

  • Control with special limitations.
  • Control of actuating devices with significant dynamic, e.g., actuating motors with position feedback signal.

PID sequence controller

PID 顺序控制器主要用于通风和空调设备中以控制温度和湿度。空气状态是通过几个设备元件的顺序控制和切换程序来达到的，其中每个受控变量（温度、湿度）都需要自己的顺序控制器。

一般的侧面应用，例如供热设备也是可能的。

Neutral zone [Nz]

中性区用于在达到工作点后减少控制命令。通过很小的控制差异，输出信号保持恒定。

Gain factor [GainFac]

控制增益可在运行期间通过增益系数 [GainFac] 进行更改。例如，这对于控制室外空气风门的能量回收顺序控制很有意义，因为风门的位置取决于室外空气温度。

Inverting the controller output [Inv]

对于顺序控制器，控制器输出信号可以反转，而不影响控制动作的方向。例如，如果控制序列中的序列控制器元件必须通过直接动作进行参数化（由于操作序列），但设备期望反向定位信号。

Positioning time of the plant

定位信号的最大上升时间或下降时间可以根据设备进行调整，例如执行器打开时的运行时间或阀门打开时的定位时间。这提高了控制质量。

Controller output for offset.

控制器的偏移输出允许为 P 和 PD 控制器设置恒定负载下的工作点。对于 PI 和 PID 控制器，积分器值在启动期间使用偏移值进行初始化（操作模式“关闭”> 操作模式“打开”的转换）。

Tracking

跟踪用于提高控制质量（例如抗饱和），例如在以下情况下：

  • If a limitation controller acts directly on the actuating device (e.g., minim or maximum selection), the positioning signal of the controller no longer influences the control path. Returning the effective positioning signal to the tracking input keeps the controller on the present values and guarantees continued, modulating control when the limitation controller no longer intervenes.
  • If an actuator has a position feedback signal, the signal can be sent directly to the controller on the tracking input.
  • Within the sequence, external tracking must not be used for limitation applications (e.g. use of limitation controllers). As an alternative to external tracking, the limit values [YctrMin] and [YctrMax] can be influenced directly in the case of limitation applications.

过程响应

在控制器初始化期间，控制器输出设置为值 YctrMin。初始化完成后，该功能停止约3个周期。这抵消了不利的处理顺序。然后，通过利用输入处的值来执行该功能。

在序列控制器中，每个单独的序列控制元件被单独初始化，使得控制器令牌仅在几个周期之后到达正确的序列控制器元件并且控制可用。

故障排除

The direction of control action is parameterized incorrectly

在一个序列内，从最低序列控制器元件到最高序列控制器元件的控制动作只能改变一次，并且只能从反向作用改变为正作用。如果不满足此要求，即如果控制动作参数化不正确，则错误的控制序列将被停用，并释放下一个有效的控制序列。错误参数化的顺序控制器元件设置 [ErSta] = 1（是）。

冷却顺序中的加热元件。

停用的顺序控制器元件具有反向控制作用。
