从另一个建筑元素复制设备

您可以通过拖放来复制建筑结构内的设备。

拖动设备时按住[Ctrl]键，否则设备将在建筑结构内移动。当设备掉落时Add devices对话框打开。不支持多选。

复制设备时，源设备的实例数据、I/O 分配和分配数据将复制到新创建的设备中。

Copy a device from another building element

  1. Select a device.
  2. Press the [Ctrl] key, and drag the device to the new location.
  3. The Add devices dialog box opens.
    Add devices (Dialog box)
  4. In the Number of new devices field, type the number of devices to be created.
  5. The table is updated automatically and shows the entered number of devices.
  6. Enter the details such as network address, equipment ID etc.
    Add devices (Dialog box)
  7. Click OK.
  1. The new devices are added to your project and to your building structure.
