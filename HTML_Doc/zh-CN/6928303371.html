加热/cooling状态确定(HCStaDtr11)

Overview

应用功能》Heating/cooling state determination 11" (HCStaDtr11) 确定 HVAC 控件当前是否正在加热或冷却或两者都没有，并在 BACnet 对象中提供此信息。
此外，它还确保加热和冷却之间的最小切换延迟（转换延迟）。

Function

Input:
AF 将室温与当前设定值进行比较，并检查 PID 控制器是否主动控制设备。


Output:
加热/cooling 状态 (HCSta) 供以下 AFs 使用：RThLd11、ROpUn11（作为 BACnet 对象）和 SpTR11（作为内部连接）。此外，它还提供释放加热和释放冷却信号（作为内部连接）以启用加热和冷却室温控制序列。


Configuration:
切换点可以移动，并且可以配置时间延迟以平滑切换。
