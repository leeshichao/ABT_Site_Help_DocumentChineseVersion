[R_AG] 读取模拟组

功能块 R_AG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续采集组数据（当前值/status 标志对）。

R_AG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续获取组数据（当前值/status 标志对）。此外，组管理器对象还会触发一个已配置的评估函数来计算结果值。 R_AG 以预先配置的时间间隔定期读取评估结果。读取也可以由外部源触发。

R_AG can be configured to supply multiple (up to five) evaluated, resulting values based on the selectable evaluation functions. At least one evaluation function must be configured.

专有对象对于分组基础结构是必需的：组管理器对象和一个或多个组成员对象。各个数据点通过组成员对象进行分组和引用，并且数据由组成员对象获取并转发到组管理器对象。

Functioning

Compatible data points:

  • Analog inputs [AI]
  • Analog output [AO]
  • Analog calculated value [ACalcVal]
  • Analog configuration value [ACnfVal]
  • Analog process value [APrcVal]

Required property from grouped data points:

  • Present value
  • Status flag

取值范围

Interval

Read interval

可配置的轮询时间，指定读取计算结果的频率。
值 0 禁用计时器。在这种情况下，可以使用 [ImpRead] 从外部源触发评估结果的读取。
[UpdInd] 使用属性更新计数（如果可用）。这允许在新值等于先前值时检测值是否已更新。在没有更新计数的对象中，如果发生更改，[UpdInd] 将更改为属性当前值。

时间

15s_0ms

ImpRead

Impulse for read

可连接引脚，允许外部源提供数字脉冲来启动读取。
由于[ImpRead]可以互连，因此可以同步多个功能块的读数以在图表中进行采集。
Note
如果[Interval] = -1s，则禁用[ImpRead]。

布尔值

0

EvlFnct1…EvlFnct5

Evaluation function 1…Evaluation function 5

[EvlFnct1] 确定对来自具有公共 [GrpTag] 的已获取组数据的有效当前值执行的过程类型。
[EvlFnct1] 属于五个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX]、[ValMaxX] 和 [ValNumX]。通常，应用工程师在编程编辑器中设置它，并且在运行时不能更改。
如果未配置，[EvlFnct1] 默认设置为 MaxInt。在这种情况下，评估功能被禁用并且 [Dstb1] = 1。

[EvlFnct2]...[EvlFnct5] 的功能与 [EvlFnct1] 相同。

整数

32767

计算总和。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
2: Average
计算平均值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
3: Minimum
选择最小值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
4: Maximum
选择最大值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
5: Count of values(COUNTOFVAL)
有效值的数量，范围为 [ValMin1] 到 [ValMax1]。结果在输出 [Cnt1] 处提供。
8: Average, lowest values(AVERAGEMIN)
可定义数量 [ValNum1] 的最小有效值的平均值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
9: Average, highest values(AVERAGEMAX)
可定义数量 [ValNum1] 的最大有效值的平均值。它适用于 [ValMin1] 到 [ValMax1] 范围内的值。
10: Last updated
在有效值中搜索最后更新的值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。

ValMax1…ValMax5

Maximum value 1…Maximum value 5

评估函数的可选可配置参数，为具有公共 [GrpTag] 的采集组数据值设置上限。
[ValMax1] 属于五个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX]、[ValMaxX] 和 [ValNumX]。

  • [ValMax1] must be greater than [ValMin1].
  • If [ValMax1] and [ValMin1] remain when specifying default values, the acquired group data has no high or low limits and everything is considered as within the range.
  • [ValMax1] cannot be changed during runtime.

[ValMax2]...[ValMax5] 的功能与 [VaIMax1] 相同。

评估函数的可选可配置参数，为具有公共 [GrpTag] 的采集组数据值设置下限。
[ValMin1] 属于五个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX]、[ValMaxX] 和 [ValNumX]。

ValNum1…ValNum5

Number of values 1…Number of values 5

可配置参数与评估功能引脚 [EvlFnct1] 的选项 8 和 9（AVERAGEMIN 和 AVERAGEMAX）一起使用。
[ValNum1] 表示要在特定范围 [ValMin1]…[ValMax1] 内评估的值的数量。
[ValNum1] 属于五个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX]、[ValMaxX] 和 [ValNumX]。
[ValNum1] 支持选定的值 1…30。规格 4 是根据经验选择的，以实现可靠的运行结果。
如果有效值的数量在 [ValMin1]...[ValMax1] 范围内且小于 [ValNum1]，则评估函数将处理该范围内的可用有效值。
通常，应用工程师在编程编辑器中设置 [ValNum1]，并且在运行时无法更改。
Note
[ValNum2]...[ValNum5] 的功能与 [VaINum1] 相同。

输出

描述

数据类型

Val1...Val5

Value 1...Value 5

真实的

0.0

基于 [EvlFnct1] 中选择的评估函数评估的结果值。

[Val1] 是根据 [ValNum1] 以及基于 [ValMin1] 和 [ValMax1] 的范围进行处理的结果。

[Val1] 属于五个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。

[Val1] 显示：

  • 0.0, if no present values in the acquired group data for the given [GrpTag] were valid. [Dstb1] = 1.
  • 0.0, if [EvlFnct1] remains on the default value. [Dstb1] = 1.
  • The last valid value if [Dstb1] is 0.

[Val2]...[Val5] 的功能与 [Val1] 相同。

Cnt1…Cnt5

Count 1…Count 5

整数

0

基于 [EvlFnct1] 中选择的 CountOfVal 评估函数计算的结果值。

[Cnt1] 属于五个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。
[Cnt1] 提供：

  • The number of valid, present values from the range [ValMin1] to [ValMax1].
  • 0, if no present values in the acquired group data for the given [GrpTag] were valid. [Dstb1] = 1.
  • The last valid value if no valid, present values in the acquired group data of the given [GrpTag] exist or match the optional, configured range [ValMin1] to [ValMax1]. [Dstb1] = 1.

[Cnt2]...[Cnt5] 的功能与 [Cnt1] 相同。

Dstb1...Dstb5

Disturbance 1...Disturbance 5

[Dstb1]表示在[EvlFnct1]上选择的评估结果是否有效。
[Dstb1] 属于五个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。
如果获取的组数据中至少有一个值有效，则 [Dstb1] = 0。
如果获取的组数据中没有有效值，则 [Dstb1] = 1。
[Dstb2]...[Dstb5] 的功能与 [Dstb1] 相同。

布尔值

0

UpdInd1...UpdInd5

Update indication 1...Update indication 5

布尔值

0

[UpdInd] 表示评估中的至少一个当前值已更新为新值或相同值。如果更新的值位于配置的 ValMin/ValMax 范围内，则 [UpdInd] 仅设置为 1。

仅当 [Dstb1] = 0 时，[UpdInd1] 才设置为 1。

[UpdInd1]...[UpdInd5] 的功能与 [UpdInd1] 相同。

Note
UpdInd 不支持评估函数“CountOfVal”。
