添加多个设备

您可以通过智能复制和粘贴添加多个设备。您需要 Microsoft Excel 来执行智能复制和粘贴。

如果手动添加 IP 地址，请设置DHCPcolumn in Excel toFALSE.

Add devices

  1. A building structure is defined.
  1. In Building > Building structure, right-click a building or building element and select Add devices.
  2. The Add devices window opens.
  3. Select a device
  4. Click Next.
  5. Select Grid view.
  6. Click Smart copy.
  7. The data has been copied to the clipboard.
  8. Open Microsoft Excel.
  9. Paste the date in a Microsoft Excel worksheet.
  10. Add more devices using copy and paste in the worksheet, and edit the values.
  11. Select the whole table including the headline.
  12. Go to the Add devices window, and click Smart paste.
