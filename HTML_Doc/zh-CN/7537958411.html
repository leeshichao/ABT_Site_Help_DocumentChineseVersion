应用保存的 I/O 分配

房间的各个 I/O 分配可以保存在房间的“详细信息”窗格中，在I/O assignment选项卡。
I/O assignment (Details pane)

在Template视图中，您可以应用以前保存的 I/O 分配，也可以将 I/O 分配重置为应用程序模板的默认 I/O 分配。

要打开Template视图，选择一个房间，然后在“详细信息”窗格中打开I/O assignment.

 

Apply a saved I/O assignment

  1. An I/O assignment is saved in the Custom view.
  1. In the Details pane of a room, open the I/O assignment tab.
  2. (Optional) Click Clear all assignments, in order to clear all I/O assignments.
  3. Select a previously saved I/O assignment from the table.
  4. Click Apply.
  1. The selected I/O assignment is applied.

您可以在以下位置查看已保存的 I/O 作业模板列表：Settings > I/O assignment templates.

I/O assignment templates

Apply the default I/O assignment of the application template

  • Click Reset to application template.
  1. The default I/O assignment of the application template is applied.

您可以更改应用程序模板的默认 I/O 分配Configuration > I/O assignment.
