存储数量

最多提供10个DIFEs，存储编号有41位。 20 位用于资费，10 位用于电表子单位。没有任何应用可以全部使用如此巨大的位数。

 

DIB fields in preset mode

DIB 字段（例如功能、存储编号、费率和子单元）被建模为虚拟属性，并可视化为单独的用户界面元素。

验证：

  • Storage Number: Max. 41 bits -> Max. value = 2199023255552
  • Tariff: Max. 20 bits -> Max. value = 1048576
  • Subunit: Max. 10 bits -> Max. value = 1,024

根据在这些虚拟属性中输入的值，计算容纳该值所需的位数，并据此调整 DIFE 的数量（添加 /removed）。
