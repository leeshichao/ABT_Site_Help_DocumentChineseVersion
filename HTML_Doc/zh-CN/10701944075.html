COV increment field bus ✳

 

 

"COV increment field bus”定义了将导致 Modbus 上的数据点更新消息的“当前值”的最小变化。

Heartbeat timers ✳

 

 

"Heartbeat timers”定义了如果“当前值”长时间没有变化，则用于更新子系统特定数据点的心跳计时器。

H1、H2 的间隔值可以在现场总线管理对象中配置。
心跳计时器独立于 COV 触发的更新。
心跳定时器和轮询定时器是相互独立的。

没有任何

没有更新子系统特定的数据点。

H1

最高优先级。典型间隔值：5s…60s。

H2

低优先级。典型间隔值：分钟...小时。

Min repetition time ✳

 

 

"Min repetition time“定义了 Modbus 数据点的两次连续更新之间的最短等待时间。

"Min repetition time”用于在“当前值”变化过大的情况下限制网络流量。

"Min repetition time" 可以为零以允许快速更新 MODBUS 数据点。

Process value 1和Process value 2Output value 1和Output value 2 ✳

 

 

"Process value 1“（X1），”Process value 2“（X2），”Output value 1“（Y1）和”Output value 2" (Y2) 用于计算线性函数 (f)。需要线性函数来计算过程值中的输出值。

范围：-3.402822E+38...3.402822E+38
单位：取决于为输出对象选择的工程单位。
