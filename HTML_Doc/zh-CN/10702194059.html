Bit-Offset ✳

 

 

"Bit-Offset“定义读取数据位集（线圈、离散输入）时的偏移量。这允许支持数据点地址的大规模操作/correction。

-1

 

0

 

100

 

Number of bits ✳

 

 

"Number of bits" 定义位集的大小（无符号）。

范围：2…16； 16:=U16-B 和 U16-L

Mapping table ✳

 

 

"Mapping table” 定义“当前值”到子系统特定位集数据的映射，该数据对应于“的数组索引”Mapping table”.映射表

实际长度的约束：
映射表、状态数和状态文本需要相同的长度。

例子：
当前值=1 => 映射表[1]:=0x0000 => 0x0000
当前值=2 => 映射表[2]:=0x0001 => 0x0001
