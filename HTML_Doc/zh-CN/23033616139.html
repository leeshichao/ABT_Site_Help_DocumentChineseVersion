循环对象

二元循环对象包含控制器的 BACnet 属性。

Naming

“名称”、“描述”和“命名扩展”之间存在依赖关系。对其中一项属性的任何更改都会影响其他两项属性。

笔记：
通过输入项目特定的文本可以消除依赖性。

示例1：
如果选择“AQualCtr”作为预配置的“描述”，则“AQualCtr”设置为“名称”，选择“有功能量”。如果选择“Abs”作为“命名扩展”的补充，则描述将由“（绝对）”补充为“送风IAQ控制器（绝对）”，并且名称变为“AQualCtr（Abs）”。该名称还构成对象名称的最后一个元素。

示例2：
如果选择“房间温度控制器”作为预配置的“描述”，“TRCtr”将设置为“名称”。除了“命名扩展”之外，输入“01”（项目特定文本）会生成“名称”“TRCtr(01)”。该名称还构成对象名称的最后一个元素。

Name

 

 

'Name' 是特定于实例的名称。它用于设置层次对象名称。

财产ID：4438

Description

 

 

'Description' 描述了一个 BACnet 对象。 “描述”是一个可翻译的字符串，在内部保存为文本引用或直接保存为字符串。

财产ID：28

Name extension

 

 

'Name extension' 是名称的可选扩展名。它唯一地标识一个对象或区分对象。

财产ID：4437

Note
文本目录中的名称也可用于“命名扩展”。

Alarming

警报是根据 BACnet 对象内的内部报告原则实现的。

选择“属性”选项卡添加扩展，在“启用事件”字段中选择“是”。设置所需的 BACnet 属性显示在 ABT 站点和编程编辑器的“属性”选项卡下。
Alarming

启用事件

 

 

“启用事件”启用警报功能。显示设置函数所需的 BACnet 属性。

要设置“是”，请将“具有事件配置的扩展”设置设置为“固有事件注册”。

财产ID：35

Limit value for error

 

 

'Limit value for error' 表示为“浮动限制”事件算法提供给事件通知的错误限制。当监测值与设定点的差异超过所提供的差异限制时，“浮动限制”事件算法会显示事件。

财产ID：34

Hysteresis to normal

 

 

'Hysteresis to normal' 确定当返回低于或高于极限值的正常范围时，值必须保持的最小差异。有两种分类：

“Hysteresis On”和“Hysteresis Off”定义了分级控制器或 2 位 PID 控制器的差异，可以在线修改。
它用于以下情况：

  • Controller-Type = Staged
  • Controller-Type = PID
  • Controller-Mode = 2-position

默认值为 0.5。

“迟滞开启”的属性 ID：4854

“滞后关闭”的属性 ID：4853

财产ID：25

Monitoring time deviation

 

 

'Monitoring time deviation' 确定以 [s] 为单位的时间，在此期间必须超过极限值，然后才会触发“To-offnormal”。

财产ID：113

Monitoring time deviation to normal

 

 

'Monitoring time deviation to normal' 确定以 [s] 为单位的时间，在此期间，在触发“To-offnormal”事件之前返回到正常范围时必须保持限制值加上“正常滞后”。

财产ID：356

Notification class

 

 

'Notification class' 确定事件的优先级以及事件是否必须被确认或重置。以下是通知类：
1: Highest priority notification (acknowledge, reset)
2: Highest priority notification (acknowledge)
3: Highest priority notification
4: High priority notification (acknowledge, reset)
5: High priority notification (acknowledge)
6: High priority notification
7: Medium priority notification (acknowledge, reset)
8: Medium priority notification (acknowledge)
9: Medium priority notification
10: Low priority notification (acknowledge, reset)
11: Low priority notification (acknowledge)
12: Low priority notification
13: Lowest priority notification (acknowledge, reset)
14: Lowest priority notification (acknowledge)
15: Lowest priority notification
16: None priority notification
17: Buffer ready notification
18: Device alert notification

财产ID：17

Enable event detection

 

 

'Enable event detection' 启用事件检测。 “事件状态”始终为“正常”，设置为“否”。

财产ID：353

Suppress event detection

 

 

'Suppress event detection' 确定事件检测是否被抑制。
否：没有压制。事件被识别。
是：抑制事件检测。事件检测（OffNormal 事件）的算法被抑制。

财产ID：354

Suppress event notification

 

 

'Suppress event notification' 确定是否抑制事件通知。
否：没有压制。事件已被报道。
是：抑制事件通知。 “启用事件”的所有 3 位均设置为“False”。激活后，将使用通知类别 18：设备警报通知发送最后一个事件，以便收件人了解抑制并相应地显示。

财产ID：4972

Trend

趋势是一个单独的 BACnet 对象（Trendlog 对象）。然而，它在 ABT 站点和编程编辑器中并未描述为单独的 BACnet 对象，而是描述为 BACnet 对象的趋势函数。

启用趋势

 

 

“启用趋势”启用趋势功能。类型为 TRENDLOG 的新 BACnet 对象被实例化，自动连接到所选对象的属性“当前值”，并且设置所需的 BACnet 属性显示在“属性”选项卡中。
是：趋势功能启用。
否：趋势功能被禁用。

Enable logging

 

 

'Enable logging' 启用趋势记录。数据点的记录从开始日期和到达开始时间开始。
是：日志记录已启用。
否：日志记录已禁用。

如果达到停止日期和停止时间或缓冲区已满（如果已设置），趋势记录就会停止。

默认情况下未定义开始日期和开始时间（通配符）。换句话说，设置“启用日志记录”=“是”会立即开始趋势分析。

财产ID：133

Logging Type

 

 

'Logging Type' 确定何时对数据点进行趋势分析。
轮询：对象值按照“记录间隔”设置中输入的间隔持续趋势化。
已触发：激活触发器后，对象值会呈现趋势。
COV（值更改）：每次值更改都会记录新值（“COV”）。

财产ID：197

Logging interval

 

 

'Logging interval' 确定记录值的时间间隔（周期）。通过将“日志记录类型”设置为“轮询”，该设置才会生效。

财产ID：134

Stop when full

 

 

'Stop when full' 确定缓冲区已满时是否停止趋势记录。
是：一旦缓冲区已满，记录就会停止。
否：即使缓冲区已满，记录也会继续。新值将覆盖最旧的值（先进先出）。

财产ID：144

Buffer size

 

 

'Buffer size' 确定可以保存到缓冲区的最大值数。设置“如果已满则停止”确定缓冲区已满时如何继续。

Note
仅当“启用日志记录”为“否”时，才能更改属性“缓冲区大小”。

属性“缓冲区大小”的值必须大于或等于属性“通知阈值”的值。

财产ID：126

Notification threshold

 

 

'Notification threshold' 确定缓冲区何时发送检索数据的请求。

一旦达到设定的数据条目数，就会发送事件通知，以便管理站检索数据。检索后数据点将从缓冲区中删除。

财产ID：137

Other

Neutral zone

 

 

'Neutral zone' 定义控制器在设定点周围的不敏感区域。

如果控制差值的绝对和小于中性区的一半（设定值 - 控制器输入 < 中性区/2），则在 7 个过程循环期间在控制器输出（当前值）处跟踪调节变量。此后，控制器输出保持恒定，直到控制差超出中性区。控制器输出再次接管计算出的操纵变量。

控制器类型 = staged 时不使用中立区。

单位差值显示中性区的工程单位。

Gain

 

 

"Gain" 定义回路使用的比例增益参数。该属性是在工程期间设置的。该属性不用于分级控制器。

Units for gain

 

 

"Units for gain“表示该房产的工程单位”Gain”。该属性是在工程期间设置的。

Integral action time Tn

 

 

"Integral action time Tn" 定义环路使用的积分增益参数。该属性是在工程期间设置的。该属性不用于分级控制器。

Units for integral action time

 

 

"Units for integral action time“表示工程单位”Integral action time Tn如果控制器类型 = staged，则不使用积分常数单位。

Derivative action-time Tv

 

 

"Derivative action-time Tv" 定义循环使用的微分增益参数。该属性是在工程期间设置的。该属性不用于分级控制器。

Units for derivative action-time ✳

 

 

"Units for derivative action-time“表示该房产的工程单位”Derivative action-time Tv".

如果 Controller-Type = staged，则不会使用 Derivative-Constant-Units

环路控制逻辑使用该属性来防止逻辑控制超出受控设备的范围并防止积分饱和。该属性是在工程期间设置的。

该物业“Units for controller output“表示工程单位”Controller output" (Present value).

Controller output minimum

 

 

"Controller output minimum“指定”的最小值Controller output" (Present value） 财产。

环路控制逻辑使用该属性来防止逻辑控制超出受控设备的范围并防止积分饱和。

该物业“Units for controller output“表示工程单位”Controller output" (Present value).

Rise time from 0 to 100%

 

 

'Rise time from 0 to 100%' 定义信号从 0 [%] 变化到 100 [%] 所需的时间 [1/10 s]。该时间应与执行器的运行时间相匹配。

财产ID：4996

Fall time from 100 to 0%

 

 

'Fall time from 100 to 0%' 定义信号从 100 [%] 变为 0 [%] 所需的时间 [1/10 s]。该时间应与执行器的运行时间相匹配。

财产ID：4995
