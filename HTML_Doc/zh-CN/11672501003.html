Airflow Control Loop

调节流量控制回路以将测量的空气流量驱动到设定点。性能是根据速度和稳定性来定义的。对于关键的通风系统，所需的操作通常是阶跃响应，几乎没有超调。对速度的期望和要求各不相同。设计并调整控制回路以满足期望。

这意味着您需要知道预期的性能。阅读项目规范、验收测试说明。与客户交谈。找出他们需要什么。如有必要，请撰写正式的信息请求。

除了在单个流量控制回路中实现所需的速度和稳定性之外，可能还需要匹配房间中各个流量回路的特性。在加压室中，各个终端的空气流量是协调的。当某一终端的流量发生变化时，控制系统会改变其他流量以保持必要的平衡。在过渡期间，流量可能会暂时失去平衡，从而影响房间增压。在某些情况下，客户会担心这种暂时的不平衡；在其他情况下则不然。

可能需要调整单独的流量回路，使它们以大致相同的速度响应，并最大限度地减少房间压力的波动。

Design consideration- 选择速度满足要求和期望的执行器。

Tuning values for damper

使用这些设置作为起点。它们应该提供已经接近最快稳定响应的流量响应。

计算起点的近似值

确定风门完全打开时的气流。 （如果与真实系统交互工作，则打开阻尼器；如果不是，则猜测一个值）

增益 = 配置的最大流量 / 风门打开时的流量

配置的最大流量 = 最大值：（最大冷却流量、最大加热流量、最大通风流量、标称流量）

（替代方法，如果流量@打开阻尼器太高而无法读取或太高而无法进行实际调整

find damper setting where flow is approximately equal to Max flow (or Nominal flow if Nominal is more than max)

增益=阻尼器@最大流量/100

或增益 = 阻尼器 @ 标称流量 / 100（如果标称流量大于最大流量）

计算 Tn = 执行器行程时间 / 2

设置 Trise 和 Tfall = 执行器冲程时间

中性区 = 最小流量时的相对流量设定值 / 20

（如果最小流量非常低或为零，则此方法不起作用。尝试最大流量/100）

Additional tuning hints

  • If you see good response for small flow changes but overshoot on large steps, increase the Rise and Fall times for the actuator. Repeat the step flow changes and observe the new response.
  • If you are unable to meet performance expectations, rethink what might be wrong. Here are some things to consider:
    - Actuator speed – is the actuator being used the right one for the job.
    - PID controller parameters – check PID settings to make sure nothing is overlooked.
    - Airflow control loop – is there too much delay in the flow sensing system. Some flow sensors have a time constant of several seconds, and there is also a noise filter in the flow control AF (CetVavSu xx). Either of these can limit the speed of the airflow control loop. Check the value of the noise filter in the flow control AF. Values larger than zero for TiConAirFl (Time constant for air volume flow) will slow the sensor response.

Face velocity control loop

调整面速度控制环路以将面速度传感器指示的值驱动至设定点。性能是根据速度和稳定性来定义的。对窗扇运动的期望响应通常是快速的，但超调量很小。对速度的期望和要求各不相同。设计并调整控制回路以满足期望。这意味着：您需要知道预期的性能。阅读项目规范、验收测试说明。与客户交谈。查出。

与流量控制环路相比，面速度环路的响应速度较慢。

Design issues
该环路与排气流量控制环路以级联方式工作。因此，这取决于排气流动回路的性能。如果排气流量控制回路没有正确调整，面速度回路将难以调整并且无法发挥其应有的性能。

Tuning procedure for face velocity control loop

1) 首先调整气流控制回路，遵循流量控制回路程序。手动命令流量设定值以观察性能。观察流量控制环路的大致响应时间。请注意命令设定值时达到新值大约一半所需的时间。 （在步骤3中使用）

2) 评估恒流量下测得的速度信号的稳定性。检查高、低开度。打开足够远，使速度处于预期的控制范围内（速度接近设定值）。如果测量的速度波动太大，请增加滤波器时间常数（面速度衰减滤波器AtnFltVFace在 FhSpEh13 中）。 1 到 5 秒范围内的值可能比较合适。

3) 设置 FV 循环参数的起始值：

增益 = (100% / FV 设定值) * (最小流量 / 缩放流量)

Tn = FV 过滤时间 + 流量控制循环时间

上升时间 = 执行器的行程时间

下降时间 = 执行器的行程时间

中性区 = FV 设定点 * 0.03

4) 观察并调整回路运行情况。

是还是是：

- 在固定窗扇开口处保持稳定
- 保持不同开口处的面速度（或气流限制）
- 窗扇打开时快速增加..是否存在超调
- 窗扇关闭时迅速减小..是否存在超调

您可能会发现流量设定值明显超调。不要用它来评估响应。检查实际流量和面速度传感器指示的速度。在级联控制设计中，排气流量设定值超调并返回以满足面速度控制所需水平的实际流量是正常的。

Tuning values for venturi

使用这些设置作为起点。它们应该提供已经接近最快稳定响应的流量响应。

  • Gain = flow @ open damper / 4
    (see note if flow is too high to read or too high for realistic tuning)
  • Calculate Tn = actuator stroke time / 2
  • Set Rise and Fall times = actuator stroke time
  • Neutral zone = relative flow setpoint at minimum flow / 5
    (if minimum flow is very low, or zero, minimum flow / 5 will not work; in this case try max flow / 25 )
  • Calculate flow setpoint time constant = actuator stroke time / 2

如果打开阻尼器时的流量太高而无法读取或太高而无法实际调节，请找到流量约等于最大流量或标称空气体积流量中较大者的阻尼器设置，然后按如下方式计算增益：
增益=风门@（最大流量或标称风量流量中的较大者）/100/4
将 Max__VAR_000__ 的值提高到所需值以上不会改变交付的物理流量，应用程序中表示的 __UNT_001__ 值会受到影响。
