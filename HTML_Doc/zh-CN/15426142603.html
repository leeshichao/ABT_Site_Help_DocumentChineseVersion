[CMD_BG] 命令二进制组

功能块 CMD_BG 以特定优先级将数据类型 Bool 的当前值分配给特定组数据变量的多个数据点。

CMD_BG 以特定优先级将数据类型 Bool 的当前值分配给特定组数据标签的多个数据点。

专有对象对于分组基础结构是必需的：组管理器对象和一个或多个组成员对象。各个成员数据点通过组成员对象进行分组和引用。

CMD_BG 将特定组数据标记的 value/priority 对写入组管理器对象的属性“组命令”。数据由组管理器对象转发到组成员对象，并从那里分发到具有适当组数据标签的受影响的成员数据点。

Functioning

Compatible data points:

  • Binary output [BO]
  • Binary configuration value [BCnfVal]
  • Binary process value [BPrcVal]
  • Third-party objects with the required properties

Required property of a grouped data point:

  • Present value
  • Status flag

Optional properties

  • Priority array

Operate with priorities

该功能块使用 2 种方法来控制是否按优先级运行：

1. 独占控制（计划优先级1..5、9..12、14..16）

  • Initialized at startup
    • Multiple input sets of a function block cannot command the same priority.

2. 最后胜利控制（计划优先级7、8、13）

  • Not initialized at startup.

Pins

输入

描述

数据类型

默认值
取值范围

EnIn1…EnIn4

Enable input 1…Enable input 4

[EnIn1] 确定是否以[PrioIn1] 的优先级命令[ValIn1]，或者释放优先级。
[EnIn1] 属于四个输入集之一，每个输入集包括 [ValInX]、[EnInX]、[PrioInX] 和 [RptcInX]。这些输入集用于根据需要以不同的优先级命令数据点。
[EnIn1] 可由开发人员配置或链接到图表并由控制程序在运行时计算。
[EnIn2]…[EnIn4]的功能与[EnIn1]相同。

布尔值

0

0 - 如果当前未激活，则通过将另一个 [EnInX] 设置为 1 来释放 [PrioIn1] 的优先级。
1 - 命令 [PrioIn1] 的优先级。

ValIn1…ValIn4

Value input 1…Value input 4

[PrioIn1] 处的命令值。
[ValIn1] 可由开发人员配置或链接到图表并由控制程序在运行时计算。
如果 [EnIn1] 为 1 并且 [ValIn1] 发生变化，则以 [PrioIn1] 的优先级指令 [ValIn1]。
[ValIn2]...[ValIn4] 的功能与 [ValIn1] 相同。

布尔值

0

PrioIn1…PrioIn4

Priority input 1…Priority input 4

整数

17

[PrioIn1] 属于 4 个输入集之一，并接收 [ValIn1] 附带的优先级。
[PrioIn1] 可以配置并且在运行时不能更改。值 17 表示未使用该输入。
[PrioIn2]...[PrioIn4] 的功能与 [PrioIn1] 相同。

Priority range:
1...16（请参阅稍后对优先级 6 和 8 的限制）。

Exclusive control:
优先级 1...5、9...12 和 14...16

在控制程序启动期间，功能块可以使用独占控制来初始化范围 1...5、9...12 和 14...16 中分配的优先级。

该功能块不支持运行时独占优先级控制。最后一个有效命令控制或释放优先级。

由于启动期间的独占控制，同一功能块上的两个或多个输入集不能具有共同的独占控制优先级，因为这将导致冲突。

  • Last wins:
    Priorities 7, 8, and 13
  • No initialization of priorities during startup.
  • During runtime, the last valid command controls priority.
  • If 2 or more input sets have the same priority and are commanded concurrently, only the input set with the first numeric order is performed (In1...In4).
  • If 2 or more input sets have the same priority and the same conditions for commanding and releasing are issued concurrently, the command process wins.

Prio 6:
每个 BACnet 对象至少保留命令优先级 6。 on/off 时间功能。优先级为 6 的命令会被 BACnet 对象拒绝。
对于分钟。在/off时间函数上，控制程序必须包含一个逻辑并使用另一个优先级。

Prio 8:
命令优先级 8 计划用于手动操作，并且通常在功能块上未分配。最后获胜功能允许控制程序更改或启用操作员命令。

RptcIn1…RptcIn4

Repeat command input 1…Repeat command input 4

[RptcIn1] 重复命令或释放优先级。
如果 [RptcIn1] = 1 且 [EnIn1] = 1，则功能块在每个编程周期中重复来自 [ValIn1] 的命令，优先级来自 [PrioIn1]。
如果 [RptcIn1] = 1 且 [EnIn1] = 0，则功能块在每个编程周期强制释放 [PrioIn1] 的优先级。
[RptcIn2]...[RptcIn4] 的功能与 [RptcIn1] 相同。
Note
[RptcIn1] 可能不会永久强制为 1。这可能会影响性能或网络流量。
[RptcIn1] 可以链接，通常由控制程序计算和设置。

布尔值

0

DscdcIn1…DscdcIn4

Discard command input 1…Discard command input 4

[DscdcIn1] 用于在重新启动或恢复与组成员自动化站的通信时配置重复命令 [ValIn1]。
[DscdcIn1] 可以配置，但在运行时不能更改。

布尔值

0

0 - 重新启动期间或一旦与组成员的自动化站的通信恢复后，组管理器会以优先级 [PrioIn1] 重复来自 [ValIn1] 的最后一个命令。
1 - 重新启动期间或组成员自动化站的通信恢复后，组管理器不会以优先级 [PrioIn1] 重复来自 [ValIn1] 的最后一个命令。

[DscdcIn2]...[DscdcIn4] 功能与 [DscdcIn1] 相同。
