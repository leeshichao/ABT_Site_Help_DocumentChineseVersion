连接到设备的 Web 界面

使用此过程启动已配置设备的 Web 界面。

Connect to the web interface

  1. The network interface card on the laptop is configured.
    Configuring a network connection
  2. The LAN cable from the commissioning laptop is connected to the network or USB cable is directly connected to the device.
    Connection types and network card settings
  3. If connected through the room unit, wait for the device to restart after a download (15 to 30 seconds).
  1. Select Startup > Configure and download.
  2. Select a discovered device in the Discovered devices tab.
  3. Right-click and select Go to web interface.
  4. Enter your login credentials if prompted.
    Web interface
  1. The web interface of the device displays.
