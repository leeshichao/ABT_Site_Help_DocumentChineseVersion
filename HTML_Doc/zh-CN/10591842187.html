房间增压 VAV 最小通风 (CetVavVntCtl11)

Overview

应用功能》CET room pressurization VAV ventilation control 11, minimum ventilation" (CetVavVntCtl11）与房间压力控制应用程序配合以实现通风目的。通风率是从基于房间操作模式和 HVAC 工厂模式的一组配置值中选择的。

主要特点：

根据入住情况选择通风率，通过房间运行模式和工厂模式反映出来。

  • Ventilation includes transfer air (maybe for airflow tracking instead)
  • Ventilation monitor
  • Ventilation alarm
  • Normalized airflow values
    • monitor
    • configuration
  • Rapid Ventilation – high flow rate driven by command from user or external application.

Function

AF 选择配置值之一作为房间的当前通风率。如果 HVAC 工厂模式是：

  • Comfort
  • Pre-comfort
  • Economy
  • Protection

AF 应用相应的费率。

如果 HVAC 工厂模式有任何其他状态，则 AF 根据房间运行模式和 HVAC 房间运行模式选择通风率。

在典型应用中，房间占用时间表或占用传感器驱动房间操作模式和通风率。

Normalized flow values

AF 包括每个房间操作模式下最小通风率的配置值。这些值可以用多种数字表示形式输入：

  • physical volumetric flow units (typically selected method of configuration)
  • air changes per hour (alternate method of configuration)
  • airflow volume per unit of floor area (alternate method of configuration)

用户通过设置单独的多状态配置值来指示应用哪种数字表示（RVntMinUnit）表示配置的最小流量数据的单位。该应用程序以物理流量单位计算所需的通风率，并将该数据写入计算值对象。

除了以物理流量单位表示的监测值外，AF 还计算 2 个归一化流量值以监测通气量。

  • Air changes per hour: flow rate divided by room volume. (If the configured value of room volume is zero (the default value), set the monitoring value to zero.)
  • Airflow per unit floor area: flow reate divided by floor area. (If the configured value of the floor area is zero (the default value) the application sets the monitoring value to zero.)

当通气率数据无效时，所有通气 AV 的可靠性均设置为“Unreliable_Other”。

AirFlVnt
Ventilation air volume flow (AirFlVnt) 是指通过房间稀释和去除空气污染物的气流。在负压房间中，这包括供应流和输送空气（或总排气）。在正压房间中，这只是供应流。

VntVRate
Ventilation velocity rate (VntVRate) 是每单位建筑面积气流的测量通风率。

VntAchgRate
Ventilation air change rate (VntAchgRate) 是测量的每小时换气次数的通风率。

VntAlm
Ventilation alarm (VntAlm）旨在作为建筑运营商的实时指标，并作为长期指标，随时间记录并用于验证和改进操作。

SpAirFlVnt
Ventilation air volume flow setpoint SpAirFlVnt) 基于房间运行模式的通风气流设定值。可由操作员或外部过程覆盖的过程值对象。

Engineering and commissioning

用户可以命令通风级别，其他应用程序可以通过设置 BA-Object 来覆盖它SpAirFlVnt。对象以物理流量单位表示。

计算值对象指示每个房间操作模式的最小流量。这些值以物理流量单位表示，显示基于房间体积或建筑面积的计算结果。

AirFlVnt, VntAchgRate和VntVRate用于监控。
