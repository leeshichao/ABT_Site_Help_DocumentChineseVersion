编程编辑器

在Programming编辑器为你的工厂编程。您可以从Library和Project tree到Programming编辑器并连接它们。
Working with the Programming editor

The chart

这Programming编辑器包含一张大图表。顶层的所有 I/Os 都是可见的。
Depiction and structuring of flat plants

The blocks in the chart

该图表包含块以及块之间的连接。有些块有图标并用颜色编码。
Depiction of function blocks and nested charts

Pins

块有销钉。默认情况下，并非所有引脚都可见。块底部的绿色三角形表示某些引脚被隐藏。您可以选择哪些引脚可见。
Showing and hiding pins

The data flow between the blocks

可以连接块。线条显示块之间的数据流。块之间的数据从左到右、从上到下流动。可以进行 1:n 连接。
Running sequence of function blocks
