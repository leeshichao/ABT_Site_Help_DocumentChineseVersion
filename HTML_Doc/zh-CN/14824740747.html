[CHARFNCT] 线性化特性

CHAR 功能块使用特性曲线（函数）来计算每个输入值的输出值。

CHARFNCT 功能块使用特性曲线（函数）来计算每个输入值的输出值。

该特性曲线通过输入辅助点[Xn]、[Yn]来定义。可以选择辅助点之间的插值类型：

  • Linear
  • Smooth
  • Linear inverse
  • Smooth inverse
  • Stepped
Functioning

CHARFNCT 根据参数化特性曲线 [X1]、[Y1]...[Xn]、[Yn] 和定义的插值类型 [ChlinMod] 计算相应的函数。

此函数用于计算每个输入值 [In] 的输出值 [Out]。

在辅助点定义的功能范围之外，输出值对应于第一个或最后一个辅助值。

Types of interpolation

[ChlinMod] = 1 (Linear):

该功能在辅助点[Xn]、[Yn]之间进行线性插补（直线）。

[ChlinMod] = 2 (Smooth):

该功能在辅助点[Xn]、[Yn]之间进行平滑插值（曲线）。

[ChlinMod] = 3 (Linear inverse):

[ChlinMod] 的反函数 = 线性

特性曲线不能完全单调（上升或下降、不恒定、不上升、不下降）。

[ChlinMod] = 4 (Smooth inverse):

[ChlinMod] 的反函数 = 平滑

特性曲线不能完全单调（上升或下降、不恒定、不上升、不下降）。

[ChlinMod] = 5 (Stepped):

对于输入值，点 CHARFNCT 搜索下一个较小的辅助点 [Xi] 并将其功能值 [Yi] 发送到输出。当输入值[In]小于[X1]时，发出[Y1]。步进函数以多个 [NumVldXY] 值对 [X]、[Y]（辅助点的数量）的形式给出。辅助点之间不进行插值。

Application

[ChlinMod] = 1（线性）且 [ChlinMod] = 2（平滑）：

该块通常用于根据空调设备中的外部空气温度来校正房间设定值（夏季/winter 补偿）。

[ChlinMod] = 3（线性倒置）和 [ChlinMod] = 4（平滑倒置）：

补偿空气处理设备中的非线性特性以提高整体控制响应是一个典型的应用。

Troubleshooting

CHARFNCT 在三种情况下生成错误消息。在这些情况下，[Out] = 0 是输出值。

  • If the number of auxiliary points is smaller than 2 and greater than 10.
  • If the auxiliary point X[i] >= X[i+1].
  • If the characteristic curve entered for "inverse linear" or "Smoothed inverted" interpolation is not monotonous (rising or falling, not constant, not rising, and not falling at the same time).
Application example

风门位置 < > 风门体积流量之间非线性特性曲线的线性化：

体积流量控制器的操纵变量影响非线性执行装置“空气阻尼器”。控制链“控制器+线性化+空气阻尼器”表现出近线性响应，因为反转特性曲线可以补偿非线性。
