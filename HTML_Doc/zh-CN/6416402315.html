照明本地手动操作（LgtLocManOp11）

Overview

应用功能》Lighting local manual operation 11" (LgtLocManOp11）控制灯光的本地手动开关和调光。

它针对按钮事件和照明执行器响应之间的较短响应时间进行了优化。

Function

用户可以switch or dim使用本地按钮点亮。

AF 检查priority照明输出并按适当的优先级写入，请参见下表。

特殊配置的按钮（命令“用户定义 1...3”）可用于更改照明输出 (LgtOut) 的优先级：

  • Automatic mode 6 (Prio 15, "Enable control"), available only with a lighting control AF (LgtBrgtSwi11 or LgtConstCtl11).
  • Manual mode 3 (Prio 13).
  • Manual mode 1 (Prio 7), prioritized operation, excludes intervention from central AFs and system operator.

Enable external switch-on value

此配置将“开启”更改为“转到级别”命令。该电平由图表的 SwiOnVal 输入引脚提供。只要“转到关卡”命令处于活动状态，照明输出就会更新。
照明输出的自动关闭功能不支持此功能。在这种情况下，SwiOnVal 输入被禁用。

Indication on the KNX PL-Link light pushbuttons

AF 读取照明输出的当前状态并将以下信息发送到照明按钮（用于指示目的）：

  • The Present state of the lighting output.
  • Manual operation locked is set:
    • if ManM1 (Prio 7) is not active and present priority < ManM3 (Prio 13)
      This means: Locked is set at priorities 1…12
    • if ManM1 (Prio 7) is active and present priority < ManM1 (Prio 7)
      This means: Locked is set at priorities 1…6.

PL-Link 按钮的 LED 指示行为必须通过设备配置进行设置。


Staircase timer
楼梯功能（自动关闭）由照明输出 BACnet 对象 LgtAOut 和 LgtBOut 提供。请参阅属性“自动关闭功能”和“自动关闭时间”。

配置相应的照明输入对象 LgtIn 以始终发送打开命令。每当按下照明按钮时，就会重新启动关闭计时器。

Engineering and commissioning

Configuration
除了 EnBrgtCtlSwiOn 之外，AF 本身没有任何配置。

  • TX-I/O: The channels for the pushbuttons can be configured to send the required commands to the AF.
  • KNX PL-Link devices: Devices have a predefined functionality for blinds pushbuttons. The device can be selected, but not configured.
    KNX PL-Link can only send scenes (this can be used as a workaround).
  • The LED indication behavior of the PL-Link pushbuttons must be set via device configuration.


S-Mode devices

S 模式设备不支持预烧。其他功能可能也不受支持。请参阅设备文档。


Location of AF

  • The AF must be located on the same room automation station as the connected lighting actuators.
  • To reach a short response time it is recommended to connect the pushbuttons to the same room automation station, as well.


Technical hints
为了性能，AF LgtLocManOp11 被分配给 OB40。当通过本地按钮手动操作照明时，这是达到短响应时间所必需的。按下本地按钮的事件会触发 AF 中的性能。

除了按下按钮时触发 AF 之外，每 20 个 OB1 周期执行一次 AF 。
