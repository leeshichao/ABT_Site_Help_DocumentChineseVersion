设置 MS/TP 最大服务器值

使用此过程可为网络上的所有 MS/TP 设备设置 MS/TP 最大服务器值。

Set the Max server address

  1. Open Startup > Configure and download.
  2. Discover the devices to verify that all devices are communicating.
  3. In the Discovered devices tab, select a configured device.
  4. Right-click and select Set Max Server for all devices on network.
  5. Enter a value that is as great as the highest MAC address on the network (Auto, 1 to 127).
  1. The project data for the device instances will be updated automatically.

对于可自由编程的设备，每个设备实例的项目数据必须从ABT Pro 通过选择Advanced成分。
Advanced

在此网络上创建的任何其他设备必须配置相同的最大服务器值。确保最大服务器设置大于网络（包括路由器）上的最高 MAC 地址。如果没有，那么与这些设备的通信将会受到负面影响。
