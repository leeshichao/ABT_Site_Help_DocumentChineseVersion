将 TX-I/O 模块添加到总线接口模块（仅适用于 TXB3.M）

 

Add TX modules and accessories

  1. You have added a bus interface module.
    Adding devices
  1. Go to Building > Building structure.
  2. Right-click a bus interface module and select Go to engineering.
  3. Open the I/O configuration task.
    I/O configuration
  4. Click Add module.
  5. The Add module dialog box opens.
  6. Select a TX module from the list.
    Device list
  1. You have added a TX module to the bus interface module. You can now create and assign I/Os to the module.
    Creating I/O data points
