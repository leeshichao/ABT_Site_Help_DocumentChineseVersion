属性区域包含有关所选项目的详细信息。这些小节根据所选内容而变化。

选择自动化站时的小节：

  • General

    • Application type information

  • BACnet/IP interface
  • BACnet MS/TP interface

选择房间操作员单元时的小节：

  • General
    • Catalog information
  • Device information
  • Functions
  • Alarm

有关所选自动化站和房间操作员单元的更多信息，请参阅相应的硬件文档。
