State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Out of service

 

 

"Out of service" 包含每个工作日（周一至周日）的每日时间表。

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

财产ID：81

Next value

 

 

"Next value" 指示下一个值以及调度对象调度下一个值之前的时间。
至少在接下来的 48 小时内每分钟都会确定这些值。

Time to next value ✳

 

 

下一个值和到达下一个值的时间将由调度对象调度。
这些值将在至少 48 小时内每分钟确定一次。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

财产ID：4930

Description

 

 

"Description" 是一串可打印的字符，其内容不受限制。

Object identifier

 

 

"Object identifier" 是用于识别对象的数字代码。它必须在互联网范围内是唯一的。

Object name

 

 

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

Object type

 

 

"Object type“ 表示特定对象类型类中的成员资格。例如”Analog input“，”Binary output“，”Event enrollment“，”Trend log“， ETC。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。
