[OSSC] 最佳启动停止控制

功能块 OSSC 在房间占用开始和结束之前优化 HVAC 设备的激活。

OSSC 在房间占用开始和结束之前优化 HVAC 设备的激活。 OSSC 用于在入住开始时以尽可能低的能耗（启动阶段持续时间短）提供所需的室温。此外，能源供应（供暖或制冷）会在使用结束前（尽可能长的停止阶段）被切断。

Functioning

OSSC 根据调度程序值确定启动和停止阶段：当前操作模式、下一个操作模式以及到下一个操作模式的时间。还考虑了室外温度和室温。

适应是在每个工厂启动或停止后进行的。

OSSC 中集成了以下函数：

  • Optimum start stop control (OSSC) function for heating and cooling plants (not simultaneous)
  • Automatic adaptation of operating values

Start phase

The start phase comprises:

步

过程

1

在开始占用之前（[OpModR] = Comfort 或 [OpModR] = Pre-Comf），OSSC 计算以下值：

  • Required duration of the start phase [TiSttEst].
  • Time [DTiStt] to start phase.
  • Required room temperature setpoint [SpTRStt] in the start phase.

2

在计算出的时间，操作模式更改为 [PrOpMod] = 启动。开始阶段开始。

3

在启动阶段，OSSC 通过室温设定点 [SpTRStt] 控制室温。
控制旨在确保入住开始时的室温 [TR] 对应于温度设定点 [SpCmf] 或 [SpPcf]。

4

启动阶段 [TiSttEst] 结束后，操作模式为 [PrOpMod] = 无效。开始阶段结束。此时开始入住。

5

在占用期间（[OpModR] = Comfort 或 [OpModR] = Pre-Comf），无法启动阶段。

Stop phase

停止阶段包括：

步

过程

1

当 [OpModR] = Comfort 时，OSSC 计算以下值：

  • Required duration of the stop phase [TiSttEst].
  • Time [DTiStt] to stop phase.
  • Required room temperature setpoint [SpTRStp] in the stop phase.

2

在计算出的时间，操作模式更改为 [PrOpMod] = 停止。停止阶段开始。

3

在停止阶段，OSSC 通过室温设定点 [SpTRStp] 控制室温。
控制旨在确保入住结束时的室温 [TR] 对应于温度设定点 [SpPcf]。

4

停止阶段 [TiSttEst] 结束后，操作模式为 [PrOpMod] = 无效。停止阶段结束。占用此时结束。

如果未使用室温传感器 ([TRSen] = 0)，OSSC 将禁用停止优化。

Start phase: Temperature reached too soon

如果在 [TiSttEst] 到期之前达到启动阶段的温度设定值 [SpCmf]，则操作模式将更改为 [PrOpMod] = Pre-Comf，设定值 [SpTRStt] 更改为 [SpPcf]。另一个开始阶段是不可能的。

[TiSttEst] 的时间偏差由 [ErTiStt] > 0 表示，温度偏差 [ErTRStt] 设置为零。

Start phase: Temperature reached too late

如果在 [TiSttEst] 到期之后才达到温度设定值 [SpCmf]，则操作模式将保持在 [PrOpMod] = 启动，并且启动设定值会增加，直到达到温度设定值。操作状态更改为 [OsscSta] = Late Start。

[TiSttEst] 的时间偏差由 [ErTiStt] < 0 表示，温度偏差由 [ErTRStt] > 0 表示。

Stop phase: Temperature reached too soon

如果停止阶段的温度设定值 [SpPcf] 早于 [TiStpEst] 达到，则操作模式将更改为 [PrOpMod] = Pre-Comf，设定值将更改为 [SpTRStp] = [SpPcf]。另一个停止阶段是不可能的。
[TiStpEst] 的时间偏差由 [ErTiStp] > 0 表示，温度偏差 [ErTRStp] 设置为零。

Stop phase: Temperature reached too late

如果在 [TiStpEst] 之后未达到停止阶段的温度设定值 [SpPcf]，操作模式仍会更改为 [PrOpMod] = 无效。
[TiStpEst] 的时间偏差由 [ErTiStp] = 0 表示，温度偏差由 [ErTRStp] < 0 表示。

Special cases during room occupation

如果房间操作模式更改为 [OpModR] = Pre-Comf，操作模式将保持为 [PrOpMod] = Inactive。

OSSC 不控制启动和停止阶段之外的室温。在 start/stop 阶段之外 [PrOpMod] = 无效且室温控制必须由其他功能块接管。例如，OSSC 与功能块 HCRV 一起可用于占用阶段，而持续模式功能可用于非占用阶段。
[HCRV] Heating curve

Determination of design start and stop times

启动和停止阶段的估计时间需要配置参数。它们根据建筑属性进行设置，并在启用 OSSC 适应时进行更新。

这些参数必须在关联的 BACnet 对象上作为扩展属性可用（持久性扩展 = 最佳启动停止控制）。

参数

意义

TiSttDs

Start time for design conditions

对于 [ActgHC] = 0：[TiSttDs] 是在室外温度 [TOaDsgn] 下将房间从 15°C 加热到 20°C 所需的开始时间。在启动阶段，目标室温设定值（[SpCmf] 或 [SpPcf]）增加 [DSpTRStt]。
对于 [ActgHC] = 1：[TiSttDs] 是在设计室外温度 [TOaDsgn] 下将房间从 28°C 冷却到 24°C 所需的开始时间。在启动阶段，目标室温设定点（[SpCmf] 或 [SpPcf]）会减少 [DSpTRStt]。
[DSpTRStt] 的更改会影响所有启动参数。

TiSttLld

Start time for low load conditions

对于 [ActgHC] = 0：[TiSttLld] 是将室外温度为 15°C 的房间从 15°C 加热到 20°C 所需的开始时间。在启动阶段，目标室温设定值（[SpCmf] 或 [SpPcf]）增加 [DSpTRStt]。
对于 [ActgHC] = 1：[TiSttLld] 是在室外温度 20°C 的情况下将房间从 28°C 冷却到 24°C 所需的开始时间。在启动阶段，目标室温设定点（[SpCmf] 或 [SpPcf]）会减少 [DSpTRStt]。
[DSpTRStt] 的更改会影响所有启动参数。

TiSttWe

Start time for weekend conditions

如果房间长时间无人居住，[TiSttWe] 是在设计室外温度 [TOaDsgn] 下添加到基本启动时间的时间（[OpModR] = 保护或 [OpModR] = 经济）。
周末过后，可以使用此参数提前开始启动阶段。
[OpModFb] 必须正确生成并反馈到此参数以影响过程。

TcnTRStp

Time constant of room temperature during stop time

[TcnTRStp] 是关闭供暖或制冷（室外温度恒定）时房间制冷或供暖的时间常数。
时间常数的确定：时间常数是维持最终值的63%所需的时间。时间常数到期后，从最终温度的 63% 开始更改为室温。

Troubleshooting

Outside temperature error

如果外部气温出现故障，OSSC 块不会启动停止阶段。

Room temperature error

如果室温有故障，OSSC 块既不会启动启动阶段，也不会启动停止阶段。

Access to BACnet object

如果访问 BACnet 对象属性时出错，则会使用默认值执行启动和停止优化。

如果 BACnet 对象引用无效，则不会执行启动和停止优化。
