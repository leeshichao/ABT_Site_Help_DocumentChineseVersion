寻址 MS/TP 设备

此操作仅适用于未配置的 MS/TP 设备。根据所选的连接类型，使用关联的过程自动寻址指定网络上所有未配置的 MS/TP 设备。此操作将仅设置设备的 MAC 地址。

必须配置网络上的一台设备。从该配置的设备，可以向网络上的其他设备发出自动寻址操作。

所有过程最多可能需要 3 分钟。
要使这些功能发挥作用，请确保所有工程设备都具有该复选框Use Auto Addressing活性。

Room unit connection

默认情况下，Discovered devices选项卡显示本地连接的设备。这Discover按钮为您提供选择任一选项 Locally connected deviceorAll从Discovery对话框。如果All选中后，发现的设备将在表中列出。

  1. A Room unit connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Room unit connection tab.
  3. Click Connect.
  4. Select Startup > Configure and download.
  5. In the Discovered devices tab, by default the Locally connected device will display in the Discovered devices table.
  6. To display all devices on the local network, click the Discover button and select All from the drop-down list box in the Discovery dialog box.
  7. Click OK.
  8. All configured devices on the selected network display in the Discovered devices table.

  9. PXC3 设备不支持通过 Room 设备进行连接。

  10. Select a configured device, right-click, and select Perform auto addressing.
  11. Select Yes in the Auto address network devices dialog box.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. In turn, a unique MAC address is assigned to each device. All the addressed devices display in the Discovered devices table. They can now be configured and loaded.

USB connection

默认情况下，Discovered devices选项卡显示本地连接的设备。这Discover按钮为您提供选择任一选项 Locally connected deviceorAll从Discovery对话框。如果All选中后，表中仅列出已配置的设备。如果Locally connected device选择后，表中仅列出本地连接的设备（已配置或未配置）。

  1. A USB connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the USB tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Select Startup > Configure and download.
  7. In the Discovered devices tab, by default the Locally connected device will display in the Discovered devices table.
  8. To discover devices on the same network of the MS/TP device that you made a connection, select Local network.
  9. To discover devices on another network from the MS/TP device that you made a connection, select Remote network, and specify a network number.
  10. In the Discovered devices tab, click Discover, select All from the drop-down list box, and enter the Network number in the Discovery dialog box.
  11. Click OK.
  12. All configured devices on the selected network display in the Discovered devices table.
  13. Select a configured device, right-click, and select Perform auto addressing.
  14. Select Yes in the Auto address network devices dialog box.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. In turn, a unique MAC address is assigned to each device. All the addressed devices display in the Discovered devices table. They can now be configured and loaded.

Ethernet connection

默认情况下，不显示任何设备Discovered devices选项卡。这Discover按钮为您提供选择的选项All从Discovery对话框。结果，发现的设备列在表中。

  1. An Ethernet connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Ethernet tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Select Startup > Configure and download.
  7. In the Discovered devices tab, click Discover, select All from the drop-down list box, and enter the Network number in the Discovery dialog box.
  8. To discover devices on another network from the MS/TP device that you made a connection, select Remote network, and specify a network number.
  9. Click OK.
  10. All configured devices on the selected network display in the Discovered devices table.
  11. Select a configured device, right-click, and select Perform auto addressing.
  12. Select Yes in the Auto address network devices dialog box.
  1. This sends a request to the discovered device to discover all unaddressed MS/TP devices on that network. In turn, a unique MAC address is assigned to each device. All the addressed devices display in the Discovered devices table. They can now be configured and loaded.
