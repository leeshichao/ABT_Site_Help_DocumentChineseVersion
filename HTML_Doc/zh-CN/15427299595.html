[W_DATI] 写入日期和时间

功能块 W_DATI 使用数据类型 DateAndTime 的当前值更新计算值对象的属性当前值和可靠性。

W_DATI 使用数据类型 DateAndTime 的当前值更新计算值对象的属性当前值和可靠性。

Functioning

Compatible data points:

  • Date/time calculated value [DaTiCalcVal]

Required properties:

  • Present value
  • Tracking value
  • Status flag
  • Reliability
Pins

输入

描述

数据类型

默认值
取值范围

EnWrit

Enable write

如果 [EnWrit] = 1，则启用将输入 [Val] 和 [SetValid] 中的值写入 BACnet 对象。
如果[EnWrit]从0变为1，则发生写入。

布尔值

1

Val

Value

日期和时间

01.01.1990
00:00:00.000

虚拟值，由控制程序计算和分配以更新当前值。
[Val]用于更新属性‘跟踪值’；接下来是 BACnet 对象在内部使用写入的跟踪值更新当前值。

如果满足以下条件，则写为 [Val]：

  • [SetUnspf] = 0 and [Val] changes
  • [SetUnspf] changes
  • [SetValid] changes.
  • [RptWrit] is 1.

SetUnspf

Set unspecified value

定义是否可以写入当前值的未指定值。

布尔值

0

0 - 写入 [Val] 中的值。
1 - 写入未指定的值。 （[Val] 被忽略）

SetValid

Set valid value indication

由控制程序计算并分配的值，指示[Val]是否可靠。

如果 [EnWrit] = 1 并且以下项目之一适用，则 [SetValid] 映射到更新可靠性的错误代码：

  • [SetValid] changes.
  • [Val] changes.
  • [RptWrit] is 1.

布尔值

1

0 - 可靠性错误代码 7（不可靠 - 其他）。
1 - 可靠性错误代码 0（无故障）。

RptWrit

Repeat write

强制将 [Val] 和 [SetValid] 写入数据点。每个程序周期都会重复写入，直到 [RptWrit] = 1。
控制程序通常计算并设置[RptWrit]。

Note:
[RptWrit] 不能永久强制为 1。这可能会影响性能和通信流量。

布尔值

0

0 - 无操作。
1 - [Val] 和 [Sta] 在每个编程周期写入数据点。

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

 

输出

描述

数据类型

默认值
取值范围

PrVal

Present value

引用的 BACnet 对象的属性“当前值”的值。 [PrVal] 在发生故障时提供最后的有效值。

日期和时间

01.01.1990
00.00.00.000

PrValSta

Present value state

指示属性“当前值”是否具有未指定的值。

发生故障时，[PrValSta] 指示最后的有效值。

布尔值

0

0 - 属性的值未指定。
1 - 指定属性的值。

Dstb

Disturbed

[Dstb]表示引用的BACnet对象是否有错误。

[Dstb] = 1 如果：
BACnet 对象 = 访问期间出错
OR
“状态标志”=故障

否则 [Dstb] = 0

布尔值

0

Rlb

Reliability
指示属性“可靠性”的值（如果该属性可用）。

整数

0：未检测到故障

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes

Troubleshooting

如果 BACnet 对象位于另一个设备上，则写入功能不可用。
