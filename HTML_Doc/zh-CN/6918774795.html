报告类型

报告可以通过提供有关数据点、应用程序类型等的信息来帮助您分析项目。您可以在以下任务中创建报告：

  • Building > Building structure
    Reports for buildings, building elements, and devices.
  • Building > Central functions
    Only reports for hierarchy elements
  • Startup > Export
    Creating engineering data reports

您还可以选择包含项目的所有设备或您选择的设备。

  • Selected devices (rooms)
    Includes only the selected devices.
  • Include all devices from project
    Includes all devices contained in the project.

可以使用以下报告类型。

报告类型

描述

设备详情

PXC4/5/7:

所有系统组件（自动化站以及 TX-I/O 模块和附件）的列表，以及相应的详细信息，例如自动化站的设备地址、序列号等。

房间自动化：

自动化站列表，其中包含相应的详细信息，例如设备地址、位置、序列号、固件版本（如果可用）每种类型的设备总数等。

数据点调试-按地址排序

按自动化站的数据点地址排序的数据点列表和相应的调试状态。

数据点调试 - 按工厂排序

按自动化站设备排序的数据点列表和相应的调试状态。

数据点配置 - 按地址排序

显示点配置的详细信息。该信息按总线和房间自动化站的范围进行分组，按数据点地址或按自动化站的设备排序。

数据点配置 - 按工厂排序

显示点配置的详细信息。该信息按总线分组，房间自动化站的范围按自动化站的数据点地址排序。

电源和导轨

PXC4/5/7 报告显示分配给自动化站导轨的 TX-I/O 模块和附件的配置，包括功耗估算和相应的详细信息，例如机房、面板名称、设备地址、导轨长度等。

子系统网络报告

显示有关以下内容的子系统网络报告：

  • Modbus network
  • M-bus network
  • KNX PL-Link network

该报告提供了 Modbus（TCP 和 IP）、M-bus 和 KNX PL-Link 设备的子系统网络的排序列表。
报告结构中列出了设备数量、单个设备的数据点数量、设备详细信息、设备描述、波特率、奇偶校验、停止位、设备类型和设备地址等详细信息。

如果采用 Modbus 或 M-bus 网关或电平转换器，报告还涵盖其相关信息。

Notification class report

显示通知类条目的详细信息，例如收件人列表。

分组

包含群组成员、群组编号、自动化站等的中心功能摘要。

BACnet reference for PXC4/5/7

显示 BACnet 参考列表，包括每个 PXC4/5/7automation 站使用的参考源。

趋势日志定义

显示每个设备的所有趋势日志对象的概述。该报告包含趋势日志对象最重要的配置属性。

报警定义

显示每个设备的所有警报对象和事件注册对象的概述。该报告包含警报对象和事件注册对象的最重要的配置属性。

循环配置

提供客户项目中定义的循环（控制器）对象配置的详细信息，还显示输出、输入和设置数据点引用。

时间表配置

提供所有调度程序以及带有时间段和切换值的调度对象的详细信息。

BACnet/SC report

显示 BACnet/SC 集线器和节点的列表以及相关 BACnet/IP 信息。

IP 端口使用报告

显示报告中每个设备的已用和未用 IP 端口。该报告适用于 PXC4/5/7 器件。

对象总结报告

显示 Desigo CC 许可证点（每个设备）的计算。

云激活

显示所有支持云的设备及其激活密钥的概述，以便用户可以手动将设备注册到云。

网络证书报告

显示网络证书列表以及有关证书类型、有效期和其他重要信息的相关信息。

BACnet/SC certificate report

显示 BACnet/SC 证书的列表以及有关证书类型、有效期和其他重要信息的相关信息。

申请模板1

显示自动化站列表以及项目基于模板的设备所使用的应用程序模板。

查看1

显示设备、结帐和参数信息。结帐信息通常由用户填写。

模板配置1

所使用的应用程序模板的名称和类型信息，包括项目基于模板的设备的所选配置选项的摘要。

BACnet reference1

显示项目中用于房间自动化站或基于应用程序模板的设备的 BACnet 引用列表。

操作顺序1

为可配置应用程序提供操作顺序的可视化。帮助用户了解设备上当前加载的应用程序类型。

应用帮助报告

所使用的应用程序模板的名称和类型信息，包括项目基于模板的设备的所选配置选项的摘要。

1 – 这些报告仅在以下情况下可用All devices from the project被选中。

报告的可用性取决于设备类型（例如 DXR1/2、PXC3、PXG3 或 PXC4/5/7 等）。平衡报告可在Startup > Global functions/Export，以及设备的 Web 界面中。

 

Creating a report

  1. Select at least one building, building element, device or hierarchy element.
  2. Right-click the selected elements and select Reports.
  3. The Select report dialog box opens.
  4. Choose to include all devices of the project or the devices you selected.
  5. Select the report type you want to create.
  6. Click OK.
  1. The selected report is generated and opens in the Reports component.
