照明亮度恒定控制（LgtConstCtl11）

Overview

应用功能》Lighting brightness constant control 11" (LgtConstCtl11）将亮度水平控制在恒定值，并根据亮度水平自动打开和关闭照明。

照明输出的模拟控制值是主要输出。


Features:

  • Modulating lighting command
  • Lighting on/off switching
  • Setpoint shift
  • Correction function for the brightness sensor
  • Interacts with the following optional AFs: Lighting green leaf (LgtGrnLf11) and the lighting manager/subordinate functionality (LgtCtlMst11 / LgtCtlSlv11)

Function

 

Brightness setpoint
AF 根据配置值亮度设定值 (LgtSpBrgt)、照明操作策略 (LgtOpStrgy) 和亮度设定值因子 (SpFacBrgt) 计算当前亮度设定值 (LgtPrSpBrgt)。

  • If LgtOpStrgy = Energy efficiency, then LgtPrSpBrgt = LgtSpBrgt * SpFacBrgt
  • If LgtOpStrgy = Comfort optimization, then LgtPrSpBrgt = LgtSpBrgt

 

Daylight control
/off 上的 AFswitches 照明基于日光水平，通过延迟和滞后进行平滑，以防止令人讨厌的变化（例如来自经过的云层）。

  • Lighting is switched on if it is dark ((LgtSpBrgt - Brgt) > HysSwiOn) throughout the delay LgtDlyOnBrgt.
  • Lighting is switched off under the following conditions:
    • The lighting actuator is at the minimum limit (PrgsVal <= Min+TshVal and OpSta = 1).
    • It is too bright (Brgt > LgtSpBrgt + 0.5*HysBrgtCtl) throughout the delay DlyOffBrgt.
    • Switching-off by brightness is allowed (EnSwiOffBrgt = 1).


Constant lighting control
照明命令在每个更新间隔（参数 UpdIvl）定期计算。

根据照明输出的当前值（进度值），AF 根据亮度差和给定限制计算新的照明控制值 (LgtVal = LgtPrgsVal + / - StepVal)。

步长值 StepVal 使用以下公式计算：

StepVal = StepFac * Abs(LgtSpBrgt - LgtBrgtEff)

功能：
StepVal 受参数 StepValMin 和 StepValMax 限制。

  • The control algorithm starts with the value SwiOnVal if lighting is off and constant lighting control is activated.

  • 当存在功能可用时，缺席级别也被解释为关闭。

  • Constant lighting control starts with the current progress value if lighting is on and constant lighting control is activated or constant lighting control is activated by low brightness.
  • A new lighting control value is performed at each update interval (UpdIvl). The update interval is ignored and a new control value is performed immediately if priority is higher than AutoM6 (Prio 15).
  • Control stops and the current lighting control value is held if the current brightness level is within the setpoint hysteresis (LgtBrgEff t>=LgtSpBrgt - 0.5*HysBrgtCtl and LgtBrgtEff<=LgtSpBrgt + 0.5*HysBrgtCtl).


User feedback
如果用户在太亮时尝试激活亮度控制（通过手动干预），则 AF 在延迟时间 TiOnBrgt 期间使用值 SwiOnValBrgt 打开照明。如果延迟 TiOnBrgt 后仍然太亮，照明就会熄灭。

此回复不适用于以下两种情况：

  • After room automation station start up with active default priority (17).
  • Presence detection activates constant lighting control.


Setpoint shift
AF 将亮度设定点移动到更高或更低的值。设置配置参数 EnSpShift = 1 以激活该功能。

如果照明打开，每个控制命令后都会保存临时设定点。经过一段延迟（参数 UpdIvl）后，当前亮度值将被保存为恒定照明控制的临时设定值。亮度设定点 LgtSpBrgt 不变。当照明关闭时，临时设定点重置为 LgtSpBrgt。 LgtPrSpBrgt 提供当前设定值。

笔记：

  • Constant lighting control is activated after each manual operation, if the function is active (except for Go to level, Ramp to and Fade to commands).
  • The brightness setpoint as calculated by the lighting operation strategy is overridden.


Brightness sensor correction
AF 考虑了人造光与日光测量的灵敏度差异、维护因素、邻近照明的影响以及阴影的影响（如果配置）。请参阅 AF LifeCyc11、AF ImncInfl11 和 AF ShdDlgtCorr11 的说明。 AF 动态改变传感器校正。设置参数 EnBrgtCorr = 1 以激活该功能。如果 AF 作为从属操作（标志 Slv = 1），则使用 AF LgtCtlSlv11 提供的日光值和计算出的人工部分来计算亮度。

如果启用日光测量，则通过内部连接提供校正的亮度值 (LgtBrgtEff)。

所有必需的参数必须设置为准确的值，亮度传感器校正功能才能正常工作。


Energy efficiency
AF 计算绿叶功能所需的信息 (AF LgtGrnLf11)。

如果从 LgtGrnLf11 接收到 LgtCmdAutoMod，则自动模式 6（优先级 15）被激活。

Engineering and commissioning

亮度控制功能在启动后激活（标志 SttUpFns = 1）。


Enable functionality in other AFs
标志 EnAutoCtl 和 LgtCtlAvl 启用其他 AFs 中的功能。它们通常不会改变。然而，特殊功能可能需要它。在更改之前请考虑标志对整个房间部分的影响。


Configure the UP258 brightness sensor
对于 UP258 亮度传感器设置（UP258 > 功能 > 通道 2 的属性），确保最小重复时间（默认 10 秒）小于恒定照明控制的更新间隔 UpdIvl。如果 PL-Link 负载太高，则可以增加最小重复时间，但随后也必须增加 UpdIvl 并且照明控制速度会减慢。

请勿更改设置 COV lux（默认 5 lx）和 COV（默认 1 %）。例外：如果需要高校正因子（即高于 10），则可以降低 COV lux，从而导致恒定照明控制灵敏度出现问题（传感器仅检测到以下亮度变化：COV lux * 校正因子）。


Calibrate the brightness sensor
仅当亮度传感器校正功能禁用时才需要校准。 (EnBrgtCorr = 0)

否则，将模拟输入的 BA 对象的校正因子属性设置为 1。

考虑内部光传感器的测量范围。 （例如 UP258 20…1000 lx）

请按如下方式进行：

  1. Calibrate under normal lighting conditions in the room. In other words, open blinds, but ensure that brightness in the room is still below the brightness setpoint.
  2. Place a lux-meter on the table where the brightness setpoint takes effect.
  3. Command lighting to a constant value to achieve the brightness setpoint together with incoming daylight.
  4. Calculate the quotient of the brightness on the table (as measured by the lux-meter) and the brightness measured by the brightness sensor on the ceiling (BrgtTable / BrgtSensor).
  5. Enter this value in the correction factor property for analog input BA object "Brgt".

 

Configure brightness sensor correction function
仅当亮度传感器校正功能启用时才配置。 （EnBrgtCorr = 1）。否则，参数没有影响。

需要校准，因为传感器安装在天花板上，并且亮度必须控制在表 /desk 级别。

需要校准的照度计才能获得可靠的配置结果。

考虑内部光传感器的测量范围。 （例如 UP258 20…1000 lx）

请按如下方式进行：

  1. Set the BA object's correction factor property for the analog input "Brgt" to 1.
  2. Measure first in a dark room, preferably without daylight.
  3. Measure the illuminance of the lamp at 100% output with a lux-meter on the table.
  4. Enter this value under parameter Inmc.
  5. Calculate CorrFacAlgt = Inmc / Brgt (value measured by the brightness sensor)
  6. Enter the value under parameter CorrFacAlgt.
  7. Now measure under normal daylight conditions in the room. In other words, lighting is switched off. Room brightness should be approximately 500 lx.
  8. Calculate CorrFacDlgt = brightness as measured with lux-meter / Brgt (value measured by the brightness sensor)
  9. Enter the value under parameter CorrFacDlgt.
  10. Make sure that AF ShdDlgtCorr11 is configured; two measurements are necessary for the correction factors daylight! See the description of AF ShdDlgtCorr11.
  11. Insert the parameters in AF ShdDlgtCorr11.


西门子 UP258 的典型值：

CorrFacAlgt = 8（人造光比传感器指示的光亮 8 倍）

CorrFacDlgt = 2.5（日光比传感器指示的亮度亮 2.5 倍）

CorrFacRdcDlgt = 1.2


Influence of the neighboring lighting groups
为了正确操作 AF，必须分配照明对邻居照度正面 /rear 的影响。请参阅AF LgtImncInfl11。


Lighting correction daylight
必须指定日光阴影校正因子才能正确操作 AF。如果没有可用的有效值，则 AF LgtConstCtl11 (CorrFacDlgt) 的“内部”校正因子日光处于活动状态。


Speed of the constant lighting control
如果恒定照明控制太慢，请增加参数 StepFac（建议：最大 0.05 %/lx）。如果太高，可能会发生过冲，因为一步会导致比亮度控制迟滞（HysBrgtCtl）更高的亮度变化。


Noticeable brightness difference when coming from below or from above the brightness setpoint

  • Control stops at LgtSpBrgt + 0.5 * HysBrgtCtl (coming from a brightness which is higher than the brightness setpoint)
  • Control stops at LgtSpBrgt - 0.5 * HysBrgtCtl (coming from a brightness which is lower than the brightness setpoint)

如果这两种情况之间存在明显的亮度差异，请减小参数 HysBrgtCtl（建议：最小 50 lx）。


Sensor failure
如果传感器有缺陷，日光值会切换到 0 lx，并且照明会打开。
