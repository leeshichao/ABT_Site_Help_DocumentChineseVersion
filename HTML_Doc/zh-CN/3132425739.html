R_BLSX：读取多个盲注

R_BLSX 从多个（最多 16 个）聚合成员盲输入对象（成员对象通过集合视图节点对象聚合）读取结构化现值属性。输入的评估旨在检测自上次读取以来已更新的第一个输入。 R_BLSX 还向控制程序提供信号 Valid、UpdInd、ErrCode 和 ErrWrit 进行处理。 R_BLSX 还将可选地提供来自控制程序的当前最后移动方向，以写回每个成员对象的最后移动方向属性。

Control-command commanding

控制命令命令是典型的操作状态，其中盲输入对象接收由结构化现值属性元素 [PrOp]、[PrPosNr]、[PrValHgt] 和 [PrValAgl] 表示的按钮命令。 R_BLSX 将最近的输入请求传递给盲命令 XFB。命令盲 XFB 执行具有附带优先级的请求，并读取actual来自盲输出对象的盲移动方向并将其发送回 R__BLSX。 R_BLSX 可以选择将此值写入所有聚合成员盲输入对象。由于通常有多个输入影响相同的百叶窗，因此每个输入（例如，按钮传感器或操作面板）需要基于最近的输入请求了解并反映百叶窗的最后移动方向。

Hardware interrupt

该XFB支持硬件中断（OB触发器），以立即响应特定事件，例如手动开关灯。如果在分配给 OB40 或 OB41 的图表中应用 XFB，则在来自 I/O 模块的中断信号上自动发生 OB 触发。

Compatible data points:

  • Blind input [BlsIn]

参考data point objects有关 BACnet 数据点的详细说明。

Required properties:

  • Present value (structured blind input command)
  • State flag
  • Update count
  • Last moving direction

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

LstDirc

Last moving direction

整数（默认值：0）

可以选择将计算值写入多个盲输入对象的最后移动方向属性。

如果出现以下情况，将写入 [LstDirc]：

  • [LstDirc] changes.
  • [RptWrit] is True.

RptWrit

Repeat write

布尔值（默认值：False）

[RptWrit] 强制将 [LstDirc] 写入盲输入对象。只要 [RptWrit] 为 True，每个程序周期都会重复写入操作。

[RptWrit]通常由控制程序计算和设置。

Note
不得通过连接到始终为 True 的块输出来强制将 [RptWrit] 永久设置为 True。这样做会导致高水平的通信流量。

1（正确）

只要 [RptWrit] 为 True，[LstDirc] 就会在每个程序周期写入盲输入对象。

0（假）
默认

没有行动。

Pin description (outputs)

PrOp

Present operation

整数（默认值：0）

来自聚合盲输入对象的最后更新成员的现值属性的操作元素的值。

如果 [Valid] = False，[PrOp] 将提供最后一个有效值。

0（停止）

命令停止移动百叶窗。

1（上移）

命令开始向上移动百叶窗。

2（下移）

命令开始向下移动百叶窗。

3（停止或升压）

命令停止相应的移动或执行逐渐向上的移动。

4（停止或降压）

命令停止相应的移动或执行逐渐向下的移动。

5（转到高度）

命令开始将百叶窗移向 [PrValHgt] 指定的绝对高度。

6（转到角度）

用于开始将板条移向 [PrValAgl] 指定的绝对角度的命令。

7（转到位置）

开始将百叶窗移向 [PrValHgt] 和 [PrValAgl] 指定的绝对位置的命令。

8（转到预定义位置）

命令开始将百叶窗移向 [PrPosNr] 指定的预定义位置。 （例如，目标状态命令。）

20（无命令）

指示不对百叶窗控制执行器采取任何操作的命令。

PrValHgt

Present value height

实数（默认值：0.0）

来自聚合成员盲输入对象的最后更新成员的当前值属性的高度元素的值。

如果 [Valid] = False，[PrValHgt] 将提供最后一个有效值。

PrValAgl

Present value angle

实数（默认值：0.0）

来自聚合成员盲输入对象的最后更新成员的当前值属性的角度元素的值。

如果 [Valid] = False，[PrValAgl] 将提供最后一个有效值。

PrPosNr

Present position number

整数（默认值：0）

来自聚合成员盲输入对象的最后更新成员的当前值属性的位置编号元素的值。

如果 [Valid] = False，[PrPosNr] 将提供最后一个有效值。

有效的

Valid

布尔值（默认值：False）

指示输出引脚 [PrOp]、[PrValHgt]、[PrValAgl] 或 [PrPosNr] 是否可靠。

1（正确）

当前值输出引脚可靠。

  • XFB can access the blind input object(s).

AND

  • In the last updated object, fault flag in state flag property = 0 (no fault)
    (Reliability = 0 (no error) or Reliability was not detected).

0（假）

当前值输出引脚不可靠。

  • XFB cannot access the blind input object(s).

OR

  • In the last updated object, fault flag in state flag property = 1 (fault)
    (Reliability ≠ 0).

UpdInd

Update indication

布尔值（默认值：False）

聚合成员对象之一的当前值（结构化盲输入命令）属性是否已被新更新的指示。

发生更新时，[UpdInd] 从 0 切换到 1 (True)，并在下一个周期（立即）返回到 0 (False)。如果没有连接到 [UpdInd] 的附加功能块（例如计数器功能块），则无法检测切换。仅当 [Valid] 为 True 时，[UpdInd] 才会设置为 True。

[UpdInd] 使用更新计数属性。如果新值与先前值相同，则可以将值识别为已更新。

UpdMbr

Update member

整数（默认值：0）

最后更新的盲输入对象。

[UpdMbr] 将显示最后更新的成员对象的集合视图节点对象 ItemId 的索引号。

NumVals

Number of valid values

整数（默认值：0）

集合视图节点对象中有效盲输入对象的数量。

NumMbrs

Number of aggregated members

整数（默认值：0）

集合视图节点对象中成员对象的总数。

ErrCode

Error code indication

整数（默认值：20）

上次执行 XFB 读操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.

ErrWrit

Error while writing

整数（默认值：20）

上次对结果对象执行 XFB 写入操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.
