房间单元 LED (KNX)（LgtIn - 子系​​统特定扩展）

光输入 (LgtIn) 对象支持子系统特定扩展的以下属性Room unit LED (KNX).

✳ 表示西门子专有财产。

Room operator unit, LED indication ✳

 

 

"Room operator unit, LED indication" 定义状态 LEDs 何时打开。

Always off

状态 LEDs 始终关闭。

Lighting on

如果灯亮，则状态 LEDs 亮。

Lighting off

如果灯关闭，则状态 LEDs 亮起。

Manual operation locked

如果设备被锁定以进行手动操作，则状态 LEDs 将亮起。

Lighting on, or manual operation locked

如果灯亮起或设备被锁定以进行手动操作，则状态 LEDs 将亮起。

Lighting off, or manual operation locked

如果灯关闭或设备被锁定以进行手动操作，则状态 LEDs 将亮起。

Room operator unit, manual operation locked ✳

 

 

"Room operator unit, manual operation locked" 定义是否可以使用状态 LED 来指示设备已锁定以进行手动操作。

Note:仅当设备在没有应用程序功能的情况下使用时，手动配置才有意义。

是的

状态 LED 可用于指示手动操作锁定。

No

状态 LED 不能用于指示手动操作锁定。
