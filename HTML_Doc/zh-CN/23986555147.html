[CMD_LGTG] 命令照明组

功能块 CMD_LGTG 以特定优先级将当前值或控制命令分配给特定组数据标签的多个模拟或二进制 BACnet 照明输出对象。

CMD_LGTG 以特定优先级将当前值或控制命令分配给特定组数据标签的多个模拟或二进制 BACnet 照明输出对象。支持目标状态命令和控制命令命令。

分组基础设施需要专有对象：一个组管理者对象和一个或多个组成员对象。各个成员数据点（照明输出对象）通过组成员对象进行分组和引用。

CMD_LGTG 将特定组数据标签的值/优先级对写入组管理器对象的组命令属性。数据从组管理器对象传递到组成员对象，在组成员对象中数据被分发到具有匹配组数据标签的预期照明输出对象。

Functioning

Compatible data points

  • Analog lighting output [LgtAOut]
  • Binary lighting output [LtgBOut]

Required properties of grouped data points

  • Present value
  • Control command (structured lighting output command)

Operate with priorities

该功能块使用 2 种方法来控制是否按优先级运行：

1. 独占控制（计划优先级 1...5、9...12、14...16）

  • Initialized at startup
    • Multiple input sets of a function block cannot command the same priority.

2. 最后胜利控制（计划优先级7、8、13）

  • Not initialized at startup.

 

专属控制
优先级：1...5、9...12 和 14...16

最后获胜控制权
优先级：7、8 和 13

Pins

输入

描述

数据类型

默认值
取值范围

EnIn1…EnIn4

Enable input 1…Enable input 4

[EnIn1] 控制是否以[PrioIn1] 保持的优先级命令[ValIn1] 或[OpIn1]，或者是否释放优先级。
[EnIn1] 属于四个输入集之一，每个输入集包含 [EnInX]、[ValInX]、[OpInX]、[LvlInX]、[StepInX]、[PrioInX]、[RptcInX] 和 [DscdcInX]。这些输入集根据需要以不同的优先级控制分组的照明输出对象。
[EnIn1] 可以在编程编辑器中进行参数化（由开发人员设置）或链接，并由控制程序在运行时计算。
[EnIn2]...[EnIn4] 的功能与 [EnIn1] 相同。

布尔值

0

0 - 如果 [PrioIn1] 当前未由设置为 1 的不同 [EnInX] 激活，则释放 [PrioIn1] 的优先级。
1 - 命令 [PrioIn1] 优先级。

ValIn1...ValIn4

Value input 1...Value input 4

[ValIn1] 用于命令 [PrioIn1] 处的当前值属性（目标状态命令）。
[ValIn1] 可以在编程编辑器中进行参数化（由开发人员设置）或链接，并由控制程序在运行时计算。
在以下情况下，[ValIn1] 以当前值进行命令，优先级由 [PrioIn1] 保持：

  • [EnIn1] is 1 and [ValIn1] changes by a value equal or greater than [TshVal].
  • [EnIn1] is 1 and [ValIn1] changes to a limit value such as 0.0 or 100.0 ([TshVal] is ignored).

[ValIn2]...[ValIn4] 的功能与 [ValIn1] 相同。
Note
如果使用 [ValIn1]，则不得使用 [OpIn1]，并且必须保留默认值 32767。

真实的

0.0

OpIn1…OpIn4

Operation input 1…Operation input 4

[OpIn1] 用于命令 [PrioIn1] 处的控制命令属性（[LvlIn1] 和 [StepIn1]）。
[OpIn1] 可以在编程编辑器中进行参数化（由开发人员设置）或链接，并由控制程序在运行时进行计算。如果[OpIn1]等于最大整数值，则输入集作为目标状态命令运行。对于所有其他值，[OpIn1] 用作控制命令。
如果 [OpIn1] 发生变化且 [EnIn1] = 1，则 [OpIn1] 命令的优先级由 [PrioIn1] 保持。
[OpIn2]...[OpIn4] 的功能与 [OpIn1] 相同。
Note
If [OpIn1] is used, [Valln1] must not be used.

整数

32767：无

0：停止
1：调暗
2：调暗
3: Step up
4：下台
5：开机
6：关闭
7：转到级别
8：上升至
9：淡入淡出
32767：无

LvlIn1...LvlIn4

Level input 1...Level input 4

[Lvlln1] 是命令字段 [OpIn1] 的一部分，定义输入集的目标级别。它与 [OpIn1] 命令一起写入灯光输出对象，并与一些操作命令（例如 Go to level、Fade to、Ramp to）结合使用。
[Lvlln1] 可以在编程编辑器中进行参数化（由开发人员设置）或链接，并由控制程序在运行时计算。
[LvlIn2]…[LvlIn4] 的功能与 [LvlIn1] 相同。

真实的

0.0

StepIn1...StepIn4

Step input 1...Step input 4

[Stepln1] 是命令字段 [OpIn1] 的一部分，定义输入集的步长增量。它与[OpIn1]的命令一起写入灯光输出对象，并与一些操作命令（例如Step up和Step down）一起使用。

[StepIn1] 可以在编程编辑器中进行参数化（由开发人员设置）或链接，并在运行时由控制程序计算。

[StepIn2]...[StepIn4] 的功能与 [StepIn1] 相同。

真实的

0.0

PrioIn1...PrioIn4

Priority input 1...Priority input 4

整数

17

[PrioIn1] 保留[Valln1] 或[OpIn1] 附带的优先级。
[PrioIn1] 可以配置并且在运行时不能更改。值 17 表示不使用输入集。
[PrioIn2]...[PrioIn4] 的功能与 [PrioIn1] 相同。
Note
同一功能块上的输入集不得共享共同的独占控制优先级。

Priority range
1...16（请参阅稍后对优先级 6 和 8 的限制）。

Exclusive control
优先级 1...5、9...12 和 14...16
在控制程序启动期间，功能块使用独占控制来初始化范围 1...5、9...12 和 14...16 中的任何分配的优先级。

该功能块不支持运行时独占优先级控制。最后一个有效命令控制或释放优先级。

由于启动期间的独占控制，同一功能块上的两个或多个输入集不得共享公共的独占控制优先级，因为这将导致冲突。

Last wins
优先级 7、8 和 13

  • No initialization of priorities during startup.
  • At runtime, the last valid command controls priority.
  • If two or more input sets have the same priority and are commanded at the same time, only the input set with the first numeric order is performed (In1...In4).
  • If two or more input sets have the same priority and conditions for commanding and releasing are given at the same time, the command operation wins.

Priority 6
根据 BACnet 标准，命令优先级 6 保留用于最小 On/Off 功能。优先级为 6 的命令会被 BACnet 对象拒绝。
对于最小 On/Off 函数，控制程序必须包含一个逻辑并使用另一个优先级。

Priority 8
根据 BACnet 标准，命令优先级 8 用于手动操作，通常不会分配在功能块上。最后获胜功能允许控制程序更改或释放操作员命令。

RptcIn1...RptcIn4

Repeat command input 1...Repeat command input 4

[RptcIn1] 重复命令或释放优先级。
如果 [RptcIn1] = 1 且 [EnIn1] = 1，则功能块在每个编程周期中重复来自 [ValIn1] 或 [OpIn1]、[LvIIn1] 和 [StepIn1] 的命令，优先级来自 [PrioIn1]。
如果 [RptcIn1] = 1 且 [EnIn1] = 0，则功能块在每个编程周期中释放 [PrioIn1] 的优先级。
[RptcIn2]...[RptcIn4] 的功能与 [RptcIn1] 相同。
Note
[RptcIn1] 不得永久强制为 1。这可能会影响性能或网络流量。
[RptcIn1] 可以链接，通常由控制程序计算和设置。

布尔值

0

DscdcIn1...DscdcIn4

Discard command input 1...Discard command input 4

[DscdcIn1] 用于配置在重新启动或恢复与组管理器自动化站的通信时重复 [ValIn1] 命令。
[DscdcIn1] 可以配置，但在运行时不能更改。
[DscdcIn2]...[DscdcIn4] 的功能与 [DscdcIn1] 相同。

布尔值

0

0 - 重新启动时或与组管理器自动化站的通信恢复后，组管理器会以优先级 [PrioIn1] 重复来自 [ValIn1] 的最后一个命令。
1 - 重新启动或与组管理器自动化站的通信恢复后，组管理器不会以优先级 [PrioIn1] 重复来自 [ValIn1] 的最后一个命令。

TshVal

Threshold value

[TshVal] 是用于控制功能块写入尝试的配置值。仅当值的变化大于或等于 [TshVal] 时才允许尝试。
例外：如果新值是限制值（例如 0.0 或 100.0），则忽略 [TshVal]。

Note
[TshVal] 不得设置为 0.0。

真实的

1.0

Group data tag 1

[GrpTag1]定义了由功能块集中分配的特定组数据。 [GrpTag1]仅用于目标状态命令（当前值、优先级）。
系统提供预定义和可定制的标签。通常，应用工程师在编程编辑器中设置 [GrpTag1]，并且在运行时无法更改。必须设置与功能块的数据类型匹配的标签。
