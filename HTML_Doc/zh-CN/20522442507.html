废弃房间编程

您可以在房间编程中丢弃已开始编程但不再需要的应用程序模板。

Discard room programming in ABT Site

  1. Close Room programming.
  2. In Building > Application & device overview, navigate to the application template you want to discard.
  3. Right-click the application template and select Delete.
  1. Room programming is discarded.

Discard in room programming

  1. In Programming > Project navigation view, navigate to the automation station.
  2. Right-click the automation station and select Discard.
  1. Room programming is discarded.
