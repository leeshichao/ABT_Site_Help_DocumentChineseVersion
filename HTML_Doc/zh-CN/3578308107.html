命令控制对象 (CmdObj)

命令控制对象 (CmdObj) 类型用于命令一组 BACnet 对象，其配置值取决于特定的操作模式。命令控制对象基于 BACnet 标准并包含专有属性。

命令对象类型定义了一个标准化对象，其属性表示多操作命令过程的外部可见特征。您可以使用 Command 对象根据写入“的操作代码”将一组值写入一组对象属性。Present value命令对象的“。每当“Present value“写入 Command 对象的属性，它会触发 Command 对象采取一组操作来更改一组其他对象的属性值。

当需要命令大量BACnet对象时，可以使用分组和组通信。此外，当需要命令过程值和未配置值时，可以使用分组和组通信或通过控制程序直接命令 BACnet 对象。
