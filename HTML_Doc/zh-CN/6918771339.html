更改应用程序参数

您可以从以下位置开始更改应用程序参数Building > Application & device overview.

Change application parameters

  1. Select an application template.
  2. Click Building > Application & device overview > Go to configuration.
  3. Configuration > Application configuration opens.
  4. Complete the application configuration.
    Configuring features (template)
  5. Select the Default values task.
    Default values
  6. Click Show/hide parameter.
  7. The Show/hide parameter dialog box opens where you can configure properties and default values.
    Show/hide parameter (dialog box)
  8. Click OK.
  9. Select the I/O assignment task and assign I/O's according to the specifications of your project.
    Assigning I/O's (template)
  1. You have changed the parameters of the selected application template.

更改应用程序模板不会增加应用程序模板版本号。中的值Version列由用户管理。
