设备列表

这Device list任务列出所有设备及其属性。您可以有效地更改各个属性并对许多设备属性执行唯一性检查。
Checking for duplicate device properties

使用此编辑器可以更改与此模板关联的所有设备的默认值（从 ABT 站点导出）。

可以在导出的编辑器（即 Excel）中添加和/或删除设备。

  • Switching to the Device list task closes and reopens the current project in the background. Open Report or Configuration tabs will be closed.
  • In the Device list task the component selector, the task selector, and the split buttons are disabled.

命令

描述

节省

保存当前更改。按钮上方的数字表示所做更改的数量。

关闭

关闭Device list任务。如果您关闭Device list任务如果不保存，所有更改都会丢失。

加载实例参数

默认情况下隐藏实例参数以节省加载时间。要查看设备表中的实例参数，请单击Load instance parameter在工具栏中。

Note
对于某些检查，例如IP 地址范围检查，必须加载实例参数。

智能复制

复制要粘贴到 Excel 或其他电子表格软件中的表格数据。

智能粘贴

将剪贴板中的数据粘贴到表中，执行某些检查以处理 Excel 或其他电子表格软件中更改的数据。

加载数据以进行扩展检查

仅对最初加载的数据进行最重要的检查。使用此按钮加载数据以进行扩展检查，以便执行所有检查（需要更多时间）。
Extended checks

查看

执行所有强制性检查和中选择的可选检查Configure checks。结果显示在Details和Log选项卡。

配置检查

允许您设置可选检查。

Names

  • Unique room names. Selected by default.
  • Unique room segment names. Selected by default.
  • Unique central function names. Selected by default.
  • Unique plant names. Selected by default.
  • Unique equipment IDs. Cleared by default.
    • Empty equipment IDs allowed. Disabled, if Equipment ID check is disabled.

Advanced

  • Check room segment assignment to rooms. Selected by default.
  • Check room segment context in building. Selected by default.
  • Check integrity of I/O assignment. Selected by default.
  • Allow only one local broadcast UDP port. Selected by default.
  • Allow only two DNS servers. Selected by default.
