R_LGTX：读取多重照明

R_LGTX 从多个（最多 16 个）聚合成员照明输入对象（成员对象通过集合视图节点对象聚合）之一读取结构化的当前值属性。 R_LGTX 旨在检测自上次读取以来已更新的第一个输入。 R_LGTX 向控制程序提供信号 Valid、UpdInd、ErrCode 和 ErrWrit 进行处理。

R_LGTX 还将可选地提供来自控制程序的当前照明状态、值和手动操作锁定条件，以写回每个聚合照明输入对象。如果关联的输入引脚已连接以在运行时接收值，则 R_LGTX 将执行此操作。否则（输入引脚未接线），下载/重启后，R_LGTX 将仅写入非默认值（由工程师设置）的聚合 BA-对象。

Control-command commanding
控制命令命令是典型的运行时条件，其中照明输入对象接收由具有元素 [PrOp]、[PrLvl] 和 [PrStep] 的结构化当前值属性表示的按钮命令。 R_LGTX 向命令照明 XFB 提供最新的输入请求。命令 lighting XFB 将带有优先级的请求写入照明输出对象，并读取actual照明状态和值（可能与命令的不同）以及照明输出对象的当前优先级。命令照明 XFB 将这些值提供回 R_LGTX，以（可选）写入每个聚合照明输入对象的属性（照明状态、照明值和房间操作员单位，手动操作锁定）。由于通常有多个输入影响相同的灯光，因此每个输入对象需要根据最近的输入请求了解并反映灯光的实际状态和值。

Manual operation lock
命令 lighting XFB 可以读取灯光输出对象的当前优先级，如果它高于手动操作所使用的优先级，则可以通知灯光输入设备并阻止手动操作。

Hardware interrupt

该XFB支持硬件中断（OB触发器），以立即响应特定事件，例如手动开关灯。如果在分配给 OB40 或 OB41 的图表中应用 XFB，则在来自 I/O 模块的中断信号上自动发生 OB 触发。

Compatible data points:

  • Lighting input [LgtIn]

参考data point objects有关 BACnet 数据点的详细说明。

Required properties:

  • Present value
  • State flag
  • Update count
  • Lighting value
  • Lighting state

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

瓦尔

Value

实数（默认值：0.0）

控制程序从照明输出对象读取的照明执行器的当前值。

[Val] 表示要写入所有聚合成员照明输入对象的照明值属性。 [Val] 的输入和使用是可选的。

[Val] 将为以下任何一项写入：

  • [Val] changes by an amount equal or greater than [TshVal].
  • [Val] changes to ActlMin (0) or to ActlMax (100). [TshVal] is ignored.
    (ActlMin and ActlMax are internal variables of this XFB.)
  • [RptWrit] is True.

Note
[Val] 将被写入所有聚合成员照明输入对象，无论有效或停止服务状态。这些状态（故障、停止运行）适用于当前值字段（操作、级别和步进增量）的物理输入。如果可以与对象进行通信，则当前应用程序定向值的更新仍然适用于发送到对象字段。

斯塔

State

布尔值（默认值：False）

控制程序从照明输出对象读取的照明执行器的当前状态。

[Sta] 表示写入所有聚合成员照明输入对象的照明状态 (On/Off) 的照明状态属性。 [Sta] 的输入和使用是可选的。

有下列情况之一的，将写为 [Sta]：

  • [Sta] changes.
  • [RptWrit] is True.

Note
[Sta] 将被写入所有聚合成员照明输入对象，无论有效或停止服务状态。这些状态（故障、停止运行）适用于当前值字段（操作、级别和步进增量）的物理输入。如果可以与对象进行通信，则当前应用程序定向值的更新仍然适用于发送到对象字段。

TshVal

Threshold value

实数（默认值：1.0）

用于控制 XFB 写入尝试的参数化值。仅当值差等于或大于 [TshVal] 时才允许尝试。

例外：更改等于限制值，例如 0.0 或 100.0（[TshVal] 被忽略）。

Note
[TshVal]must not设置为 0.0。

ManOpLck

Manual operation locked

布尔值（默认值：False）

[ManOpLck] 提供有关是否允许在照明输入设备（按钮或操作面板）上进行手动操作的信息。灯光命令XFB可以读取灯光输出对象当前的优先级，如果它高于手动操作所使用的优先级，则可以通知灯光输入设备并阻止手动操作。 [ManOpLck] 的输入和使用是可选的。

[ManOpLck] 将针对以下任一情况写入：

  • [ManOpLck] changes
  • [RptWrit] is True.

Note
[ManOpLck] 将被写入所有聚合成员照明输入对象，无论其状态是否有效或停止服务。这些状态（故障、停止运行）适用于当前值字段（操作、级别和步进增量）的物理输入。如果可以与对象进行通信，则当前应用程序定向值的更新仍然适用于发送到对象字段。

RptWrit

Repeat write

布尔值（默认值：False）

[RptWrit] 强制将输入 [Val]、[Sta] 和 [ManOpLck] 写入照明输入对象。只要 [RptWrit] 为 True，每个程序周期都会重复写入操作。

[RptWrit]通常由控制程序计算和设置。

Note
不得通过连接到始终为 True 的块输出来强制将 [RptWrit] 永久设置为 True。这样做会导致高水平的通信流量。

1（正确）

只要 [RptWrit] 为 True，[Val] 和 [Sta] 就会在每个程序周期写入照明输入对象。

0（假）
默认

没有行动。

Pin description (outputs)

PrOp

Present operation

整数（默认值：0）

来自聚合照明输入对象的最后更新成员的当前值属性的操作元素的值。

如果 [Valid] = False，[PrOp] 将提供最后一个有效值。

0（停止）默认值

命令停止调光。

1（开始调暗）

用于连续增加当前调光值直至 100% 或直到收到停止命令的命令。

2（开始调暗）

用于将当前调光值连续减小至 0% 或直到收到停止命令为止的命令。

3（升级）

通过添加 [PrStep] 指定的量，以离散步骤（步进增量）增加当前调光值的命令。

4（降压）

通过减去 [PrStep] 指定的量，以离散步长（步进增量）减少当前调光值的命令。

5（开启）

打开照明执行器的命令。

6（关闭）

关闭照明执行器的命令。

7（转到级别）

直接将照明执行器设置为[PrLvl]指定的目标电平的命令。 （例如，目标状态指挥。）

20（无命令）

指示不对照明执行器采取任何操作的命令。

PrLvl

Present level

实数（默认值：0.0）

来自聚合照明输入对象的最后更新成员的当前值属性的级别元素的值。

如果 [Valid] = False，[PrLvl] 将提供最后一个有效值。

PrStep

Present step

实数（默认值：0.0）

来自聚合照明输入对象的最后更新成员的当前值属性的步骤元素的值。

如果 [Valid] = False，[PrStep] 将提供最后一个有效值。

有效的

Valid

布尔值（默认值：False）

指示输出引脚 [PrOp]、[PrLvl] 或 [PrStep] 是否可靠。

1（正确）

当前值输出引脚可靠。

  • XFB can access the lighting input object(s).

AND

  • In the last updated object, fault flag in state flag property = 0 (no fault)
    (Reliability = 0 (no error) or Reliability was not detected).

0（假）

当前值输出引脚不可靠。

  • XFB cannot access the lighting input object(s).

OR

  • In the last updated object, fault flag in state flag property = 1 (fault)
    (Reliability ≠ 0).

UpdInd

Update indication

布尔值（默认值：False）

指示聚合成员对象之一的当前值（结构化照明输入命令）属性是否已新更新。

发生更新时，[UpdInd] 从 0 切换到 1 (True)，并在下一个周期（立即）返回到 0 (False)。如果没有连接到 [UpdInd] 的附加功能块（例如计数器功能块），则无法检测切换。仅当 [Valid] 为 True 时，[UpdInd] 才会设置为 True。

[UpdInd] 使用更新计数属性。如果新值与先前值相同，则可以将值识别为已更新。

UpdMbr

Update member

整数（默认值：0）

最后更新的照明输入对象。

[UpdMbr] 将显示最后更新的成员对象的集合视图节点对象 ItemId 的索引号。

NumVals

Number of valid values

整数（默认值：0）

集合视图节点对象中有效照明输入对象的数量。

NumMbrs

Number of aggregated members

整数（默认值：0）

集合视图节点对象中成员对象的总数。

ErrCode

Error code indication

整数（默认值：20）

上次执行 XFB 读操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.

ErrWrit

Error while writing

整数（默认值：20）

上次对结果对象执行 XFB 写入操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.
