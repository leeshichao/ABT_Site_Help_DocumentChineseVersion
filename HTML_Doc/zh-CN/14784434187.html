优先事项

Priority stages

程序块、功能块以及输入和输出交换命令和请求。由于各种命令可能重叠，因此必须按紧急程度确定命令的优先级。为此，这些命令接收不同的优先级。

存在以下优先级组：

  • Emergency mode with priority stages 1…3
  • Protection function with priority stages 4…6
  • Manual mode with priority stages 7, 8 and 13
  • Automatic mode with priority stages 9…12 and 14…16
  • Default value with priority stage 17 (no priority)

使用此优先级机制的 BACnet 对象具有优先级矩阵。优先级矩阵包括所有 17 个优先级。优先级矩阵中的条目可以通过与输出对象的输入互连或通过 BACnet 从程序到达。

BACnet 对象的输出 [PrVal] 上的命令由优先级矩阵中具有最高优先级（最低编号）的条目组成。该值显示在输出块的输出 [PrVal] 上。如果有多个命令，则选择最新的命令，例如具有相同优先级的启用请求可用。一旦当前命令不再可用，就会选择具有下一个较低优先级阶段的命令。
