Add devices
  1. A building structure is defined.
  1. Go to Building > Building structure.
  2. Right-click a building or building element and select Add devices.
  3. The Add devices dialog box opens.
    Add devices (Dialog box)
  4. In the Application templates table, select a device from the Device types list, for example, PXC4/5, PXC7 or PXG3.W200-2.

  5. Click Next.
  6. In the Number of new devices field, type the number of devices to be created.
  7. The table is updated automatically and shows the entered number of devices.
  8. Enter the details such as network address, equipment ID etc.
    Add devices (Dialog box)
  9. Click OK.
  1. The new devices are added to your project and to your building structure.
    Note: No BACnet/SC configuration is adopted when a device is created or duplicated.
Add automation stations
  1. A building structure is defined.
    Defining a building structure
  2. There is at least one application template in your project or in your library to select. If there is no application template available, click Add application template in Building > Building structure.
    Adding project-specific application templates
  1. Go to Building > Building structure.
  2. Right-click a building or building element and select Add devices.
  3. The Add devices dialog box opens.
    Add devices (Dialog box)
  4. Select an application template from the Application templates table.
  5. Click Next.
  6. In the Number of devices field, type the number of automation stations to be created.
  7. The table is updated automatically and shows the entered number of automation stations.
  8. Enter the details such as network address, equipment ID etc.
    Add devices (Dialog box)
  9. Click OK.
  1. The new automation stations are added to your project and to your building structure.
    Note: No BACnet/SC configuration is adopted when a device is created or duplicated.
