与同一自动化站上的工厂交换数据

要与同一自动化站上的其他工厂交换数据，您可以连接图表、使用通用现场设备或使用通用 BACnet 值对象。

Exchange data by connecting charts

  1. Open the chart of plant 1 and the chart of plant 2.
  2. Click the Split window vertically icon in the toolbar.
  3. The chart of plant 1 is shown in the left window and the chart of plant 2 is shown in the right window.
  4. Drag the output pin of the block of plant 1 to the input pin of the block of plant 2.
  1. The blocks are connected and the connection is visible.

Exchange data by using a common field device

  1. Open the chart of plant 2.
  2. Drag a BACnet input object from the Project tree of plant 1 to a function block in plant 2 or to an empty space in the chart of plant 2.

Exchange data by using a common BACnet value object

  1. Select plant 1 in the Plants navigation view and click the BACnet view icon.
  2. The BACnet object view opens.
  3. Open the chart of plant 2.
  4. Drag a function block from the Library to the chart of plant 2.
  5. Click the Split window vertically icon.
  6. The BACnet object view of plant 1 is shown in the left window and the chart of plant 2 is shown in the right window.
  7. Drag a BACnet object from the BACnet object view onto the function block in the chart of plant 2.
