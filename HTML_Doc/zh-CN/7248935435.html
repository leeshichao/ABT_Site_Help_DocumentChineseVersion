RC：读取配置扩展

读取配置扩展 xFB 支持读取由配置扩展定义的一组参数。配置扩展附加到功能类型的视图节点对象，并且 RC 允许访问配置扩展的属性。 （每个功能单元代表需要特定参数集的特定功能。）

仅当相应的触发标志指示 BA 对象的任何属性发生更改时，XFB 才会执行读取操作。 SFC 返回每个属性的指示，指示读取是否成功。

有许多特定的 RC xFBs，每个房间和具有配置扩展的房间段应用程序功能各有一个。例如，“RC_LgtDlgtCtl01”读取属于功能单元“LgtDlgtCtl01”的配置扩展（日光照明控制 01，取决于日光）。本节末尾列出了示例列表。

Compatible data points:

  • View-Node-Object of type functional

Optional properties:

  • Present priority
  • Reliability

 

Support data types:

数据类型

REAL

BOOLEAN

UNSIGNED

INT

TIME

Note
TIME 格式：在属性上您会看到 60，但在 xFB 输出引脚上您会看到 « T#1M » 。该属性必须以秒为单位；输入“0.1”将是 100 毫秒，这是不正确的。

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

CnfExtn

CnfExtn 定义属于该 XFB 的配置扩展。 ABT 工具使用配置扩展标识将适当的配置扩展附加到视图节点对象

  • CnfExtn is an enumerated data type.
  • CnfExtn value will be set by the system during initiation runtime setup.

CnfExtnVers

CnfExtnVers 定义配置扩展的版本

  • CnfExtnVers will be changed (incremented) when the Config Extension changes e.g adding / removing properties

Pin description (outputs)

我的Par_x

MyPar_a表示BA-View-Node-Object的引用属性的实际值。该属性由 Config-Extension 定义，并且 MyPar_x 将具有与该属性相同的名称。

对于配置扩展的每个属性，将提供适当的 MyPar_x 输出（最多四个：MyPar_a、MyPar_b 等）。

  • MyPar_a is initialized according data type on startup (0.0, 0, false, 0msec, …, and ReadVld will be set to false. Right after initialization the XFB tries to read the property of the Config-Extension.
  • MyPar_a will be set to the value of the referenced property of the Config-Extension, if the property is accessible and could be read successfully.
  • My_Par_a will deliver its last value, in case the property cannot be accessed anymore.

ReadVld

Rea ReadVld指示MyPar_x是否有效

  • ReadVld will be set to true if all properties of the Config-Extension could be read successfully.
  • If ReadVld is false, ErrCode will indicate the respective error reason

ErrCode

Error code indication

整数（默认值：20）

上次执行 XFB 读操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.

Workflow:

Read-Config-Extension XFB 将指示必须将哪个配置扩展分配给视图节点功能对象。绑定会自动进行。

ABT 读取 XFB 提供的配置扩展标识和配置扩展版本信息，并将配置扩展的适当版本附加到视图节点对象。

如果 ABT 找到多个 Read-Config-Extension XFB，则不会完成任何 Config-Extension 的分配并指示错误。
