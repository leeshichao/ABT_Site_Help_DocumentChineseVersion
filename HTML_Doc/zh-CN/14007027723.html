[HOLD_R] 保持实际值

功能块 HOLD_R 将当前或保存的输入值切换到输出。

如果输入 [Hld] 的值为 1，HOLD_R 将保留输出 [Out] 上的最后一个值。如果 [Hld] 的值为 0，则在输出 [Out] 处提供输入 [In] 的当前值。

Process response

启动时，HOLD_R 保存 BACnet 对象中的持久值。如果 [Hld] = 1，则设置读出的持久值并将其保存在输出 [Out] 上。如果 [Pers] = 0 或访问错误，则使用第一个处理周期的输入值 [In] 设置输出 [Out]。

持久值必须作为扩展属性在关联的 BACnet 对象上可用（“通过持久性扩展”=“保留实数”）

Application example

如果保存输入值以供以后获取的处理，则使用 HOLD_R。例如，保存测量值或计算的设定值。
