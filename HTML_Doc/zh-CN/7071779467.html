通过 USB 端口连接

USB 电缆将调试笔记本电脑连接到设备。

此外，设备还建立与 IP 或 MS/TP 网络的附加连接。如果连接的设备重新启动（例如，在配置期间等），调试笔记本电脑与 IP 或 MS/TP 网络之间的连接将中断。

Connect the USB cable

提供一根 USB 电缆（一端为 A 型插头，另一端为 B 型插头）。
USB 驱动程序 RNDIS 已安装（Windows 10 或更高版本）或本地存在。

较旧的设备可能仍使用西门子 USB 远程 NDIS 网络设备驱动程序。

  1. Plug in the USB cable to the commissioning laptop and device.
  2. A new USB IP network connection is created.
  3. In the Common toolbar, select the arrow beside the Connect button.
    Connect and disconnect
  4. Select the USB tab.
  5. Configure the connection.
    • Select the device type: IP for DXR2.E../PXC..E.. devices or MS/TP for DXR2.M../TXB3.M devices or PTP for all DXR1.. devices.
  6. Click Connect.
  7. The connection is made to the Ethernet/IP network.
  8. Select Startup > Configure and download.
    The device can now be discovered.
