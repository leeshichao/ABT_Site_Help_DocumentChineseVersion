创建 ABT Pro 项目

您可以从 ABT 站点创建 ABT Pro 项目Advanced > ABT Pro.

 

Create an ABT Pro project

  1. Click Add project.
  2. A dialog box opens where you can enter properties for the new project.
  3. Enter the data according to your project specifications. See table below.
  1. The project is created.

命令

描述

项目名称

要使用的项目的名称。

Note
输入项目名称后，将无法重命名该项目。

小路

只读信息。该项目保存在当前 ABT 站点项目的目录中。您可以更改 ABT 站点项目路径Project Manager > Settings.
Settings

作者

作者姓名。默认为当前登录用户的名称。

评论

该项目的免费评论。评论将显示在Advanced > ABT Pro，在Description场地。
