设备实例编号

环境

描述

每个单位的数量范围

定义每个单位的范围。允许使用 1 到 4'194'302 之间的数字。默认为200.

您可以检查重复的设备实例编号Building > Device list.

③ Room ID overview tab

列出客户项目中有关房间 IDs 的所有可用信息。对于每个应用程序模板，会列出第一个和最后一个使用的房间 ID 以及定义的房间 ID 结尾。数据是只读的。

环境

描述

用法

应用程序模板或 ABT Pro 项目的名称。

Room ID start

应用程序模板或 ABT Pro 项目的第一个使用的房间 ID。

最后使用的房间 ID

应用程序模板或 ABT Pro 项目最后使用的房间 ID。

Room ID end

应用程序模板或 ABT Pro 项目的最后一个可用房间 ID

Get new range

您可以通过单击获取房间 IDs、组编号和设备实例的新范围Get new range。系统将根据设置的每个单位的编号范围来扩展结束编号。Range settings选项卡。

创建设备并用完 ID 范围后，删除设备后系统不会释放已使用的范围。如果您用完了一个系列，您需要获得一个新的系列才能添加新设备。要获取新范围，请打开Settings > Number ranges，选择对应的概览，点击Get new range.

 

④ Central function overview tab

列出有关客户项目中的中心功能的所有可用信息。对于每次使用，都会列出组类别、第一个和最后一个使用的组编号以及组编号末尾。数据是只读的。

环境

描述

用法

ABT Pro 项目或基于类型的中央函数的名称。同一名称可以为多个组类别列出多次。

团体类别

组类别的名称，例如中央气象站。同一类别可以在不同的应用程序模板或 ABT Pro 项目中多次列出。

组号开始

此应用程序模板或 ABT Pro 项目中组类别的第一个使用的组编号。

最后使用的组号

此应用程序模板或 ABT Pro 项目中最后使用的组类别的组编号。

组号结尾

此应用程序模板或 ABT Pro 项目中组类别的最后一个可用组编号。

 

⑤ Device instance number overview tab

列出有关客户项目中的设备实例编号的所有可用信息。对于每次使用，都会列出起始编号、结束编号和最后使用的设备实例编号。 ABT Pro 项目的设备实例编号不可用。数据是只读的。

设备实例号开始

最后使用的设备实例编号

应用模板最后使用的设备实例编号。
Note
不显示 ABT Pro 项目最后使用的设备实例编号。它们由 ABT Pro 管理。

终端设备实例编号
