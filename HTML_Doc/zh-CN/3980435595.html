CNT_UPDN：向上和向下计数器

CNT_UPDN (FB446) 块形成一个斜率控制的向上 /downward 计数器。

功能性

向上计数器输入 [CntUp] 处的模块以递增斜率向上计数至最大计数器限制 [CntValLm]，或在向下计数器输入 [CntDn] 处向下计数至计数器下限 0。计数增量为 1。

当达到计数器上限时，计数器停止并设置 [LmRd] = 1（是）。

当达到计数器下限时，计数器停止并设置 [ZeRd] = 1（是）。

如果模块在输入 [CntUp] 和 [CntDn] 处具有递增的斜率，则计数器保持其值。

当前计数器值位于输出 [CntVal] 处，当前计数器状态位于输出 [LmRd]（达到或超过 [CntValLm] 上限）或 [ZeRd]（达到或低于计数器值 0）。

如果由于计数器以高于限制的起始值启动，或者因为上限设置为低于当前计数器值的值而超出计数器上限，则 [LmRd] = 1（是）。对于输入 [CntUp] 处的更多计数器脉冲，计数器保留其当前计数器值；通过输入 [CntDn] 处的计数器脉冲向下计数仍然是可能的。

通过复位输入 [CntReset] 复位计数器。如果 [CntReset] 1（是），则计数器设置为 0。

计数器还可以设置为起始值 [SttVal]。如果 [SetStt] 为 1（是），[SttVal] 表示当前计数器值。如果计数器起始值 [SttVal] 为负，则通过 [SetStt] 信号 ([SetStt] = 1) 为计数器设置值“0”。

Caution

  • [SetStt] and [CntReset] are not slope-controlled.
  • When using this block, remember that the counter can be incremented or decremented only after the second machine cycle because of slope control.

计数器可接受高于计数器上限 [CntValLm] 的值，因为高于 [CntValLm] 的值对于计数器起始值 [SttVal] 也是可能的。计数器上限 [CntValLm] 允许负值。达到计数器限制的可能计数增量数取决于起始值（或 [CntReset]）、计数方向、当前计数器值以及当前计数器值是否高于计数器限制。

当开始新的向上计数过程时，[CntReset]和[CntUp]可以同时执行。计数器相应地初始化并开始向上计数。

当开始新的向下计数过程时，[CntDn]和[SetStt]可以同时执行。计数器相应地初始化并开始向下计数。

如果同时存在[CntReset]，则具有优先权。

应用

该块用于对可通过斜率进行评估的事件进行计数。例如，这些是双执行器（泵、风扇、压缩机）的开关，以便根据定义的顺序更改控制聚合。另外，可以根据这些开关生成维护消息。

过程响应

从第二个处理周期开始，该块将使用输入处的值进行处理，因为只有此时输入处的值才被视为有效。默认值在第一个处理周期内发布。

Note:输入 [CntUp] 或 [CntDn] 处的连续信号在启动时被识别为递增斜率。
