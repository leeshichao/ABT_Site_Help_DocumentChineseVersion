Release parameters

  1. Open Startup > Global functions.
  2. Select the Command tab.
  3. Select a command list.
  4. A list of parameters displays by description, units, and value field. The list provides units, range checking, default value, and state text.
  5. Select the parameters in the Command tab or the building elements in the Discovered devices tab to select all associated parameters.
  6. Click Release.
  1. The selected parameters are removed from the table if the Release command is successful. For parameters with a priority array, a relinquish command is sent to the device.
