② Project information

柱子

描述

姓名

项目名称是只读的（请参见Project Manager > Projects).

描述

输入描述文本（自由文本，最多 1024 个字符）。

版本

输入项目的版本号（自由文本，最多 255 个字符）。

SAP 设备编号

输入公司的 SAP 编号（自由文本，最多 255 个字符）。

地点

位置信息在项目管理器中可见，可用于过滤项目

 

顾客

输入客户姓名（自由文本，最多 255 个字符）。

国家

输入项目所在的国家/地区（自由文本，最多 255 个字符）。

地区

输入项目所在区域（自由文本，最多 255 个字符）。

地址

输入项目所在的地址（自由文本，最多 255 个字符）。

城市

输入项目所在的城市名称（自由文本，最多 255 个字符）。

邮政编码

输入项目所在的邮政编码（自由文本，最多 255 个字符）。

自定义字段1

建议始终使用自由文本字段（最多 255 个字符）来表示组织内相同类型的信息。

自定义字段2

建议始终使用自由文本字段（最多 255 个字符）来表示组织内相同类型的信息。

作者

对于组织内相同类型的信息，建议始终使用自由文本字段（最多 1024 个字符）。

位置信息也可在项目管理器的位置栏中找到（请参阅Project Manager > Projects).
