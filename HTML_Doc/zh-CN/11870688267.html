转换项目

使用旧工具版本创建的项目必须进行转换。一次转换可以直接在Project Manager > Projects. 不支持对 Branch Office Server (XWP-BOS) 管理的客户项目进行单一转换。请联系您当地的工具经理以获得转换项目的支持。

对整个项目都有效。以下进一步信息仅适用于客房申请。

基于 Pack & Go 或 Pack & Return 数据的项目无法转换。

包含 ABT Pro 数据的项目只能通过批量转换进行转换。批量转换实用程序需要单独的许可证。

 

Convert a project

  1. The project is marked with the symbol.
  2. The project does not contain ABT Pro project data.
  3. The project is not managed by the Branch Office Server (XWP-BOS).
  1. Double-click the project and click OK.
  2. Enter User name and Password and click OK.
  3. The project is converted. The symbol is no longer displayed.
