配置 RDG2 应用程序类型

  1. A RDG2 KNX PL-Link device was added.
  1. In the KNX PL-Link area, select the device.
  2. Select the Properties tab on the right.
  3. Modify the properties as required.
  4. Select the Configuration tab on the right.
  5. The Configuration view shows the properties of the selected device feature.
  6. In the Name column, select Application type.
  7. From the Application type drop-down list, select the application type.
  8. Configure the required properties in the Configuration view.
    Note: Use the Name filter, for example, P001 or parameter name to display the parameter directly.
