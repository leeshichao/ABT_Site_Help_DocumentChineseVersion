证书（Crtf）

对象证书 (Crtf) 表示 X509 证书的外部可见功能。

TLS/SSL 客户端证书被描述为证书对象，并包含对相应文件的引用。在本例中，使用 BACnet 安全连接节点的客户端证书来建立与服务器的相互 TLS 连接。证书对象承担关于证书有效性的描述和警告。

Basic model

Reliability

 

 

'Reliability' 提供有关证书对象的“当前值”是否可靠的信息。如果“当前值”在证书对象上不可靠，则属性“可靠性”指示失败的根源。

Present value

 

 

'Present value' 显示证书状态的当前输出值。

证书注明：

  • 1: Activated
    The certificate is active.
  • 2: Expiration warning
    The certificate has an expiration warning.
  • 3: Expired
    The certificate is expired.
  • 4: Inactive
    There is no valid certificate.

State flag

 

 

'State flag' 表示证书对象的四种状态。

  • Out of service
    Out of service indicates via property 'Out of service' whether the certificate object was decoupled.
    The applicable certificate management program no longer updates properties 'Present value' and 'Reliability' if "Out of service" is set.
    Properties 'Present value' and 'Reliability' can be updated for simulations and testing if "Out of service" is set.
  • Overridden
    Value = False
  • Fault
    "Fault" indicates whether the certificate is reliable or not. "Fault" indicates whether property 'Reliability' has a value of "No fault" or not.
  • In alarm
    Value = True if intrinsic reporting is possible and the alarm states are set.

Out of service

 

 

'Out of service' 解耦证书对象以防止证书管理程序更改它。

Event state

 

 

'Event state' 确定对象是否属于活动事件状态。如果对象不支持内部报告，则此属性的值为 NORMAL。

Tracking value

 

 

'Tracking value' 表示计算值，无论对象是否通过“停止服务”解耦。证书管理提供了价值。

Number of states

 

 

'Number of states' 定义可以报告“当前值”的状态数。

财产ID：74

State text

 

 

'State text' 描述了可以报告“现值”的状态。

 

Object model

X509 version

 

 

'X509 version'表示X509证书的版本号。

Signature algorithm

 

 

'Signature algorithm' 表示X509证书的签名算法ID。

最大长度：最多 32 个字符。

X509 serial number

 

 

'X509 serial number'表示X509证书的序列号。

最大长度：32 个字符。

Valid from

 

 

'Valid from'表示X509证书的有效期“NotBefore”。

日期和时间类型的属性显示在 GMT 和 UTC 中。

Valid to

 

 

'Valid to'表示X509证书的有效期“NotAfter”。

日期和时间类型的属性显示在 GMT 和 UTC 中。

Issuer

 

 

'Issuer' 表示 X509 证书颁发者的名称。

最大长度：512 个字符

Issuer chain

 

 

'Issuer chain' 通过 X509 证书的属性“CommonName”指示颁发者的证书链。

主题

 

 

“Subject”表示 X509 证书的属性“Subject.Name”。

最大长度：512 个字符

主题名称

 

 

“Subject name”表示 X509 证书的属性“Subject.CommonName”。

这是证书的身份。这是外部签名的 TLS/SSL 证书的 FQDN（完全限定域名）。对于自签名 TLS/SSL 证书，这可以是自动化站名称、ID 或序列号（或其组合）。

最大长度：63 个字符

主题替代名称

 

 

“Subject Alternative name”表示 X509 证书的默认扩展属性“Subject.AltName”。

最大长度：63 个字符（无前缀）

Certificate reference

 

 

'Certificate reference' 引用包含证书的文件。

Expiration warning

 

 

'Expiration warning' 指示何时触发 X509 证书的过期警告。到期日期用于触发警报。该警报旨在在证书最终到期之前更新证书。

Expiration warning time

 

 

'Expiration warning time' 代表一个可配置的永久值，可以在证书最终过期之前触发警告。 X509 证书的属性“有效期至”定义了最终到期时间。 “过期警告时间”表示为以天为单位的相对值（例如 90）。

 

Alarming

根据 BACnet 对象内的内部消息传递原理触发警报。

当报警值变为2（过期警告）或3（过期）时，立即触发报警。

Alarm values

 

 

'Alarm values' 代表“OffNormal”值的选择。

Monitoring time deviation

 

 

'Monitoring time deviation' 确定以 [s] 为单位的时间，在此期间当前状态等于触发事件“To-OffNormal”之前为“警报值”定义的状态。警报值之间的变化也考虑时间。

财产ID：113

Notification type

 

 

"Notification type“传达对象生成的通知是否应为类型”Event“ 或者 ”Alarm".

Event state

 

 

'Event state' 确定对象是否属于活动事件状态。如果对象不支持内部报告，则此属性的值为 NORMAL。

Notification class

 

 

'Notification class' 确定事件的优先级以及事件是否必须被确认或重置。以下是通知类：
1: Highest priority notification (acknowledge, reset)
2: Highest priority notification (acknowledge)
3: Highest priority notification
4: High priority notification (acknowledge, reset)
5: High priority notification (acknowledge)
6: High priority notification
7: Medium priority notification (acknowledge, reset)
8: Medium priority notification (acknowledge)
9: Medium priority notification
10: Low priority notification (acknowledge, reset)
11: Low priority notification (acknowledge)
12: Low priority notification
13: Lowest priority notification (acknowledge, reset)
14: Lowest priority notification (acknowledge)
15: Lowest priority notification
16: None priority notification
17: Buffer ready notification
18: Device alert notification

财产ID：17

Time stamp of event

 

 

"Time stamp of event" 分别传达 TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL 事件的最后事件通知的时间。

Event message texts

 

 

'Event message texts' 由一组三个可写字符串组成，每个状态转换一个（To-Offnormal、To-Fault 和 To-Normal）。
