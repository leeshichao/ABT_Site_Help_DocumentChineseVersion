导出模块和 I/Os（仅适用于 TXB3.M）

您还可以将 I/O 配置数据导出到 xml 文件。第二步，您可以在 xml 编辑器或文本编辑器中编辑该文件，然后重新导入更改的配置。

您无法将附件导入或导出到总线接口模块。


该过程与创建数据导出的过程相同。

Create a data export

  1. Go to Building > Building structure
  2. Select a device or a hierarchy object.
  3. Right-click and select Create export.
  4. The Create export dialog box opens.
  5. Select the type of content to export:
    Select contents
    • Management station/Management platform (Desigo Insight or Desigo CC)
    • Electrical data (CAD)
    • BACnet engineering data exchange (EDE)
      Note: Verify if the Object structure on BACnet is set correctly. KBOB does not allow additional hierarchies (structured view object).
      See Device details
      See BACnet object instances.
    • BACnet object instance numbers (PXC4/5/7 only)
      See BACnet object names.
    • BACnet object names (PXC4/5/7 only)
    • BACnet object properties (PXC4/5/7 only)
    • I/O configuration (TXB3.M/E)
      Scope
    • Selected devices (rooms)
    • All devices from the project
  6. (Optional) Enter a comment.
  7. Click OK.
  1. The selected content is exported to the default directory for exports.
  2. A dialog box displays allowing you to open the containing folder.
