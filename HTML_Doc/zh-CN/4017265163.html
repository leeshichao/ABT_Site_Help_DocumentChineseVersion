趋势日志对象 (TrndLogS)

趋势日志 (TrndLogS) 对象监视引用对象的属性，并在满足预定义条件时将属性值和时间戳保存（“记录”）在内部缓冲区中以供后续检索。当值发生变化或通过写入“触发器”属性“触发”时，可以定期记录数据。触发器属性允许通过网络写入操作或内部进程来控制样本的采集。还会记录阻止数据采集的错误以及记录过程本身的状态或操作的变化。每个带时间戳的缓冲区条目称为趋势日志“记录”。

Enable logging

 

 

"Enable logging" 指示并控制是否启用 (TRUE) 或 (FALSE) 事件和收集的数据记录。当且仅当启用为 TRUE 时才会发生记录，"Local time“ 是在 或 之后 ”Start time“， 和 ”Local time“是之前”Stop time“。 如果 ”Start time" 包含任何通配符，则忽略启用日志记录的条件。如果 "Stop time" 包含任何通配符，则忽略启用日志记录的条件。 "Log buffer" 记录 log-status 类型的记录时不考虑 " 的值Enable logging“ 财产。

Logging Type

 

 

"Logging Type“指定是否”Trend log" 对象使用轮询、COV 或触发采集来收集记录。

Logging interval

 

 

"Logging interval“ 指定在以下情况下记录引用属性的周期间隔（以百分之几秒为单位）：Logging Type" 的值为 POLLED。如果 "Align intervals" 属性具有值 COV 或 TRIGGERED 之一，然后是 " 的值Logging interval“财产为零并被忽略。

Start time

 

 

"Start time" 指定此属性启用日志记录的日期和时间。如果任何日期和时间字段包含通配符值，则启用日志记录的条件为 "Start time" 被忽略。如果 "Start time“指定“之后的日期和时间”Stop time"，则日志记录被禁用。A "Stop time“ 那是之前的”Start time“是不允许的。

Stop time

 

 

"Stop time" 指定此属性禁用日志记录的日期和时间。如果任何日期和时间字段包含通配符值，则禁用日志记录的条件为 "Stop time" 被忽略。如果 "Stop time" 指定早于 " 的日期和时间Start time"，则日志记录被禁用。A "Start time“那是在”之后Stop time“是不允许的。

Stop when full

 

 

"Stop when full" 指定当缓冲区已满时是否停止 (TRUE) 或 (FALSE) 记录。当由于添加一条记录会导致缓冲区已满而停止记录时，Enable 将设置为 FALSE 并记录该事件。

如果 ”Stop when full" 是可写的，尝试将值 TRUE 写入属性，同时 "Record count“等于”Buffer size“导致最旧的日志缓冲区记录被丢弃，并导致”Enable logging" 属性设置为 FALSE 并记录事件。

Buffer size

 

 

"Buffer size" 指定日志缓冲区可以容纳的最大记录数。

"Buffer size”可以由任何工程和调试或操作和监控功能编写。如果“Buffer size" 更改为新的、较小的值时，最旧的日志记录将根据需要被丢弃。
Note
在在线模式下，“Buffer size" 仅当启用日志记录设置为“否”时才能更改。
的值“Buffer size" 必须等于或高于 " 的值Notification threshold".

Align intervals

 

 

"Align intervals" 指定是否启用 (TRUE) 或 (FALSE) 时钟对齐的定期记录。如果启用定期记录，则 " 的值Logging interval" 是秒、分钟、小时或天的因数（即，除以无余数），则指定用于记录的周期的开始分别与秒、分钟、小时或天对齐。

如果对象支持时钟对齐日志记录，则需要此属性。如果“Logging Type" 属性的值不是 POLLED。

Interval offset

 

 

"Interval offset" 指定从为日志记录指定的时间段开始到实际获取日志记录开始之间的偏移量（以百分之秒为单位）。使用的偏移量是 " 的值Interval offset“取模”的值Logging interval”。也就是说，如果“Interval offset" 值为 31 且 "Logging interval“为30，使用的偏移量为1。”Interval offset“如果”则无效Align intervals" = FALSE。如果对象支持时钟对齐日志记录，则需要此属性。

Log device object property ✳

 

 

"Log device object property“指定要用作 BACnet 的对象属性”Trend log" object's data source. The data source object property is identified by a device object property reference, which includes the following elements:

  • Device-ID: Specifies the device in which the data source object is located. For "Trend log" objects that support only local trending, the device ID element is omitted.
  • Object-ID: Specifies the data source object.
  • Property-ID: Specifies the data source property.

Log buffer

 

 

"Log buffer" 是 BACnet 日志记录的列表。每个日志记录传达一组记录的数据值或与数据收集相关的错误、" 中的状态更改Trend log multiple”，或者指示托管“的设备中的时间和/or日期已更改Trend log multiple“ 目的。

State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Record count

 

 

"Record count" 表示当前驻留在 Log_Buffer 中的日志记录数。向此属性写入零值会导致 Log_Buffer 中的所有日志记录被删除，并且 Records_Since_Notification 重置为零。完成后，此事件将作为初始条目在日志中报告。

BACnet 属性：[Record_Count]

Total record count

 

 

"Total record count" 表示 BA-Trend-Log 或 BA-Trend-Log-Multiple 对象自创建以来收集的记录总数。当 Total-Record-Count 的值达到其最大可能值 232 – 1 时，它采用的下一个值是 1。一旦该值返回到 1，其语义值（收集的记录总数）就会丢失，但在生成通知中的用途仍然存在。

Notification threshold

 

 

"Notification threshold“指定”的值Records collected since notification” 发生通知。

Resubscription interval for COV

 

 

"Resubscription interval for COV" 如果趋势日志通过 COV 订阅从远程设备获取数据，则指定 COV 重新订阅之间的秒数。前提是 COV 订阅有效。

  • This optional property, of type Unsigned, specifies the number of seconds between COV resubscriptions, provided that COV subscription is in effect.
  • SubscribeCOV requests specify twice this lifetime for the subscription and specify the issuance of confirmed notifications.
  • If COV subscriptions are in effect, the first COV subscription is issued when the Trend Log object begins operation or when Enable becomes TRUE.
  • If present, the value of this property is non-zero. If this property is not present, then COV subscription is not attempted.

Records collected since notification

 

 

"Records collected since notification" 表示自上次通知以来收集的记录数，或者如果之前没有发生通知，则表示自记录开始以来收集的记录数。

Last notified record number

 

 

"Last notified record number" 表示导致 Records-Since-Notification 属性的值等于或大于 Notification-Threshold 属性的值的趋势记录的序列号。如果自记录开始后没有发生任何通知，则 Last-Notify-Record 的值为零。

Notification class

 

 

"Notification class“ 持有对“ 的引用Notification class object”，并指出是哪个“Notification class object" 在为此对象生成通知时使用。

Event enable

 

 

“事件启用”启用或禁用特定事件通知功能（即在工程/configuration期间）。

异常状态

允许启用和禁用 TO-OFFNORMAL 事件通知功能。

故障

允许启用和禁用 TO-FAULT 事件通知功能。

恢复正常

允许启用和禁用 TO-NORMAL 事件通知功能。

Acknowledged transitions

 

 

"Acknowledged transitions" 传送三个标志，分别指示 TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL 事件的确认接收。这些标志在发生相应事件时被清除，并在以下任何条件下设置：

  • Upon receipt of the corresponding acknowledgment;
  • Upon the occurrence of the event if the corresponding flag is not set in the "Event enable" property (meaning event notifications will not be generated for this condition and thus no acknowledgment is expected);
  • Upon the occurrence of the event if the corresponding flag is set in the "Event enable" property and the corresponding flag in the "Acknowledgement required" property of the "Notification class" object implicitly referenced by the "Notification class" property of this object is not set (meaning no acknowledgment is expected).

Notification type

 

 

"Notification type“传达对象生成的通知是否应为类型”Event“ 或者 ”Alarm".

Time stamp of event

 

 

"Time stamp of event" 分别传达 TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL 事件的最后事件通知的时间。

Enable event detection

 

 

"Enable event detection" 允许在工程时启用或禁用相应对象的事件通知。当 "Enable event detection" 为 false，则对象的内部算法不执行。因此，不会发出事件通知，并且对象的动态属性不会更新。

Event state

 

 

"Event state“提供了一种方法来确定该对象是否具有与其关联的活动事件状态。”Event state”属性表示对象的事件状态。“中的变化Event state" 值为 FAULT 的属性被视为故障事件。如果对象不支持内部报告，则该属性的值为 NORMAL。
