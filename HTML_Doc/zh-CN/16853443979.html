[CMP_T] TIME 值的比较器

Description

该指令比较两个输入值并设置输出值，如下所示：

  • GT = 1 if IN1 > IN2
  • GE = 1 if IN1 ≥ IN2
  • EQ = 1 if IN1 = IN2
  • LE = 1, if IN1 ≤ IN2
  • LT = 1 if IN1 < IN2
