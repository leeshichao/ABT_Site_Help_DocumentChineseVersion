Number of bits ✳

 

 

"Number of bits" 定义位集的大小（无符号）。

范围：2…16； 16:=U16-B 和 U16-L

Heartbeat timers ✳

 

 

"Heartbeat timers”定义了如果“当前值”长时间没有变化，则用于更新子系统特定数据点的心跳计时器。

H1、H2 的间隔值可以在现场总线管理对象中配置。
心跳计时器独立于 COV 触发的更新。
心跳定时器和轮询定时器是相互独立的。

没有更新子系统特定的数据点。

H1

H2

低优先级。典型间隔值：分钟...小时。

Mapping table ✳

 

 

"Mapping table” 定义“当前值”到子系统特定位集数据的映射，该数据对应于“的数组索引”Mapping table”.映射表

实际长度的约束：
映射表、状态数和状态文本需要相同的长度。

例子：
当前值=1 => 映射表[1]:=0x0000 => 0x0000
当前值=2 => 映射表[2]:=0x0001 => 0x0001

Min repetition time ✳

 

 

"Min repetition time“定义了 Modbus 数据点的两次连续更新之间的最短等待时间。

"Min repetition time”用于在“当前值”变化过大的情况下限制网络流量。

"Min repetition time" 可以为零以允许快速更新 MODBUS 数据点。
