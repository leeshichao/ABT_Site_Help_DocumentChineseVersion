R_MNFTR：读取主要功能

R_MNFTR 在启动时读取预加载应用程序的主要功能配置，并提供信号以启用/disable 运行时操作的适当主要功能。

XFB 在预加载应用程序的上下文中使用，以评估配置的主要功能并提供启用信号以启用适当的主要功能图表。

Note
R_MNFTR 的接口与 R_FTR（读取功能）XFB 的接口相同，但 input/output 引脚可见。对于 R_MNFTR，仅 Ftr1、EnFtr1、FtrValid 和 ErrCode 可见。其他引脚不可见，但可供将来使用（例如，用于主要功能变体）。

 

Compatible with:

  • View node object (Functional)

 

Required properties:

  • Node subtype (datatype = character string, 14 character max length)

 

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。当 CFC 图表绑定到应用程序函数时，绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

未使用 [DeviceId]。对于间接访问引用，该值将保留为默认值。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。当 CFC 图表绑定到应用程序函数时，绑定会自动发生。

ItemId

物品标识符

整数（默认值：-1）

[ItemId]表示功能视图节点对象中的索引项，它引用BACnet对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。当 CFC 图表绑定到应用程序函数时，绑定会自动发生。

FtrTyp

特征类型

整数（默认值：0）

<不可见>

[FtrTyp] 是一个枚举，指定由 xFB 管理的特征选择类型：

  • 0: Optional (this feature is not required; the option can be enabled)
  • 1: Mandatory alternative (this feature is required; a variant must be enabled)
  • 2: Optional alternative (this feature is not required; a variant can be enabled)

FT1

特点1

字符串，最大长度 14 个字符（默认值：<空>）

[Ftr1] 是用于指定功能变体的多个输入引脚之一。引脚由应用工程师在 CFC 中设置。

如果 [Ftr1] 与已配置功能的视图节点对象中的节点子类型属性字符串匹配，则输出引脚 [EnFtr1] 设置为 True，发送应用程序用于启用该功能的相应嵌套应用程序模块的信号。

[Ftr2]...[Ftr10] 功能与 [Ftr1] 相同。

 

Pin description (outputs)

NoFtrCnf

没有配置任何功能

布尔值（默认值：False）

<不可见>

[NoFtrCnf] 用于指示尚未配置/未使用某个功能。

[NoFtrCnf] 初始化为 False。当 [FtrTyp] 为可选（≠1）且 xFB 成功检测到未配置任何功能时，[NoFtrCnf] 将设置为 True（在这种情况下，[FtrValid] 将为 True）。

如果 xFB 无法成功读取功能配置，[NoFtrCnf] 也将设置为 True（在这种情况下，[FtrValid] 将为 False）。

0（假）

该功能已配置。

1（正确）

该功能尚未配置或无法成功读取功能配置。

EnFtr1

启用功能 1

布尔值（默认值：False）

[EnFtr1]表示[Ftr1]指定的功能是否已配置。

[EnFtr1] 初始化为 False。如果 [Ftr1] 与已配置功能的 View 节点中的 Node 子类型属性字符串匹配，则 [EnFtr1] 设置为 True，发送应用程序用于启用相应嵌套应用程序模块的信号。

[EnFtr2]...[EnFtr10] 功能与 [EnFtr1] 相同。

Note
两个或多个启用功能输出引脚不能同时为 True。

FtrValid

功能有效

布尔值（默认值：False）

[FtrValid]表示特性配置是否有效。

如果出现以下情况，[FtrValid] 将设置为 False：

  • [FtrTyp] is mandatory (= 1) but no feature has been configured.
  • None of the [Ftr1..Ftr10] entries match the (successfully read) Node subtype property.
  • The feature configuration could not be read successfully by the xFB.

0（假）

功能配置无效或无法成功读取。

1（正确）

功能配置有效，并且 xFB 能够成功读取它。

ErrCode

Error code indication

整数（默认值：20）

上次执行 xFB 读操作的状态。

当[FtrValid]为True时，[ErrCode]将= 0，无错误。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.
