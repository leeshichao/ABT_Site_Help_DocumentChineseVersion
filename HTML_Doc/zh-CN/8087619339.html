Naming & Addressing tab

柱子

描述

姓名

自动化站的名称。

地点

自动化站的位置

描述

自动化站说明

Equipment ID

自动化站的设备ID。

设备实例编号

与 BACnet 设备关联的设备序列号（设备实例号）。

网络号 (MS/TP)

标识网络的编号。范围 1-65534。默认 1。

Use DHCP

如果选择，DHCP 用于自动配置 IP 地址。

自动寻址 (MS/TP)

激活后，会自动获取 MAC 地址设置。

地址

IP 设备的地址。

MAC address (MS/TP)

MS/TP 端口的第一个 MAC 地址。

波特率（MS/TP

指定数据发送到总线的速率。

最大管理器地址 (MS/TP)

设置Max manager address以防止将令牌传递到位于管理器 (MS/TP) 之后的未使用的 MAC 地址。

 

Instance parameter tab

柱子

描述

姓名

自动化站名称。只读。

地点

区位名称由建筑结构位置和房间、房间段或中心功能的名称组成。只读。

设备标签

自动化站设备ID。只读。

实例参数

每个实例参数一列。该列表包含对象描述、参数描述、值和单位。

您只能在 ABT 站点中查看和更改参数值，如果Avail. on AS选中所选参数的复选框。这Avail. on AS复选框设置在Configuration > Default values.
Configuring default values (template)
如果选择，相应的对象参数将在以下区域中可用：

  1. Device details > Instance parameter page
  2. Application template details > Instance parameter tab
  3. Building > Device list > Load instance parameter
  4. Checkout report
