导入备用 IEEE 802.1X 根证书

创建项目时，ABT Site 会创建一个对整个项目有效的根证书。您还可以在 ABT 站点中导入备用根证书。例如，当您的 IT 部门要求您使用由 IT 部门选择的专用 CA（证书颁发机构）生成的专有根证书时，可能会出现这种情况。

如果您需要回滚到 ABT 站点的内部根证书，您可以重新生成内部根证书。
Regenerate IEEE802.1X internal root certificate

 

Import an alternative root certificate

  1. You have an alternative root certificate, for example, from the IT department.
  1. Go to Settings.
  2. Open the Certificates task.
  3. Select the IEEE802.1X certificates tab.
  4. In the toolbar, click Import external signing certificate.
  5. Select the root certificate and click Open.
  6. You have imported a root certificate. The old root certificate is still present in the project.
  7. Download the configuration to the devices to transfer the additional trusted root certificates.
