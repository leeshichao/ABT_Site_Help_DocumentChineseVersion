I/O 分配（任务）

这I/O assignment任务允许您在应用程序模板中配置 I/O 分配。

I/O 可以通过两种方式分配：

  • Individually for each automation station in the I/O assignment tab of the Details pane of a room.
    Assigning I/O's (areas)
  • Per application template in the I/O assignment task.
    Assigning I/O's (template)

Do not change the I/O address in Web interface

NOTICE

数据点不改变状态

  1. The data point freezes at status Normal or current value when the I/O address is changed online in the web interface.
  2. The data point can no longer be accessed, and the connection status is .

    When making another change, for example, setting the data point to Out of Service, it remains frozen in status Normal or current value, the connection status changes to  and the device must be restarted.
  3. Change the I/O address offline in ABT Site and download the control program to the device.

选择 I/O 和执行器，然后单击Assign分配 I/O 的。

点击Remove删除选定的 I/O 分配。
点击Clear删除按钮集合的所有 I/O 分配。
点击Reset将选定的按钮集合重置为应用程序模板的设置。

这些按钮位于Description目标表中分配的 I/O 和按钮集合旁边的列。

最初，源列表和目标列表是从应用程序类型和应用程序模板中读取的。应用程序类型定义自动连接规则，通常是源和集合之间的一对一连接，例如 LgtBtn(1) 和 LgtBtnCol。具有自动连接规则的分配由图标。
