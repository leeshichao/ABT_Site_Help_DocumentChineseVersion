报告

这Reports组件只包含一项任务：Reports任务。使用Reports管理特定于项目的报告的任务。生成的报告可以打开、查看、打印和导出。

② Group tree

显示一个树，您可以在其中导航每个设备的报告页面。

③ Preview area

这Preview区域显示生成的报告。

④ Preview status bar

这Preview状态栏显示页码（例如第 1 页，共 3 页），以及自定义报告视图的工具栏（例如Zoom).

出口报告

打开Export report您可以在其中浏览目录、选择文件类型并保存报告的对话框。支持以下文件类型：

  • PDF (*.pdf)
  • Microsoft Excel (97-2003) (*.xls)
  • Microsoft Excel (97-2003) Data-Only (*.xls)
  • Microsoft Excel Workbook Data-Only (*.xlsx)
  • Microsoft Word (97-2003) (*.doc)
  • Character Separated Values (CSV) (*.csv)
  • Microsoft Word (97-2003) - Editable (*.rtf)
  • Rich Text Format (RTF) (*.rtf)
  • XML (*.xml)
