Notification class template

通知类将用于在 ABT Pro 和 ABT Site 中创建的新设备。默认通知类别是 Desigo。

稍后可以在 ABT 站点中在 ABT Pro 和房间编程中更改 Desigo PXC4/5/7 设备的通知类别。在Log选项卡，将显示一条消息。

AMEV、Desigo 和 KBOB 由总部可见并交付。如果还有其他区域总部模板，列表也会显示这些模板。区域总部模板必须存储在：
C:\ProgramData\Siemens\Desigo\ABT\Libraries\RC\NotificationClasses.

Note：在 ABT Pro 中，如果设备是从Add device对话框，则 ABT 站点中选择的通知类将被视为默认。通过库添加的设备采用库中定义的通知类（当前显示 Desigo 的内容）。
Replace a notification class template of a device

Import template

可以将新的通知类模板导入到项目中，并在组合框中自动选择作为新的默认模板。

 

Setting IP

描述

APDU retries

指定 APDU（应用协议数据单元）传输失败时的重试次数。
默认值为 3。

APDU 段超时（毫秒）

指定在多个段中发送 APDU 时的超时值（以毫秒为单位），范围为 1000 到 10000。
默认值为 2000。

APDU 超时（毫秒）

当可以在一次传输中发送 APDU 时，指定从 1000 到 10000 的超时值（以毫秒为单位）。
默认值为 3000。
