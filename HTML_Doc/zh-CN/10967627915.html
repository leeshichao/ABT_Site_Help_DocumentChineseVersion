配置：QMX3.P87（PrphDev - 子系​​统特定扩展）

"Configure: QMX3.P87”是“外围设备”(PrphDev) 对象的子系统特定扩展。

✳ 表示西门子专有财产。

Backlight timeout ✳

 

 

"Backlight timeout” 定义操作后背光保​​持开启的时间。如果在定义的时间内没有任何活动，背光将关闭。

范围：00:03...120:00 毫米：秒

Backlight brightness ✳

 

 

"Backlight brightness“定义了主动使用期间背光的亮度。

范围：0...100 %

Enable key beep ✳

 

 

"Enable key beep" 定义按下按键是否应伴有短促的蜂鸣声。

是的

按下按键时会发出短促的蜂鸣声。

No

按下按键时没有声音。

Area 1 text display time ✳

 

 

"Area 1 text display time" 定义屏幕区域 1 中显示的文本的滚动速率。显示时间结束后，屏幕区域 1 中显示新文本。

单位：1/10 秒

范围：5 到 30

Setpoint display time ✳

 

 

"Setpoint display time" 定义设定点值显示的时间量。显示时间过后，将显示平均值。

单位：1/10 秒

范围：5 到 3600，默认 100（10 秒）

Air volume flow units (SI) ✳

 

 

"Air volume flow units (SI)" 定义显示气流值时使用的 SI 单位。如果为整个设备选择 US 单位 (ActiveUnitSet)，则该字段不活动。

m3/h

立方米每小时

l/s

升每秒

Enable automatic sash positioning ✳

 

 

"Enable automatic sash positioning” 定义：

是的

允许使用 Key_8 激活窗扇定位装置。 “关闭窗扇”图标出现在 Key_8 旁边。

No

Key_8没有任何功能。 Key_8 旁边不显示“关闭窗扇”图标。

Enable fume hood integrated light ✳

 

 

"Enable fume hood integrated light” 定义：

是的

使 Key_4 能够用作灯开关。 “灯泡”图标出现在 Key_4 旁边。

No

Key_4没有任何功能。 Key_4 旁边不显示“灯泡”图标。

Enable operation: Green leaf ✳

 

 

"Enable operation: Green leaf”定义“绿叶”LED 是否指示是否满足能效状态的条件以及用户是否可以将应用程序重置为能效参数值。

是的

“绿叶”LED 指示是否满足能效状态的条件，并且用户可以将应用程序重置为能效参数值。

No

“绿叶”LED 并不指示是否满足能效状态的条件，并且用户无法将应用程序重置为能效参数值。

Enable fume hood operation, mode off ✳

 

 

"Enable fume hood operation, mode off“定义是否允许用户将通风柜操作设置为关闭。

是的

允许用户将通风柜操作设置为关闭。

No

用户不得将通风柜操作设置为关闭。

Enable fume hood operation, mode auto ✳

 

 

"Enable fume hood operation, mode auto“定义是否允许用户将通风柜操作设置为自动模式。

是的

允许用户将通风柜操作设置为自动模式。

No

不允许用户将通风柜操作设置为自动模式。

Enable fume hood operation, mode low✳

 

 

"Enable fume hood operation, mode low“定义是否允许用户将通风柜操作设置为低。

是的

允许用户将通风柜操作设置为低。

No

用户不得将通风柜运行设置为低。

Enable fume hood op., mode medium ✳

 

 

"Enable fume hood op., mode medium“定义是否允许用户将通风柜操作设置为中等。

是的

允许用户将通风柜操作设置为中等。

No

用户不得将通风柜运行设置为中度。

Enable fume hood operation, mode high ✳

 

 

"Enable fume hood operation, mode high“定义是否允许用户将通风柜操作设置为高。

是的

允许用户将通风柜操作设置为高。

No

用户不得将通风柜运行设置为高。
