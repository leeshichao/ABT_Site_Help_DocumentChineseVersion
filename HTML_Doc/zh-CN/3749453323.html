CMD_BG：命令二进制组

CMD_BG 以特定优先级将数据类型布尔值的当前值分配给特定组数据标签的多个数据点。

分组基础设施需要专有对象：一个组管理者对象和一个或多个组成员对象。各个成员数据点通过组成员对象进行分组和引用。

CMD_BG 将特定组数据标签的值/优先级对写入组管理器对象的组命令属性。数据从组管理器对象传递到组成员对象，在组成员对象中数据被分发到具有匹配组数据标签的预期成员数据点。

Compatible data points:

  • Binary output [BO]
  • Binary configuration value [BCnfVal]
  • Binary process value [BPrcVal]
  • Third party objects containing the required properties.

参考data point objects有关 BACnet 数据点的详细说明。

Required properties of grouped data points:

  • Present value
  • State flag

Operate with priorities

该功能块使用 2 种方法来控制是否按优先级运行：

1. 独占控制（计划优先级 1...5、9...12、14...16）

  • Initialized at startup
    • Multiple input sets of a function block cannot command the same priority.

2. 最后胜利控制（计划优先级7、8、13）

  • Not initialized at startup.

 

专属控制
优先级：1...5、9...12 和 14...16

最后获胜控制权
优先级：7、8 和 13

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

GrpTag

Group data tag

双字（默认值：0）

[GrpTag]定义了由XFB集中分发的特定组数据（当前值、优先级）。

系统提供预定义的标签以及用户可定义的标签。 [GrpTag] 通常由应用程序开发人员在 CFC 中设置，并且在运行时不得更改。必须将其设置为与 XFB 的数据类型匹配的标记。

EnIn1...4

Enable input 1

布尔值（默认值：False）

[EnIn1] 控制是否以[PrioIn1] 保持的优先级命令[ValIn1]，或者是否释放优先级。

[EnIn1] 属于四个输入集之一，每个输入集包含 [EnInX]、[ValInX]、[PrioInX]、[RptcInX] 和 [DscdcInX]。这些输入集根据需要以不同的优先级命令数据点。

[EnIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

[EnIn2]...[EnIn4] 功能与 [EnIn1] 相同。

1（正确）

命令[PrioIn1] 保持的优先级。

0（假）
默认

如果 [PrioIn1] 所持有的优先级当前未被设置为 True 的不同 [EnInX] 激活，则该优先级将被释放。

ValIn1...4

Value input 1

布尔值（默认值：False）

[PrioIn1] 处命令的值。

[ValIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

如果 [EnIn1] 为 True 并且 [ValIn1] 发生变化，则 [ValIn1] 将按照 [PrioIn1] 所保留的优先级进行命令。

[ValIn2]...[ValIn4] 功能与 [ValIn1] 相同。

PrioIn1...4

Priority input 1

整数（默认值：17）

[PrioIn1] 持有[ValIn1] 附带的优先级。

[PrioIn1] 已参数化，运行期间无法更改。值 17 表示未使用输入集。

[PrioIn2]...[PrioIn4] 功能与 [PrioIn1] 相同。

Note
同一功能块上的输入集不得共享共同的独占控制优先级。

优先范围

1...16

请参阅下面对优先级 6 和优先级 8 的限制。

专属控制

优先级 1...5、9...12 和 14...16

控制程序启动时，功能块使用独占控制来初始化范围 1...5、9...12 和 14...16 中的任何分配的优先级。

在运行时，该功能块不支持独占优先级控制。最后一个有效命令或释放控制优先级。

由于启动期间的独占控制，同一功能块上的两个或多个输入集不得共享公共的独占控制优先级，否则将导致冲突。

最后获胜

优先级 7、8 和 13

  • No initialization of priorities on start-up.
  • At runtime, last valid command (or release) controls the priority.
  • If two or more input sets have the same priority and are commanded at the same time, only the input set in first numerical order is performed (In1...In4).
    Exception:
    If two or more input sets have the same priority, and inputs providing value (either target state or control-command) are changed at the same time, the input set in last numerical order will win (In1...In4).
  • If two or more input sets have the same priority and conditions for commanding and releasing are given at the same time, the command operation wins.

优先级 6

根据 BACnet，命令优先级 6 保留用于最小 on/off 功能。优先级为 6 的命令会被 BACnet 对象拒绝。

为了提供最小的 on/off 功能，控制程序应包含其他优先级的功能和命令。

优先级 8

根据 BACnet，命令优先级 8 供手动操作员使用，通常不会在功能块上分配。最后获胜功能可以允许控制程序改变或释放操作员命令。

RptcIn1...4

Repeat command input 1

布尔值（默认值：False）

[RptcIn1] 强制重复命令或释放优先级。

  • If [RptcIn1] = 1 (True) and [EnIn1] = 1 (True), the function block repeats a command of [ValIn1] with every program cycle at the priority in [PrioIn1].
  • If [RptcIn1] = 1 (True) and [EnIn1] = 0 (False), the function block repeats a release with every program cycle at the priority in [PrioIn1].

[RptcIn2]...[RptcIn4] 功能与 [RptcIn1] 相同。

Note
不得通过连接到始终为 True 的块输出来强制将 [RptcIn1] 永久设置为 True。这样做会导致大量通信流量。

[RptcIn1] 是可链接的，通常由控制程序计算和设置。

DscdcIn1...4

Discard command input 1

布尔值（默认值：False）

[DscdcIn1] 用于配置在重新启动时重复的 [ValIn1] 命令或与组成员的自动化站重新建立通信。

[DscdcIn1] 已参数化，并且在运行期间无法更改。

  • If [DscdcIn1] = 0 (False) group manager will repeat the last command of [ValIn1] at priority [PrioIn1] in case of restart or to re-establish communication with group member’s automation station.
  • If [DscdcIn1] = 1 (True) group manager will not repeat the last command of [ValIn1] at priority [PrioIn1] in case of restart or to re-establish communication with group member’s automation station.

[DscdcIn2]...[DscdcIn4] 功能与 [DscdcIn1] 相同。

Pin description (outputs)

ErrWrit

Error while writing

整数（默认值：20）

访问或写入组管理器对象期间遇到的错误的错误代码值。

无法指示向组成员成功分发命令。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.
