输入身份验证凭据

要配置发现的设备，您可能需要提供身份验证凭据才能登录设备。身份验证列（Auth）在任何Startup任务显示以下状态之一。

  • Default – Displays as a starting point for authentication. Startup has not yet attempted an action to acquire credentials, or the device has the default Administrator Access Control Protocol (ACP) credentials.
  • Pending – Displays after the user provides credentials and clicks Login in the Authentication dialog box. Startup is unable to authenticate with devices on a different subnet to the currently connected adapter. The credentials provided by the user are cached and used for the next action requiring authentication.
  • Authorized – After the user performs an action requiring authentication. If authentication succeeds, the status is set to Authorized.
  • Unauthorized – Displays after the user performs an action requiring authentication. The attempted credentials were denied access by the device and the authentication fails.

当设备中上次加载的访问控制配置文件（用户配置文件）与您的凭据不匹配时，请使用以下过程输入您的身份验证凭据。

Enter authentication credentials

  1. Open Startup > Configure and download.
  2. Select a device in the Discovered devices tab.
  3. Right-click in the row and select Provide authentication.
  4. The Authentication dialog box displays.
  5. Enter your User name and Password.
  6. Click Login.
  1. The Auth column displays the status: Pending.
