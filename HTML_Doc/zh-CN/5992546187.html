② Toolbar

命令

描述

打开模板

打开Configuration > Application configuration您可以在其中重新配置所选的应用程序模板。
Changing application parameters

必须选择项目模板才能激活该命令。

Note

如果更改已下载的模板：在线系统中的所有配置和调试数据都将被覆盖。为防止数据丢失，请在模板中进行离线更改之前将在线系统数据读回到 ABT 站点。

将模板添加到项目中

打开一个对话框以创建新的应用程序模板。必须选择模板或类型和设备类型。
Adding project-specific application templates

导入申请类型

打开一个对话框以导入项目特定的应用程序类型（例如来自 ABT Pro 的 *.s1ca 文件）。
Importing project-specific types

刷新

刷新视图。

应用帮助

打开所选应用程序模板或应用程序类型的联机帮助。仅当有相应的帮助可用时，该按钮才处于活动状态。

 

③ Source selection tabs

源选择选项卡将可用的应用程序模板和应用程序类型与当前项目或已安装的库分开。

选项卡

描述

项目中的模板

显示该项目的所有应用程序模板（项目数据）。

库中的模板

显示已安装的 HQ 和 RC 库中的所有应用程序模板。

库中的类型

仅显示已安装的 HQ 和 RC 库中的应用程序类型。
Installing HQ or RC libraries

应用程序类型随应用程序库一起提供。应用程序模板是完全配置的应用程序类型。
