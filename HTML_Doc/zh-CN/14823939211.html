[CONT_4ST] 四阶段步进开关

功能块 CONT_4ST 根据模拟输入值确定多级组件的最终开关级。

CONT_4ST 根据模拟输入值确定多级组件的最终开关级。

可以对四个开启阈值和四个迟滞进行参数化。

Functioning

CONT_4ST 根据模拟值 [In] 确定请求的设定点阶段 [SpSt]。

Direct acting ([Actg] = 0)

如果控制动作的方向是直接的 ([Actg] = 0)，则需要更高的级来增加输入值 [In]。然后按以下顺序对接通点进行参数化：[SwiOnPt1] < [SwiOnPt2] < [SwiOnPt3] < [SwiOnPt4]。

如果 [In] ≥ [SwiOnPt1]，则请求的设定点阶段为 [SpSt] 1。如果 [In] ≥ [SwiOnPt2]，则为 2，依此类推。如果 [In] 低于开启点 [SwiOnPt1]...[SwiOnPt4] - 迟滞 [Hys1]...[Hys4]，则阶段将复位。如果不遵守此顺序，CONT_4ST 会相应地设置接通点。

Reverse acting ([Actg] = 1)

如果控制动作方向相反 ([Actg] = 1)，则请求下级以增加输入值 [In]。然后按以下顺序对接通点进行参数化：[SwiOnPt4] < [SwiOnPt3] < [SwiOnPt2] < [SwiOnPt1]。

如果 [In] ≤ [SwiOnPt1]，则请求的设定点阶段为 [SpSt] 1。如果 [In] ≤ [SwiOnPt2]，则为 2，依此类推。如果 [In] 高于开启点 [SwiOnPt1]...[SwiOnPt4] + 迟滞 [Hys1]...[Hys4]，则阶段将重置。如果不遵守此顺序，CONT_4ST 会相应地设置接通点。

Adding up an additional value

偏移量 [Ofs] 允许向 [SpSt] 添加附加值。

Switch-on and switch-off delay

延迟打开和关闭（[DlyOn]、[DlyOff]）。为每个阶段设置开启或关闭延迟。 Only one stage can be switched on or off at a time.

Min. runtime and min. pause time

此外，每个阶段的最小运行时间 [TiRnMin] 和每个阶段的最小暂停时间 [TiOffMin] 可以参数化。这些时间使该级在打开后至少运行指定的时间或关闭至少指定的时间。

Reach highest or lowest stage

  • If the highest stage is reached (by including switch-on delay and min. pause time), output [ReqHi] = 1.
  • If the lowest stage is reached and switched back completely (by including switch-off delay and min. switch-on time), output [ReqLo] = 1.

Switch off or run function

通过 [EnFnct] = 0 可以完全禁用该功能。当 [EnFnct] = 0 时，无论可能启动的最小运行时间如何，输出 [SpSt] 和所有时间都会复位。当[EnFnct] = 1 时，该函数运行。

Enable ramp-up and ramp-down

  • If [EnHi] = 1, ramp-up is enabled.
  • If [EnLo] = 1, ramp-down is enabled.

Switching in sequence multiple CONT_4ST

如果4个可能的阶段或组件不够，可以依次切换多个CONT_4ST功能块。在这种情况下，延迟时间可用于每个单独的块 CONT_4ST（例如两个独立的 4 级电加热线圈）或多个 CONT_4ST（例如 8 级加热线圈）。

Application

CONT_4ST 可以根据模拟值将组件切换到各个阶段。这些阶段例如是作为温度控制执行器的多级加热线圈或多级风扇，取决于空气质量传感器。

Process response

启动期间，所有时间都会重新启动。如果输入值 [In] 请求更高的阶段，则较低的阶段将按图 3 所示的顺序运行。然后，CON_4ST 由输入处的值进行处理。根据处理顺序，这些是由前面的功能块计算的输出值或 CONT_4ST 的特定于实例的默认值。
