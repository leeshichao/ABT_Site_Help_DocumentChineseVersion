添加数据点

Prerequisites

  • A project must be open with a room automation station selected.
  • The BACnet objects editor is open.

Procedure

可以通过两种方式添加数据点：

  1. Click in the Type field of the first empty row.
  2. Select the desired data point type from the drop-down menu.
  1. A new data point object type row is added to the BACnet objects editor table and the object properties display in the Inspector window on the Properties tab.

OR

  1. Open the BACnet objects editor tools task card.
  2. Select the desired data point from the BACnet object types and drag it on an empty row in the BACnet objects editor.
  1. A new data point object type row is added to the BACnet objects editor table and the object properties display in the Inspector window on the Properties tab.

有关详细信息，请参阅：BACnet 对象编辑器检查器窗口属性选项卡
