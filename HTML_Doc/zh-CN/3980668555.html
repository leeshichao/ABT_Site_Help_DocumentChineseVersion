SWI_2PH：On/off 开关，具有可调节的接通点和迟滞

SWI_2PH (FB432) 块在将输入信号与接通和关断点、接通点偏移和迟滞进行比较后生成二进制输出信号。

功能性

该块中集成了以下功能：

  • Function can be enabled/disabled.
  • Selectable direction of control action.
  • Adjustable switch-on point shift.
  • Adjustable hysteresis.

该块在输入信号 [In] 与有效开关点 [EfOnPt] 和 [EfOffPt] 之间进行比较后生成二进制输出信号，有效开关点由开关点 [SwiOnPt]（设定点）、迟滞 [Hys] 和开关点偏移 [ShftOnPt] 定义。

迟滞 [Hys] 定义有效开关点 [EfOnPt] 和 [EfOffPt] 之间的开关差。

通过相对于接通点 [SwiOnPt] 平行移动有效开关点 [EfOnPt] 和 [EfOffPt]，变量 [ShftOnPt] 可以保持迟滞 [Hys]。

有效接通点 [EfOnPt] 由接通点 [SwiOnPt]（设定值）和接通点偏移 [ShftOnPt] 定义。

有效关断点 [EfOffPt] 由相对于有效接通点 [EfOnPt] 的迟滞 [Hys] 给出。

该块功能可以通过引脚 [EnFnct] 完全启用/disabled。

 

控制动作的方向由[Actg]定义。

Action: Direct ([动作] = 0)

IF

THEN

In > SwiOnPt + ShftOnPt

输出 = 1

SwiOnPt + ShftOnPt - Hys < In < SwiOnPt + ShftOnPt

无动作

In < SwiOnPt + ShftOnPt - Hys

输出 = 0

 

Action: Reverse ([实际] = 1)

IF

THEN

In < SwiOnPt + ShftOnPt

输出 = 1

SwiOnPt + ShftOnPt < In < SwiOnPt + ShftOnPt + Hys

无动作

In > SwiOnPt + ShftOnPt + Hys

输出 = 0

应用

  • In air conditioning and heating to control (disable and enable) components and aggregates.
  • General: Performance of switching functions depends on a specific signal value.

过程响应

从过程中的第一个周期开始，使用输入处的值处理该块。启动期间，如果值 [In] 介于有效开启点和有效关闭点之间，则输出设置为 [Out] = 0（关闭）。
