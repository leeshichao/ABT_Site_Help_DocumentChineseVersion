Create I/O data points

  1. Go to Building > Building structure.
  2. Right-click a device and select Go to engineering.
  3. Open the I/O configuration task.
    I/O configuration
  4. In the Plants navigation view, select the plant you want to add the data points.
  5. The Add data point menu becomes active.
  6. In the Plants navigation view, click Add data point or right-click and select Add data point.
  7. The Add data point dialog box opens.
  8. Enter Type, Signal type, Unit, Description, Name and Object name of the I/O. Add Extension if required.

    Note: The Object name field is only visible if the option Show property on adding objects is activated.
    Plant automation tab
  9. In the Property view, set the properties of the I/O.
  10. In order to duplicate created I/Os, right-click at least one I/O and select Duplicate.
  1. You have created I/Os and set the I/O properties.

Add a new data point from the library to an I/O module

  1. Click the Tabular view tab on the I/O configuration area.
  2. In the Plants navigation view, click to set the drag destination focus new.
  3. The data points will be assigned to this plant .
    Note: It is always possible to drag a data point directly to the position in the Plants navigation view, where its functionally belongs too (for example, valve).
  4. Select the Library tab.
  5. Drop the data point to the I/O module. Free or compatible I/O slots are displayed in green.
  1. You added a new data point to the plant.
