[W_TI] 写入时间

功能块 W_TI 将单位时间的值转换为双整数，并使用双整数类型的当前值更新计算值对象的属性“当前值”和“可靠性”。

W_TI 将单位时间的值转换为双整数，并使用双整数类型的当前值更新计算值对象的属性“当前值”和“可靠性”。

W_TI 将时间值转换为在属性“单位”中发送的单位。

W_TI 可以处理以下单位：

  • Milliseconds
  • Hundredths of a second
  • seconds
  • Minutes
  • Hours
  • Days
  • Weekly
  • No units

如果属性“单位”设置为与列出的单位不同的值，则忽略当前值并将输出干扰设置为 1。如果属性“单位”未设置单位，则假定当前值为毫秒。

不支持月和年为单位，因为当前值 1 已经超过了 S7 数据类型 Time 的最大值。

Functioning

Compatible data points:

  • Integer calculated value [ICalcVal]

Required properties:

  • Present value
  • Tracking value
  • Status flag
  • Reliability
  • Unit
Pins

输入

描述

数据类型

默认值
取值范围

EnWrit

Enable write

如果 [EnWrit] = 1，则启用将输入 [Val] 和 [SetValid] 中的值写入 BACnet 对象。
如果[EnWrit]从0变为1，则发生写入。

布尔值

1

Val

Value

虚拟值，由控制程序计算和分配以更新当前值。
[Val]用于更新属性‘跟踪值’；接下来是 BACnet 对象在内部使用写入的跟踪值更新当前值。

如果 [EnWrit] = 1 并且以下项目之一适用，则写入 [Val]：

  • [Val] changes.
  • [SetValid] changes.
  • [RptWrit] is 1.

时间

0 ms

SetValid

Set valid value indication

由控制程序计算并分配的值，指示[Val]是否可靠。

如果 [EnWrit] = 1 并且以下项目之一适用，则 [SetValid] 映射到更新可靠性的错误代码：

  • [SetValid] changes.
  • [Val] changes.
  • [RptWrit] is 1.

布尔值

1

0 - 可靠性错误代码 7（不可靠 - 其他）。
1 - 可靠性错误代码 0（无故障）。

RptWrit

Repeat write

强制将 [Val] 和 [SetValid] 写入数据点。每个程序周期都会重复写入，直到 [RptWrit] = 1。
控制程序通常计算并设置[RptWrit]。

Note:
[RptWrit] 不能永久强制为 1。这可能会影响性能和通信流量。

布尔值

0

0 - 无操作。
1 - [Val] 和 [Sta] 在每个编程周期写入数据点。

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

[Dstb]表示引用的BACnet对象是否有错误。

OR

否则 [Dstb] = 0

整数

整数

Troubleshooting

如果 BACnet 对象位于另一个设备上，则写入功能不可用。
