窗扇校准和验证

Sash calibration

校准期间必须使用窗扇的整个行程。

(Web interface – Room segment/HVAC/Fume hood sash/Fume hood sash 1 position/properties)

  1. Set ‘Process value 1’ and ‘Signal value 1’ = 0. Set ‘Process value 2’ and ‘Signal value 2’ = 10,000.
  2. Fully close the sash.
  3. Record the reading of ‘Present value’ as SV1.
  4. Measure the distance from the bottom of the sash opening to the bottom of the sash in inches (cm). Record as PV1. Should be at or very near 0.
  5. Raise sash to maximum height.
  6. Record the reading of ‘Present value’ as SV2.
  7. Measure the distance from the bottom of the sash opening to the bottom of the sash in inches (cm). Record as as PV2.
  8. Set ‘Process value 1’ = PV1, ‘Signal value 1’ = SV1, ‘Process value 2’ = PV2, ‘Signal Value 2’ = SV2.

Sash calibration verification

(Web interface – Room segment/HVAC/Fume hood sash)

  • Close the sash fully and verify that the value displayed at ‘Fume hood sash 1 position’ (FhSash1Pos) is at the minimum set during calibration. Open the sash half way and verify that the value displayed at ‘Fume hood sash 1 position’ (FhSash1Pos) is equal to the current measured value. Open the sash fully and verify that the value displayed at ‘Fume hood sash 1 position’ (FhSash1Pos) is at the maximum set during calibration.
