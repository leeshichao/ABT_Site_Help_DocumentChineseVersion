打开 BACnet 对象编辑器

Prerequisites

  • A project must be open.
  • A room automation station must be added to the project.

Procedure

要打开 BACnet 对象编辑器：

  1. Expand the project folder in the Project tree.
  2. Double-click the BACnet objects icon in the project folder.
  1. The BACnet objects editor opens.

OR

  1. Right-click the BACnet objects icon in the project folder to display the context menu.
  2. Select Open.
  1. The BACnet objects editor opens.
