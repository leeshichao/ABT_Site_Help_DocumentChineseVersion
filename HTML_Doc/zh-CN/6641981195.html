PRIO_4BO：优先级范围转换器到 4 个布尔值

功能块 PRIO_4BO [FB419] 将可参数化的优先级范围转换为布尔输出信号。可以参数化一到四个优先级范围。

当 K [1...17] 上的输入值在参数化优先级范围内时，相应的输出 Outx 将设置为 true。

该函数调用TIME_TCK[]函数来获取当前定时器值。

 

块规格

K (Selector):K 选择哪个优先级范围处于活动状态，相应的 Out1...4 将设置为 true。

Inputs (Priority ranges):SwiOnPt1...4 可以定义一到四个优先级范围。如有必要，可以定义附加的 SwoOffPt。

Outputs:Out1...4 将被设置为唯一 true，这意味着只有一个输出可以同时为 true。

Switch-off point:将检查 SwiOnPts 和 SwiOffPt 的参数化是否有效。

Valid:如果输入值 K 在有效范围 [1...17] 内，则将进行检查

SwiOnPt1...4

帕克斯

 

Switch-on point

  • The SwiOnPt1...4 can be used to define one to four priority ranges to be converted to the outputs Out1...4.
  • The SwiOnPt defines the switch on point fort the outputs Out1...4.
  • The SwiOnPt can be parameterized by enum values 1...17.

如果 SwiOnPt 不用于定义优先级范围，则必须将其设置为 255“未定义”。

SwiOffPt

帕克斯

 

Switch-off point

  • The SwiOffPt can be used additionally to define a switch off point.
  • The SwiOffPt can be parameterized by enum values 1...17.

如果未使用 SwiOffPt，则必须将其设置为 255“未定义”
