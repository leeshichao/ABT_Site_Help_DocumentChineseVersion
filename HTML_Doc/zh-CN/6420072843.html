HVAC green leaf (HvacGrnLf11)

Overview

应用功能》HVAC green leaf 11, energy efficiency" (HvacGrnLf11) 确定用户手动操作是否影响 HVAC 能效，并在收到重置请求后处理返回到正常（节能）状态。

Function

Inputs:
HVAC 确定能源效率的主要输入是：

  • Setpoint shift (configurable limit), heating/cooling status (via internal connection).
    The leaf symbol on the room operator unit turns red if the user increases the setpoint while the application is heating (decreases while cooling) by more than a configurable delta (TolMaxSpTRShft).
  • Fan speed operation, fan speed control values (via internal connection).
    The leaf symbol on the room operator unit turns red if the user sets a higher fan speed than is required by the automatic control.


Output:
AF 向房间操作员单元（通过 RGrnLf11）提供能效指示 HVAC (HvacEei)。
如果从房间操作员单元（REeiRst，通过 RGrnLf11）收到重置请求，并且设置不适合节能 HVAC 操作，则 AF 会释放手动设置（通过内部连接）。
