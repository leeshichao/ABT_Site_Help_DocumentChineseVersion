[DIFFCALC] 微分函数

功能块 DIFFCALC 对输入值进行微分。

DIFFCALC 区分输入值。

Functioning

DIFFCALC 获取输入 [In] 处的当前值，将其与输入处的先前值进行比较，并提供值相对于时间的变化率作为结果。

Acquiring input value

DIFFCALC 定期从输入 [In] 获取值。该间隔的持续时间在输入 [SmplRate] 处配置。

Output limitation

可以通过输入 [VMax] 处的配置来限制输出值。结果限制在 -1.2*[VMax] 和 1.2*[VMax] 范围内。

Conversion

在计算输入变化率时，DIFFCALC 使用秒作为时间单位。因此，结果的单位必须被视为每秒的值。输入[CnvFac]提供更改输出值单位的选项。 DIFFCALC 将计算出的输入变化率（以秒为单位）乘以输入 [CnvFac] 处的值，然后将其提供给输出 [Out]。通过[VMax]执行限制后完成转换。

Filtering

DIFFCALC 可以通过评估多个采样输入值（最新值）来对输出值进行过滤。输入 [RngMin] 和 [RngMax] 可用于配置评估值的数量。对于使用固定数量的采样输入值进行过滤，[RngMin] 和 [RngMax] 必须相等。

Filtering adjustment

对于某些使用过滤的情况，与缓慢变化的值相比，快速变化的值可能希望具有较弱的过滤。对于这种情况， DIFFCALC 可以根据值变化的速率自动调整评估输入值的数量。

要启用此功能，[RngMin] 和 [RngMax] 的值必须不同。 DIFFCALC 计算 [RngMin] 和 [RngMax] 定义的范围内评估的样本数。该算法基于两个内部计算的过滤值之间的差异：一个通过评估 [RngMin] 输入样本（弱过滤），另一个通过评估 [RngMax] 输入样本（强过滤）。它们的差异越大，功能块输出的评估值的实际数量越接近 [RngMin]，从而对快速变化的值实现较弱的过滤，反之亦然。

输入 [RngAdj] 处的值可用于影响计算实际结果时弱滤波和强滤波之间的差异的影响。 [RngAdj] 输入处的值用作此差异的增益因子，因此 [RngAdj] 处的值越大，评估值的实际数量越接近 [RngMin]，以便更快地更改输入值。

输入 [VMax] 处的值还会影响评估值的实际数量的计算。它用作弱滤波和强滤波之间差异的除数，因此[VMax]的值越大，实际评估值的数量越接近[RngMax]。

Application

DIFFCALC 可以与累加器输入结合使用，累加器输入提供累加值，例如： m3或千瓦时。来自此类输入的值可以提供给 DIFFCALC 以获得相应的 m3/h 或千瓦。所得值可用于以下控制逻辑：设备保护、指示、通过监测室温变化率来检测打开的窗户或其他目的。
