添加中心功能

为了能够在项目中使用中心功能，您需要将它们添加到您的项目中。基本上该过程与添加设备相同。

以下过程是分组过程的一部分。
Grouping

中央功能自动化站仅在自动化站视图中可见。

Add a central function to your project

  1. A building structure is defined.
    Defining a building structure
  2. There is at least one application template in your project or in your library to select. If there is no application template available, click Add application template in Building > Building structure.
    Adding project-specific application templates
  3. A central function hierarchy is defined.
    Defining a central functions hierarchy
  1. In Building > Building structure, right-click a building or building element and select Add devices.
  2. The Add devices dialog box opens.
  3. Select a central function template from the drop-down list.
    Add devices (Dialog box)
  4. In the Number of new automation stations field, type the number of central functions to be created.
  5. The table is updated automatically, and shows the entered number of central functions.
  6. Enter the details such as network address, equipment ID etc.
    Add devices (Dialog box)
  7. Click OK.
  8. The new central functions are added to your project and to your building structure.
  9. The central functions are placed in the Unplaced central functions folder in Building > Central functions.
  10. Drag the created central functions from the Unplaced central functions folder to your central function hierarchy.
  1. The created central function is added to your central function hierarchy.
    In order to use the central function in a room, assign group members to group managers.
    Assigning group members to group managers
