发现已寻址的 MS/TP 设备

多生成树根据所选的连接类型，使用关联的过程来发现已寻址的 MS/TP 设备。

在进行新查询之前，Clear table必须执行。这是确保仅列出相应设备的唯一方法。

Room unit connection

默认情况下，Discovered devices选项卡显示本地连接的设备。这Discover按钮为您提供选择任一选项AllorLocally connected device从Discovery对话框。如果All选中后，发现的设备将在表中列出。

  1. A Room unit connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Room unit connection tab.
  3. Click Connect.
  4. Select Startup > Configure and download.
  5. In the Discovered devices tab, click Discover and select a Discovery filter (All or Locally connected device) from the list box.
  6. Click OK.
  1. All locally connected devices on the selected network display in the Discovered devices table.

PXC3 设备不支持通过 Room 设备进行连接。

USB connection

默认情况下，Discovered devices选项卡显示本地连接的设备。这Discover按钮为您提供选择任一选项AllorLocally connected device从Discovery对话框。如果All选中后，表中仅列出已配置的已发现设备。如果Locally connected device选择后，表中仅列出本地连接的设备（已配置或未配置）。

  1. A USB connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the USB tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Select Startup > Configure and download.
  7. To discover devices on the same network of the MS/TP device that you made a connection, select Local network.
  8. To discover devices on another network from the MS/TP device that you made a connection, select Remote network, and specify a network number.
  9. Click OK.
  1. All devices on the selected network display in the Discovered devices table.

Ethernet connection

默认情况下，不显示任何设备Discovered devices选项卡。这Discover按钮为您提供选择任一选项AllorLocally connected device从Discovery对话框。结果，发现的设备列在表中。

  1. An Ethernet connection has been established.
    Connection types and network card settings
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Select the Ethernet tab.
  3. Select the MS/TP option.
  4. Configure the Network card.
  5. Click Connect.
  6. Go to Startup > Configure and download.
  7. In the Discovered devices tab, click Discover and select a Discovery filter (All or Locally connected device) from the list box.
  8. To discover devices on another network, select Remote network, and specify a network number.
  9. Click OK.
  1. All devices on the selected network display in the Discovered devices table.
