配置

使用Configuration组件来创建和配置特定于项目的房间应用程序模板并管理默认值和 I/O 分配。

要打开Application selection, selectBuilding > Building structure > Add device/Add application template.
要打开项目特定的房间应用程序模板，请选择Building > Application & device overview > Go to configuration.
Configuring default values (template)

要添加特定于项目的房间应用程序模板，请选择Building > Building structure > Add automation station/Add application template.
Adding project-specific application templates
