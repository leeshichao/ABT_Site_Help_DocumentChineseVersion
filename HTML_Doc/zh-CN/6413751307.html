命令

描述

预览

执行在命令编辑器表中选择的命令。显示每个选定设备下方所有选定参数的当前值状态。您可以选择执行命令值或取消。该按钮在以下情况下启用：

  • The command tab is selected
  • At least one parameter is selected
  • At least one device or building element is selected

发布

将值返回到原始状态。该按钮在以下情况下启用Command选项卡被选中。

上传报告数据

根据所选标签列表中包含的参数向所选设备发出读取请求。该按钮在以下情况下启用：

  • The Report tab selected.
  • At least one configured device is selected (objects are ignored in the editor) in either the Engineered devices or Discovered devices tabs.

创建上传的数据报告

打开一个对话框，用于选择报告类型和报告中要包含的设备。您可以创建一系列报告，显示设备状态、设备实例数据等，在Reports组件查看区域。

转到网页界面

打开所选设备的 Web 界面Web interface组件窗口。必须配置设备。
Connecting to the web interface of the device
Note
仅当设备已配置且可访问（如蓝色突出显示所示）时，您才能访问 Web 界面。

提供身份验证

打开Authentication对话框。您必须输入您的User name和Password登录设备。
Entering authentication credentials
