将楼层节点从 1 楼过渡到 BACnet/SC

Configuration ABT Site – BACnet/SC

Shows the BACnet/SC configuration in ABT Site. BACnet/IP is set toDisabled在设备上AS_11 – Floor hub, 1st floor和AS_12 – Floor node 1st floor，而其他设置为Enabled。 BACnet/IP 路由在所有设备上被禁用（清除）。

 

Topology and data communication

说明哪些设备可以传送数据以及数据的传输方式。在设备上禁用 BACnet/IPAS_11 – Floor hub 1st floor和AS_12 – Floor node 1st floor使设备和 BACnet 对象从 BACnet/IP. 的角度不可见 设备不再能够通过 BACEye 进行访问，并且 BACnet 参考来自 XWP PX 100 楼层中心、一楼和楼层节点、一楼的控制器，不再运行（可靠性）。

 

从建筑中心到楼层节点的 BACnet/SC 连接说明了仅描述功能的视觉通信路径。数据始终通过楼层集线器传输！
