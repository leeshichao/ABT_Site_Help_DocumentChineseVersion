发现配置（NwkView - 子系​​统特定的扩展）

 

Discovery scope ✳

 

 

"Discovery scope" 指定设备发现过程的网络范围。

范围：本地网络、远程网络

0..100 [%] 映射到 0..90°

Network number ✳

 

 

"Network number" 表示与该网络关联的 BACnet 网络号。

0

该数字未知或无法确定。默认值

0..65534

取值范围

Max. device instance number ✳

 

 

"Max. device instance number" 指定设备发现过程的最大范围。

默认值：4194302

Min. device instance number ✳

 

 

"Min. device instance number" 指定设备发现过程的最小范围。

默认值：1

Include 3rd party devices ✳

 

 

"Include 3rd party devices" 指定是否在设备发现过程中检索第 3 方设备。

默认值：假

Command ✳

 

 

"Command" 允许触发设备发现过程。

准备好

准备好新命令，默认值

发现

BA-框架将使用当前配置属性设置触发发现命令“Who is”。
