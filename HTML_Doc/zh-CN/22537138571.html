[CMN_STA] 常见状态

功能块公共状态从视图节点对象读取状态相关属性。

CMN_STA 从视图节点对象读取状态相关属性。

Functioning

Compatible data points

  • System view [SysView]

Required properties

  • Last event notification propagation
  • Aggregation flags
  • Last event timestamp
  • Suppress event notification command
  • Acknowledged transitions
Pins

输入

描述

数据类型

默认值
取值范围

确认

承认

确认引用的视图节点对象范围内的所有 BACnet 对象。

布尔值

0

重置

重置

重置引用的视图节点对象范围内的所有 BACnet 对象。

布尔值

0

SupEvtNtf

抑制事件通知

禁止引用视图节点对象范围内的 BACnet 对象的事件通知。

Note
如果同一视图节点对象被控制程序中的多个功能块访问，则只允许这些功能块之一的引脚互连。
该函数不适用于引用视图节点对象范围内的 BACnet 第三方对象。

布尔值

0

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

 

输出

描述

数据类型

默认值
取值范围

HiNewEvt

高优先级，新事件

指示在引用的视图节点对象范围内是否检测到具有高优先级警报的 BACnet 对象转换到状态“Fault”或状态“OffNormal”。

The output is set to 1 for one cycle.

Note
如果启动时存在处于“Fault”或“OffNormal”状态的高优先级警报的 BACnet 对象，则输出不会设置为 1。

布尔值

0

HiEvtSta

高优先级，事件状态

指示在引用的视图节点对象的范围内是否存在状态为“Fault”或“OffNormal”的具有高优先级警报的BACnet对象。

布尔值

0

0 - 范围内不存在处于“Fault”或“OffNormal”状态的高优先级警报的 BACnet 对象。
1 - 范围内存在处于“Fault”或“OffNormal”状态的高优先级警报的 BACnet 对象。

HiAckSta

High priority, acknowledge state

指示引用的视图节点对象的范围内是否存在需要确认的具有高优先级警报的 BACnet 对象。

布尔值

1 - 范围内存在需要确认的具有高优先级警报的 BACnet 对象。

1 - 范围内存在需要重置的具有高优先级警报的 BACnet 对象。
