启动

这Startupcomponent includes tasks that provide for device discovery, loading, node setup, upload, device web interface, and balancing for a customer project.

这Startup组件包含以下任务：

任务

描述

Configure and download

打开包含工程自动化站的工作包。下载配置数据、参数数据、新应用程序，或手动配置和加载自动化站。更新并上传自动化站。
Manually configuring devices
Downloading device configurations
Connecting to the web interface of the device
Uploading a device configuration
Uploading runtime instance data
Updating user profiles for engineered devices
Updating firmware of engineered devices

Global functions

选择命令列表，指定要命令和监视的自动化站，选择参数和值，然后创建报告。
Commanding
Uploading report data
Global commanding and reporting
Creating and viewing balancing reports

Export

创建打包并返回文件、创建一系列报告并显示报告选择对话框以查看一个或多个报告。
Creating Pack & Return files
Creating engineering data reports
Creating reports for uploaded data

Commissioning and diagnostics

可以保存、分析和导出调试和诊断信息，例如以便现场支持进行进一步分析。

Startup用于以下工作流程：
Installing an ABT project (no subcontracting)
Balancing air/water (with Pack & Go)
