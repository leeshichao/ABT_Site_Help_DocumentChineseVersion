解锁应用程序模板

Apogee 市场上使用应用程序编号来命名应用程序模板和锁定应用程序模板。它们必须在应用程序类型中启用才能处于活动状态和可见状态。要使申请号可见，您必须选中该复选框Show application number.
Number ranges

Locked templates

Apogee 使用 HQ 库模板的应用程序编号，范围为 14000 到 14999。此应用程序编号范围锁定模板。因此，I/O 配置和应用程序功能无法更改。

Unlocked templates

Apogee 使用 15000 到 15999 范围内的项目特定模板的应用程序编号（对于已更改的 HQ 模板）。

Unlock an application template

  1. The application number is in the range of 14000 to 14999.
  1. In Configuration > Application selection, select the template.
  2. Click Open template.
  3. Configuration > Application configuration opens.
  4. The icon displays after the template name.
  5. Click Template properties.
  6. The template properties display.
  7. Click Unlock.
  8. The entry fields for application number and version are unlocked.
  9. The application number changes automatically to 15000. The application template is unlocked.
  10. Change template properties as needed.
    • Change application number (15000 to 15999). There is no check for unique application number.
    • Change version.
  11. Click OK.
  1. The unlocked icon displays after the template name.
