导入xml文件的基本规则

xml file structure

  1. The max. number of modules to import is 8. If the xml contains more than 8 modules, only the first 8 modules will be imported.
  2. If no module and channel address is specified, a new data point is created, but not assigned to a module channel.
  3. If the name, type, module address and channel address exist, the data point information is updated.
  4. You can use the same import file again and again for updating data point information. Existing data points with equal xml data will be skipped and not imported.

您无法将附件导入或导出到总线接口模块。

Modifying modules and data points (XML)

添加数据点而不分配模块
