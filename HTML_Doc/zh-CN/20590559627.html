创建模板

您可以创建一个模板来分配 ABT 站点中的控制器。

Create a template

  1. In the toolbar of the Room programming editor, click Create template.
  2. Fill in the fields in the pop-up window accordingly.
  3. Confirm your entries with Create template and close project.
  4. The Room programming editor is closed.
  5. A template is created in ABT Site.
  1. In ABT Site, you can now assign controllers to the template created.
