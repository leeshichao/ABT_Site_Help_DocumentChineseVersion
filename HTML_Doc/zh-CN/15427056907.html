[RP_DINT] 读取双整数值的属性

功能块 RP_DINT 从数据点读取数据类型 Double 整数的指定属性或数组元素值。

RP_DINT 从数据点读取数据类型 Double 整数的指定属性或数组元素值。

Functioning

Compatible data points:

  • Any BACnet data point with read property or array element of data type Double Integer.

RP_DINT 不考虑 BACnet 对象状态，也不考虑 BACnet 对象使用情况。

Pins

输入

描述

数据类型

默认值
取值范围

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

PrpyId

Property identifier

参数化 BACnet ID 的编号property即已读。

整数

0

ArrayIdx

Array index

功能块访问的数组元素的索引号。
可选的配置输入，用于指示对数据类型 BACnetArray 或 BACnetPriorityArray 的属性元素的访问。
运行时期间无法更改。

整数

-1

-1：未使用。
0：指定引用属性的数组长度。
Note
仅 RP_UNSG 支持读取数组长度。
>0：配置值。

 

输出

描述

数据类型

默认值
取值范围

Val

Value

BACnet 对象的引用属性的值。

如果以前可访问的对象或属性不再可访问（例如，通信错误），则功能块将提供最后的有效值。

双整数

0

Dstb

Disturbed

[Dstb] 指示是否访问了引用的 BACnet 对象。
[Dstb] = 0，如果：
BACnet 对象访问 = 访问成功
[Dstb] = 1，如果：
BACnet 对象访问 = 访问期间出错

布尔值

0

PrioAct

Priority active

指示[ArrayIdx]查询的优先级数组元素是否包含命令值或值“NULL”。

Note
如果引用的属性不是优先级数组元素，则 [PrioAct] 保持默认值。

布尔值

0

0 - 查询的优先级为“NULL”或引用的属性不是优先级数组元素。
1 - 命令查询的优先级。

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes
