构建名称选项

确定自动化站位置名称的构建方式。

  • Reuse (default)
    Includes the building element name in the location name.
  • New
    Starts the location name with the building element name.
  • Skip
    Leaves out the building element name when building location names.

默认为Reuse，即重用名称 Flr_2，构建类似 B_1'Flr_2 的位置名称。
如果您选择New，同一示例中的位置名称为 Flr_2。
如果您选择Skip，同一示例中的位置名称为 B_1。

类型

建筑元素的类型，例如建筑物、厂房等
