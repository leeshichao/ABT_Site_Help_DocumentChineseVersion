脉宽调制：var.speed（AO - 子系​​统特定扩展）

模拟输出 (AO) 对象支持子系统特定扩展的以下属性Pulse width mod.: var.speed.

PWM frequency ✳

 

 

"PWM frequency" 定义 PWM 输出信号的频率。
频率范围：100 .. 5000 Hz
频率默认：2500 Hz

Output position

 

 

"Output position" 定义所连接的物理输出是否被处理为 NO（常开）或 NC（常闭）。

NO contact

连接的物理输出被处理为 NO。

NC contact

连接的物理输出被处理为 NC。

财产ID：4970

Process value 1和Process value 2 ✳

 

 

"Signal value 1“（X1），”Signal value 2“（X2），”Process value 1“（Y1）和”Process value 2" (Y2) 用于计算线性函数 (f)。需要线性函数来根据测量信号值计算当前值。

单位：取决于过程值。

范围：

如果从测量信号值计算当前值所需的函数完全由所选信号类型定义，则为 -1。示例：Ni1000

如果从测量信号值计算当前值所需的函数未完全由所选信号类型定义，则任何值 ≠-1。

Drive operating hours ✳

 

 

"Drive operating hours" 表示变频器运行的累计时间，即 Present-Value > Present-Value-1 期间。

"Drive operating hours" 每 4 小时持久存储一次。
