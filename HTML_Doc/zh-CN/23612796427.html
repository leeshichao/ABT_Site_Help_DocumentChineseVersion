推荐工程模式应用

现场设备目录中的 PL-Link RDG20..KN 和 RDG26..KN 实例提供的标准设备图表涉及 RDG20..KN 和 RDG26..KN （BACnet 对象拥有的功能） RDG20..KN 和 RDG26..KN) 以及编程模式，请参阅“推荐的编程模式应用”一章。
Recommended programming pattern applications

此外，还有一些功能（RDG20..KN 和 RDG26..KN 拥有的 BACnet 对象）没有相关的编程模式，即所谓的工程模式。

工程模式：配置对象值

  • BACnet object can be configured by an O&M client

工程模式：监控对象价值

  • BACnet object can be monitored by an O&M client

工程模式：操作对象值

  • BACnet object can be operated by an O&M client
