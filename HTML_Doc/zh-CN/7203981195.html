ABT 站点用户界面

ABT 站点用户界面提供了一个框架，该框架在一个窗口中收集所有 ABT 组件（例如，构建、启动等）。该框架还提供常见功能，例如Undo, Redo, Help，以及同一窗口中不同任务（例如建筑结构、应用程序选择）的拆分视图。

ABT 站点框架包含以下用户界面元素。

① Common toolbar

公共工具栏包含窗口标题和标准 Windows 状态图标，用于最小化、调整大小、最大化和关闭窗口。窗口标题的构建如下：

SIEMENS - ABT Site - <Project name>

② Component selector with common tools

仅当实例可用时，以下组件才处于活动状态。否则，组件名称将呈灰色显示。一旦组件的第一个实例打开，该组件就处于活动状态并且可以选择。

  • Startup
  • Web interface
  • Configuration
  • Engineering
  • Reports

③ Component toolbar

根据任务的不同，每个组件可能包含不同的工具。

④ Work area
