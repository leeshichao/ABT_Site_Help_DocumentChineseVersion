UDP port ✳

 

 

"UDP port" 表示用于 IP-子网-本地组通信的 UDP 端口号。

如果 BA-Group-Manager 和所有 BA-Group-Member-Objects 连接在同一个 IP-子网上，并且包含相同的本地组通信-UDP-端口，则本地组通信-UDP-端口将用于将组通信广播域限制为 IP-子网。

这种优化通常允许取代房间分段分组的全局广播。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，将激活 Local-Group-Communication-UDP-Port 的新值。

IP address ✳

 

 

"IP address"表示该网口的IP地址。

如果 BACnet-DHCP-Enable 为 true，则 BACnet-IP-地址不可在线修改

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，将激活 BACnet-IP-Address 的新值。

IP subnet mask ✳

 

 

"IP subnet mask" 表示该网络的子网掩码。

如果 BACnet-DHCP-Enable 为 true，则 BACnet-IP-Subnet-Mask 不能在线修改。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，将激活 BACnet-IP-Subnet-Mask 的新值。

IP default gateway ✳

 

 

"IP default gateway" 表示默认 IP 网关。

如果 BACnet-DHCP-Enable 为 true，则不能在线修改 BACnet-IP-Default-Gateway。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，将激活 BACnet-IP-Default-Gateway 的新值。

Enable (IP) DHCP ✳

 

 

"Enable (IP) DHCP" 属性指示该网络是否通过 DHCP 配置。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，BACnet-IP-DHCP-Enable 的新值将被激活。

Device instance number ✳

 

 

"Device instance number" 表示 BA-设备对象的对象标识符的实例号。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，实例编号的新值将用作 BA-Device-Object 的对象标识符的对象实例编号。

Device name ✳

 

 

"Device name" 表示 BA-设备对象的对象名称。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，Device-Name 的新值将用作 BA-Device-Object 的 Object-Name。

Command ✳

 

 

"Command" 属性允许触发网络端口对象执行的各种操作。仅当属性 Command 的值为空闲时才可以写入新命令。

Command

Function

闲置的

默认值。将返回一个错误。

激活

当前配置属性设置将被激活。

仅当属性 Command 的值为空闲时才可以写入新的命令激活。

该属性值将保持活动状态，直到激活完成或失败。

如果属性 Changes-Pending 为 false，则属性 Command 将设置为空闲。

如果设置激活成功，Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

如果设置激活失败，可靠性属性将设置为 ACTIVATE-FAILURE。 Changes-Pending 属性将保持为 true，Command 属性将设置为空闲。

如果设备在不重新初始化整个设备的情况下无法执行激活，则在运行命令 activate 时它将重新初始化自身。

丢弃更改

修改的配置属性设置将被丢弃。

仅当属性 Command 的值为空闲时，才可以写入新的命令丢弃更改。

修改后的属性将恢复为 Changes-Pending 首次设置为 true 时包含的属性值集。 Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

重启端口

设备将重新初始化以重新启动并重新连接到网络。

仅当属性 Command 的值为空闲时才可以写入新的命令重新启动。

Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.
