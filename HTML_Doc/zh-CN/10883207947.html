重要的！

除非了解后果，否则不要更改值。其中一些属性不得更改。

Auto-zero mode ✳

 

 

"Auto-zero mode" 定义如何处理校准。

1

残疾人

2

一经请求

3

基于时间（参见“Auto-zero mode, timer")

Disable auto-zero mode ✳

 

 

"Disable auto-zero mode" 定义当应用程序读取较大的气流变化时是否暂时禁用校准。

Auto-zero mode, timer ✳

 

 

"Auto-zero mode, timer" 定义校准频率的时间值。

Pressure deviation ✳

 

 

"Pressure deviation”定义了死区偏移，在允许校准之前，测量的气流必须在该死区偏移内持续一段时间。（另请参见“Pressure deviation hold time")

Infinite impulse resp.filter time ✳

 

 

"Infinite impulse resp.filter time" 定义内部系统响应时间的 RMS 值。

In use objects list ✳

 

 

"In use objects list" 包括当前“正在使用”的 BA 对象的所有对象标识符的列表。

Samples for average sensors calculation ✳

 

 

"Samples for average sensors calculation" 定义滚动样本平均值中连续采集的样本数。

Supported signal types ✳

 

 

"Supported signal types" 定义硬件支持哪些信号类型。

Pressure deviation hold time ✳

 

 

"Pressure deviation hold time“定义了在允许校准之前测量的气流必须保持稳定的时间。

Calibration command ✳

 

 

"Calibration command" 触发设备的校准。

Ready

设备已准备好接受新请求。

Calibrate

开始设备校准。

Auto-zero mode, zero value ✳

 

 

"Auto-zero mode, zero value”定义了在最后一个校准周期中记录的“计数值”，用于计算传感器的零偏移。
