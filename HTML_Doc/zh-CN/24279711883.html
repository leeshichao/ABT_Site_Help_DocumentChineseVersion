[EvtAckCoord22] 事件并确认与 3 个优先事项的协调

Program block, name / node subtype: [EvtAckCoord22] Event and acknowledge coordination with 3 priorities

Library hierarchy: Universal functions

Family: EvtAckCoord

项目树

图表

Configurator

程序块存储在没有 I/Os. 的库中 使用auto-create and auto-connect函数创建 I/Os 和 /or 将它们连接到接口块，例如 R_A、CMD_B。或者，从包含库中预定义 I/Os 的文件夹中取出 I/Os，并从工厂中取出 /or，并将它们连接到接口块。

Function

请在 1.5 或更高版本的设备上使用此功能。

提供多达8个接口，用于接收来自不同来源的聚合警报、故障、手动干预及其状态的双整数信号。

它解释最多 8 个双整数信号并将它们组合成一个新的双整数输出信号，该信号可以使用进一步的逻辑进行处理，例如事件灯控制。

该程序块具有以下可选功能：

Option: Event interface 1...Event interface 8

用于从另一个结构以双整数值对象的形式接收有关聚合警报、故障、手动干预及其状态的信息的接口。

最有可能来自不同自动化站中 SysFnctAS21x 的 SttUpAlmHdl22b 的“事件接口输出”。

Option: Acknowledge interface input

用于接收确认信号的接口。

Option: Acknowledge interface output

用于发送确认信号的接口。
