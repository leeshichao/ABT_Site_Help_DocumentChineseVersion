R_TRIG：识别上升沿和触发脉冲

R_TRIG (FB402) 块识别正斜率。

功能性

对于输入 [In] 的正斜率，在程序周期内输出 [Out] 设置为 [Out] = 1。

应用

R_TRIG 块用于各种控制任务，例如识别按钮的初始使用。

过程响应

运行函数之前初始化：

  • The old status of the input value is assumed to be [In] = No.

从该过程的第三个周期开始，块将使用输入处的值进行处理，因为只有在这个阶段，输入处的值才被认为是有效的。在该过程的前两个周期中，输出的值为默认值。

Note:启动期间，输入端的连续信号 [In] = Yes 被识别为前沿。输出 [Out] = On 处的相应脉冲出现在该过程的第三个周期中。
