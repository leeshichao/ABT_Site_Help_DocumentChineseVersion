[INTEGRAL] 积分函数

功能块 INTEGRAL 计算积分输入值随时间变化的面积。

INTEGRAL 计算积分输入值随时间变化的面积。

可以使用转换因子来修改积分和的单位。

Functioning

INTEGRAL 循环获取输入值[In]并按时间积分。当前结果在输出 [Out] 处提供。

输入使能函数[EnFnct]可用于启动集成。当 [EnFnct] = 0 时，输出 [Out] 上的值设置为 0.0，并且当前积分和保留在内部。

Set start value

在积分过程之前或期间，可以将积分总和的输出值 [Out] 设置为输入 [SttVal] 上的预定义起始值。起始值必须小于计数器限制。如果输入设置起始值 [SetStt] 上的值设置为 1，则输出值设置为起始值。

Set counter limit

计数器值限制 [CntValLm] 是积分和的上限，达到该上限时重新开始积分，并将 [LmRd] 设置为 1，持续一个周期。

Set conversion factor

INTEGRAL 在内部计算中使用秒为时间单位。如果输入 [In] 上的值以分钟或小时为单位，则可以设置转换系数。

输入值[单位]

转换

换算系数

修改后的输入值[单位]

0.000278

0.016667

Enable negative value count

如果输入 [EnCntDn] 设置为 1，则功能块会考虑负输入值。结果，可以在输出处生成负值的和。

如果仅期望正输入值，则可以将 [EnCntDn] 设置为 0 以避免处理测量错误。

Application example

INTEGRAL 用于随时间推移对输入值求和的地方：

  • Calculate volume [m3] from volume flow [m3/s]
  • Calculate electrical energy [kWh] from electrical power [kW]
Process response

如果 [Pers] = 1，功能块会在启动时从 BACnet 对象读取最后保存的积分值，并使用该值作为第一个积分和。如果出现错误，或者如果 [Pers] = 0，则积分和从 0 开始。

属性“顶行值”和“旧起始值”必须在关联的 BACnet 对象上作为扩展属性可用（“通过持久性扩展”=“积分”）。
