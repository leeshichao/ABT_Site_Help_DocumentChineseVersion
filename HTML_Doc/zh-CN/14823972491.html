[RATE_LIM] 变化率限制

功能块 RATE_LIM 限制输入信号的变化率以及最小值和最大值。

RATE__LIM 限制输入信号的变化率以及最小值和最大值。

Functioning

该函数计算并限制变化率如下：

Signal increase

最大限度。信号增加变化率 = [MaxIn] - [MinIn] / [TiUp]

如果输入信号 [In] 超过信号增加的最大变化率，则输出信号 [Out] 的变化率受到限制。因此，输出值[Out]仅以线性方式增加。

Signal decrease

最大限度。信号下降变化率 = [MaxIn] - [MinIn] / [TiDn]

如果输入信号 [In] 超过信号下降时的最大变化率，则超出输出信号 [Out] 的变化率。因此，输出值[Out]仅以线性方式减小。

Minimum and maximum values

[MinIn] 和 [MaxIn] 限制输出值 [Out]。

最小值：

如果输入值 [In] 小于 [MinIn]，则输出值设置为 [Out] = [MinIn]。

最大值：

如果输入值 [In] 大于 [MaxIn]，则输出值设置为 [Out] = [MaxIn]。

Enabling and disabling the function

  • When [EnFnct] = 1, the function is switched on.
  • When [EnFnct] = 0, the function is switched off. Input [In] is available at output [Out].
