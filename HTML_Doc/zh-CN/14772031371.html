Separators

① Plant designation

工厂名称位于图表顶部Programming编辑器，例如 HGen21。在预定义的植物上，类型与库中的名称匹配。

② Main separator

标识图表的结构或功能细分。

例如，工厂 HGen21 被细分为以下区域：

  • Operating mode determination (plant)
  • Sensors and control
  • Main pump group, twin pump
  • Boiler 1, modulating control with CTR
  • Boiler 2, single-stage control with hysteresis

③ Sub-separator

将主分离器细分为各个区域。例如，HGen21 中的主分隔符“锅炉 1，使用 CTR 进行调节控制”分为以下子区域：

  • Operating mode determination (boiler 1)
  • Burner (boiler 1)
  • Pump (boiler 1)
  • Valve (boiler 1)

④ Function separator

按功能细分子分隔符。例如，子分隔符“运行模式确定（锅炉1）”分为以下功能：

  • Exception acquisition
  • Manual switch
  • Temperature setpoint determination
Comments and enumerations

注释允许更详细的结构或为编程提供附加注释。

枚举注释显示功能块的设置枚举。

⑤ Function comments

允许在分隔符内进行功能或结构细分。例如，主分隔符“操作模式确定”中的功能分隔符“启动控制”是使用以下功能注释构建的：

  • Maintain plant switch-off
  • Alarm handling and delay after startup

⑥ Programming comment

解释或确定程序逻辑或程序功能。

⑦ Programming comment main block

强调主块的程序功能。

⑧ Enumeration comment

显示设置的枚举。

⑨ Caution comment

强调特殊情况或条件。
