您可以自定义Selected parameters列表中的列表Available parameters.

Customize the list of parameters

  1. You have generated a list of custom favorites automatically
  1. Open Configuration > Favorites.
  2. Select an item in the favorites list.
  3. Click Edit.
  4. The Parameters window opens to the right. You can see the available parameter values in the Parameters tab.
  5. Tick the checkbox for the required parameters from the list and Read only option.
  6. Click Apply on the toolbar.
  1. You have customized the list of parameters.
