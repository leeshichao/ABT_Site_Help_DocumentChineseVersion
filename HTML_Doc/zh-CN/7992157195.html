BO 3 位，无子系统特定扩展

下表显示了信号类型为“BO 3-Pos Relay”和“BO 3-Pos Triac”（没有任何子系统特定扩展）的模拟输出 (AO) 的通道配置属性。

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

从 0 到 100% 的上升时间

“从 0 到 100% 的上升时间”定义信号从 0 [%] 到 100 [%] 所需的时间。

范围：6.3...6553.5 [秒]

从 100 到 0% 的下降时间

“从 100 到 0% 的下降时间”定义信号从 100 [%] 到 0 [%] 所用的时间。

范围：6.3...6553.5 [秒]

反应时间

“反应时间”定义了前往 0 % 或从 0 % 出发时的额外运行时间。反应时间补偿了电机和驱动器之间的间隙。

Note:
内冲程模型在反应时间内不改变。

范围：0.0...50.0 [秒]

关闭时间

“关闭时间”定义了改变方向之前的暂停时间长度。

范围：0.0...25.5 [秒]

中立区

定位中立区。

如果冲程模型和过程值 (DY) 之间的差异超过死区加上迟滞的一半，则会生成 OPEN 或 CLOSE 脉冲，该脉冲的长度足以使执行器返回到死区内的位置。

最小脉冲长度等于上升时间或下降时间乘以迟滞。见图Hysteresis and Neutral zone (3-position).

范围：0...10 [%]

迟滞

行程模型中的滞后。

范围：0...10 [%]

开始同步

“启动同步”定义了启动时执行器行程模型的同步方法。同步在启动时自动启动。

没有任何

单次打开：1.5 x 上升时间期间的 OPEN 命令

单次关闭：1.5 x 下降时间期间的 CLOSE 命令

终端位置同步

“结束位置同步”定义到达结束位置（0% 或 100%）时的同步方法。

无：不同步

连续：永久同步（0% 或 100%）

单：同步 1.5 x 上升时间 (100%) 或 1.5 x 下降时间 (0%)

每 10 分钟：每 10 分钟同步 1.5 x 上升时间 (100%) 或 1.5 x 下降时间 (0%)

每 20 分钟：每 20 分钟同步 1.5 x 上升时间 (100%) 或 1.5 x 下降时间 (0%)

连续打开：永久同步（100%）

连续关闭：永久同步（0%）

单开：同步 1.5 倍上升时间 (100%)

单次关闭：同步 1.5 x 下降时间 (0%)

每 10 分钟打开一次 打开：每 10 分钟同步 1.5 x 上升时间 (100%)

每 10 分钟关闭一次：每 10 分钟同步 1.5 x 下降时间 (0%)

每 20 分钟打开一次 打开：每 20 分钟同步 1.5 倍上升时间 (100%)

每 20 分钟关闭一次：每 20 分钟同步 1.5 x 下降时间 (0%)

中继功能

“继电器功能”定义了上升命令和下降命令的逻辑。

直接：使用正常逻辑。

反转：反转正常逻辑以修复错误接线。

坡

“斜率”定义用于计算测量值或定位值的线性函数的斜率。

截距

“截距”定义用于计算测量值或定位值的线性函数的截距。

单元

“单位”定义输入或输出的物理单位。

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。
