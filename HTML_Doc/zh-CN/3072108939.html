XFB error codes

输出引脚ErrCode表示错误代码值。 ErrCode 通常用于在 CFC 在线模式下（在 ABT 中）测试控制程序。在正常操作期间，控制程序可以使用 ErrCode 来处理特定的错误异常（例如：超出范围、低于范围）。

  • ErrCode = 0 indicates no error, Valid is True.
  • ErrCode > 0 will set output pin Valid to False.

ErrCode < 20

值小于 20 的错误代码源自 BACnet 对象可靠性属性的评估。这些错误代码可能表明现场设备存在问题。

ErrCode > 20

值等于或大于 20 的错误代码表示 XFB 和 BACnet 对象（数据点）之间存在问题，例如难以访问对象和 /or 所需属性。 XFB 和 /or 数据点配置值可能设置不正确。

Troubleshooting notes

如果错误代码表明 XFB 的 DeviceID 或 ObjectID 有问题，请验证引用的 BACnet 对象是否与 XFB 兼容。

对于 XFB 访问集合视图节点对象：

  • ObjectID points to the Collection view node object (which must be in the same device).
  • Referenced BACnet object must be of compatible type with XFB.
