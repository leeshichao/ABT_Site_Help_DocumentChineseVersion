[SP_SPLY] 确定供气设定值

功能块 SP_SPLY 计算加热、冷却和能量回收单元的设定值。

SP_SPLY 计算供暖、制冷和能量回收单元的设定值。低和高送风设定值以及能量回收的输出值控制相应的组件。

Functioning

能量回收的输入控制操作 [ActgErc] 需要能量回收单元的操作模式信息：加热或冷却。当能量回收单元在加热模式下运行时，它需要一个用于加热的设定点，而在运行模式冷却下，它需要一个用于冷却的设定点。根据输入 [ActgErc] 中的值，SP_SPLY 在输出 [SpErcSu] 上提供 [SpHiSuIn] 或 [SpLoSuIn] 中的值。

在某些情况下，能量回收单元以[SpHiSuIn]和[SpLoSuIn]的平均值工作。在这些情况下，能量回收设定点 [SelSpErc] 的输入选择用于指示是否提供输出 [SpErcSu] 上的平均值。 [SelSpErc] = 1 表示使用输出 [SpErcSu] 的平均值。

Enable and disable function block

如果 SP_SPLY [EnFnct] = 0 被禁用，则输出：

  • [SpLoSu] is set to the value form [SpMinSu]
  • [SpHiSu] is set to the value from [SpMaxSu]
  • [SpErcSu] is set with the average of inputs [SpHiSuIn] and [SpLoSuIn]

如果启用 SP_SPLY [EnFnct] = 1，则 SP_SPLY 向输出 [SpHiSu] 和 [SpLoSu] 提供相应输入 [SpHiSuIn] 和 [SpLoSuIn] 的值。输出 [SpErcSu] 处的值由输入 [ActgErc] 和 [SelSpErc] 确定。所有输出值均受 [SpMinSu] 和 [SpMaxSu] 定义的范围限制。

Replace supply air setpoints at outputs

您可以通过在输入 [EnSbstVal] 上设置值 1 来覆盖 SP_SPLY 的调试、测试和维修功能。在这些情况下，输出 [SpHiSu]、[SpErcSu] 和 [SpLoSu] 设置为相同的值。该值可以在输入 [SbstVal] 上配置。如果 [EnSbstVal] = 1，则功能块上不考虑 [SpMinSu] 和 [SpMaxSu] 的限制。
