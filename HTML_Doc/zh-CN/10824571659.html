KNX PL-链接：SAB（BlsOut - 子系​​统特定扩展）

百叶窗输出 (BlsOut) 对象支持子系统特定扩展的以下属性KNX PL-Link: SAB.

End position detection ✳

 

 

"End position detection" 定义了如何确定运行时间。

Manual

必须测量和配置运行时间。查看属性“Move down time“ 和 ”Move up time".

Note:添加老化和温度依赖性缓冲器。

Auto

该模块永久检测“Move down time”和“Move up time”并报告重大变化。Auto不建议将集成电子元件用于在极限位置断开的执行器。

Once at startup

该模块检测到“Move down time“时间和”Move up time" 启动时一次并在内部保存这些值。Once at startup不建议将集成电子元件用于在极限位置断开的执行器。

Move up time ✳

 

 

"Move up time“定义了执行器将百叶窗从下端位置移动到上端位置所需的时间。

范围：00:03:000...05:00:000 [分钟:秒:毫秒]

Move down time ✳

 

 

"Move down time“定义了执行器将百叶窗从上端位置移动到下端位置所需的时间。

范围：00:03:000...05:00:000 [分钟:秒:毫秒]

Move completion time ✳

 

 

"Move completion time" 定义添加到 " 的时间Move up time” 或 “Move down time“当百叶窗移向终点位置之一时。”Move completion time" 确保移动将被末端触点停止。

范围：00:000...20:000 [秒:毫秒]

Slat rotation maximum time ✳

 

 

"Slat rotation maximum time“定义了执行器将板条从关闭位置移动到打开位置所需的时间。

范围：00:00:000...01:40:000 [分钟:秒:毫秒]

Number of slat steps ✳

 

 

"Number of slat steps“定义了将百叶窗板条从关闭位置移动到打开位置所需的步骤数。

范围：2...255

Blinds position 0, closed ✳

 

 

"Blinds position 0, closed“定义了预定义位置 P0 的百叶窗高度和板条角度。

范围：0...100 %

Blinds position 1, visual protection ✳

 

 

"Blinds position 1, visual protection" 定义了预定义位置 P1 的百叶窗高度和板条角度。

范围：0...100 %

Blinds position 2, sun altitude low ✳

 

 

"Blinds position 2, sun altitude low“定义了预定义位置 P2 的百叶窗高度和板条角度。

范围：0...100 %

Blinds position 3, sun altitude high ✳

 

 

"Blinds position 3, sun altitude high“定义了预定义位置 P3 的百叶窗高度和板条角度。

范围：0...100 %

Blinds position 4, open ✳

 

 

"Blinds position 4, open“定义了预定义位置 P4 的百叶窗高度和板条角度。

范围：0...100 %

Calibration command ✳

 

 

"Calibration command" 触发设备的校准。

Ready

设备已准备好接受新请求。

Calibrate

开始设备校准。

Calibration status ✳

 

 

"Calibration status" 显示校准状态。

Pending

In process

Manually calibrated

Automatically calibrated
