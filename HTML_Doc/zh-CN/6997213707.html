Function

The AFreads来自一个或多个风传感器的值，确定最高值并使用开关延迟来衰减结果。提供结果（WdSpdRs）用于监控。

允许的限值是根据遮阳产品的设计值配置的。

The AFtransfers以下为 CenPrtShd11：

  • A configurable blinds setting (CmdLmExc) in the event the limit value is exceeded.
  • A configurable blinds setting (CmdSenFlt) in the event of a sensor fault (if all wind sensors report "unreliable").

Engineering and commissioning

AF 在预加载的应用程序上不可用。

根据位置（气象站、屋顶、立面、建筑物边缘），另一种风速可能占主导地位。可以定义多个限值来补偿风传感器和遮阳产品之间的偏差。为了one限制值，使用CenWdPrt11；为了three限制值使用 CenWdPrt11 和 CenWdPrt12。
