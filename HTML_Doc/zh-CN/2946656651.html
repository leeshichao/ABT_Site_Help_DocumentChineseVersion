百叶窗输出对象 (BlsOut)

百叶窗输出 (BlsOut) 对象类型定义了百叶窗执行器的标准化表示模型，用于自动化和控制以及操作和监控。该对象独立于现场设备和盲人特定技术。用于绝对定位和直接控制的相应驱动控制逻辑可以由特定数据采集或联网现场设备来执行。盲输出对象具有两种范例来命令盲执行器：

  • Target state commanding for the purpose of absolute positioning
  • Control commanding for the purpose of direct control

控制程序、系统程序、操作和监控、工程和调试功能以及其他 BACnet 对象，例如位于任何楼宇自动化站上的命令、时间表和组对象，可以使用一种或两种方法来控制百叶窗。然而，各个属性可能不会在每个控制程序周期期间被命令。

通常可以通过切换按钮、按下一个或多个按钮或通过菜单命令来触发以下操作：

  • Stop–Stop moving
  • Move-up–Start moving upwards
  • Move-down–Start moving downwards
  • Stop-or-step-up–Stop a respective moving or perform a gradual moving upwards
  • Stop-or-step-down–Stop a respective moving or perform a gradual moving downwards
  • Goto-height, goto-angle, goto-position–Start moving to a specified position

控制命令 ✳

 

 

BACnet 对象属性，允许以与状态命令相同的方式对百叶窗致动器进行控制命令，通过写入包括附加操作参数的操作值以及该属性的相应优先级，或者通过释放特定优先级。

阅读：

  • Property is mainly provided to facilitate commanding and releasing.
  • Reading the property Control command delivers the last value of a control command commanded by a client.

指挥：

  • Commanding the property Control command with a particular operation value including additional operation parameters, and a priority sets the respective priority slot according to Progress value and marks it as control commanded.
  • If the commanded priority is higher or equal to the Present priority, the Control command will be output to data acquisition.

发布：

  • Releasing the property Control command with a particular priority releasing the corresponding priority slot and re-arbitrates the Priority array.
  • Releasing the property Control command yields the same result as releasing Present value.

释放后直接控制：

  • If a priority slot gets active after releasing, and the respective priority was commanded by a control command, the BACnet object resumes direct control.
  • In this case, the BACnet object does not output a control command to the data acquisition because re-output the previously commanded control command would not produce the same result as before.
  • Operations such step-up by step-increment, dim-up, stop, or move the angle of a blind only depend on timing constraints and/or initial states, which are no longer identical to the time of initial commanding.
  • However, control programs and/or operation and monitoring functions operating on the respective priority may now command new control commands, which will allow smooth movements or changes and avoid undesirable target state hopping observed by building users.

Last moving direction ✳

 

 

"Last moving direction”表示百叶窗执行器最后的移动方向。

  • Represents the last up/down moving direction of the blind actuator’s height or angle.
  • Is updated by data acquisition, unless "Out of service" is set.
  • The data acquisition provides respective estimated/simulated values if "Last moving direction" is not available.
  • May be used by a blind sensor solely for visualization purposes, for realizing the toggle functionality, or other purposes.

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Out of service

 

 

"Out of service" 包含每个工作日（周一至周日）的每日时间表。

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

进度值 ✳

 

 

指示百叶窗实际位置的 BACnet 对象属性。

  • Progress value refers to the normalized moving range.
  • Progress value will be updated by a data acquisition.
  • If Progress value is not available, the data acquisition has to provide respective estimated/simulated values.
  • While a blind is moving, Progress value may be continuously updated.
  • If the Present priority was commanded by a control command, the BACnet object will update the respective priority slot and Present value with every notified Progress value to convey the illusion of a continuous target state commanding to clients of the object.
  • If no priority is active and Default control is TRUE, the BACnet object will update Default and Present value with every notified Progress value to convey the illusion of a continuous modifying of Default to clients of the object.

I/O address ✳

 

 

"I/O address“识别并记录数据源，并方便以标准化方式配置、修改和查询作业。

内容“I/O address" 是特定于技术的，包括：

Actuator type ✳

 

 

"Actuator type" 表示所使用的执行器的类型。该属性是在工程期间设置的。该属性通常由操作和监控功能使用，以可视化和操作盲点位置，例如高度和角度。

  • "Actuator type" = Blind
    • Height and angle of actuator can be moved.
    • Position includes height and angle.
    • Example: Venetian blinds.
  • "Actuator type" = Shutter
    • Only height of actuator can be moved.
    • Angle cannot be moved
    • Default value for angle: 0%
    • Example: Awnings
  • "Actuator type" = Louver
    • Only angle of actuator can be moved
    • Height can’t be moved
    • Default value for height position: 0%

示例：垂直百叶窗

Maximum actual value ✳

 

 

"Maximum actual value“定义了输出允许的物理范围的上限。

  • Valid range of "Maximum actual value": "Minimum actual value" <= "Maximum actual value" <= 100%
