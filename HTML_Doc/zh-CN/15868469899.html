将日历分配给调度程序

Add a calendar object

  1. In the Project tree, select [Plant name] > Resources > Coordination.
    Coordination folder
  2. Double-click Add object.
  3. The Add Coordination object dialog box opens.
  4. In the Object type field, select Calendar.
  5. Complete the required fields.
  6. Click OK.
  7. A new calendar object is created in the Project tree.
  8. Right-click the newly created object and select Properties.
  9. Select the BACnet view option.
  10. Modify the calendar properties as required.
  11. Click Close.
  12. Right-click the calendar and select Properties.
  13. The Calendar opens.
  14. Configure the calendar.
    Exception schedules

描述和名称是链接的，即描述与名称匹配，反之亦然。要取消描述与名称的链接，请单击描述右侧的链图标Description和Name字段。要重新链接描述和名称，请再次单击链图标。

Assign a calendar to a scheduler

  1. You have added one or more calendar objects in the Project tree.
    Plants navigation view
  1. Drag a scheduler from the Function block folder in the Library to the Programming editor.
  2. Open the Properties tab of the scheduler.
  3. Click Calendars.
  4. Do one of the following:
    • To assign specific calendars, select the checkbox of a calendar in the Assign column and click Assign selected.
    • To assign all calendars, click Assign all.
  1. The calendars are assigned to the scheduler.
