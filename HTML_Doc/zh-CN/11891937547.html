Import modules and I/Os

  1. You have added a bus interface module.
    Adding devices
  1. Go to Building > Building structure.
  2. Right-click a bus interface module and select Import data.
  3. Select a file to import.
  1. You have imported am xml file. You can edit the data point properties in Engineering > I/O configuration.
    I/O configuration

如果总线接口模块已在I/O configuration任务，关闭并再次打开它以刷新设备中的导入数据。
