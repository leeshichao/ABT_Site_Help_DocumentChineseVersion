照明操作策略（LgtOpStrgy11）

Overview

应用功能》Lighting operating strategy 11" (LgtOpStrgy11）根据房间运行模式控制自动模式的照明运行策略。

Function

操作策略（LgtOpStrgy）支持以下值：

  • Energy efficiency: In automatic mode the lights are set to reduced consumption of electrical energy.
  • Comfort optimization: In automatic mode the lights are set to visual comfort.

该策略可以针对每个房间的操作模式进行配置。


Output
响应 (LgtOpStrgy) 通过分组分发到房间分段中的照明应用程序 (Lgt11)。
BACnet 客户端还可以操作对存在检测器的响应。
