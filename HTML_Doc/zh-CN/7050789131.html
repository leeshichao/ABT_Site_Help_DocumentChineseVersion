发现设备

InStartup > Configure and download, theDiscovered devices选项卡允许您执行以下任务：

  • Select all or a specific set of devices by network number.
  • Filter the devices to display.
    • Before a new query is required, a Clear table must be performed. In cases where not all devices can be reached the first time, the filter must be performed several times. In this case, the table must not be cleared.
    • The filter affects the instance number range only and must be entered before you start the discovering process. Devices that were created with an older than SVS400 version can sporadically be displayed outside of the defined area.
  • List the status of the devices based on the locally connected device type and connection type.
  • Display all connected devices based on the network number and status specified.
  • Clear the contents of the Discovered devices table.
