风扇操作 (FanOp11)

Overview

应用功能》Fan operation 11" (FanOp11）处理风扇速度的手动操作。 FanOp11 读取手动风扇速度并确定对工厂模式和风扇的影响。它还向房间操作员单元提供当前风扇速度以供显示。

Function

该 AF 具有多个可命令的 BACnet 对象，用于监视以及通过房间操作员单元进行操作。支持所有常见风扇类型。如果某个对象与正在使用的风扇类型不对应，则该对象将自动设置为“未使用”并且不再被考虑。

Manual commands
当检测到手动风扇速度命令（优先级 13 激活）时，将根据当前配置设置设备运行模式和风扇速度，并通过分组功能以优先级 13 对房间段中的风扇设备进行命令。

用于开窗触点关闭的手动风扇速度配置：

范围FanOpManCmd必须设置为Semiautomatic control确保当窗户触点感应到窗户打开时，风扇将转动 OFF，无论手动风扇速度命令如何。请参阅配置。

Green Leaf interaction
如果按下 GreenLeaf 按钮，则会评估最后一个手动风扇速度命令的效率，如果认为效率低下，则会重置。

FanCmdEefMan

2:Automatic

Fan operation at manual command
▶ 手动风扇命令如何影响风扇速度运行和 HVAC 控制功能。

1:Semiautomatic control
▶ 手动风扇速度命令影响 PltOpMod 和风扇速度操作：

  • If manual fan speed = OFF, PltOpMod goes to Protection (Prio13)
  • If manual fan speed = ON, fan is commanded ON unless window contact senses open window.

2:Direct control
▶ 对风扇的手动风扇速度命令仅影响风扇速度操作：

  • If manual fan speed = OFF, fan is commanded OFF
  • If manual fan speed = ON, fan is commanded ON
