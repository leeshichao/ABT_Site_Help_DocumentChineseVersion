BO 带三位控制的 3 位双向晶闸管

以下部分显示信号类型为“BO 3-Pos Triac”的模拟输出 (AO) 和子系统特定扩展三位控制的属性。 Desigo 5.x 不支持具有子系统特定扩展三位控制的模拟输出。

Channel configuration properties

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

单元

“单位”定义输入或输出的物理单位。

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。

Subsystem-specific extension properties

列出的属性显示在BACnet objects editor > Inspector window > Properties > Configuration在编辑器表中选择数据点时选项卡。

✳ 表示西门子专有财产。

Startup synchronization

 

 

'Startup synchronization' 定义了启动时同步执行器行程模式的方法。同步在启动时自动启动。

None

 

Single open

在 1.5 倍上升时间期间打开命令。

Single close

在 1.5 倍上升时间期间关闭命令。

财产ID：4992

End position synchronization

 

 

'End position synchronization' 定义执行器行程模型到达最终位置时的同步方法（0% 或 100%）。

None

不同步

Continuous

始终在 0% 或 100% 同步

Single

如果 PrVal 在 1.5 x 上升或下降时间期间为 0 或 100%，则同步一次

Every 10 min

如果 PrVal 在 1.5 倍上升或下降时间期间为 0 或 100%，则每 10 分钟同步一次

Every 20 min

如果 PrVal 在 1.5 倍上升或下降时间期间为 0 或 100%，则每 20 分钟同步一次

Continuous open

始终在 100% 同步

Continuous close

始终在 0% 同步

Single open

如果 PrVal 在 1.5 倍上升时间 (100%) 期间处于 100%，则同步一次

Single close

如果 PrVal 在 1.5 x 下降时间 (0%) 期间处于 0%，则同步一次

Open every 10 min

如果 PrVal 在 1.5 倍上升时间 (100%) 期间为 100%，则每 10 分钟同步一次

Close every 10 min

如果 PrVal 在 1.5 x 下降时间 (0%) 期间为 0%，则每 10 分钟同步一次

Open every 20 min

如果 PrVal 在 1.5 倍上升时间 (100%) 期间为 100%，则每 20 分钟同步一次

Close every 20 min

如果 PrVal 在 1.5 x 下降时间 (0%) 期间为 0%，则每 20 分钟同步一次

财产ID：4991

Function command ✳

 

 

"Function command" 允许触发命令的运行，例如同步或校准。

该命令的运行可能需要一些时间。在此期间，执行器将由同步或校准命令控制，并且无法执行目标状态。

Ready

执行器已准备好迎接新的请求。

Synchronize

强制与属性中定义的值同步“Startup synchronization".

Calibrate

与 DXRx 硬件同步相同。对于 PL-Link 设备，提供单独的校准序列。

Rise time from 0 to 100% ✳

 

 

"Rise time from 0 to 100%" 定义信号从 0 [%] 变化到 100 [%] 所用的时间。

范围：63...65535 [0.1 秒]

Fall time from 100 to 0% ✳

 

 

"Fall time from 100 to 0%" 定义信号从 100 [%] 变为 0 [%] 所用的时间。

范围：63...65535 [0.1 秒]

Hysteresis

 

 

'Hysteresis' 确定行程模型中的滞后。

财产ID：4989

Neutral zone ✳

 

 

"Neutral zone" 定义控制器在设定点周围的不敏感区域。

如果控制差值的绝对总和小于中性区的一半（“设定点”-“控制器输入”<“中性区”/2），则在 7 个过程循环期间在“控制器输出”（当前值）处跟踪调节变量。此后，“控制器输出”保持恒定，直到控制差值超出“中性区”。 “控制器输出”再次接管计算的调节变量。

如果 Controller-Type = staged，则不会使用“Neutral-Zone”

“微分值单位”表示“中性区”的工程单位。

范围：0...40

Control action

 

 

"Control action" 定义上升和下降命令的逻辑。

直接的

正常逻辑：针对 0 到 100 % 的命令打开。

撤销

反转逻辑：对于 0 到 100 % 的命令关闭。例如，可用于将阀门旋转与执行器的安装位置相匹配。

财产ID：4988

Reaction time

 

 

"Reaction time“定义执行器终端位置和阀门开始打开点之间的额外运行时间。

Note:
内行程模型在反应时间内不会改变。

范围：0...500 [0.1 秒]

财产ID：4987

Switchover delay

 

 

"Switchover delay" 定义了方向改变开始之前的中断长度。

范围：0...255 [0.1 秒]

财产ID：4986

Progress value

 

 

"Progress value" 显示当前阀门位置。只读。

单元： [％]

财产ID：5083
