CNT_UP：向上计数器

CNT_UP (FB444) 块是具有较高计数器限制的斜率控制向上计数器。

功能性

如果输入“向上计数”[CntUp] 处存在递增斜率，则“CNT_UP”块将计数器值 [CntVal] 加 1。计数增量为1。

Note:为了识别斜率，块必须经过两个机器周期。因此，计数最早在第二个机器周期之后发生。

Counter limit.

如果计数器值达到或超过计数器限值 [CntValLm]，则设置输出“已达到限值”[LmRd] = 1（是），并且向上计数器停止。

如果计数器以高于计数器限值的起始值 [SttVal] 启动，或者如果计数器限值设置为低于当前计数器值 [CntVal] 的值，则 [LmRd] = 1 (Yes) 并且向上计数器停止。

达到计数器限制的可能计数增量数量取决于起始值 [SttVal]（或 [CntReset]）、当前计数器值以及当前计数器值是否高于计数器限制。

Reset counter

如果输入“重置计数器”为 [CntReset] = 1（是），则计数器值保持为 [CntVal] = 0（不受斜率控制）。

如果 [CntReset] = 0（否），则计数器启动。

一个新的计数器进程可以与[CntReset]和[CntUp]同时启动。计数器相应地初始化并开始向上计数。

Set start value.

如果输入“设置起始值”为 [SetStt] = 1（是），则计数器值保持在 [CntVal] = [SttVal]（不受斜率控制）。

如果 [SetStt] = 0（否），计数器将从起始值 [SttVal] 开始。

如果起始值 [SttVal] 为负，则计数器从值“0”开始。

过程响应

从第二个处理周期开始，该块将使用输入处的值进行处理，因为只有此时输入处的值才被视为有效。默认值在第一个处理周期内发布。

Note:输入 [CntUp] 处的连续信号在启动时被识别为递增的斜率。
