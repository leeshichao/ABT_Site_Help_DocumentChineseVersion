Add application templates

  1. There is at least one application template or application type in your project or library to select.
  1. Open Building > Building structure.
  2. Click Add application template.
  3. Select an application template from your project or an application type from your library.
  4. Select the application station type from the application station table, e.g., DXR2.E12P, or a template from the template list.
  5. Click Add template to project.
  6. A dialog box opens next to the button.
  7. Type the New template name, Version, Description, and check the room ID and device instance number values in the corresponding fields.
  8. Click OK.
  9. Configuration > Application configuration opens.
  10. The name of the created application template displays at the top of the configuration sections.
  11. Complete the application configuration.
    Configuring features (template)
  12. Select the Default values task.
  13. Click Show/hide parameter.
  14. The Show/hide parameter dialog box opens where you can configure properties and default values.
    Configuring default values (template)
  15. Click OK.
  16. Select the I/O assignment task and assign I/O's according to the specifications of your project.
    I/O assignment (task)
  1. The application template is created and is now available as a template for creating automation stations.
