将 BACnet 趋势日志描述和名称与趋势 BACnet 对象同步

默认情况下，BACnet 趋势日志描述和名称与相关的 BACnet 对象不匹配。Sync trend descriptions and names允许在整个自动化站中有效地将 BACnet 趋势日志的名称和描述同步到其相关的 BACnet 对象。INFO： Desigo CC 可以处理趋势日志对象的不同名称和判断，并且不需要此同步。

  1. The assignment of the BACnet objects is done. The result is shown as: Result with assigned hierarchy.
  2. The assignment of the BACnet objects is not performed. The result is shown as: Result without assigned hierarchy.
  1. Go to Building > Building structure.
  2. Right-click the automation station and select Go to engineering.
  3. Open the BACnet objects task.
  4. From the Device functions drop-down list, select Sync trend descriptions and name.
  5. The Device function dialog box opens.
  6. Click OK.
