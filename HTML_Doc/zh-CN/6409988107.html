网页界面

这Web interface组件显示已配置设备的实例，以进行在线调试和工程设计。

要打开已配置设备的实例，请选择Startup > Configure and download，然后单击Web interface.
Connecting to the web interface of the device

Note: 适用于的一些信息和限制Web interface是：
- DXR2, PXC3, PXC4/5/7 devices open the internalWeb Interface ABT 站点内的用户界面
- PXG3.Wx00-1/-2、PXMx0.E 或 PXC7.A (Apogee) 在外部浏览器（例如 Chrome）中打开
- 其他设备如 PXMx0-1 提供 Web 界面，可以直接使用外部浏览器打开，使用直接 IP (URL) 地址

您可以登录多个设备并在设备之间切换。每个设备都会在一个选项卡中打开。如果会话保持空闲状态，它将超时并返回登录提示，您必须重新输入密码才能重新登录。

如果没有显示网页，并且通过 MS/TP 或房间设备连接到设备，则右侧的“WPC_...zip”文件夹丢失。 WPC 文件夹必须与固件版本相对应。所有固件版本均发布在官方“Desigo 固件库”中。

 

这Web interface组件用于以下工作流程/tasks：

  • Installing an ABT project (no subcontracting)
  • Installing an ABT project (with subcontracting)
  • Commissioning an ABT project
  • Balancing air/water (with Pack & Go)

有关将 DXR2 连接映射到 I/O 地址的帮助，请参阅以下主题。
DXR2.. Pins and addresses

要连接到设备的网络界面，您的计算机必须使用 Google Chrome。

对设备上 Web 服务器的访问受密码保护。
