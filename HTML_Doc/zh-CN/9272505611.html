全球指挥

使用以下过程来命令一台或多台设备的一个或多个对象：

Connecting

  1. You have connected via the room unit.
    Connecting directly to a room operator unit
  1. In the Common toolbar, select the arrow beside the Connect button.
  2. Set up the connection.
    Connect and disconnect
  3. Click Connect.

Discovering all devices and organize the data fields

  1. Open Startup > Global functions.
    Global functions
  1. Select the Discovered devices tab.
  2. Click Discover.
  3. Select All from Discovery drop-down menu.
  4. The locally connected devices display in the Discovered devices table.
  5. Scroll to the left.
  6. Select the Tag heading and drag-and-drop it to the right of the Name heading.
  7. Select the Value heading and drag-and-drop it to the right of the Tag heading.
  8. Select the Units heading and drag-and-drop it to the right of the Value heading.

Selecting the command list and parameters

  1. Select the Command tab.
  2. In the Command list, select Air Balancer Commanding List.
  3. Select the check boxes for the desired parameters.

Previewing the commands

  1. Select all devices.
  2. Click Preview.

Committing the commands

  1. Enter values to be commanded.
  2. Select all devices.
  3. Click Commit.
  4. Click Yes in the warning dialog box.
  1. If the commands were successful, the values will be updated.
    Log viewer and status bar (Log and Jobs)

Balancing individual devices

  1. Right-click a device and select Go to web interface. When the web interface of the device displays:
    Login to the device.
    Enter User name = Balancer
    Enter Password = [password]
  2. Click Favorites.
  3. Click Room ## and Room segment ##.
  4. (Optional) Select various favorites menus to view the balancer tasks.

Going to the Startup component

  • Select the Startup component.

Releasing Commands

这些参数可以单独发布或作为设备的一部分发布。

  1. Select a single device.
  2. Click Release.
  1. The selected parameters will be removed from the view.

如果该参数使用优先级数组进行命令，则还将发送放弃命令。尝试释放单个参数。
