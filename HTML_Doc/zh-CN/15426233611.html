[CMN_EVT] 常见事件

功能块 CMN_EVT 读取公共事件对象的当前值和附加属性。

CMN_EVT 读取公共事件对象的当前值和附加属性。

Functioning

Compatible data points:

  • Common event [CmnEvt]

Required properties:

  • Present value
  • Status flag
  • Alarm object count
  • Fault object count
  • Extended fault object count
  • Unacknowledged fault object count

Optional properties:

  • Reliability
  • Event state
  • Extension by event configuration
  • Acknowledged transitions
  • Suppress event notification
  • Suppress event detection
  • Acknowledge.
Pins

输入

描述

数据类型

默认值
取值范围

SupEvtDet

Suppress event detection

抑制事件的检测。
Note
如果未启用“内部报告”扩展，则功能块的功能中不会考虑输入值。
如果控制程序中的多个函数访问同一个 BACnet 对象，则只有这些函数块之一可以互连到引脚。
该函数不适用于 BACnet 第三方对象。

布尔值

0

SupEvtNtf

Suppress event notification

抑制事件通知。
Note
如果未启用“内部报告”扩展，则功能块的功能中不会考虑输入值。
如果控制程序中的多个功能块访问同一个 BACnet 对象，则只有这些功能块之一可以互连到引脚。
该函数不适用于 BACnet 第三方对象。

布尔值

0

Ack

Acknowledge

允许在引用的 BACnet 对象范围内确认 BACnet 对象的任何未确认的转换。
该函数不适用于 BACnet 第三方对象。

布尔值

0

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

 

输出

描述

数据类型

默认值
取值范围

PrVal

Present value

引用的 BACnet 对象的属性“当前值”的值。

整数

1

Dstb

Disturbed

[Dstb] 指示引用的 BACnet 对象是否处于故障状态或处于 OffNormal 状态。当 BACnet 对象返回正常状态时，[Dstb] 保留其值，直到确认转换到正常状态为止。
[Dstb] = 1，如果：
BACnet 对象 = 访问错误
OR
“状态标志”=故障
OR
'事件状态' <> 正常

[Dstb] = 0，如果上述条件不满足 AND '确认的转换' = x, x, 1。

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [Dstb] 在断电后重新启动后不会保留该值。
BACnet 第三方对象不考虑属性“事件状态”和“已确认的转换”。

布尔值

0

Flty

Faulty

[Flty] 指示引用的 BACnet 对象上的最后一个事件是否有错误。如果 BACnet 对象返回到正常状态，[Flty] 将保留其值，直到确认转换到正常状态为止。
[Flty] = 1，如果：
BACnet 对象 = 访问期间出错
OR
“状态标志”=故障

[Flty] = 0，如果不满足上述条件 AND 以下可能性之一有效：

  • 'Event state' = Offnormal
  • OR
  • 'Event state' = Normal AND 'Acknowledged transitions' = x, x, 1

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [Flty] 在断电后重新启动时不会保留该值。
BACnet 第三方对象不考虑属性“事件状态”和“已确认的转换”。

布尔值

0

OffNrml

Offnormal

[OffNrml] 指示引用 BACnet 对象上的最后一个事件是否异常。当 BACnet 对象返回正常状态时，[OffNrml] 保留其值，直到确认转换到正常为止。
[OffNml] = 1，如果：
BACnet 对象 = 访问成功
AND
“状态标志”=无故障
AND
“事件状态”=非正常

[OffNml] = 0，如果上述条件未满足 OR '事件状态' = 正常 AND '已确认的转换' = x, x, 1。

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [OffNml] 在断电后重新启动后不会保留该值。
该函数不适用于 BACnet 第三方对象。

布尔值

0

Rlb

Reliability
指示属性“可靠性”的值（如果该属性可用）。

整数

0：未检测到故障

EvtInd

Event indication

指示处于“故障”或“异常”状态的 BACnet 对象是否包含在所引用的 BACnet 对象的范围内。

布尔值

0

0 – 具有故障或异常状态的 BACnet 对象不属于范围的一部分。
1 – 具有故障或异常的 BACnet 对象属于范围的一部分。

NewEvt

New event

Indicates if a BACnet object transitioning to state Fault or Offnormal is included within the scope of the referenced BACnet object.
The output is set to 1 for one cycle.

Note
在以下情况下，输出不会设置为 1：

  • A BACnet object within the scope transitions from state Fault or Offnormal to another state Fault or Offnormal.
  • In the same cycle, one BACnet object transitions to state Normal and another to state Fault or Offnormal.
  • BACnet objects in state Fault or Offnormal exist at startup.
  • A new BACnet object transitions to state Fault or Offnormal within the scope of a nested plant component with common event.

布尔值

0

AckSta

Acknowledged state

指示引用的 BACnet 对象的范围是否包括未确认的转换。

布尔值

0

0 - 没有 BACnet 对象具有未确认的转换
1 - 具有未确认转换的 BACnet 对象

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes
