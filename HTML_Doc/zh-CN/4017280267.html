组管理器对象 (GrpMaster)

组管理器 (GrpMaster) 对象类型允许将公共组数据分发给组成员以及从组成员收集单独的组数据。组管理器对象的组成员资格可以通过组类别和组编号属性来配置。可以通过在工程系统中修改组号或者在运行系统中在线修改组号来改变组成员资格。对于特定组类别和组编号，只能存在一个组管理器对象。 GrpMaster 对象属性是：

✳ 表示西门子专有财产。

Group category ✳

 

 

"Group category“允许房间自动化站区分独立的应用领域，例如设定值分组、占用分组、盲分组和照明分组。

Group category number ✳

 

 

"Group category number" 标识组类别中的特定组，例如设定点组 1 和 2，或照明组 3、6 和 7。

Group number ✳

 

 

"Group number“允许在”中配置特定的成员资格Group category”，例如设定点控制 1 或 2，或照明控制 1 或 2。

  • The application-oriented partitioning into different categories implies that all managers and members of a particular "Group category" will fit together and that the respective "Group number" can be arbitrarily configured.
  • "Group number" can be modified online to change the group membership.

Context reference ✳

 

 

"Context reference" 表示对 BA-Group-Manager-Object 或 BA-Group-Member-Object 的周围应用程序上下文的引用。

State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Out of service

 

 

"Out of service" 包含每个工作日（周一至周日）的每日时间表。

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

财产ID：81

Group command ✳

 

 

"Group command“允许通过客户端功能（例如控制程序）将公共组值列表分发给组的所有成员。

Transmission timeout ✳

 

 

"Transmission timeout" 定义时间间隔（以秒为单位），在该时间间隔内 "Group member“对象必须确认由”分配的组命令Group manager“ 目的。

  • "Transmission timeout" = 0: No acknowledgement of distributed group commands by "Group member" objects required.
  • "Transmission timeout" > 0: Acknowledgement of distributed commands by "Group member" objects required. If not all group members acknowledge a distributed command within the "Transmission timeout", the "Group manager" object will distribute the respective group command again. The number of redistribution will be restricted by the property "Transmission repeat".
  • Is distributed to the "Group member" by the "Group manager" objects.

Transmission repeat ✳

 

 

"Transmission repeat" 定义组命令重新分发的最大次数。

如果一个或多个组成员不确认“Transmission timeout“， 这 ”Group manager" 对象再次重新分发相应的组命令。

这 ”Transmission repeat“ 财产：

  • Defines the number of re-distributions.
  • "Transmission repeat" = 0 or "Transmission timeout" = 0: No redistribution of group commands.
  • Is distributed to the "Group member" by the "Group manager" objects.

Data collection interval ✳

 

 

"Data collection interval" 是一个属性，定义在 " 之前等待的最小秒数Group member“对象可以将另一条收集到的组数据消息发送给”Group manager“ 目的。

Data collection link ✳

 

 

"Data collection link" 定义了收集组成员数据的方法。

  • "Data collection link" = Normal (default):
    Monitored data is sent over the normal communication network.
  • "Data collection link" = Use separate link, if available:
    Monitored data is sent over a separate communication network if a separate link is available.

Synchronization interval members ✳

 

 

"Synchronization interval members" 定义了 " 的时间间隔（以秒为单位）Group member“对象定期监督其可用性”Group manager“ 目的。

  • "Synchronization interval members" can be modified online.
  • "Synchronization interval members" is stored as non-volatile property of the "Group manager" object.
  • "Synchronization interval members" is distributed to the Group Member objects by the "Group manager" object.
  • Minimal allowed value: 15 min., typical value range: 15…180 min.

Member collected data send time slot ✳

 

 

"Member collected data send time slot“定义具有不同时隙值的组管理器对象。这使得它们的组成员能够在不同时隙内发送检测到的变化数据，以避免通信高峰。

这是一个大的系统优化属性。

范围：0...40 秒

默认值：0 秒

Member COV data send time slot ✳

 

 

"Member COV data send time slot“定义具有不同时隙值的组管理器对象。这使得它们的组成员能够在不同时隙内发送收集的数据，以避免通信高峰。

这是一个大的系统优化属性。

范围：0...40 秒

默认值：0 秒

Command sequence number ✳

 

 

"Command sequence number" 指示 BA-Group-Manager-Object 用于标记最后一个分布式组命令的当前序列号。

Group members ✳

 

 

"Group members" 表示对组的 BA-Group-Member-Objects 的引用的有序列表。

如果 Group-Member-Object 不再监管其 Group-Manager-Object，则 Group-Manager-Object 将在 5 * Heartbeat-Interval 的间隔后删除相应的 Group-Member-Object。

Group members context ✳

 

 

"Group members context" 表示对 " 中配置的组的 BA-Group-Member-Objects 的周围应用程序上下文的引用列表Group category“ 和 ”Group number".

如果 ”Group number“修改后，Group-Manager-Object将被清除”Group members context" 并确定对新 BA-Group-Member-Objects 的上下文引用。

Event state

 

 

"Event state“提供了一种方法来确定该对象是否具有与其关联的活动事件状态。”Event state”属性表示对象的事件状态。“中的变化Event state" 值为 FAULT 的属性被视为故障事件。如果对象不支持内部报告，则该属性的值为 NORMAL。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

财产ID：4930

Description

 

 

"Description" 是一串可打印的字符，其内容不受限制。

Object name

 

 

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

Object identifier

 

 

"Object identifier" 是用于识别对象的数字代码。它必须在互联网范围内是唯一的。

Object type

 

 

"Object type“ 表示特定对象类型类中的成员资格。例如”Analog input“，”Binary output“，”Event enrollment“，”Trend log“， ETC。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。
