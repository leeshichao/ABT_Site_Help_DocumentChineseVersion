复制 I/O 和 Modbus 对象

使用上下文菜单轻松创建现有对象的副本Engineering > I/O configuration和Engineering > Modbus.

 

您可以创建以下对象的副本。

  • Devices
  • Plants
  • TX/IO data points
  • Modbus data points

 

Example: Duplicate an I/O data point in the I/O configuration task

  1. An I/O data point is existing in the project.
  1. Go to Building > Building structure.
  2. Right-click an automation station and select Go to engineering.
  3. Open the I/O configuration task.
  4. Right-click an I/O data point and select Duplicate.
  1. An I/O data point is added to the plant.

I/O 数据点已创建，但不会自动分配。
