取值范围

Link speed ✳

 

 

"Link speed" 指示以每秒位数表示的网络通信速率。值 0 指示未知的通信速率。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，将激活 Link-Speed-Autonegotiate 的新值。

Link speeds ✳

 

 

"Link speeds" 表示该网络端口支持的链路速度的数组。

Link speed auto-negotiation ✳

 

 

"Link speed auto-negotiation" 指定端口的自动协商设置。

如果修改此属性，则属性 Changes-Pending 将设置为 true。
当将 activate 值写入属性 Command 时，将激活 Link-Speed-Autonegotiate 的新值。

真的

该网络端口的速度由设备自动确定。

错误的

链接速度由属性值决定”Link speed".

Max. number of managers

 

 

"Max. number of managers“指定管理器节点的最高可能地址。相同的信息也将被建模为网络端口对象的属性。

范围：1..127

如果修改此属性，则属性 Changes-Pending 将设置为 true。

当将 activate 值写入属性 Command 时，将激活 Max-Manager 的新值。

Maximum info frames

 

 

"Maximum info frames" 指定节点在必须传递令牌之前可以发送的信息帧的最大数量。

如果修改此属性，则属性 Changes-Pending 将设置为 true。

当将 activate 值写入属性 Command 时，将激活 Max-Info-Frames 的新值。

MAC address ✳

 

 

"MAC address" 表示该网络上使用的 BACnet MAC 地址，将在注册设备时由云端提供。

Device instance number ✳

 

 

"Device instance number" 表示 BA-设备对象的对象标识符的实例号。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，实例编号的新值将用作 BA-Device-Object 的对象标识符的对象实例编号。

Device name ✳

 

 

"Device name" 表示 BA-设备对象的对象名称。

如果修改此属性，则属性 Changes-Pending 将设置为 true。当将 activate 值写入属性 Command 时，Device-Name 的新值将用作 BA-Device-Object 的 Object-Name。

Command ✳

 

 

"Command" 属性允许触发网络端口对象执行的各种操作。仅当属性 Command 的值为空闲时才可以写入新命令。

Command

Function

闲置的

默认值。将返回一个错误。

激活

当前配置属性设置将被激活。

仅当属性 Command 的值为空闲时才可以写入新的命令激活。

该属性值将保持活动状态，直到激活完成或失败。

如果属性 Changes-Pending 为 false，则属性 Command 将设置为空闲。

如果设置激活成功，Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

如果设置激活失败，可靠性属性将设置为 ACTIVATE-FAILURE。 Changes-Pending 属性将保持为 true，Command 属性将设置为空闲。

如果设备在不重新初始化整个设备的情况下无法执行激活，则在运行命令 activate 时它将重新初始化自身。

丢弃更改

修改的配置属性设置将被丢弃。

仅当属性 Command 的值为空闲时，才可以写入新的命令丢弃更改。

修改后的属性将恢复为 Changes-Pending 首次设置为 true 时包含的属性值集。 Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

重启端口

设备将重新初始化以重新启动并重新连接到网络。

仅当属性 Command 的值为空闲时才可以写入新的命令重新启动。

Changes-Pending 属性将设置为 false，Command 属性将设置为空闲。

Changes in progress ✳

 

 

"Changes in progress" 指示网络端口对象中的配置设置是否映射到当前配置设置。

错误的

配置设置反映当前端口配置信息。

真的

配置设置已修改，但尚未在端口上激活。

State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

财产ID：4930

Description

 

 

"Description" 是一串可打印的字符，其内容不受限制。

Object name

 

 

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

Object identifier

 

 

"Object identifier" 是用于识别对象的数字代码。它必须在互联网范围内是唯一的。

Object type

 

 

"Object type“ 表示特定对象类型类中的成员资格。例如”Analog input“，”Binary output“，”Event enrollment“，”Trend log“， ETC。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。
