设置 ABT 项目

Desigo ABT 项目通常从主项目（XWP 或 CT）开始。在那里进行基本设置，即集成到网络结构或数据库中以存档 ABT 项目。

ABT 站点特定设置（例如工具语言和默认项目文件夹）在Project Manager > Settingsin ABT Site.
Settings

1

打开Settings > User profiles.

-- Users：定义用户、用户设置和密码。

-- Roles：定义角色和访问权限。

-- Common settings：定义常用设置。

User profiles

2

打开Settings > Address defaults.

-- IP：定义网络中的 IP 命名和地址默认值。

-- MS/TP: Define MS/TP naming and address defaults in the network.

-- BACnet：定义BACnet命名。

-- BACnet > More：定义 IP 和 MS/TP 网络的一般属性。

Address defaults

3

打开Settings > Naming defaults.

-- Object names：在 ABT 站点中设置命名默认值。

-- Naming rules：定义ABT项目和ABT站点命名规则。

Naming defaults

4

打开Advanced > User designation.

-- User designation settings: Define user designation rules and structure.

User designation

5

打开Settings > Localization.

-- 定义 ABT 项目特定的时区、语言和单位属性。

Localization

6

打开Settings > Number ranges.

-- Range settings：为组号、房间 IDs 和中央功能定义 ABT 项目特定范围。

Number ranges
