VAV 房间热功率控制 (VavThPwrCtl11)

Overview

This AF "VAV room thermal power control 11" (VavThPwrCtl11) 根据工厂模式和房间运行模式选择供暖设定值和制冷设定值。两个 PID 控制器（一台供暖，一台制冷）使用设定点对房间部分中的供暖和制冷设备组件进行排序。

VavThPwrCtl11在舒适模式下仅支持单个温度设定点，而不是单独的加热/cooling设定点。

热功率控制功能是一种室温控制算法，包括 PID 反馈控制器和传热计算。它通过调节供给流量和供给流温度来控制室温。当送风流量因加压或通风需求而变化时，此功能会调节送风温度以平衡流向房间的热流。

房间段支持以下设备：

  • Radiator
  • Radiant ceiling
  • Heating coil
  • Supply air VAV damper
  • Cooling coil

主要特点：

  • Select active room temp setpoint for heating and cooling based on plant mode and room operating mode
  • Select temperature control mode (modulate or 2-position) and active elements (air, rad)
  • Feedback control for multiple heating elements: Rad, Rcg, Hcl, Primary flow
  • Feedback control for multiple cooling elements: Rcg, , Ccl, Primary flow
  • Feedback control for a supply air terminal as one element
  • Elements enabled by collected "available" signals

Function

该 AF 与房间部分 HVAC 设备组件 AF 协作进行加热和冷却。每个加热和冷却元件都有一个 PID 控制器，并根据为此应用程序模板配置的 HVAC 设备启用。

Thermal Power Control feature Active

热功率控制功能用于舒适模式。电源端子用作单个元件。 AF 设置气流设定点和供气温度设定点，以按反馈控制器设定的速率调节传热。

它选择流量和温度设定点，以满足配置的流量和温度限制的最低气流速率提供所需的热流。

加热控制顺序：1）供电端子，2）散热器，3）加热吊顶，4）加热盘管

冷却控制顺序：1) 冷却天花板，2) 冷却盘管

可以通过配置更改此默认顺序。

Thermal Power Control feature Inactive

在舒适模式之外不使用热功率控制功能。终端的反馈控制器被禁用，并且元件不参与加热/cooling 序列。

加热控制顺序：1）散热器，2）加热吊顶，3）加热盘管，4）VAV加热

冷却控制顺序：1) 冷却天花板，2) 冷却盘管，3) VAV 冷却

可以通过配置更改此默认顺序。

Room temperature feedback

室温 PID 输出是高于和低于零的百分比。该值表示送风终端向房间的传热率。

Calculate supply air temperature heating and cooling setpoint

排气温度设定点来自根据当前送风流量向上或向下缩放反馈值。通常，它会按比例放大，因为实际流量小于最大加热或冷却流量。如果流量较低，则需要更大的温差才能提供相同的加热或冷却功率。

Calculate Supply Flow Setpoint for Cooling and Heating

当需要冷却时，温度环的值为负值，并受到供应流量最小值和最大值的限制。然后计算输出冷却需求（以百分比表示）并将其映射到冷却气流限制。

当需要加热时，温度环值为正值，并受到供应流量最小值和最大值的限制。然后计算输出加热需求（以百分比表示）并将其映射到加热气流限制。

Engineering and commissioning

此温度控制功能旨在快速应用再加热，以避免通风柜流量变化导致房间内调节送风快速变化时可能导致的不舒服的气流。它直接响应流量变化来调整再加热，而无需等待室温漂移到死区并超出舒适范围。因此，它可能比基本温度控制序列使用更多的能量。

如果送风温度环路超调，实验室工作人员可能会注意到冷却季节期间施加的热量并质疑操作。这可以通过调整送风温度控制回路或实施基本温度控制来解决。
