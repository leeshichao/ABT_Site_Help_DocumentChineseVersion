模拟调度程序 (ASchedule)

对象类型调度程序模拟包括模拟调度程序的 BACnet 属性。

Naming

“名称”、“描述”和“命名扩展”之间存在依赖关系。对其中一项属性的任何更改都会影响其他两项属性。

笔记：
通过输入项目特定的文本可以消除依赖性。

示例1：
如果选择，预配置的“描述”“房间操作模式调度程序”会将“名称”设置为“ROpModSched”。如果选择“A”作为“命名扩展”的补充，则描述由“(通风和空调)”补充为“房间操作模式调度程序(通风和空调)”，并且“名称”变为“ROpModSched(A)”。该名称还构成对象名称的最后一个元素。

示例2：
如果选择，预配置的“描述”“家用热水调度程序”会将“名称”设置为“DhwSched”。除了“命名扩展”之外，选择“01”（项目特定文本）会生成“名称”“DhwSched(01)”。该名称还构成对象名称的最后一个元素。

Name

 

 

'Name' 是特定于实例的名称。它用于设置层次对象名称。

财产ID：4438

Description

 

 

'Description' 描述了一个 BACnet 对象。 “描述”是一个可翻译的字符串，在内部保存为文本引用或直接保存为字符串。

财产ID：28

Name extension

 

 

'Name extension' 是名称的可选扩展名。它唯一地标识一个对象或区分对象。

财产ID：4437

Note
文本目录中的名称也可用于“命名扩展”。

Object name

 

 

'Object name' 唯一指定自动化站内的 BACnet 对象。

财产ID：77

Object naming rule

 

 

'Object naming rule' 定义了工程过程中设置对象名称的规则。值范围是“分层”或“自定义”。在“hierarchical”下，对象名称是根据层次结构形成的。对象名称直接在“自定义”下设置。 BACnet 层次结构无关紧要。
Note
'Object naming rule' 是一个内部属性。无法通过标准的 right/write 过程访问它。

财产ID：4436

Other

Schedule default value

 

 

'Schedule default value' 如果没有其他调度程序值处于活动状态，则设置用于“当前值”的默认值。
调度程序默认值介于“当前最小值”和“当前最大值”之间。

财产ID：174

Priority for writing

 

 

'Priority for writing' 设置对象列表中输入的命令对象的优先级。
优先级范围：1...16

财产ID：88

Note
在当前工具版本中，只能使用 BACnet 浏览器在线修改对象列表。

Suppress fault monitoring

 

 

'Suppress fault monitoring' 确定是否抑制故障监控（故障事件）（“是”/“否”）。设置“是”会抑制“可靠性”的评估，并且“可靠性”的值保持为“无故障”。

财产ID：357

Out of service

 

 

"Out of service" 包含每个工作日（周一至周日）的每日时间表。

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

财产ID：81

Units

 

 

'Units' 显示 ' 的物理单位Present value'.

财产ID：117

Resolution

 

 

'Resolution' 表示值所代表的准确性。它定义了属性“当前值”的工程单位的最小可识别变化，并可以在线修改。
“分辨率”通常用于操作和监控功能，以表示“当前值”：
“分辨率”只能是 > 1 的整数。
“分辨率”仅用于显示屏上的缩写描述，例如操作和监控站。它不用于缩短程序处理的实际值。

财产ID：106

'Present maximum value'

 

 

'Present maximum value' 设置当前值的最高值。大于配置的最大值的值被限制为最大值。

财产ID：65

Present minimum value

 

 

'Present minimum value' 设置当前值的最低值。小于配置的最小值的值被限制为最小值。

财产ID：69

Object access level

 

 

'Object access level' 定义特定于实例的对象访问级别。 'Object access level' 用于客户端应用程序对对象的一般过滤和处理。

  • 'Object access level' is a configuration property that can only be set up offline (ABT, application configuration).
  • 'Object access level' is evaluated by the client applications.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

财产ID：4930

Object identifier

 

 

'Object identifier' 是唯一标识自动化站内的对象的不变指示符。

财产ID：75

Naming parent

 

 

'Naming parent' 指的是根据（应用程序）层次结构叠加的 BACnet 对象。

  • The superposed object can refer to one BACnet object on the same device. A reference to a remote device is not possible.
  • The superposed BACnet object can refer to a BACnet object that is part of the common system hierarchy.

财产ID：4398
