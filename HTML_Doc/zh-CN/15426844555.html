[R_MG] 读取多状态组

功能块 R_MG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续采集组数据（当前值/status 标志对）。

R_MG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续获取组数据（当前值/status 标志对）。此外，组管理器对象还会触发一个已配置的评估函数来计算结果值。 R_MG 以预先配置的时间间隔定期读取评估结果。读取也可以由外部源触发。

R_MG 可配置为根据可选评估函数提供多个（最多八个）评估结果值。必须至少配置一个评估函数。

专有对象对于分组基础结构是必需的：组管理器对象和一个或多个组成员对象。各个成员数据点通过组成员对象进行分组和引用，并且数据由组成员对象获取并转发到组管理器对象。

Functioning

Compatible data points:

  • Multistate input [MI]
  • Multistate output [MO]
  • Multistate calculated value [MCalcVal]
  • Multistate configuration value [MCnfVal]
  • Multistate process value [MPrcVal]

Required properties of group data points:

  • Present value
  • Status flag
Pins

输入

描述

数据类型

默认值
取值范围

Interval

Read interval

可配置的轮询时间，指定读取计算结果的频率。
值 0 禁用计时器。在这种情况下，可以使用 [ImpRead] 从外部源触发评估结果的读取。
[UpdInd] 使用属性更新计数（如果可用）。这允许在新值等于先前值时检测值是否已更新。在没有更新计数的对象中，如果发生更改，[UpdInd] 将更改为属性当前值。

时间

15s_0ms

ImpRead

Impulse for read

可连接引脚，允许外部源提供数字脉冲来启动读取。
由于[ImpRead]可以互连，因此可以同步多个功能块的读数以在图表中进行采集。
Note
如果[Interval] = -1s，则禁用[ImpRead]。

布尔值

0

EvlFnct1…EvlFnct8

Evaluation function 1…Evaluation function 8

[EvlFnct1] 确定对来自具有公共 [GrpTag] 的已获取组数据的有效当前值执行的过程类型。
[EvlFnct1] 属于八个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX] 和 [ValMaxX]。通常，应用工程师在编程编辑器中设置它，并且在运行时不能更改。
如果未配置，[EvlFnct1] 默认设置为 MaxInt。在这种情况下，评估功能被禁用并且 [Dstb1] = 1。
[EvlFnct2]...[EvlFnct8] 的功能与 [EvlFnct1] 相同。

整数

32767

3: Minimum
取最小值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
4: Maximum
取最大值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。
5: Count of values
有效值的数量，范围为 [ValMin1] 到 [ValMax1]。结果显示在输出 [Cnt1] 上。
10: Last updated
在有效值中搜索最后更新的值。这适用于 [ValMin1] 到 [ValMax1] 范围内的值。

ValMax1…ValMax8

Maximum value 1…Maximum value 8

评估函数的可选可配置参数，为具有公共 [GrpTag] 的采集组数据值设置上限。
[ValMax1] 属于八个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX] 和 [ValMaxX]。

  • [ValMax1] must be greater than [ValMin1].
  • If [ValMax1] and [ValMin1] remain when specifying default values, the acquired group data has no high or low limits and everything is considered as within the range.
  • [ValMax1] cannot be changed during runtime.

[ValMax2]...[ValMax8] 的功能与 [VaIMax1] 相同。

整数

7

ValMin1…ValMin8

Minimum value 1…Minimum value 8

评估函数的可选可配置参数，为具有公共 [GrpTag] 的采集组数据值设置下限。
[ValMin1] 属于八个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValMinX] 和 [ValMaxX]。

  • [ValMin1] must be less than [ValMax1].
  • If [ValMin1] und [ValMax1] remain when specifying default values, the acquired group data has no high or low limits and everything is considered as within the range.
  • [ValMin1] cannot be changed during runtime.
    The functionality from [ValMin2]...[ValMin8] is the same as [ValMin1].

整数

1

GrpTag

Grouping tag

指定功能块获取和评估的特定组数据（当前值、状态标志）。
系统提供预定义和可定制的标签。通常，应用工程师在编程编辑器中设置[GrpTag]，并且在运行时无法更改。必须设置与功能块的数据类型匹配的标签。

输出

描述

数据类型

默认值
取值范围

Val1...Val8

Value 1...Value 8

整数

1

基于 [EvlFnct1] 中选择的评估函数评估的结果值。

[Val1] 属于八个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。

[Val1]表示：

  • 1, if no present values in the acquired group data for the given [GrpTag] were ever valid. [Dstb1] = 1.
  • 1, if [EvlFnct1] remains as is. [Dstb1] = 1.
  • The last valid value if [Dstb1] = 0.

[Val2]...[Val8] 的功能与 [VaI1] 相同。

Cnt1…Cnt8

Count 1…Count 8

整数

0

基于 [EvlFnct1] 中选择的 CountOfVal 评估函数计算的结果值。

[Cnt1] 属于八个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。
[Cnt1] 提供：

  • The number of valid, present values from all acquired group data or those that match the optional, given range [ValMin1] to [ValMax1].
  • 0, if no present values in the acquired group data for the given [GrpTag] were valid. [Dstb1] = 1.
  • The last valid value if [Dstb1] = 1.

[Cnt2]...[Cnt8] 的功能与 [Cnt1] 相同。

Dstb1...Dstb8

Disturbance 1...Disturbance 8

[Dstb1]指示[EvlFnct1]上的评估选择结果是否有效。

[Dstb1] 属于八个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。

如果采集的组数据中至少有一个值有效，则 [Dstb1] = 0。

如果获取的组数据中没有有效值，则 [Dstb1] = 1。

[Dstb2]...[Dstb8] 的功能与 [Dstb1] 相同。

布尔值

0

UpdInd1...UpdInd8

Update indication 1...Update indication 8

[UpdInd1] 表示评估中至少一个当前值已更新为新值或相同值。如果更新的值位于配置的 ValMin/ValMax. 内，则 [UpdInd] 仅设置为 1

仅当 [Dstb1] = 0 时，[UpdInd1] 才设置为 1。

[UpdInd2]...[UpdInd8] 的功能与 [UpdInd1] 相同。

Note
[UpdInd1] 不支持评估函数“CountOfVal”。

布尔值

0
