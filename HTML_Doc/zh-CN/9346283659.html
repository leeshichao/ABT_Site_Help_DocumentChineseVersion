基本照明，用于集成 (LgtBsc11)

Overview

应用功能》Lighting 11, basic, for integration" (LgtBsc11) 用于由不识别 BACnet 照明输出对象（Apogee 或第 3 方系统）的管理系统监控和操作照明。

Function

AF 提供包含基本信息的界面。


Operating
AF 支持通过模拟过程值写入照明输出 (LgtCmd)。 （长CmdBsc）。

为了优先写入/release照明输出，将模拟值映射到照明命令输出对象的目标状态。

优先级 EmgMod1-ManMod2 (Prio 1-8) 映射到照明命令对象的 ManMod2 (Prio 8)。优先级 AutoMod1-AutoMod7 (Prio 9-16) 映射到照明命令对象的 ManMod3 (Prio 13)。

引入值-1%用于重新命令或重新释放照明输出。示例：用户命令 50%，写入 -1%，然后再次命令 50%。

Note:对于 ABT 6.0 及更高版本，在重新命令相同值或重新释放照明输出之前不再需要命令 -1%。之前的“命令为 -1”行为仍然有效，但用户现在可以重新命令相同的值without命令到-1% 的中间步骤。例如：命令 50%，然后再次命令 50%。由于两种重新命令方法都是允许的，因此 ABT 6.0 之前开发的应用程序不受影响。


Monitoring
AF 以模拟和多状态计算值对象的形式提供当前值和优先级。 （长StaBsc，长PrioBsc）。

Configuration

没有任何。
