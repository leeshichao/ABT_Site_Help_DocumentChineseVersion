Create a Pack & Go file for Installer
  1. At least one device is created and configured.
  2. The notification class must be defined at engineering time. A change in a Pack & Go project is not possible at later time.
  1. Select one or more devices, or any other element in the building structure which contains devices.
  2. Right-click the selected elements and select Create Pack & Go.
  3. The Create Pack & Go dialog box opens.
  4. Select the contents to be included.
  5. In the Name work package field, enter a description (mandatory).
  6. In the Work Package Inclusion, select work package specific templates or all project templates.
  7. Click OK.
  1. A Pack & Go file is created and stored in the default directory for exports.
  2. The devices included in the work package are locked.
  3. The application templates included in the work package are locked.
  4. The building hierarchy is locked.

您可以在中定义默认导出路径Project Manager > Settings > Export path.

Create a Pack & Go file for Balancer
  1. At least one device is created and configured.
  2. The notification class must be defined at engineering time. A change in a Pack & Go project is not possible at later time.
  1. Select one or more devices, or any other element in the building structure which contains devices.
  2. Right-click the selected elements and select Create Pack & Go.
  3. The Create Pack & Go dialog box opens.
  4. Select Balancer data.
  5. Select the contents to be included.
  6. In the Name work package field, enter a description (optional).
  7. In the Work Package Inclusion, select work package specific templates or all project templates.
  8. Click OK.
  1. A Pack & Go file is created and stored in the default directory for exports.
  2. The devices included in the work package are not locked.
  3. The application templates included in the work package are not locked.
  4. The building hierarchy is not locked.
