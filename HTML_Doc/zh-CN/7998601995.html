用户指定设置选项卡

用户名称由单独的结构项组成，这些结构项在User designation settings选项卡。

您可以在中创建用户指定Advanced > User designation.
User designation
Creating project-specific user designations

 

您只能导入用户指定文件（从 XWP 导出），如果User designation settings表是空的。如果需要导入用户指定文件，请先删除现有结构。

如果您有 XWP 项目，则必须从 XWP 导出文件 (*.xwpuds) 导入用户名称。否则，您将无法在 Desigo CC 中使用用户名称而不会出现导入错误。

您可以更新 15 个级别的用户指定结构。

① User designation settings table

柱子

描述

姓名

用户指定级别的名称。

描述

每个用户指定级别的描述。不用于用户指定。

分离器

用户指定级别旁边的分隔符。也允许使用空格作为分隔符。

带分隔符：
位置'大楼'楼层'翼'房间'段

不带分隔符：
位置 大楼 楼层 翼楼 房间 段

混合：
位置'大楼楼层翼'房间'段

INFO：请勿对 Desigo CC 使用字符 : 和 *。 Desigo CC 中的别名字段无法处理这些字符。

分钟。长度

用户指定级别的最小字符长度。

最大限度。长度

用户指定级别的最大字符长度。

预定义

用户指定级别的预定义名称。

数据点

必须将一个特定的结构项标记为数据点。数据点可以是任何类型的 BACnet 对象。

导入用户名称

打开文件浏览器，您可以在其中选择并导入 XWP 项目中的用户指定文件 (*.xwpuds)。导入的文件存储在 ABT 站点项目中，并覆盖项目中的所有用户指定定义。
