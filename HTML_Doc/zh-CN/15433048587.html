[W_UNSG] 写入无符号

功能块 W_UNSG 使用数据类型无符号的当前值更新计算值、简单过程值和简单过程值参考对象的属性“当前值”和“可靠性”。

W_UNSG 更新以下属性：

  • 'Present value' and 'Reliability' for a calculated value object with a present value of data type Unsigned.
  • 'Present value' of a simple process value object with a present value of data type Unsigned.
  • 'Present value' of a simple process value reference object with a present value of data type Unsigned.

W_UNSG 与 W_M 的值范围不同，W_M 也读取数据类型 Unsigned 的当前值。

Functioning

Compatible data points:

  • Unsigned calculated value [UCalcVal]
  • Unsigned simple process value [USmpPrcVal]
  • Unsigned simple process value reference [USmpPrcValR]

Required properties:

  • Present value
  • Tracking value (for calculated value objects only)
  • Status flag
  • Reliability

Optional properties:

  • Extension by event configuration
  • Event state
  • Acknowledged transitions
  • Extension by data aggregation
  • Maintenance state
  • Operating hours
  • Suppress event notification
  • Suppress event detection
  • Enable aggregation
Pins

输入

描述

数据类型

默认值
取值范围

EnWrit

Enable write

如果 [EnWrit] = 1，则启用将输入 [Val] 和 [SetValid] 中的值写入 BACnet 对象。
如果[EnWrit]从0变为1，则发生写入。

布尔值

1

Val

Value

虚拟值，由控制程序计算和分配以更新当前值。

[Val] 更新以下属性：

  • 'Tracking value' for calculated value objects; the BACnet object then internally updates the present value with the written value.
  • 'Present value' for simple process value objects.
  • 'Present value' for simple process value reference objects.

如果 [EnWrit] = 1 并且以下项目之一适用，则写入 [Val]：

  • [Val] changes.
  • [SetValid] changes (for calculated value objects only).
  • [RptWrit] is 1.

双字

0

SetValid

Set valid value indication

由控制程序计算并分配的值，指示[Val]是否可靠。

如果 [EnWrit] = 1 并且以下项目之一适用，则 [SetValid] 映射到更新“可靠性”的错误代码：

  • [SetValid] changes.
  • [Val] changes.
  • [RptWrit] is 1.

Note
[SetValid] 中的值仅写入属性“可靠性”的计算值类型的数据点。

布尔值

1

0 - 可靠性错误代码 7（不可靠 - 其他）。
1 - 可靠性错误代码 0（无故障）。

RptWrit

Repeat write

强制将 [Val]（和 [SetValid]）写入数据点。如果 [RptWrit] = 1，则在每个编程周期中重复写入。
[RptWrit]通常由控制程序计算和设置。

Note:
[RptWrit] 不能永久强制为 1。这可能会影响性能和通信流量。

布尔值

0

0 - 无操作。
1 - 将 [Val]（和 [SetValid]）写入每个程序周期的数据点。

SupEvtDet

Suppress event detection

抑制事件的检测。
Note
如果未启用“内部报告”扩展，则功能块的功能中不会考虑输入值。
如果控制程序中的多个函数访问同一个 BACnet 对象，则只有这些函数块之一可以互连到引脚。
该函数不适用于 BACnet 第三方对象。

布尔值

0

SupEvtNtf

Suppress event notification

抑制事件通知。
Note
如果未启用“内部报告”扩展，则功能块的功能中不会考虑输入值。
如果控制程序中的多个功能块访问同一个 BACnet 对象，则只有这些功能块之一可以互连到引脚。
该函数不适用于 BACnet 第三方对象。

布尔值

0

EnDataAgn

Enable data aggregation

允许激活或停用数据聚合。
Note
如果未启用数据聚合扩展，则功能块的功能中不会考虑输入值。
如果控制程序中的多个块访问同一个 BACnet 对象，则只有这些功能块之一可以互连到引脚。
该函数不适用于 BACnet 第三方对象。

布尔值

0

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

双字

0

Dstb

Disturbed

[Dstb] 指示引用的 BACnet 对象是否处于故障状态或处于 OffNormal 状态。当 BACnet 对象返回正常状态时，[Dstb] 保留其值，直到确认转换到正常状态为止。
[Dstb] = 1，如果：
BACnet 对象 = 访问错误
OR
“状态标志”=故障
OR
'事件状态' <> 正常

[Dstb] = 0，如果上述条件不满足 AND '确认的转换' = x, x, 1。

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [Dstb] 在断电后重新启动后不会保留该值。
BACnet 第三方对象不考虑属性“事件状态”和“已确认的转换”。

布尔值

0

Flty

Faulty

[Flty] 指示引用的 BACnet 对象上的最后一个事件是否有错误。如果 BACnet 对象返回到正常状态，[Flty] 将保留其值，直到确认转换到正常状态为止。
[Flty] = 1，如果：
BACnet 对象 = 访问期间出错
OR
“状态标志”=故障

[Flty] = 0，如果不满足上述条件 AND 以下可能性之一有效：

  • 'Event state' = Upper limit
  • OR
  • 'Event state' = Lower limit
  • OR
  • 'Event state' = Normal AND 'Acknowledged transitions' = x, x, 1

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [Flty] 在断电后重新启动时不会保留该值。
BACnet 第三方对象不考虑属性“事件状态”和“已确认的转换”。

布尔值

0

HiLmRd

High limit reached

指示所引用的 BACnet 对象上的最后一个事件是否基于达到上限而处于非正常状态。当 BACnet 对象返回正常状态时，[HiLmRd] 保留其值，直到确认转换为正常状态为止。
[HiLmRd] = 1, if:
BACnet 对象 = 访问成功
AND
“状态标志”=无故障
AND
'事件状态' = 上限

[HiLmRd] = 0，如果不满足上述条件 OR 以下可能性之一有效：

  • 'Event state' = Lower limit
  • 'Event state' = Normal AND 'Acknowledged transitions' = x, x, 1

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
如果 BACnet 对象的状态正常，则输出 [HiLmRd] 在断电后重新启动时不会保留该值。
该函数不适用于 BACnet 第三方对象。

布尔值

0

LoLmRd

Low limit reached

指示所引用的 BACnet 对象上的最后一个事件是否基于达到下限而处于非正常状态。如果 BACnet 对象返回正常状态，[LoLmRd] 将保留其值，直到确认转换为正常状态为止。
[LoLmRd] = 1, if:
BACnet 对象 = 访问成功
AND
“状态标志”=无故障
AND
'事件状态' = 下限

[LoLmRd] = 0，如果不满足上述条件 OR 以下可能性之一有效：

  • 'Event state' = Upper limit
  • 'Event state' = Normal AND Acknowledged transitions = x, x, 1.

Note
CNT_BA 计算值为 1 的输入的数量。当参数化的最小值时进行设置。数量已达到或超过。
输出如果 BACnet 对象的状态正常，[LoLmRd] 断电后重新启动时不会保留该值。
该函数不适用于 BACnet 第三方对象。
