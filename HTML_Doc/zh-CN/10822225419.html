测速脉冲（AI - 子系​​统特定扩展）

模拟输入 (AI) 对象支持子系统特定扩展的以下属性Tacho impulse.

✳ 表示西门子专有财产。

索引，BACnet 对象编辑器 > 属性 > 配置

Process value 1和Process value 2 ✳

 

 

"Signal value 1“（X1），”Signal value 2“（X2），”Process value 1“（Y1）和”Process value 2" (Y2) 用于计算线性函数 (f)。需要线性函数来根据测量信号值计算当前值。

单位：取决于过程值。

范围：

如果从测量信号值计算当前值所需的函数完全由所选信号类型定义，则为 -1。示例：Ni1000

如果从测量信号值计算当前值所需的函数未完全由所选信号类型定义，则任何值 ≠-1。

Pulse integration time ✳

 

 

"Pulse integration time" 定义用于累积脉冲并计算相应脉冲频率的时间（以秒为单位）。
