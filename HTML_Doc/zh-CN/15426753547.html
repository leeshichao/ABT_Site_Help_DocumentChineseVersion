[R_DATI] 读取日期和时间

功能块 R_DATI 读取数据类型 DateAndTime 的数据点的当前值和附加属性。

R_DATI 读取数据类型 DateAndTime 的数据点的当前值和附加属性。

Functioning

Compatible data points:

  • Date/time calculated value [DaTiCalcVal]
  • Date/time configuration value [DaTiCnfVal]
  • Third-party objects with the required properties

Required properties:

  • Present value
  • Status flag

Optional properties:

  • Reliability
  • Update count

BaObjRef

BA-Object reference

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

 

输出

描述

数据类型

默认值
取值范围

PrVal

Present value

引用的 BACnet 对象的属性“当前值”的值。

[PrVal] 在发生故障时提供最后的有效值。

Note
The default initial value for [PrVal] can be changed to another value in the programming editor as needed.

DateAndTime

01.01.1990
00:00:00:000

PrValSta

Present value state

指示属性“当前值”是否具有未指定的值。

发生故障时，[PrValSta] 指示最后的有效值。

布尔值

0

0 - 属性的值未指定。
1 - 指定属性的值。

Dstb

Disturbed

[Dstb]表示引用的BACnet对象是否有错误。
[Dstb] = 1 如果：
BACnet 对象 = 访问期间出错
OR
“状态标志”=故障
OR
‘更新计数’ = 0

否则 [Dstb] = 0

布尔值

0

Rlb

Reliability
指示属性“可靠性”的值（如果该属性可用）。

整数

0：未检测到故障

UpdInd

Update indication

布尔值

0

指示属性“当前值”是否已更新。

更新后，[UpdInd] 从 0 变为 1，并在下一个周期（立即）返回到 0。如果没有连接到 [UpdInd] 的附加功能块（例如计数器功能块），则无法检测到转换。仅当 BACnet 对象没有故障时，[UpdInd] 才会设置为 1。

[UpdInd] 使用属性更新计数（如果可用）。这允许在新值等于先前值时检测值是否已更新。在没有更新计数的对象中，如果发生更改，[UpdInd] 将更改为属性当前值。

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes
