[PWM] 脉宽调制

功能块 PWM 将模拟值转换为基于时间的交替离散值。

PWM 将模拟值转换为基于时间的交替离散值。

Functioning

PWM 将模拟值转换为基于时间的交替离散值。输出 [Out] 保持 True 或 False 值的持续时间取决于模块的时间配置和输入 [In] 处的当前值。输出 [Out] 处 True 值的持续时间与输入 [In] 处的值成正比。

时间 [TiOnMin] 定义输出开启后所需的最短开启时间。时间 [TiOffMin] 定义输出关闭后所需的最短关闭时间。 [TiPrd] 的值必须大于 0，块才能开始运行。如果 [TiOffMin] 和 [TiOnMin] 之和大于 [TiPrd]，则最小导通时间调整如下：[TiOnMin] = [TiPrd] – [TiOffMin]。如果 [TiOffMin] 大于 [TiPrd]，则忽略 [TiOffMin] 和 [TiOnMin] 处的配置值。

[TiOffMin] 和 [TiOnMin] 处配置的值定义输入 [In] 的最小和最大有效值。输入 [In] 处的值低于最小有效值将被解释为 0%。输入 [In] 处的值高于最大有效值时被解释为 100%。
