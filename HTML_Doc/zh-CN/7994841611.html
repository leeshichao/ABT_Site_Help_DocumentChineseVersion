MO 具有升压功能

以下部分显示了具有子系统特定扩展“Boost 函数”的多状态输出 (MO) 的属性。 Desigo 5.x 不支持具有子系统特定扩展“Boost 功能”的多状态输出。

Channel configuration properties

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

测绘种类

“映射类型”定义过程值如何映射到输出。

1 到 n 映射：映射表为每个多状态过程值定义一个输出。

上下映射：映射表为每个多状态过程值定义一个或多个输出。可以有多个输出，但只能采用固定组合。

二进制映射：映射表为每个多状态过程值定义一个或多个输出。可以有多个输出。

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

映射（表）

映射参数：

  • Active channel number: Number of active channels
  • MO value: Multistate process value mapped to the active channel

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。

Subsystem-specific extension properties

列出的属性显示在BACnet objects editor > Inspector window > Properties > Configuration在编辑器表中选择数据点时选项卡。

✳ 表示西门子专有财产。

Boost time ✳

 

 

'Boost time' 设置以 1/10 [s] 为单位的时间，在此期间电机在启动时在最高阶段运行，然后切换回所需阶段。

一些带级的小型风扇上的电机扭矩太低，无法在最低级运行风扇。因此，多级风扇可以在最高级启动，然后再切换回所需级。
