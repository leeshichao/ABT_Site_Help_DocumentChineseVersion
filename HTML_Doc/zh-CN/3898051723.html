UP 220/31

本节介绍特定应用的按钮接口 UP 220/31。

有关属性的说明，请参阅硬件目录中的“KNX PL-链接设备”一章。

List of UP 220/31 devices

此列表包含库中的 UP 220/31 设备。对于 UP 220/31 按钮分配是适应性的。

设备

描述

BlsBtnDev_UP220/31_2xBls

  • 2x blind moving up/down for button pairs

LgtBtnDev_UP220/31_1xStaircase

  • 1x light trigger for single buttons with LED, e.g. staircase lighting

LgtBtnDev_UP220/31_2xDim

  • 2x light dimming for button pairs

LgtBtnDev_UP220/31_2xStaircase

  • 2x light trigger for single buttons with LED, e.g. staircase lighting

LgtBtnDev_UP220/31_4xTog

  • 4x light switching for single buttons

PshBtnDev_UP220/31_1xDim-1xBls

  • 1x light dimming for button pairs
  • 1x blind moving up/down for button pairs

PshBtnDev_UP220/31_2xTog-1xBls

  • 2x light switching for single buttons
  • 1x blind moving up/down for button pairs
