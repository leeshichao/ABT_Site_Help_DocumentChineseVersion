用户指定

用户名称定义使用新用户名称来组织分配的 BACnet 对象。 BACnet 名称将替换为新的用户名称。使用 BACnet 浏览器，您只能将用户指定视为 BACnet 对象名称。

使用User designation创建特定于项目的用户指定的任务。未分配数据点的用户指定树显示在Italic。 ABT Pro：复制自动化站或房间时，先前创建的用户名称会丢失。
Creating project-specific user designations

你必须定义User designation settings在您可以使用之前User designation任务。前往Settings > Naming defaults > User designation settings并定义User designation settings.
User designation settings tab

更改为User designation settings也适用于您已经创建的用户指定。
