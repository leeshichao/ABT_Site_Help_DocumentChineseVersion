基本着色，用于集成 (ShdBsc11)

Overview

应用功能》Shading 11, basic, for integration, for shading and daylight use with venetian blinds or awnings" (ShdBsc11) 用于由无法识别 BACnet 百叶窗输出对象（Apogee 或第 3 方系统）的管理系统监视和操作百叶窗。

Function

AF 提供包含基本信息的界面。


Operating
AF 支持通过多状态过程值 (BlsCmdBsc) 写入百叶窗输出 (BlsCmd)。

当命令 BlsCmdBsc 时，多状态值被转换为高度和角度。然后，高度和角度由百叶窗输出对象 BlsCmd 控制。

BlsCmdBsc 支持标准操作用例：

  • ManMod3 (Prio 13) = allow parallel operation in the room (for example with push buttons).
  • ManMod2 (Prio 8) = override all operations except emergency and protection.
  • Release ManMod3 (Prio 13) = set the blinds to automatic mode (Prio 16).
  • Release ManMod2 (Prio 8) = cancel a previous operation in ManMod2.

将 BlsCmdBsc 设置为 9:Undefined 不会对百叶窗执行任何操作。对于无法两次命令相同值的客户端来说，这是一种解决方法。用户首先命令 9：未定义（不移动百叶窗），然后是请求的值。


Monitoring
为了进行监控，AF 显示百叶窗高度 (BlsHgtBsc)、板条角度 (SlatAglBsc) 和实际优先级 (BlsPrioBsc)。

Configuration

没有任何。
