R_AX：读取多个模拟量

R_AX 根据可选择的评估函数读取并评估多个（最多 16 个）模拟数据点的当前值，并计算可用于更新结果 BACnet 对象的结果值。

Compatible data points:

  • Analog input [AI]
  • Analog output [AO]
  • Analog calculated value [ACalcVal]
  • Analog configuration value [ACnfVal]
  • Analog process value [APrcVal]
  • Third party objects which contain the required properties.

参考data point objects有关 BACnet 数据点的详细说明。

Required properties:

  • Present value
  • State flag

Optional properties:

  • Reliability
  • Update count

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

EvlFnct

Evaluation function

整数（默认值：2）

[EvlFnct] 确定对所有有效当前值执行的操作类型。

1：总和

计算总和。

2：平均
（默认）

计算平均值。

3：最小值

选择最小值。

4：最大

选择最大的值。

5：最后更新

选择最后更新的值。如果在同一周期内更新多个值，则选择索引号最低的值。

TshVal

Threshold value

实数（默认值：0.1）

用于控制对 Result 对象的 XFB 写入尝试的参数化值。

仅当当前 [PrVal] 与上次写入的 Result 对象之间的差异大于 [TshVal] 时，才允许尝试写入 Result 对象。 [TshVal] 对 [PrVal] 引脚的计算值没有影响。

Note
[TshVal]must not设置为 0.0。

Pin description (outputs)

PrVal

Present value

实数（默认值：0.0）

对所有有效聚合成员对象执行评估函数所得的值。该值用于更新结果对象的当前值。

如果结果对象被手动覆盖为新值，[PrVal] 将显示新值。如果 [Valid] = False，[PrVal] 将提供最后一个有效值。

如果评估值超出实际范围，[PrVal] 将提供 MAXREAL (3.402822e38)。如果计算值出现实际范围的负溢出，[PrVal] 将提供 MINREAL (-3.402822e38)。无论哪种情况，[Valid] 都将为 True。

Note
如有必要，可以在 CFC 中将 [PrVal] 的默认初始值更改为不同的值。

有效的

Valid

布尔值（默认值：False）

输出引脚[PrVal]是否可靠的指示。

1（正确）

如果至少一个聚合成员对象有效，则 [PrVal] 是可靠的。

0（假）

如果聚合成员对象均无效，则 [PrVal] 不可靠。

UpdInd

Update indication

布尔值（默认值：False）

指示聚合成员对象之一的当前值属性是否已新更新。

发生更新时，[UpdInd] 从 0 切换到 1 (True)，并在下一个周期（立即）返回到 0 (False)。如果没有连接到 [UpdInd] 的附加功能块（例如计数器功能块），则无法检测切换。仅当 [Valid] 为 True 时，[UpdInd] 才会设置为 True。

[UpdInd] 使用更新计数属性（如果存在）。这使得在新值与先前值相同的情况下可以将值识别为已更新。对于没有更新计数的对象，[UpdInd] 会切换到当前值的更改。

Note
停止使用结果对象不会影响 [UpdInd] 操作。

NumVals

Number of valid values

整数（默认值：0）

集合视图节点对象中有效的当前值的数量。

NumMbrs

Number of aggregated members

整数（默认值：0）

集合视图节点对象中成员对象的总数。

ErrCode

Error code indication

整数（默认值：20）

上次执行 XFB 读操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.

ErrWrit

Error while writing

整数（默认值：20）

上次对结果对象执行 XFB 写入操作的状态。

= 0

没有错误。

> 0

错误，请参阅XFB error codes.

Standard use:R_AX 读取并评估多个聚合成员对象并计算平均现值。控制程序使用信号 [PrVal]、[Valid] 和 [ErrCode] 进行进一步处理。

 

Extended use:R_AX 读取并评估多个聚合成员对象并计算平均现值。 [ErrCode] 可以针对特定错误代码强制 Valid 为 True。
