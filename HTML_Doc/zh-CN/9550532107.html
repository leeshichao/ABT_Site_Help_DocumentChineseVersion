设置 MS/TP 波特率

使用此过程可以设置 MS/TP 设备的 MS/TP 波特率。

MS/TP 干线的所有在线设备和所有工程设备（可自由编程的设备除外）的波特率均一步更新。此工作流程支持的设备为 DXR1、DXR2 和 PXC4。

仅当将 PXC5 和 PXC7 用作路由器时才支持它们。不支持第 3 方设备。

Set the MS/TP baud rate

  1. Disconnect all unsupported devices from the network. Disconnect by unplugging network communications.
  2. Discover all MS/TP devices to ensure that all of them are communicating.
  1. Go to Startup.
  2. Open the Configure and download task.
  3. Select a configured MS/TP device supporting proxy services (for example, DXR2 or PXC4).
  4. Disconnect all unsupported devices from the network.
  5. Right-click and select Set baud rate for all devices on network.
  6. The Set baud rate for all devices on network dialog box opens.
  7. From the Baud rate drop-down list, select the requested baud rate 9600, 19200, 38400, 76800, 115200 and click OK (see MS/TP network limits).
  8. The project data for all device instances is updated automatically, except for the freely programmable devices and the MS/TP port of the router. The baud rate of the discovered devices is adjusted.
  9. When ABT Site is connected by Ethernet via a router, the connection to the devices will stop and the baud rate of the router port must be adjusted before the devices are visible again
  10. Click OK.
  11. Configure the baud rate individually for all unsupported devices, routers and freely programmable devices.
  12. Reconnect all unsupported devices to the network.
  1. All baud rates are set. The project data for all device instances is updated automatically.

对于可自由编程的设备，每个设备实例的项目数据必须从ABT Pro通过选择Advanced成分。
Advanced

对于可自由编程的设备，必须在 ABT Pro 中更新每个设备的波特率BACnet MS/TP设置。双击工程设备窗口中的设备以打开 ABT Pro。

对于 Desigo 路由器，必须在以下位置更新路由器端口的波特率：Engineered devices > Properties > MS/TP。执行满载以更新路由器中的波特率（断开连接）Ethernet MS/TP并连接Ethernet IP).
