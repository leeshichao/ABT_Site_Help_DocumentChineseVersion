CMD_LGT：命令照明

CMD_LGT 用于命令单个模拟或二进制照明输出对象。 CMD_LGT 可以以特定优先级命令控制命令属性（控制命令命令）或当前值属性（目标状态命令）。 CMD_LGT 还用于根据需要释放优先级。

CMD_LGT reads back the arbitrated Present value and Present command properties, as well as Present priority, State flag and Reliability. CMD_LGT may optionally query a specified priority of the Priority array property to see if it is in use. CMD_LGT also reads additional required properties which provide information about status, progress and lifecycle of the light actuator.

Compatible data points:

  • Analog lighting output [LgtAOut]
  • Binary lighting output [LtgBOut]

参考data point objects有关 BACnet 数据点的详细说明。

Required properties:

  • Present value
  • Progress value
  • Control command
  • Present command
  • Present priority
  • State flag
  • In process
  • Lifecycle state
  • Burn-in time
  • Life time
  • Elapsed active time

Operate with priorities

该功能块使用 2 种方法来控制是否按优先级运行：

1. 独占控制（计划优先级 1...5、9...12、14...16）

  • Only one command source is permitted for a data point priority.
    • A function block on a project can command this priority.
    • An input set of a function block can command this priority.
  • The function block commands the priority anew or releases it if a priority is used from a function block and another commanding source changes this priority.
    • For target state command if priority is released or value changed.
    • For control command if priority is released.

2. 最后胜利控制（计划优先级7、8、13）

  • Multiple, command sources can use the same priority.
    • The last commanded value (release) remains on the priority until a new command is performed by one of the commanding sources.

 

专属控制
优先级：1...5、9...12 和 14...16

最后获胜控制权
优先级：7、8 和 13

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

TshVal

Threshold value

实数（默认值：0.1）

用于控制 XFB 写入尝试的参数化值。仅当值差等于或大于 [TshVal] 时才允许尝试。

例外：更改等于限制值，例如 0.0 或 100.0（[TshVal] 被忽略）。

Note
[TshVal]must not设置为 0.0。

EnIn1...4

Enable input 1

布尔值（默认值：False）

[EnIn1] 控制是否以[PrioIn1] 保持的优先级命令[ValIn1] 或[OpIn1]，或者是否释放优先级。

[EnIn1] 属于四个输入集之一，每个输入集包含 [EnInX]、[ValInX]、[OpInX]、[LvlInX]、[StepInX]、[PrioInX] 和 [RptcInX]。这些输入集根据需要以不同的优先级控制单个照明输出对象。

[EnIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

[EnIn2]...[EnIn4] 功能与 [EnIn1] 相同。

1（正确）

命令[PrioIn1] 保持的优先级。

0（假）
默认

如果 [PrioIn1] 所持有的优先级当前未被设置为 True 的不同 [EnInX] 激活，则该优先级将被释放。

ValIn1...4

Value input 1

实数（默认值：0.0）

[ValIn1] 用于命令 [PrioIn1] 处的当前值属性（目标状态命令）。

[ValIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

如果满足以下条件，[ValIn1] 将按照 [PrioIn1] 所保留的优先级命令当前值：

  • [EnIn1] is True and [ValIn1] changes by a value equal or greater than [TshVal].
  • [EnIn1] is True and [ValIn1] changes by a limit value such as 0.0 or 100.0 ([TshVal] is ignored).

[ValIn2]...[ValIn4] 功能与 [ValIn1] 相同。

Note
如果使用 [ValIn1]，则不得使用 [OpIn1]，并且必须保留默认值 32767。

OpIn1...4

Operation input 1

整数（默认值：32767）

[OpIn1] 用于命令 [PrioIn1] 处的控制命令属性（子元素 [LvlIn1] 和 [StepIn1]）。

[OpIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。如果 [OpIn1] 等于最大整数值，则输入集作为目标状态命令运行。对于所有其他值，[OpIn1] 作为控制命令运行。

如果出现以下情况，[OpIn1] 将按照 [PrioIn1] 所持有的优先级发出命令：

  • [OpIn1] changes and [EnIn1] is True.

[OpIn2]...[OpIn4] 功能与 [OpIn1] 相同。

Note
如果使用 [OpIn1]，则不得使用 [ValIn1]。

LvlIn1...4

Level input 1

实数（默认值：0.0）

[LvlIn1] 是命令字段 [OpIn1] 的一部分，定义输入集的目标级别。它与 [OpIn1] 命令一起写入照明输出对象，并与一些 Op 命令（例如，goto-level、fade-to、ramp-to）结合使用。

[LvlIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

[LvlIn2]...[LvlIn4] 功能与 [LvlIn1] 相同。

StepIn1...4

Step input 1

实数（默认值：0.0）

[StepIn1] 是命令字段 [OpIn1] 的一部分，定义输入集的步长增量。它与 [OpIn1] 命令一起写入照明输出对象，并与一些 Op 命令（例如，升压和降压）结合使用。

[StepIn1] 可以参数化（由开发人员设置），也可以在 CFC 图表中链接并由控制程序在运行时计算。

[StepIn2]...[StepIn4] 功能与 [StepIn1] 相同。

PrioIn1...4

Priority input 1

整数（默认值：17）

[PrioIn1] 保存[ValIn1] 或[OpIn1] 附带的优先级。

[PrioIn1] 已参数化，运行期间无法更改。值 17 表示未使用输入集。

[PrioIn2]...[PrioIn4] 功能与 [PrioIn1] 相同。

Note
同一功能块上的输入集不得共享共同的独占控制优先级。

优先范围

1...16

请参阅下面对优先级 6 和优先级 8 的限制。

专属控制

优先级 1...5、9...12 和 14...16

控制程序启动时，功能块使用独占控制来初始化范围 1...5、9...12 和 14...16 中的任何分配的优先级。

在运行时，功能块继续保持独占控制。如果检测到外部覆盖，功能块将以 [PrioIn1] 保持的优先级重新命令或重新释放。

同一功能块上的两个或多个输入集不得共享共同的独占控制优先级，否则将导致冲突。

最后获胜

优先级 7、8 和 13

  • No initialization of priorities on start-up.
  • At runtime, last valid command (or release) controls the priority.
  • If two or more input sets have the same priority and are commanded at the same time, only the input set in first numerical order is performed (In1...In4).
    Exception:
    If two or more input sets have the same priority, and inputs providing value (either target state or control-command) are changed at the same time, the input set in last numerical order will win (In1...In4).
  • If two or more input sets have the same priority and conditions for commanding and releasing are given at the same time, the command operation wins.

优先级 6

根据 BACnet，命令优先级 6 保留用于最小 on/off 功能。优先级为 6 的命令会被 BACnet 对象拒绝。

为了提供最小的 on/off 功能，控制程序应包含其他优先级的功能和命令。

优先级 8

根据 BACnet，命令优先级 8 供手动操作员使用，通常不会在功能块上分配。最后获胜功能可以允许控制程序改变或释放操作员命令。

RptcIn1...4

Repeat command input 1

布尔值（默认值：False）

[RptcIn1] 用于强制重复命令或释放优先级。

  • If [RptcIn1] = 1 (True) and [EnIn1] = 1 (True), the function block forces a command of [ValIn1] or respectively [OpIn1], [LvlIn1] and [StepIn1] with every program cycle at the priority in [PrioIn1].
  • If [RptcIn1] = 1 (True) and [EnIn1] = 0 (False), the function block forces a release with every program cycle at the priority in [PrioIn1].

[RptcIn2]...[RptcIn4] 功能与 [RptcIn1] 相同。

Note
不得通过连接到始终为 True 的块输出来强制将 [RptcIn1] 永久设置为 True。这样做会导致大量通信流量。

[RptcIn1] 是可链接的，通常由控制程序计算和设置。

PrioX

Priority X

整数（默认值：17）

参数化输入，可用于查询特定优先级是否包含有效的命令值或已释放 (NULL)。

[PrioX] 在运行时无法更改。

如果[PrioX]设置为值1...16，则将查询相应的优先级。结果由输出引脚 [PrioXAct] 提供。

OphMod

Operating hours mode

整数（默认值：1）

可用于将计算出的光源生命周期状态写入生命周期状态属性的输入。生命周期状态的值由输出引脚 [OphSta] 读回并提供。

[OphMod] 是可链接的，通常由控制程序计算和设置。

Pin description (outputs)

PrVal

Present value

实数（默认值：0.0）

基于优先级数组的参考照明输出对象的仲裁当前值。

如果仲裁值是目标状态命令，则[PrVal]表示命令的目标状态值。如果仲裁值是控制命令，则[PrVal]代表执行器的进度值。

有效的

Valid

布尔值（默认值：False）

输出引脚[PrVal]是否可靠的指示。

1（正确）

[PrVal] 是可靠的。

  • XFB can access the lighting output object.

AND

  • Fault flag in State flag property = 0 (no fault)
  • (Reliability = 0 (no error) or Reliability was not detected).

0（假）

[PrVal] 不可靠。

  • XFB cannot access the lighting output object.

OR

  • Fault flag in State flag property = 1 (fault)
  • (Reliability ≠ 0).

PrPrio

Present priority

整数（默认值：17）

引用的 BACnet 对象的活动优先级。

[PrPrio] 设置为：

  • Active priority if the present priority property is accessible.
  • 17 if all priorities are released, or if the present priority property is not accessible.

PrCmd

Present command

布尔值（默认值：False）

指示当前值是来自目标状态命令还是控制命令命令。

1（正确）

控制命令。

0（假）

目标状态。

PrioXAct

Priority X active

布尔值（默认值：False）

[PrioXAct] 指示输入引脚 [PrioX] 查询的优先级是否包含有效命令值或已释放 (NULL)。

Note
如果未使用输入引脚 [PrioX]，[PrioXAct] 保持默认值。

1（正确）

命令查询的优先级。

0（假）

查询的优先级被释放(NULL)，或者输入引脚[PrioX]未被使用。

PrgsVal

Progress value

实数（默认值：0.0）

由进度值属性指示的照明执行器的实际值。

InPrgs

In progress

布尔值（默认值：False）

基于“处理中”属性，指示是否正在处理照明命令以及灯光是否正在变化。

1（正确）

正在处理照明命令。

0（假）

无照明命令。

OpSta

Operating state

布尔值（默认值：False）

[OpSta] indicates whether the lighting actuator is on or off.

1（正确）

对于模拟灯光输出对象，[PrgsVal]大于0.0。

对于二进制照明输出对象，当前值 = 1（真）。

0（假）

 

OphSta

Operating hours state

整数（默认值：0）

[OphSta]表示生命周期状态属性，表示光源的生命周期状态。

OphBrnin

Burn-in operating hours

双字（默认值：0）

基于输出对象的老化时间属性的光源所需的老化时间。

OphExpd

Expected operating hours

双字（默认值：0）

[OphExpd] 表示输出对象的 Life time 属性，表示光源的预期寿命。

奥夫

Operating hours

双字（默认值：0）

[Oph] 表示输出对象的已用活动时间属性，并指示光源的累计工作小时数。它仅以 15 分钟的间隔更新，或者当输出对象的另一个属性更改时更新。
