SAVE_4V：保存4个值（2个多态，2个实数）

块 SAVE_4V (FB433) 保存两个多状态值和两个取决于控制信号的实际值。

输入

Pin

E

Description

Save

pa

节省。

布尔值

切换以保持现有的输出值。

0（否）

默认

该块忽略输入值。该块将最后存储的值发送到输出。

1（是）

该块将输入值发送到输出。该块保存（存储）该值。

InMs1

pa

多态输入 1。

多状态（默认值 = 1）。

InMs2

pa

多态输入 2。

多状态（默认值 = 1）。

InR1

pa

实际输入1。

实数（默认值= 0.0）

InR2

pa

实际输入2。

实数（默认值= 0.0）

输出

Pin

E

Description

OutMs1

a

多态输出 1。

多状态（默认值 = 1）。

OutMs2

a

多态输出 2。

多状态（默认值 = 1）。

OutR1

a

实际输出1。

实数（默认值= 0.0）

OutR2

a

实际输出2。

实数（默认值= 0.0）

应用

该块用于连续计算，例如保存操作模式、测量值或设定点。

过程响应

从第二个处理周期开始，该块将使用输入处的值进行处理，因为只有此时输入处的值才被视为有效。默认值在第一个处理周期内发出。

故障排除

标准（参见General rules and information).
