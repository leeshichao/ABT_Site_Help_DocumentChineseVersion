连接和断开连接

在连接设置中，您可以指定通过房间设备或网络连接到设备的类型。您可以指定网络接口卡，并为 MS/TP 连接建立 BACnet 配置。

要打开连接设置，请单击旁边的箭头常用工具栏中的符号。

环境

描述

断开连接时通知

选择后，如果 ABT 站点失去连接，则会显示一条消息。

自动重新连接

在启动中包含发现

(3) USB tab

Connecting via USB port

命令

描述

目标选择

选择设备类型：IPfor DXR2.E../PXC..E.. devices,MS/TPfor DXR2.M…/TXB3.M devices orPTP对于所有 DXR1.. 设备。

IfMS/TP选择后，网络适配器将配置为自动获取 IP 地址。

IfPTP选择后，还要在下拉列表中选择可用的 COM 端口。

网络接口

允许您选择所需的网络接口。

描述

提供Name和Type连接的。只读。

IP address

允许您选择所需的网络接口 IP 地址并通过其 USB 端口进行连接。

UDP 端口号（十六进制）

显示 MS/TP 设备。允许您选择所需的 UDP 端口。以十六进制格式指定 UDP 端口：BAC0 到 BAD4。默认为十六进制BAC0 (47808).

注册为外部设备

显示 MS/TP 设备。复选框默认未选中。将在 NIC 上运行的 ABT BACnet 堆栈作为外部设备注册到 BACnet/IP 广播管理设备 (BBMD)。

如果设备与您的计算机位于不同的 IP 子网中，则必须选择Register as foreign device复选框并输入设备子网上 BBMD 的 IP 地址和 UDP 端口号。这允许您向设备发送和接收 BACnet 广播消息，例如 Who-Is。

BBMD IP Address

注册为外部设备时显示 MS/TP 设备。指定 BBMD 的 IP 地址。

BBMD UDP port number (hex)

注册为外部设备时显示 MS/TP 设备。以十六进制格式指定 BBMD 设备的 UDP 端口：BAC0 到 BAD4。默认为BAC0 (47808).

远程连接（例如通过 VPN）？ （最大 ADPU 长度将设置为 1024。）

复选框默认未选中。选择后，最大 ADPU 长度将设置为 1024。当您通过 VPN、URA 或西门子 cRSP（通用远程服务平台）连接时，请选中此框。
