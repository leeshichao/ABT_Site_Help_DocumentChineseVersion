RATE_LIM：变化率限制

RATE_LIM (FB429) 块限制输入信号的变化率以及最小值和最大值。

功能性

Rate limiter

该函数计算并限制变化率如下：

Signal increase

最大限度。信号增加变化率 = [MaxIn] - [MinIn] / [TiUp]

 

如果输入信号 [In] 超过信号增加的最大变化率，则输出信号 [Out] 的变化率受到限制。因此，输出值[Out]仅以线性方式增加。

 

Signal decrease

最大限度。信号下降变化率 = [MaxIn] - [MinIn] / [TiDn]

 

如果输入信号 [In] 降至信号下降时的最大变化率以下，则输出信号 [Out] 的变化率受到限制。因此，输出值[Out]仅以线性方式减小。

 

Minimum and maximum values

[MinIn] 和 [MaxIn] 限制输出值 [Out]。

Minimum value

如果输入值 [In] 小于 [MinIn]，则输出值设置为 [Out] = [MinIn]。

Maximum value

如果输入值 [In] 大于 [MaxIn]，则输出值设置为 [Out] = [MaxIn]。

Enabling and disabling the function

当[EnFnct] = 1（是）时，该功能启用。

当[EnFnct] = 0（否）时，该功能被禁用。输入 [In] 可在输出 [Out] 处使用。
