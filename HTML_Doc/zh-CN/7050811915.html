下载设备配置

您可以通过两种方式配置和下载设备。您可以将工程设备与已发现的设备映射，也可以将设备直接映射到已配置序列号的工程设备。

每个加载过程都是一个完整的加载过程。在线系统中的所有配置和调试数据都将被覆盖。考虑一下，所有计时器和优先级数组设置都会重置，并且通过按钮（Prio 7 和 Prio 13）进行的所有手动操作都会丢失。为防止数据丢失，请在模板中进行离线更改之前将在线系统数据读回到 ABT 站点。为了读回数据，请始终选择该选项merge online data.

请注意，合并函数是基于对象的，而不是基于参数的。为了确保离线更改不会被覆盖，请务必在对设备进行离线更改之前进行完整上传。

仅适用于美国，NGAA 支持将签名许可证从 ABT 站点下载到设备。

将设备在线导入到 Desigo CC 之前，将完整配置下载到设备。通过增量加载发出的更改不会自动导入。

当选择多台设备进行下载和/or上传时，一台或多台设备可能会因网络状况（例如网络流量过大）而导致加载失败。在这些情况下，请选择加载失败的设备并重复 download/upload 命令。

Configure and load discovered devices
  1. A USB or Ethernet connection is established.
    If connected through the room unit, the connection will be dropped. If a connection is needed, wait for the device to restart, and re-establish the connection.
    Connecting to devices
  1. Go to Startup.
    Configure and download
  2. Open the Configure and download task.
  3. In the Discovered devices tab, click Discover and select a Discovery filter from the list box.
  4. Click OK.
  5. The discovered devices display in the table.
  6. Select the engineered device and the discovered device.
  7. Click Assign.
  8. Click Load > Application configuration.
  1. The application configuration is downloaded and the device is restarted.
Configure and load devices by serial number

序列号可以预先设计、手动输入或使用条形码扫描仪输入。可以将其输入到Serial number的领域Engineered devices 选项卡。

Adding the serial number

  1. A USB or Ethernet connection is established.
    If connected through the room unit, the connection will be dropped. If a connection is needed, wait for the device to restart, and re-establish the connection.
    Connecting to devices
  1. In the Engineered devices tab, select one or more pre-engineered devices with a serial number.
    INFO: Multi-selection of automation stations is not supported for the device type PXC3. If you select several automation stations, ABT Site will try to open the same ABT Pro project several times in the background, which is impossible.
  2. In the Engineered devices tab toolbar, click Load > Device network configuration.
  3. The devices are configured and restarted.
  4. In the Engineered devices tab toolbar, click Load > Application configuration.
  1. All devices with a matching serial number are loaded and restarted. There is no need to discover and match a discovered device with a pre-engineered device.

Properties for device configuration

以下属性设置为AssignorLoad > Device network configuration only:

这些属性不包括在内Full load和Play 仅功能。

BACnet properties

  • Device object name
  • Device instance number
  • APDU retries
  • APDU segment timeout
  • APDU timeout
  • Max APDU length

IP properties

  • Host name
  • UDP port
  • Web access
  • Use DHCP
  • IP Address
  • IP Subnet mask
  • IP Default gateway
  • IP Domain name
  • Local broadcast UDP port
  • Network number (for IP network routing)

MS/TP properties

  • Baud rate
  • Network number
  • MAC address
  • Max manager address
  • Max info frames
