创建趋势日志对象

对于硬件数据点、Modbus 或 KNX PL-Link 对象报警也可以直接在其相关编辑器中创建。或者，也可以使用编程编辑器来完成此任务。

  1. Go to Building > Building structure.
  2. Right-click the automation station and select Go to engineering.
  3. Open the BACnet objects task.
  4. Select the Properties view tab.
  5. Select the Trend tab.
  6. Select the object you want to trend.
  7. From the Enable trend drop-down list, select Yes.
  8. From the Logging type drop-down list, select the option:
    • Polled
    • Triggered
    • COV
  9. Define the properties according the selected logging type.
  1. A new trend log object is created.
