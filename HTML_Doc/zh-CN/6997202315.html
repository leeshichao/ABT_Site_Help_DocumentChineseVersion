Function

当结冰损坏遮阳产品或执行器（百叶窗、遮阳篷）时，需要 AF。
此外，必须启用 AF CenPcpPrt11 才能识别降水。

防冻保护是active，如果温度降至可调整限值以下，并且同时报告降水量（来自 CenPcpPrt11）。时间延迟用于使该功能适应遮阳产品。

防冻保护是reset, if

  • there is no precipitation during a set period
  • or the outside temperature is above the limit value during a set period
  • or manually from an operator unit (using RstFrPrt)


这reaction to frost protection可以配置。默认值：打开。

这reaction to a sensor fault可配置（降水传感器和防冻监控器）。默认值：无反应。

Engineering and commissioning

制造商根据产品、位置和安装类型确定百叶窗是否需要防冻保护。

延迟时间必须设置得足够长，以允许结冰的百叶窗解冻。

防冻保护阻止自动和手动百叶窗操作。仅在超过配置的关闭点后才会发生自动重置。这可能需要数周时间（取决于所在地区）。因此，启用的防冻保护功能可以通过外部源（BACnet 命令，例如技术服务）重置。

默认值适用于温和的气候。它们保证高度的保护并需要能够手动重置。

在霜冻风险高的位置，配置对传感器故障的反应是有意义的（霜冻保护监视器：CmdSenFlt。降水探测器：必须在 CenPcpPrt11 中配置）。
