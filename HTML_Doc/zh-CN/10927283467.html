更改自动化站配置

自动化站继承其父应用程序模板的配置Building > Application & device overview.
Application & device overview

您可以通过将自动化站移动到另一个应用程序模板中来轻松更改自动化站的配置。移动的自动化站将接管目标应用程序模板的配置。

源应用程序模板和目标应用程序模板必须具有相同的类型和版本。

Move an automation station from one application template to another

  1. The source and target application template have to be of the same type and version.
  1. Open Building > Application & device overview.
  2. Select an automation station.
  3. Drag and drop the automation station to the target application template.

将自动化站从一个应用程序模板移动到另一个应用程序模板不会影响建筑结构。建筑结构中的自动化站没有移动。
