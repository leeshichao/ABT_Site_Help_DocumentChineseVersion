物业批量运营

允许高效编辑对象类型的相同属性。

  1. Mass properties can only be edited while offline.
  1. Go to Building > Building structure.
  2. Right-click the automation station and select Go to engineering.
  3. Open the BACnet objects task.
  4. Select the Properties view tab.
  5. Select the All tab.
  6. In the Type column of the table in the main working area, add a filter, for example, AI.
  7. All AI objects are listed in the table.
  8. Select the objects you want to modify.
  9. Properties that cannot be modified are hidden, for example, the Name property.
  10. Properties with the same value are displayed, these properties can be edited.
  11. Properties with different values are marked with ?. These properties can be edited.
  12. Select a property and modify the value.
  1. All selected objects are immediately updated with the new value.
