[R_TRIG] 识别上升沿和触发脉冲

功能块 R_TRIG 识别上升沿。

R_TRIG 识别出上升沿。

Functioning

对于输入 [In] 的上升沿，输出 [Out] 在程序周期内设置为 [Out] = 1。

Pins

输入

描述

数据类型

默认值
取值范围

In

Input

布尔值

0

0 - No
1 - Yes

 

输出

描述

数据类型

默认值
取值范围

Out

Output

布尔值

0

1 - On

Application

R_TRIG 用于各种控制任务，例如识别按钮的初始使用。

Process response

函数处理之前的初始化：

  • The old state of input value [In] is initialized with 1.

从第三个处理周期开始，R_TRIG 使用输入处的值进行处理，因为只有在识别出上升沿后才识别初始化类型。默认值在前两个处理周期内发出。

连续信号 [In] = 1 在处理时不会被识别为正斜率。输出 [Out] 保持 = 0。
