为 BACnet 对象设置过滤器

  1. Go to Building > Building structure.
  2. Right-click the device and select Go to engineering.
  3. Open the BACnet objects task.

组合框显示 BACnet 对象的以下预定义过滤器：

  • I/Os: Filters all the I/Os in the selected scope.
  • Network peripheral device points: Filters all the network field device points in the selected scope (excluding the network field devices).
  • BACnet references: Filters all the BACnet reference objects in the selected scope.
  1. In the Plants navigation view, select the plant or folder where you want to set the filter.
  2. Go to Predefined filters.
  4. Select the required filter from the following:
    • I/Os
    • Network peripheral device points
    • BACnet references
  5. To change the description of the data points, click on the data point under the Description column and make changes.

 

Online engineering filters

  1. Go to Engineering.
  2. Open the BACnet objects task and go online.
  3. Set filters in the following columns:
    • Value/Unit
    • Commissioning

对于表过滤器，请参阅Setting table filters in the Engineering tab.
