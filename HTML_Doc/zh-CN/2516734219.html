Present value

 

 

'Present value' 表示虚拟变量的当前值。

财产ID：85

Tracking value

 

 

'Tracking value' 表示子系统测量的未校正值。它具有与“当前值”相同的数据类型。

  • It is not limited by 'Present minimum value' and 'Present maximum value'.
  • It is not corrected by the correction factor and offset.
  • It is updated, even if "Out of service" = 'True' applies.

财产ID：5107

State flag ✳

 

 

"State flag" 代表四个布尔标志（“停止服务”、“覆盖”、“故障”、“警报中”），指示对象的一般状态。

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Out of service

 

 

"Out of service" 包含每个工作日（周一至周日）的每日时间表。

  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" will no longer be updated by the respective control program, system program or peripheral device.
  • If "Out of service" is TRUE, the properties "Present value" and "Reliability" can be modified for simulating and testing purposes.
  • If "Out of service" will be changed from FALSE to TRUE, the properties "Present value" and "Reliability" keep their values. Nevertheless, they can be individually modified afterwards.
  • If "Out of service" will be changed from TRUE to FALSE, the properties "Present value" and "Reliability" keep their values. They will be modified by the next update of the producer.

财产ID：81

Field device type

 

 

"Field device type“是连接到输入或输出的物理外围设备的文本描述。通常包含所连接设备的产品部件号。由工程师完成。数据采集不使用。

示例：QAX3.P84（房间单位）- 入口

I/O address ✳

 

 

"I/O address“识别并记录数据源，并方便以标准化方式配置、修改和查询作业。

内容“I/O address" 是特定于技术的，包括：

  • Unique selector to identify and document the respective data acquisition. For example, TX-I/O or KNX PL-Link.
  • Unique address to identify the peripheral data source. For example, TX-I/O 3.4.
  • Blank until assigned to a Module.

Commissioning state ✳

 

 

"Commissioning state" 是一个枚举值，表示 BACnet 对象的调试状态（未检查、检查失败、检查成功）。

通常在调试期间通过工程和调试功能（例如自动化构建工具或安装工具）进行设置。可以通过工程和调试，或运行和监控功能进行检查，并用于调试报告。

Commissioning information ✳

 

 

"Commissioning information" 表示有关 BACnet 对象调试状态的附加、人类可读的信息。例如，“电缆缺陷”。

通常在调试期间通过工程和调试功能（例如自动化构建工具或安装工具）进行设置。可以通过工程和调试，或运行和监控功能进行检查，并用于调试报告。

Update count ✳

 

 

"Update count” 代表“的次数Present value“属性已更新。

  • "Update count" will be incremented whenever a value is written to the property "Present value".
  • "Update count" will have a value equal to 1 as a default value after a download or object creation to indicate that the object has an initiated valid value.
  • When the value of "Update count" reaches its maximum possible value, the next value it takes will be one (wrapping to 1).
  • A control program can recognize that the same or a new value has been written to the "Present value" property by reading the current value of "Update count" and comparing it with the previously saved value of "Update count".

Resolution

 

 

'Resolution' 表示值所代表的准确性。它定义了属性“当前值”的工程单位的最小可识别变化，并可以在线修改。
“分辨率”通常用于操作和监控功能，以表示“当前值”：
“分辨率”只能是 > 1 的整数。
“分辨率”仅用于显示屏上的缩写描述，例如操作和监控站。它不用于缩短程序处理的实际值。

Correction factor ✳

 

 

"Correction factor“用于校正实际物理变量和测量值之间的潜在差异。乘法因子。

Subsystem ✳

 

 

"Subsystem" 唯一标识 BACnet 对象类型的相应 BACnet 对象类型扩展。

多个 BACnet 对象类型扩展可能可用于工程，因此建议选择。可以不选择或选择一个扩展，因此在运行时受到支持。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

财产ID：4930

Event state

 

 

"Event state“提供了一种方法来确定该对象是否具有与其关联的活动事件状态。”Event state”属性表示对象的事件状态。“中的变化Event state" 值为 FAULT 的属性被视为故障事件。如果对象不支持内部报告，则该属性的值为 NORMAL。

财产-ID：36

Description

 

 

"Description" 是一串可打印的字符，其内容不受限制。

Object name

 

 

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

Object identifier

 

 

"Object identifier" 是用于识别对象的数字代码。它必须在互联网范围内是唯一的。

Object type

 

 

"Object type“ 表示特定对象类型类中的成员资格。例如”Analog input“，”Binary output“，”Event enrollment“，”Trend log“， ETC。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。
