正常模式和异常模式

工厂始终以以下运行模式之一运行：

① 普通模式

② 通用异常模式

③ 局部异常模式

Schematic view
Sub-division in the Programming editor

用于确定工厂运行模式的图表条定义了输入块和其他功能块，使各种plant components.

输出块的开启顺序和关闭顺序可以通过以下方式定义locking.

① Normal mode

在正常模式下，各种input blocks确定当前的正常工厂运行模式 1...16。

生成的设备操作模式 1...16 被传输到功能块CMDSEQ_B.

功能块根据此信息以及开启和关闭顺序确定必须开启哪些设备组件。

功能块将相应的开启和关闭命令发送到控制器或output blocks植物成分。输出块通常工作在priority15 =“自动模式”。

一旦功能块 CMDSEQ_B 输入上请求的设备运行模式 1...16 发生变化，设备组件就会按照关闭顺序关闭，并且新需要的设备组件就会按照接通顺序打开。

② General exception mode

在一般异常模式下，当前异常模式是根据input blocks.

工厂外部或工厂内部源可以触发一般异常模式。

植物外源可能是：

  • Fire safety contact
  • Gas detection contact
  • Smoke extraction control

植物内部来源可能是：

  • Fault message for a plant component, e.g., a fan
  • Frost protection monitor

当启用异常模式时，通过功能块 CMDSEQ_B 的输入 [RpdOff] 立即结束正常模式。

开启信号或典型的关闭信号直接发送到output blocks为植物成分。输出块通常工作在priority5 =“保护”。

一旦异常模式不再适用，正常模式就会再次激活，并通过 CMDSEQ_B 切换当前操作模式所需的设备组件。

③ Local exception mode

如果异常模式在工厂的邻近区域具有优先权，则使用本地异常模式。

有两种类型的本地异常模式：

  • Local only
  • Acts locally with return to the general exception mode

Local only

示例：能量回收装置故障

故障通过本地异常模式关闭能量回收单元的输出块。工厂的其余部分继续以正常模式运行。局部异常模式不会返回到通用异常模式。

Acts locally with return to the general exception mode

示例：风扇维护开关

激活维护开关会关闭优先级 2 的风扇的输出模块（通过本地异常模式）。

优先级为 1 的命令可以覆盖锁定。例如，为了执行本地数据点测试，这是理想的。如果硬件侧没有锁定机制，则锁定必须处于优先级 1。
