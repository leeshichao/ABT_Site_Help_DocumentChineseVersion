SOL_CNV：太阳辐射转换

块 SOL_CNV (FB556) 将水平设备上的全局辐射值测量值计算为任何平面（例如垂直或倾斜的立面）上的全局辐射值。该计算取决于由块 SOL_POS 计算的太阳位置（太阳高度角和太阳方位角）以及平均水平角以及地面的反射特性。 SOL_CNV_SiUn (FB556)、SOL_CNV_UsUn (FB796)

Application

  • Converting the global radiation measurement to the horizontal plane into global radiation values on any oriented surfaces reduces the number of individual sensors.
  • Estimate of present diffuse light ratio (e.g. for anti-glare functions).

功能性

Calculates global radiation value to any oriented surface:

输入 [SolRdHor] 是水平面上太阳辐射的测量值。总辐射表用于更精确的测量。对于通常使用该块实现的遮阳应用，一个基于太阳能电池的传感器就足够了，例如西门子太阳影响传感器 QLS60（水平安装！）或类似传感器。自加热传感器/housing 是有利的，因为这也可以避免冬季测量值不正确（设备上有雪）。

需要通过块 SOL_POS 计算出的太阳位置（太阳高度角和方位角）来转换在水平面上测量的辐射值。输入通常与该块互连！

立面角度的定义（立面方向：方位角和倾斜度）对应于块 SOL_FCD 处的角度。

水平角度 [HorAgl] 决定立面如何遮挡周围建筑物、地形和树木。

  • A building on flat ground and not shaded by surrounding buildings or trees, [HorAgl] = 0°.
  • The typical building value is > 0°. For solar protection applications implemented using the block, it is generally sufficient to use a constant horizontal angle for a specific facade.

评论：

如果可用的话，也可以在此处考虑取决于方位角的水平角（例如，对于水平限制函数）（SOL_CNV）。当然，这需要修改功能块的输入接口。

Surface reflective properties:

反照率是漫反射表面反射特性的测量，即非自发光表面。它由反射的入射光的商确定，介于 0 和 1 之间。

各种表面的设置建议：

  • Fresh snow 0.80 - 0.90.
  • Old snow 0.45 - 0.90.
  • Clouds 0.60 - 0.90.
  • Desert 0.30.
  • Savannah 0.20 - 0.25.
  • Fields (uncultivated) 0.26.
  • Grass 0.18 - 0.23.
  • Forrest 0.05 - 0.18.

例子

Example: Vertical, southern-facing facade.

常数输入变量：

FcdAzmth = 180°，FcdIncl = 90°（朝南），HorAgl = 3°，反照率 = 90°。

输入变量随时间变化：

2006年1月1日至2006年1月7日苏黎世测量数据SolRdnH：计算出苏黎世2006年1月1日（当地时间）的SolEtHor和SolAzmth（地理经度8.57°和纬度47.38°）。

Diagrams:

[SolRdFcd] = 正面的太阳辐射。

[SolRdDir] = 直接太阳辐射立面。

[SolRdDfs] = 漫射太阳辐射立面。

[SolRdHor] = 水平面上的太阳辐射作为输入值。

上例中 SolRdHor（输入变量）、SolRdFcd、SolRdDir、SolRdDfs（输出变量）的时间线。

在第二个轴上输入变量 SolRdFcdref 作为补充。
