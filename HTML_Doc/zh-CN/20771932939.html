Configuring a room operator unit

Open the template view

  1. You have added a room operator unit to your project.
  1. Go to the Room programming editor.
    Duplicating and programming
  2. Open Device configuration > Device view.
  3. Select the room operator unit device.
  4. In Properties > Device information > Customized view selection, click Layout.
  1. The Template view opens.
