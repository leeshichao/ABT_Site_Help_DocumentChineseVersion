配置：QMX3.P88（PrphDev - 子系​​统特定扩展）

""Configure: QMX3.P88”是“外围设备”(PrphDev) 对象的子系统特定扩展。

✳ 表示西门子专有财产。

Backlight timeout ✳

 

 

"Backlight timeout” 定义操作后背光保​​持开启的时间。如果在定义的时间内没有任何活动，背光将关闭。

范围：00:03...120:00 毫米：秒

Backlight brightness ✳

 

 

"Backlight brightness“定义了主动使用期间背光的亮度。

范围：0...100 %

Timeout to default page ✳

 

 

"Timeout to default page" 定义按下按钮后页面显示的时间。如果在定义的时间内没有任何活动，屏幕将切换到默认页面。

单位：毫米：秒

范围：3 到 300

Timeout user operation ✳

 

 

"Timeout user operation" 定义按下按钮后页面显示的时间。如果在定义的时间内没有任何活动，屏幕将切换到默认页面。

单位：1/10 秒

范围：2 到 100，默认 30（3 秒）

Alarm display time ✳

 

 

"Alarm display time“定义了显示屏在警报图标和通风柜模式之间切换的交替周期。

如果该参数设置为 0，则显示屏不会在警报图标和通风柜模式之间交替显示。在这种情况下，用户必须按下 i-Button 才能查看警报。

单位：1/10 秒

范围：5 到 3600，默认 100（10 秒）

Setpoint display time ✳

 

 

"Setpoint display time" 定义设定点值显示的时间量。显示时间过后，将显示平均值。

单位：1/10 秒

范围：5 到 3600，默认 100（10 秒）

Air volume flow units (SI) ✳

 

 

"Air volume flow units (SI)" 定义显示气流值时使用的 SI 单位。如果为整个设备选择 US 单位 (ActiveUnitSet)，则该字段不活动。

m3/h

l/s

升每秒

Enable pushbutton, mode manual ✳

 

 

"Enable pushbutton, mode manual” 定义：

是的

启用 Key_1（手动按钮）以覆盖预定的占用更改。

No

Key_1（手动按钮）无功能。

Enable fume hood integrated light ✳

 

 

"Enable fume hood integrated light” 定义：

是的

使 Key_4 能够用作灯开关。 “灯泡”图标出现在 Key_4 旁边。

No

Key_4没有任何功能。 Key_4 旁边不显示“灯泡”图标。

Enable operation: Green leaf ✳

 

 

"Enable operation: Green leaf”定义“绿叶”LED 是否指示是否满足能效状态的条件以及用户是否可以将应用程序重置为能效参数值。

是的

“绿叶”LED 指示是否满足能效状态的条件，并且用户可以将应用程序重置为能效参数值。

No

“绿叶”LED 并不指示是否满足能效状态的条件，并且用户无法将应用程序重置为能效参数值。
