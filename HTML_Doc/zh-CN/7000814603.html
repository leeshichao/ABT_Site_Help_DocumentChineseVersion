BA object

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

姓名

“名称”显示数据点的名称。只读。

描述

“描述”是一个用于输入数据点的文本字段。

BA object type

“BA object type”显示数据点类型。只读。

BA object ID

"BA object ID" shows the ID of the data point.

Module/Channel

“Module/Channel”显示数据点在导轨上的位置。

语法：[module address].[channel number].

设备类型

“设备类型”定义信号类型。
