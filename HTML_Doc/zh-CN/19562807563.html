Signing an external BACnet/SC CSR

ABT 站点可以充当基于 Desigo 的 BACnet/SC 项目的 CA（证书颁发机构）。您可以签署外部证书签名请求（例如来自 Desigo CC 的外部证书签名请求），以便为 Desigo CC 签署证书。

根据标准规范，一个 BACnet/SC 项目只能有一个 CA。 CA 需要具有项目的根证书才能签署证书。因此，在项目一开始就明确谁是该项目的 CA 非常重要。

如果项目所有者决定使用自己选择的 CA，或者该项目是一个多供应商项目，并且除西门子之外的其他供应商担任该项目的 CA，则认证过程将分开。

  • For operational certificates:
    • ABT Site creates operational certificates for its Desigo BACnet/SC-devices
    • ABT Site exports the certificates as files, extended by certificate signing requests (CSR) and hands these files over to that project’s CA
    • The CA checks the authenticity of that request and signs the operational certificates. The CA then exports those properly signed certificates in a standardized file format and hands them back to ABT Site
    • ABT Site re-imports the certificates and provides them to the Desigo devices
  • For root certificates:
    • ABT Site imports the external CA’s root certificate and checks its authenticity
    • ABT Site provides the public part of the root certificate to all Desigo devices

ABT 站点可以处理由外部设备（例如 Desigo CC）创建的 CSRs。

这意味着 ABT 站点可以向 Desigo CC 提供根证书文件，然后从 Desigo CC 导入操作证书，处理其 CSR，签署该证书并将其导出回由 Desigo CC 导入的文件格式。

 

Sign an external certificate signing request

  1. You have a certificate signing request from an external device, for example, Desigo CC.
  1. Go to Settings.
  2. Open the Certificates task.
  3. Select the BACnet/SC certificates tab.
  4. In the toolbar, click Sign external CSR.
  5. Select the external certificate signing request, and click Open.
  6. In the confirmation dialog, click Yes.
  1. Certificate requests from Desigo CC are now signed. A log entry is written in Settings > Root certificates > External CSR signing activities.
