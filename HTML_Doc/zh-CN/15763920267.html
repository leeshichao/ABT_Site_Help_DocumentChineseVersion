典型输出块

输出块形成程序和控制器上的连接端子之间的连接。它们控制连接到控制器的设备组件，包括空气阻尼器、风扇或加热线圈。

通常使用以下输出块：

  • Output block CMD_B for binary controlled plant components
  • Output block CMD_A for analog controlled plant components
  • Output block CMD_M for multistate controlled plant components

Control of output blocks

输出块的控制基于当前操作模式组normal mode or exception mode.

输出块的开启顺序和关闭顺序可以通过以下方式定义locking.

① Normal mode

在正常模式下，功能块CMDSEQ_B根据接收到的信号确定切换哪个输出块及其打开和关闭顺序plant operating mode.

信号priority在输出块上设置（在正常模式下，通常优先级 15 =“自动模式”）。输出块切换连接的设备组件。

一旦功能块 CMDSEQ_B 输入上请求的设备运行模式 1...16 发生变化，设备组件就会按照关闭顺序关闭，并且新需要的设备组件就会按照接通顺序打开。

② General exception mode

在一般异常模式下，输出块直接由输入块启用，在适用的情况下通过中间的功能块启用。

对于启用的异常模式，正常模式通过 CMDSEQ_B 立即结束。

信号优先级在输出块上设置（通常优先级 5）。输出块切换连接的设备组件。

输出块的开启顺序和关闭顺序可以通过锁定来定义。

一旦异常模式不再适用，正常模式就会再次激活，并通过 CMDSEQ_B 切换当前操作模式所需的设备组件。

③ Local exception mode

活动的本地异常模式可以作用于特定的输出块，也可以返回到通用异常模式。
在仅影响特定输出块的情况下，正常模式继续通过功能块 CMDSEQ_B 运行。
当返回到一般异常模式时，根据本地和一般异常模式的优先级直接控制所连接的设备组件和输出块的快速关闭。
