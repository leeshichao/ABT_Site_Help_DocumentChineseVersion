中央天气数据分发，Desigo TRA V5.1 (CenWthDstr01)

Overview

应用功能》Central weather data distribution 01, Desigo TRA V5.1" (CenWthDstr01) 收集室外空气温度和湿度值，并将其转发到具有 Desigo V5.1 / V5.1 SP 功能的房间或后续中央 AFsCenWthDstr01.

岑

中央

房间

Room operating mode determination 11, with comfort button

RHvacCooxx

Room HVAC coordination set 11, for fan coil unit, radiant ceiling, radiator, radiant floor / 12 / 13 / 17

HvacUsrReq01

HVAC user request 01

Function

室外空气温度和室外空气湿度分配至 AFNHvacUsrReq01 (V5.1) 或后续中央 AFsCenWthDstr01。如果房间 V5.1 中的设定点与中央季节性补偿应用程序 (CenSsnCmp11) 协调，则使用此功能。它是 AF CenSsnCmp11 的可选部分。

Engineering and commissioning

Hierarchical grouping:

  • Recommended for large networks.
  • To support hierarchical grouping, CenWthDstr01 has to be activated in both the superior AF CenSsnCmp11 as well as in the subsequent AF CenSsnCmp11.

Note: HuRelOa is connected here in AF CenWthDstr01, whereas TOa is connected in the superior AF CenSsnCmp11.
