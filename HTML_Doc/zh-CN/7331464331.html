2 管 (SplyCho2Pipe11) 的供应链转换功能

Overview

应用功能》Supply chain changeover function for 2-pipe 11" (SplyCho2Pipe11) 评估房间的供暖/cooling 需求，并决定是否将 2 管转换水系统设置为供暖或制冷。

Function

水系统用于加热还是冷却取决于加热/cooling需求(HCDmd)。评估的转换条件通过 SplyChw-Grouping 分发到房间部分，以激活加热或冷却序列。

Cho2PipeModCmd- Cho2PipeModCmd 是 2 管道切换条件（均不/加热/冷却）的模式命令。 Cho2PipeModCmd 可以通过具有更高优先级的 BACnet 进行覆盖。

Changeover determination logic- 具有加热或冷却需求的段通过 SplyChw-Grouping 标签 HCDmd 进行计数。数量较多的加热或冷却部分将获胜。

例子：
50个段需要冷却； 30段需要加热

评价=冷却。结果将由 SplyChw-Grouping 标签 ChovrCnd2Pipe 分发，以激活或停用房间控制器。

加热期间，冷却控制器停用；在冷却过程中，情况相反。

Configuration

没有任何。

Note: Configuration in other AFs
对于 2 管或 4 管系统，SplyHw11 中的加热限制 HLm 和 SplyChw11 中的冷却限制 CLm 不得重叠，否则设备模式将在季中之外设置为“关闭”。

这意味着：HLm 必须等于或小于 CLm。
