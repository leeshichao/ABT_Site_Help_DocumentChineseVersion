CYCLEGEN：周期脉冲发生器

CYCLEGEN (FB401) 块生成一个具有可调节脉冲和暂停长度的周期。

功能性

一般情况下以及复位时输出信号 [Out] 的时间相关过程。

1. = 脉冲长度 TiOn

2. = 暂停长度 TiOff

Reset

输入值为 [Reset] = 1（是）。

  • Resets all times.
  • Switches [Out] = 0 (Off).

输入值 [Reset] 从 1（是）更改为 0（否）。

  • Restarts the switch-off time.
