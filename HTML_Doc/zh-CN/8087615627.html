Room ID

Room ID，仅适用于房间，只读。您可以在以下位置找到所有应用程序模板的房间 ID 范围的概述：Settings > Number ranges > Room ID overview.
Number ranges

点击Assign new room ID更新分配给房间的所有段（RCtl和ROpUnCtl).

您只能将新房间 IDs 分配给房间，而不能分配给段或中心功能。

Checkout packages tab

显示建筑元素、区域和设备的签出包。签出包指示相应的项目路径必须是可写的。这允许识别要从具有 Branch Office Server (BOS) 的分布式工程环境中的项目存储库签入或签出的目录。
