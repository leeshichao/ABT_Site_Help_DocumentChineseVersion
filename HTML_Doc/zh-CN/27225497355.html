  5. Creating an alarm on a BACnet object

在 BACnet 对象上创建警报

  1. Go to Building > Building structure.
  2. Right-click the automation station and select Go to engineering.
  3. Open the BACnet objects task.
  4. Select the Properties view tab.
  5. Select the Alarm tab.
  6. Select the object you want to trend.
  7. From the Enable event drop-down list, select Yes.
  8. Define the properties according the selected logging type.
  1. An alarm is created.
