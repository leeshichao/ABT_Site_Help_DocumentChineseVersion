Further information

  • BIT_I: Conversion binary to integer value
  • DW_TI: Conversion DWord value to time
  • I_BIT: Conversion integer to binary value
  • I_LOGI: Conversion integer value to logic signals
  • LOGI_I: Conversion logic signals to integer value
  • MS_MS: Conversion multistate-multistate
  • PRIO_4BO: Priority range converter to 4 boolean
  • PRIO_CNV: Priority converter to 4 boolean
  • R_DI: Conversion real to double integer
  • R_I: Conversion real to integer
  • SWICNV_B: Switch converter to Boolean
  • SWICNV_M: Switch converter to multistate
  • TI_DW: Conversion time to DWord value
