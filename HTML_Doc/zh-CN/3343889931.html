设备对象 (DevObj)

Device (DevObj) 对象类型定义了一个标准化对象，其属性表示 BACnet 设备的外部可见特征。每个 BACnet 设备中只有一个 Device 对象。设备对象由其 Object_Identifier 属性引用，该属性对于维护该对象的 BACnet 设备来说是唯一的，并且在整个 BACnet 互联网络中也是唯一的。 DevObj 对象属性是：

出厂默认值为：GMT+01:00 Berlin, Rome

Time slot for date and time synchronization ✳

 

 

"Time slot for date and time synchronization" 定义断电后等待时间同步消息的时间段（以秒为单位）。如果断电后 RTC 可以获得正确的时间，则 "Time slot for date and time synchronization“属性没有任何影响。

如果控制器在“”中设置的时间段内收到时间同步消息Time slot for date and time synchronization"，收到的日期和时间将用作新的日期和时间。

如果控制器在“设置的时间段内没有收到时间同步消息”Time slot for date and time synchronization”，最后保存的时间和日期加上等待时间将用作新的日期和时间。

默认值：300 秒
范围：0...7200 秒

Active system language ✳

 

 

"Active system language" 表示要用作系统语言的语言。

Synchronization request ✳

 

 

"Synchronization request" 允许 HMI 或配置工具指定默认情况下，在从事件缓存中清除通知后，警报服务器设备是否应向已注册的事件通知客户端发送警报通知。

如果 ”Synchronization request" 为 TRUE，在事件缓存清除后，警报通知将发送到相关注册的事件通知客户端。
当事件通知客户端是支持警报通知的西门子设备时，将该属性设置为 TRUE。

如果 ”Synchronization request" 是 FALSE，永远不会发出警报通知。
当事件通知客户端是不支持专有警报通知的第三方设备或西门子设备并且有特定原因不发送警报通知时，请将该属性设置为 FALSE。客户端在收到通知后崩溃。

Equipment identifier ✳

 

 

"Equipment identifier" 表示与 BACnet 设备关联的技术设备标识符。设备 ID 用作机械设备和 BACnet 设备之间的交叉引用。

房产价值包含在Device info当工具发现设备时的属性。

Timeout for backup ✳

 

 

"Timeout for backup" 表示正在备份或恢复的 BACnet 设备单方面结束备份或恢复过程之前不活动的最长时间（以秒为单位）。

Object list

 

 

"Object list" 包括 BA 设备的所有可访问 BA 对象的对象标识符数组。

Structured object list

 

 

"Structured object list" 包括表示对象层次结构的根对象的 BA-View-Node-Objects 对象标识符数组。

Maximum info frames

 

 

"Maximum info frames" 指定节点在必须传递令牌之前可以发送的信息帧的最大数量。

如果修改此属性，则属性 Changes-Pending 将设置为 true。

当将 activate 值写入属性 Command 时，将激活 Max-Info-Frames 的新值。

Max. number of managers

 

 

"Max. number of managers“指定管理器节点的最高可能地址。相同的信息也将被建模为网络端口对象的属性。

范围：1..127

如果修改此属性，则属性 Changes-Pending 将设置为 true。

当将 activate 值写入属性 Command 时，将激活 Max-Manager 的新值。

Description

 

 

"Description" 是一串可打印的字符，其内容不受限制。

Object name

 

 

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

评论

 

 

内容不受限制的可打印字符的字符串。

Active COV subscriptions

 

 

"Active COV subscriptions" 表示在任何给定时间都处于活动状态的活动 COV 订阅列表。

  • Whenever a COV Subscription is created with the SubscribeCOV or SubscribeCOVProperty service, a new entry is added to the Active-COV-Subscriptions list.
  • Whenever a COV Subscription is canceled, the corresponding entry will be removed from the Active-COV-Subscriptions list.

APDU segment timeout

 

 

"APDU segment timeout" 指示重传 APDU 段之间的时间量（以毫秒为单位）。此属性的建议值为 5000 毫秒。如果 "Number of APDU retries" 不为零。

为了实现可靠的通信，建议“APDU segment timeout" 所有互通设备的设备对象的属性应包含相同的值。

APDU timeout

 

 

"APDU timeout" 指示重传需要确认且尚未收到确认的 APDU 之间的时间间隔（以毫秒为单位）。对于允许修改此参数的设备，此属性的建议值为 10,000 毫秒。否则，默认值为 60,000 毫秒。如果 "Number of APDU retries" 不为零。

Application SW version

 

 

"Application SW version” 标识机器中安装的应用软件的版本。该字符串的内容是本地事务，但它可以是日期和时间戳、程序员的姓名、主机文件版本号等。

Access object list ✳

 

 

"Access object list" 包括 BA- 对象的对象标识符数组 1...7。 BA- 设备的各个 BA- 对象将根据其各自的对象访问级别分配到数组条目 1...7。

Available Flash-memory ✳

 

 

"Available Flash-memory" 表示可用闪存的大小。

Available RAM memory ✳

 

 

"Available RAM memory" 表示可用内存的大小。

Backup preparation time

 

 

"Backup preparation time" 指示在备份过程开始时发送 ReinitializeDevice-ACK 后设备可能保持无响应的时间（以秒为单位）。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Configuration files

 

 

"Configuration files" 表示 BA-Device 中的文件对象标识符数组，它定义了可以备份的文件映像。

Configuration files (S1) ✳

 

 

"Configuration files (S1)" 表示 BA 设备内的文件对象标识符列表。

Configured device address binding ✳

 

 

"Configured device address binding" 表示静态地址绑定列表。

  • A value of zero is used for the network-number portion of address entries for other devices residing on the same network as this device.
  • The list is empty if no static device bindings are forseen.

Database revision

 

 

"Database revision" 表示 BA 设备数据库的逻辑修订号。

Device address binding

 

 

"Device address binding" 表示地址绑定列表。列表中的条目标识当必须通过 BACnet 服务请求访问远程设备时将使用的实际设备地址。

  • A value of zero is used for the network-number portion of address entries for other devices residing on the same network as this device.
  • The list is empty if no device identifier-device address bindings are currently known to the device.

Engineering load context ✳

 

 

"Engineering load context" 标识所加载配置的工程上下文（例如 GUID）。

Firmware revision

 

 

"Firmware revision" 标识 BA 设备上安装的固件。

In use objects list ✳

 

 

"In use objects list" 包括当前“正在使用”的 BA 对象的所有对象标识符的列表。

Last restore time

 

 

"Last restore time" 表示 BA-设备上次恢复的时间。

Local ping interval ✳

 

 

"Local ping interval" 定义用于测试本地 BA 网络上通信主机的可达性的时间间隔（以秒为单位）。

范围：10...600 秒

默认值：180 秒

Max APDU length accepted

 

 

"Max APDU length accepted”表示单个不可分割的应用层协议数据单元中可以包含的最大八位位组数。该属性的值大于或等于50。该属性的值还受到底层数据链路技术的约束。

Max segments accepted

 

 

"Max segments accepted”表示单个不可分割的应用层协议数据单元中可以包含的最大八位位组数。该属性的值大于或等于50。该属性的值还受到底层数据链路技术的约束。

Model information ✳

 

 

"Model information”表示设备相关信息的标准化特征。

Model name

 

 

"Model name" 表示 BA 设备的型号，并定义特定设备类型在系统中的作用。它包括控制器类型和市场重要的 HW 版本，但没有其他信息，例如生产位置、预加载的应用程序组标识符或硬件版本。

Number of APDU retries

 

 

"Number of APDU retries" 表示重传 APDU 的最大次数。如果该设备不执行重试，则该属性设置为零。如果该属性的值大于零，则在 "Device“ 目的 ”APDU timeout“ 财产。

Object identifier

 

 

"Object identifier" 是用于识别对象的数字代码。它必须在互联网范围内是唯一的。

Object type

 

 

"Object type“ 表示特定对象类型类中的成员资格。例如”Analog input“，”Binary output“，”Event enrollment“，”Trend log“， ETC。

Operation URL ✳

 

 

"Operation URL" 表示设备的网址。例如：http://192.168.251.1

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。

Proprietary device features ✳

 

 

"Proprietary device features" 表示 BA 设备支持的设备功能。

Protocol object types supp.

 

 

"Protocol object types supp." 表示 BA 设备支持的对象类型服务。

Protocol revision

 

 

"Protocol revision" 标识 BA 设备支持的 BACnet 协议的修订版。

指示 BACnet 标准的次要修订级别。该值应从 1 开始，并针对影响设备通信或行为的 BACnet 标准的任何实质性更改而递增。每次更改“时，该值将恢复为零”Protocol version" 属性。更改 " 的值Protocol version“ 和 ”Protocol revision” 记录在 BACnet 标准末尾的修订历史记录中。

Protocol services supported

 

 

"Protocol services supported" 表示 BA 设备支持的协议服务。

Protocol version

 

 

"Protocol version" 表示该 BACnet 设备支持的 BACnet 协议版本。BACnet 的每次重大修订都会将此版本号增加 1。BACnet 的初始版本是版本 1。

Remote ping interval ✳

 

 

"Remote ping interval" 定义用于测试远程 BA 网络上通信主机的可达性的时间间隔（以秒为单位）。

范围：10...600 秒

默认值：360 秒

Restore completion time

 

 

"Restore completion time" 指示在恢复过程结束时发送 ReinitializeDevice-ACK 后允许设备保持无响应的时间（以秒为单位）。

Restore preparation time

 

 

"Restore preparation time" 指示在恢复过程开始时发送 ReinitializeDevice-ACK 后设备可能保持无响应的时间（以秒为单位）。

Segmentation supported

 

 

"Segmentation supported" 指示BA-设备是否支持消息分段。

支持分段 = 枚举（分段双方、分段发送、分段接收、无分段）

Serial number ✳

 

 

"Serial number“显示设备出厂时的唯一序列号。

  • Data acquisition will read "Serial number" from the device and set the respective property value.
  • If "Out of service" is TRUE, "Serial number" will not be setup by the data acquisition.
  • "Serial number" will be modeled as a string because it depends on a particular technology:
    KNX PL-Link (KNX Serial Number) 48-bit,
    DALI (CIN as used by Osram devices) 128 bit
  • "Serial number" can be empty if not available.

Server communication buffer ✳

 

 

"Server communication buffer“专用于中央功能/supply-chain功能配置。

这是大型系统的优化属性。

范围：150、300、450、600

默认值：150

Reason for system state ✳

 

 

"Reason for system state" 表示系统状态 = 不可操作的原因。

UTC (Universal time) offset

 

 

"UTC (Universal time) offset" 表示当地标准时间与协调世界时之间的偏移分钟数（-780 至 +780）。零度子午线以西的时区为正值，以东的时区为负值。" 的值UTC (Universal time) offset从 UTC 时间同步服务请求中收到的 UTC 时间中减去属性，以计算正确的本地标准时间。

Vendor identifier

 

 

"Vendor identifier" 是唯一的供应商识别码，由 ASHRAE 分配，用于区分协议的专有扩展。

Vendor name

 

 

"Vendor name" 标识 BACnet 设备的制造商。
