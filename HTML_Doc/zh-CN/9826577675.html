Enable event detection

 

 

"Enable event detection" 允许在工程时启用或禁用相应对象的事件通知。当 "Enable event detection" 为 false，则对象的内部算法不执行。因此，不会发出事件通知，并且对象的动态属性不会更新。

Suppress event detection

 

 

"Suppress event detection" 是一个可写属性，允许在运行时为对象实例临时启用和禁用事件检测功能。

Suppress event notification ✳

 

 

"Suppress event notification" 是一个可写属性，允许在运行时为对象实例临时启用或禁用事件通知功能。

Configurable event message texts

 

 

"Configurable event message texts" 由一组三个可写字符串组成，每个字符串对应一个状态转换（TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL）。这些字符串将用作事件通知中传递的全部或部分消息文本参数。

Event message texts

 

 

"Event message texts" 由一组三个可写字符串组成，每个字符串对应一个状态转换（TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL）。这些字符串将用作事件通知中传递的全部或部分消息文本参数。

Notification type

 

 

"Notification type“传达对象生成的通知是否应为类型”Event“ 或者 ”Alarm".

Notification class

 

 

"Notification class“ 持有对“ 的引用Notification class object”，并指出是哪个“Notification class object" 在为此对象生成通知时使用。

Event enable

 

 

“事件启用”启用或禁用特定事件通知功能（即在工程/configuration期间）。

异常状态

允许启用和禁用 TO-OFFNORMAL 事件通知功能。

故障

允许启用和禁用 TO-FAULT 事件通知功能。

恢复正常

允许启用和禁用 TO-NORMAL 事件通知功能。

Configured event enable ✳

 

 

"Configured event enable" 是一个 Bitstring 值，由以下三个二进制标志组成：

异常状态

允许为对象实例启用和禁用 TO-OFFNORMAL 事件通知功能。由于 BA-Device-Alert 对象仅发出 TO-NORMAL 通知，因此将此标志设置为 true 没有任何效果。

故障

允许为对象实例启用和禁用 TO-FAULT 事件通知功能。由于 BA-Device-Alert 对象仅发出 TO-NORMAL 通知，因此将此标志设置为 true 没有任何效果。

恢复正常

允许为对象实例启用和禁用 TO-NORMAL 事件通知功能。

Event state

 

 

"Event state“提供了一种方法来确定该对象是否具有与其关联的活动事件状态。”Event state”属性表示对象的事件状态。“中的变化Event state" 值为 FAULT 的属性被视为故障事件。如果对象不支持内部报告，则该属性的值为 NORMAL。

财产-ID：36

Time stamp of event

 

 

"Time stamp of event" 分别传达 TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL 事件的最后事件通知的时间。

Acknowledged transitions

 

 

"Acknowledged transitions" 传送三个标志，分别指示 TO-OFFNORMAL、TO-FAULT 和 TO-NORMAL 事件的确认接收。这些标志在发生相应事件时被清除，并在以下任何条件下设置：

  • Upon receipt of the corresponding acknowledgment;
  • Upon the occurrence of the event if the corresponding flag is not set in the "Event enable" property (meaning event notifications will not be generated for this condition and thus no acknowledgment is expected);
  • Upon the occurrence of the event if the corresponding flag is set in the "Event enable" property and the corresponding flag in the "Acknowledgement required" property of the "Notification class" object implicitly referenced by the "Notification class" property of this object is not set (meaning no acknowledgment is expected).

Reliability

 

 

'Reliability'表示是否属性值'Present value'是可靠的。如果“当前值”不可靠，则“可靠性”属性指示故障原因，并且状态指示的“故障”位设置为“真”。在正常情况下，“可靠性”属性设置为“无故障”。

如果当前日期超出指定的开始和结束日期范围，则调度程序不处于活动状态（例如，当前值 = 调度程序处于活动状态时的最后一个值）。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.

Object usage ✳

 

 

"Object usage" 指示该对象是否已使用或未使用。 "Object usage" 属性可以在客户端中隐藏或显示相应的对象及其功能。例如，可以将房间功能标记为已使用，以实现灵活的房间布置/unused. 标记为未使用的对象的行为就像该对象不存在一样。

"Object name" 表示在互联网范围内唯一的对象名称。字符串的最小长度为一个字符。 " 中使用的字符集Object name" 仅限于可打印字符。

Building automation profile ✳

 

 

"Building automation profile" 是一个枚举，指示特定类型的西门子专有对象。西门子对象基于标准 BACnet 对象。例如，西门子模拟输入、模拟输出、模拟计算值和模拟配置值基于标准模拟输入、模拟输出和模拟值 BACnet 对象。

Profile name

 

 

"Profile name" 表示该对象符合的对象配置文件的名称。为确保唯一性，配置文件名称必须以供应商标识符代码开头，后跟破折号。所有后续字符均由使用该供应商标识符代码注册的组织管理。配置文件名称前缀的供应商标识符代码表示发布和维护由配置文件名称的其余部分命名的配置文件文档的组织。
