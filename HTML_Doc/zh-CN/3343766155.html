文件对象（FileObj）

文件 (FileObj) 对象类型定义了一个标准化对象，用于描述可使用文件服务访问的数据文件的属性。

控制器使用文件对象来存储从工具加载的文件。尽管文件服务未显示为用户功能，但对象显示在 BA 对象编辑器中，以便可以在一个位置查看控制器中的完整对象集。

FileObj 对象属性是：

✳ 表示西门子专有财产。

File type

 

 

"File type" 标识了该文件的预期用途。

File access method

 

 

"File access method" 指示该对象支持的文件访问类型。

File size

 

 

"File size" 表示文件数据的大小（以八位字节为单位）。

Modification date

 

 

"Modification date" 表示上次写入数据的关联交换表示或本地修改数据的运行时表示的时间。

Runtime state data, modification counter ✳

 

 

"Runtime state data, modification counter" 是内部指示，表明该设备的本地数据库是否已更改。不可从外部更新。

Checksum ✳

 

 

"Checksum”由服务器设置，可用于验证服务器向客户端传输的数据的有效性。

Compression ✳

 

 

"Compression" 表示使用什么压缩算法来压缩服务器传输到客户端的数据。目前尚未实现。

Read-only

 

 

"Read-only" 表示是否可以更改 (FALSE) 或 (TRUE) 文件数据。

Archive

 

 

"Archive“ 表示是否”File" 已保存用于历史或备份目的。仅当自上次归档对象以来，内部进程或通过文件访问服务未对文件数据进行任何更改时，此属性才是逻辑 TRUE。

Object access level ✳

 

 

"Object access level“定义特定于实例的对象访问级别。”Object access level" 用于由客户端应用程序进行通用过滤和处理对象。

  • "Object access level" is a configuration property which can only be set up offline (ABT, application configuration).
  • "Object access level" is evaluated by client applications such as Technical Operator, DB-Import, and APOGEE Point Team mapping.
