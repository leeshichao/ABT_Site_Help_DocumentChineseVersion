[FILTER_H] 间隙

功能块 FILTER_H 根据设置的滞后带生成输出变量。

FILTER_H 根据设置的滞后带生成输出变量。

Functioning

输出变量保持默认值，直到输入变量在方向改变后经历滞后。如果输入值超过了一半的滞后，则输入值会影响输出值。

Integrated functions

  • Adjustable hysteresis band
  • Input value applied to the output via reset pulse.

Enabling and disabling the function

  • When [EnFnct] = 1, the function is switched on.
  • When [EnFnct] = 0, the function is switched off.
    No new input values are acquired and calculation is stopped. The last value is available at output [Out].

Reset

当 [Reset] = 1 时，在输出 [Out] 处发出输入 [In]。

Application

典型应用包括： 过滤信号中的噪声（来自压力传感器、温度传感器的不稳定输入信号）。此外，磁滞滤波器用于稳定大增益级联，用于具有小开关差的2点开关和具有外部移位的控制环路。

Process response

在第一个处理周期的输出处提供值 0。输入 [Reset] 在第一个处理周期中被忽略。在第二个处理周期中，过滤后的值使用值 [In] 进行初始化并在输出处提供。从第三个处理周期开始首次进行过滤。
