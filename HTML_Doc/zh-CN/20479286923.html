[Bo22] 锅炉，2 级

Program block, name / node subtype: [Bo22] Boiler, 2-stage

Library hierarchy: Heating equipment

Family: HGen

项目树

图表

Configurator

程序块存储在没有 I/Os. 的库中 使用auto-create and auto-connect函数创建 I/Os 和 /or 将它们连接到接口块，例如 R_A、CMD_B。或者，从包含库中预定义 I/Os 的文件夹中取出 I/Os，并从工厂中取出 /or，并将它们连接到接口块。

Function

使用其自己的外部控制单元控制锅炉。

锅炉控制单元 (Bu22) 的接口启用阶段 1 或阶段 2，并读取故障和反馈的可选信号。

该程序具有锅炉标称功率和打开或关闭时的瞬态时间（锅炉处于瞬态状态的信号，该信号会阻止为功率控制和补偿生成进一步升压和降压脉冲的逻辑）的设置（例如，打开时为 5 分钟，关闭时为 2 分钟）。

阀门、泵和控制单元接口的开启和关闭顺序在功能块 CMDSEQ_B 中定义。

该程序块具有以下可选功能：

Option: Mixing valve (1xAO, 1xAI)

控制混合阀 (Vlv24) 的位置。

PID 控制器改变混合阀的位置，以将回水温度（这是锅炉入口温度）维持在给定的设定点。

此选项只能与可选返回温度一起成功应用。

有一个配置值“设定点最低回水温度”(SpTRtMin)。

参数定义了流动温度和回水温度之间的温差。这是锅炉在其标称流量 = DeltaT（例如 8 K）下可以维持的温度增量。

另一个参数定义当前回水温度设定值和水流温度设定值（锅炉出口温度设定值）之间的关系：

0：回水温度设定值遵循流量温度设定值 (PrSpT)。

回水温度的最终设定值计算如下：最大值 (SpTRtMin, (PrSpT - DeltaT)。

1：回水温度设定值改变进水温度设定值 (PrSpT)。

回水温度设定值为 SpTRtMin。

当前流量温度设定点计算如下：最大值（引脚“Sp”处的值，(SpTRtMin + DeltaT)。

Option: Pump (1xBO, 4xBI)

控制泵 (Pu21)。可以有不同的替代方案，例如 TwnPu21。

锅炉运行时泵运行，可选截止阀打开。

Option: Shutoff valve (1xBO, 2xBI)

控制锅炉运行时打开的截止阀 (Vlv21)。

Option: Deactivate frost protection in case of gas detection

读取气体探测器的状态并停止任何因防冻保护而打开的设备。

当检测到气体时，关闭所有设备（阀门关闭，泵关闭，锅炉控制单元禁用）。

Option: Flow temperature (1xAI)

创建流量温度的模拟输入并读取其信号。它可以产生警报（上限和下限）。

Option: Frost protection

如果锅炉的水流温度（出口）和/or回水温度（进口）低于一定值，例如8℃，截止阀打开，水泵启动，确保水循环。

如果温度进一步下降，例如下降至 5 °C，则锅炉控制接口将启用锅炉并启动锅炉。

有一个参数可以设置锅炉级的防冻保护。

Option: Keep valves open and pump running for specified time on overtemperature

如果温度过高，截止阀将保持打开状态，泵将继续运行指定的时间，例如 2 分钟。

Option: Local temperature control for flow temperature limitation

如果水流温度（锅炉出口温度）超出锅炉水流温度容差（例如 4 K），则从阶段 2 切换到阶段 1。

此选项只能与可选的流动温度一起成功应用。

Option: Operating mode switch (1xMI=3xBI)

读取操作模式开关的状态，通常位于电气面板的前面，状态为“自动”、“关闭”、“第 1 阶段”和“第 2 阶段”。

Option: Overtemperature detector (1xBI)

读取来自过热检测器的信号并生成警报。

程序逻辑停止向锅炉控制单元发出启用命令。当选项“在过热时保持阀门打开且泵运行指定时间”处于活动状态时，泵将停止并且截止阀会延迟关闭。否则，泵将停止并且截止阀将立即关闭。

Option: Return temperature (1xAI)

创建回水温度的模拟输入并读取其信号。它可以产生警报（上限和下限）。

Option: Safety temperature limiter (1xBI)

读取安全温度限制器的信号并生成警报。

程序逻辑停止向锅炉控制单元发出启用命令。当选项“在过热时保持阀门打开且泵运行指定时间”处于活动状态时，泵将停止并且截止阀会延迟关闭。否则，泵将停止并且截止阀将立即关闭。

Option: Setpoint shift with external signal for operating mode "Fixed"

带有自己的外部控制单元的锅炉具有“固定”运行模式。操作模式“Fixed”位于“On”模式之后。它确保该锅炉保持其标称功率，并且在调节后打开的另一个能量发生器保持主流温度。

另一个程序块 (HGenCtl22) 中的 PID 控制器将主流温度与其设定值进行比较，如果出现偏差，则增加其输出 (in %)。锅炉可以读取此信号，如果其运行模式为“固定”，则会导致本地设定点增加，例如，0-100 % 将锅炉的设定点增加 0-3 K。这使锅炉保持在其标称功率并防止其调制。
