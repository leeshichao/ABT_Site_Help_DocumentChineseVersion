  6. CLB_VNTR: Venturi valve calibration function

任务中，您还可以通过 xml 文件导入数据。在第二步中，您可以编辑 __VAR_001__-IVNTR 模块的数据点属性。

这CLB_VNTR块用于自动或手动校准空气阀。校准数据用于计算所需气流的阀门位置。

在自动校准过程中，阀门执行器被命令到达一系列预定义的位置，并在每个位置测量空气体积流量。如果收集到的数据包含足够的“对”（位置 - 空气流量）并且这些对形成单调递增的空气体积流量曲线，则认为校准成功。成功校准后，有效的气流数据将从非活动表复制到活动表中，以便在正常操作期间使用。

校准结果在关联的 MCalcVal 对象的当前值属性中提供。

 

  • Compatible data points:
  • Multistate calculated value [MCalcVal]

参考data point objects有关 BACnet 数据点的详细说明。

 

Required properties:

  • Present value
  • Tracking value
  • State flag
  • Reliability
  • Enabled subsystem specific extension: Venturi valve

 

Pin description (inputs)

BaObjRef

BA-Object reference

结构

[BaObjRef] 定义 XFB 和 BACnet 对象之间的绑定连接。绑定会自动发生。

手动配置尝试是不必要的，并且可能会导致系统错误。

DeviceId

设备标识符

双字（默认值：16#3FFFFF）

[DeviceId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

ObjectId

对象标识符

双字（默认值：16#3FFFFF）

[ObjectId] 在单个标识符中包含对象类型和对象实例。

它用于识别设备内的对象。

ItemId

物品标识符

整数（默认值：-1）

[ItemId] 表示功能视图节点对象中的项目索引，它引用 BACnet 对象。

[ObjectId] 和 [ItemId] 一起定义对 BACnet 对象的间接访问引用。

值-1表示使用直接绑定。

ClbCmd

Calibration command

整数（默认值：1）

要运行的命令。

= 1

准备好

= 2

校准（开始校准过程：自动采集气流数据）

= 3

应用（评估非活动表中的数据并更新校准状态；如果认为非活动表可接受，则使用新值设置活动表）

= 4

取消（取消自动气流数据采集的校准过程；校准状态设置为失败，并且重置非活动表）

AirFl

Air volume flow

实数（默认值：0.0 m3/h）

传感器测量的当前空气体积流量。

AirFlMin

Minimum air volume flow

实数（默认值：0.0 m3/h）

空气体积流量水平低于该水平，信号就会失去准确性，并且流量反馈不再有用。 （风道速度 350fpm（1.778 米/s）是一个下限值，可用于帮助确定 [AirFlMin]）

TshAflMin

Threshold for minimum air volume flow

实数（默认值：0.1 m3/h）

测量的空气流量与 [AirFlMin] 之间的最小差异，低于该差值，系统将认为空气流量等于 [AirFlMin]。

SrchAtp

Search attempts

整数（默认值：5）

尝试搜索与最小气流相对应的阀门位置的次数。

最小值：0
最多：10

TiRnActr

Actuator run time

时间（默认值：90s）

执行器从 0% 运动到 100% 的时间。

最小值：0
最长：300秒

TiHld

Holding time

时间（默认值：3s）

阀位改变后气流稳定的时间。

允许的最小值：0
允许的最大值：300s

MsngPrd

Measuring period

时间（默认值：5s）

测量空气流量的时间。计算测量期间的空气流量平均值。

最小值：0
最长：300秒

AflCtlMod

Control mode for air volume flow

布尔值（默认值：True）

定义阀门控制中使用闭环还是开环。

1（正确）

闭环

0（假）

开环

SpAirFl

Setpoint air volume flow

实数（默认值：0.0 m3/h）

要求的风量流量。在正常运行期间，活动表中的数据将用于计算所需空气体积流量所需的阀门位置。

PrVlvPos

Present valve position

实数（默认值：0.0%）

用于计算输出引脚 [AirFlClb] 值的阀门位置。在正常操作期间，当阀门设置为当前阀门位置值时，活动表中的数据将用于计算预期空气流量。

最小值：0.0%
最大值：100.0%

 

Pin description (outputs)

PrVal

Present value

整数（默认值：1）

引用的 MCalcVal BACnet 对象的当前值。如果 [Valid] = False，[PrVal] 将提供最后一个有效值。

1：初始

阀门尚未校准。 Block 为计算出的阀位值和空气体积流量校准值提供 0.0。

2：校准失败

已尝试进行校准，但非活动表中的数据不可接受，并且不会设置在活动表中。

3：校准

阀门已成功校准（自动或手动）。该块根据活动表中的数据提供计算值。

VlvPosVal

Valve position value

实数（默认值：0.0%）

根据活动表数据和 [SpAirFl] 计算出的阀门位置。

最小值：0.0%
最大值：100.0%

AirFlClb

Air volume flow calibration value

实数（默认值：0.0 m3/h）

根据活动表数据和 [PrVlvPos] 计算出的风量流量。

NumClbPts

Number of valid calibration points

整数（默认值：0）

活动表中有效对的数量。

最小值：0
最多：16

TiRmgClb

Remaining calibration time

时间（默认值：0s）

预计校准过程完成之前剩余的预计时间。

最小值：0 秒
最长：900秒（15分钟）

有效的

Valid

布尔值（默认值：False）

输出引脚[PrVal]是否可靠的指示。

1（正确）

[PrVal] 是可靠的。

  • XFB can access the BACnet object.

AND

  • Fault flag in state flag property = 0 (no fault)
    (Reliability = 0 (no error) or Reliability was not detected).
  • AND
  • Subsystem specific extension properties are accessed successfully.

0（假）

[PrVal] 不可靠。

  • XFB cannot access the BACnet object.

OR

  • Fault flag in state flag property = 1 (fault)
    (Reliability ≠ 0).
  • OR
  • Subsystem specific extension properties are not accessed successfully.
