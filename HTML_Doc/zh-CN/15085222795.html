使用功能块访问 BACnet 对象

现场设备的 BACnet 对象列在Project tree。具有程序功能的功能块是图表中 BACnet 对象的对应部分。功能块和 BACnet 对象是分开的，但它们看起来像是同一个块。

当您将相应的 BACnet 对象拖动到图表中时，会自动创建以下功能块。

Access a BACnet object

  • Drag a field device, i.e. a BACnet input/output object, from the Project tree to the Programming editor.
  1. A function block with program function is created.
  2. The function block has the same name as the BACnet input/output object.
  3. The function block is assigned to the BACnet input/output object.
