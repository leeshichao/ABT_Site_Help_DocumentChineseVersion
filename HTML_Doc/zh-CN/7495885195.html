供应链 VAV 覆盖值 (SplyVavOvrr11)

Overview

应用功能》Supply chain VAV overridden value 11" (SplyVavOvrr11) 允许技术人员/平衡员覆盖 VAV 应用程序以平衡和调试管道系统。

Function

技术人员通过 SplyAir 组分配至目标对象来覆盖 VAV 风门位置和 VAV 流量设定值。请参阅工程和调试。
