[WP_REAL] 写入实际值的属性

WP_REAL 写入数据点中数据类型 Real 的指定写入属性或数组元素。

WP_REAL 写入数据点中数据类型 Real 的指定写入属性或数组元素。

Functioning

Compatible data points:

  • Any BACnet data point with write property or array element of data type Real.

WP_REAL 不考虑 BACnet 对象状态，也不考虑 BACnet 对象使用情况。

Pins

输入

描述

数据类型

默认值
取值范围

EnWrit

Enable write

控制输入​​，启用或禁用将 [Val] 写入属性或数组元素。
如果[EnWrit]从0变为1，则发生写入。

布尔值

1

Val

Value

由控制程序写入属性或数组元素的计算值或配置值。

写于时：

  • [EnWrit] is 1 and [Val] changes by a value greater than or equal to [TshVal].
  • [EnWrit] changes from 0 to 1.
  • [RptWrit] and [EnWrit] are 1.

真实的

0.0

RptWrit

Repeat write

强制将 [Val] 写入属性或数组元素。只要 [RptWrit] = 1，就会在每个编程周期中重复写入。
[RptWrit]通常由控制程序计算和设置。
Note
[RptWrit] 无法永久强制为 1。这可能会导致网络流量增加。

布尔值

0

0 - 无操作。
1 - [Val] 在每个编程周期写入属性或数组元素。

TshVal

Threshold value

用于控制功能块写入尝试的配置值。仅当值的变化大于或等于 [TshVal] 时才允许尝试。

Note
无法设置为 0.0。

真实的

0.1

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

PrpyId

Property identifier

参数化 BACnet ID 的编号property这是写的。

整数

0

ArrayIdx

Array index

功能块访问的数组元素的索引号。
可选的配置输入，用于指示对数据类型 BACnetArray 或 BACnetPriorityArray 的属性元素的访问。
运行时期间无法更改。

整数

-1

-1：未使用。
0：指定引用属性的数组长度。
Note:
由于写入该字段不是控制程序功能，因此 [ArrayIdx] = 0 被功能块拒绝。
>0：配置值。

 

输出

描述

数据类型

默认值
取值范围

Dstb

Disturbed

[Dstb] 指示是否访问了引用的 BACnet 对象。
[Dstb] = 0，如果：
BACnet 对象访问 = 访问成功
[Dstb] = 1，如果：
BACnet 对象访问 = 访问期间出错

布尔值

0

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes
