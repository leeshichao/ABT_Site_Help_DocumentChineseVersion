RANDOM：随机数生成

块 RANDOM (FB426) 提供随机输出信号。新值的顺序可以确定：随机或恒定。可以限制输出信号的值范围。

Application

该块允许以下应用：

  • Generate a random number of pulses e.g. for random switch-on or switch-off of any functions or aggregates.
  • Generate a random number for further use.

功能性

块 RANDOM 生成实数值输出信号 [Out] 和二进制输出信号 [Imp]。

[Out] 的实际值在值范围 [OutMin]、[OutMax] 内随机分布。

[Out] 和 [Imp] 的输出值以 [TiMin]、[TiMax] 之间的随机间隔或以恒定间隔（例如每 10 秒）发出。

 

Example1: Random number [Out] at intervals between [TiMin] and [TiMax].

如果[TiMin] < [TiMax]，则最早在[TiMin]之后、最晚在[TiMax]之后发出新的随机数[Out]。

同时发出一个新脉冲[Imp]。每个脉冲持续一个程序周期。

 

Example 2: Random number [Out] in each program cycle.

如果[TiMin] = [TiMax] = 0，则在每个程序周期中发出一个新的随机数[Out]。

二进制输出信号 [Imp] 恒定：[Imp] = 1。

 

Example 3: Random number [Out] at constant intervals.

如果[TiMin] = [TiMax] = x，则总是在时间x之后发出新的随机数[Out]。

同时发出一个新脉冲[Imp]。每个脉冲持续一个程序周期。

（前提条件：x <> 0）
