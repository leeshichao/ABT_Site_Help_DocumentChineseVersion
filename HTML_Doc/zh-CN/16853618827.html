[EPS_DI] DINT 值的近似精度

Description

该指令将 IN 的绝对值与输入值 INTERVAL 进行比较。 If the absolute value of IN is smaller than the limit INTERVAL, the output values QA are set to 1 and QN to 0. The input value IN is contained in the interval.否则，输出参数 QA 设置为 0，QN 设置为 1。输入值 IN 超出区间。

INTERVAL must have a positive value.

If INTERVAL is ≤ 0 , then QA = 0.

Troubleshooting

ENO = 0 if IN = -2,147,483,648
