UP 223..

本节介绍用于特定应用的按钮 UP 223/2、UP 223/3 和 UP 223/5。

有关属性的说明，请参阅硬件目录中的“KNX PL-链接设备”一章。

List of UP 223/2 devices

此列表包含库中的 UP 223/2 设备。

设备

描述

按钮分配

LgtBtnDev_UP223/2_3xDim

  • 3x light dimming for button pairs

PshBtnDev_UP223/2_1xDim-1xBls-2xScn

  • 1x light dimming for button pairs
  • 1x blind moving up/down for button pairs.
  • 2x scene control for single buttons

PshBtnDev_UP223/2_1xDim-2xBls

  • 1x light dimming for button pairs
  • 2x blind moving up/down for button pairs

PshBtnDev_UP223/2_2xDim-1xBls

  • 2x light dimming for button pairs
  • 1x blind moving up/down for button pairs

PshBtnDev_UP223/2_2xTog-2xBls

  • 2x light switching for single buttons
  • 2x blind moving up/down for button pairs

PshBtnDev_UP223/2_4xTog-1xBls

  • 4x light switching for single buttons
  • 1x blind moving up/down for button pairs
