修复

您可以修复计算机上已安装的 ABT 站点和 ABT Pro 工具和库或功能。如果与 ABT Site 或 ABT Pro 一起安装的库已损坏并且无法按预期运行，请使用修复选项。请完成以下步骤来修复工具：

  1. Extract the ABT setup package by using ABT_Installer.exe.
  2. In the ABT Installer’s welcome dialog box select the setup language of your choice and click Next.
    Note: The language you select here is for ABT Installer only and not the ABT Pro or Site product language.
  3. Select Repair, to repair the installed tools and libraries.
  5. Select the tools and libraries that you want to repair and click Next. If you have installed ABT Site, then you can see only ABT Site libraries to repair.
  6. Verify the tools and libraries you want to repair from the components selected list and click Repair.
  7. Select Restart Now and click Restart to restart your machine. You must restart your machine after you repair the tool.
  1. You have successfully repaired the installed features.
