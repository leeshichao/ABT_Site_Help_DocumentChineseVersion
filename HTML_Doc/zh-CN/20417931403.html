[TDiffStepDn21] 降压温差

Program block, name / node subtype: [TDiffStepDn21] Temperature difference for step down

Library hierarchy: Universal functions

Family: TDiffStepDn

Function

如果主温差（主流温度 - 主回水温度）太小并低于某个设定值，则为功率控制和补偿逻辑生成降压请求。

最有可能的是有一个水力平衡器（或储罐），并且在用户侧测量流动温度，在发电侧测量主回水温度。

两个温度之间的微小差异表明发电功率可能过高，必须降低。

程序中的参数定义了如何计算温差：主流温度设定点与主回水温度之间，或者测量的主流温度与主回水温度之间。

程序中的参数化延迟定义了设备启动后功能激活的时间，例如 15 分钟。
