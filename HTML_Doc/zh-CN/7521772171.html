使用此过程来命令关联设备或建筑元素内的选定参数。

Command parameters

  1. Open Startup > Global functions.
  2. Select the Command tab.
  3. Select a command list.
  4. A list of parameters displays by description, units, and value field. The list provides units, range checking, default value, and state text.
  5. Select the parameters for commanding.
  6. Select the Engineered devices or Discovered devices tab.
  7. Parameters that were commanded previously in the current session display.
  8. Select devices, either individually or by selecting building elements, for commanding.
  9. Click Preview.
  10. The parameter settings are read and the results display below the device.
  11. Set the desired values.
  12. Click Commit.
  1. The commands for the selected parameters within the associated devices or building elements are issued. If successful, the parameters are updated for the selected devices with the commanded value.
