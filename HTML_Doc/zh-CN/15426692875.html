[R_BSCHED] 读取二进制调度程序

功能块 R_BSCHED 读取二进制调度程序对象的当前值和附加属性。

R_BSCHED 读取二进制调度程序对象的当前值和附加属性。

Functioning

Compatible data points:

  • Binary schedule [BSchedule]

Required properties:

  • Present value
  • Status flag
  • Next value
  • Time to next value

Optional properties:

  • Reliability
Pins

输入

描述

数据类型

默认值
取值范围

BaObjRef

BA-Object reference
功能块和 BACnet 对象之间的链接。

结构

---

BaObjRef
> DeviceID

Device identifier
[DeviceID] 在一个 ID 中包含对象类型和对象实例。
标识设备对象：本地或远程。本地设备对象也可以通过值 16#3FFFFF 来标识。

双字

16#3FFFFF

BaObjRef
> ObjectID

Object identifier
[ObjectID] 在一个 ID 中包含对象类型和对象实例。
标识设备上的对象。

双字

16#3FFFFF

BaObjRef
> ItemID

Item identifier
[ItemID] 表示引用 BACnet 对象的视图节点对象中的索引。
[ObjectID] 和 [ItemID] 一起定义对 BACnet 对象的间接引用。
值-1表示直接接口。

整数

-1

 

输出

描述

数据类型

默认值
取值范围

PrVal

Present value

引用的 BACnet 对象的属性“当前值”的值。

[PrVal] 在发生故障时提供最后的有效值。

Note
The default initial value for [PrVal] can be changed to another value in the programming editor as needed.

布尔值

0

PrValSta

Present value state

指示是否启用当前周期的调度。当属性“当前值”不具有值 Null 时启用计划。
发生故障时，[PrValSta]表示最后的有效值。

布尔值

0

0 - 禁用当前期间的计划。
1 - 启用当前周期的调度并且 [PrVal] 显示其值。

NxVal

Next value

引用的 BACnet 对象的属性“下一个值”的值。
发生故障时，[NxVal] 指示最后的有效值。

布尔值

0

NxValSta

Next value state

R_B 读取二进制数据点的当前值和附加属性。
发生故障时，[NxValSta] 表示最后一个有效值。

布尔值

0

0 – 禁用下一个周期的计划。
1 – 启用下一个周期的调度并且 [NxVal] 显示其值。

TiNxVal

Time to next value

属性“Time”的值到引用的 BACnet 对象的下一个值。
发生故障时 [TiNxVal] 指示最后的有效值。

时间

0 ms

Dstb

Disturbed

[Dstb]表示引用的BACnet对象是否有错误。

[Dstb] = 1 如果：
BACnet 对象 = 访问期间出错
OR
“状态标志”=故障

否则 [Dstb] = 0

布尔值

0

Rlb

Reliability
指示属性“可靠性”的值（如果该属性可用）。

整数

0：未检测到故障

ErrCode

Error code indication

整数

0: No error

= 0 - No error
> 0 - XFB error codes
