[DLY_BO] 布尔值延迟

功能块 DLY_BO 根据延迟时间延迟输入信号并将其提供给输出。

DLY_BO 根据延迟时间延迟输入信号并将其提供给输出。

出去(t)= ln(t-Dly)

Functioning

DLY_BO 将每个新输入值 [In] 写入其缓冲区。如果输入值较上次保存的输入值发生更改，则输入值是新的。延迟 [Dly] 到期后，该输入值将在输出处提供。最后一个输入值在输出端保持待定状态，直到提供下一个延迟输入值。

Multiple new input values

在延迟时间内到达的多个新输入值按顺序保存在缓冲区（环形缓冲区）中。如果缓冲区已满（最多 100 个值），则即使延迟时间尚未到期，也会提供最早保存的输入值。这种强制输出最多发生。在循环时间内。没有任何值丢失。强制输出显示[Sta]=1。

提供输出上的初始值 [Init]，直到提供第一个延迟输入值。

Application

DLY_BO 允许对百叶窗电机进行级联控制，以防止同时启动时出现电峰值。
