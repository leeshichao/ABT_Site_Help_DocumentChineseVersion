更改特定于用户的用户名称

更改级别结构或分隔符Settings > Naming defaults > User designation settings不会自动更改已设计的用户指定。要更改现有的用户指定，请使用智能复制和粘贴功能。

对用户指定设置的更改不会自动显示在Advanced > User designation。重新启动项目以刷新视图。

 

Change user-specific user designations

在以下示例中，分隔符更改为'to+.

  1. Open Advanced > User designation.
  2. Right-click the root element and select Smart copy.
  3. Open Microsoft Excel and paste the tree.
  4. In Settings > Naming defaults > User designation settings, make your changes to the user-specific user designation.
  5. When adding or removing levels, adapt the columns in Microsoft Excel accordingly.
  6. Copy the content from Microsoft Excel.
  7. In Advanced > User designation click Smart paste.
  8. Click Adjust.
  9. Click Save.
  10. Restart the project to refresh the view.
