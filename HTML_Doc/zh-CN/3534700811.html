BlsIn

下表显示了不带任何子系统特定扩展的百叶窗输入 (BlsIn) 的通道配置属性。

列出的属性显示在Hardware and network editor > Inspector window > Properties当数据点“BIB”在Device view选项卡。

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

脉冲长度

“脉冲长度”定义了按钮必须按下多长时间才能被检测为长脉冲。

范围 0.1…25.5 [秒]

重复时间

“重复时间”定义了与长脉冲相比，非常长的脉冲所需的额外时间。

范围：0.1…25.5 [秒]

按两次时间

“按两次时间”定义双击的最大暂停时间。

范围 0.1…25.5 [秒]

按钮事件（列表）

启用或禁用列表中的按钮事件：选项的分类取决于通道的数量。

上升沿

下降沿，长按

下降沿，按 2x，长

重复循环

短按 2 次

按 2 次，长按

按两个按钮

按钮事件（表）

定义按钮事件。

  • Pushbutton event (from list)
  • Action: Operation associated to the pushbutton event: Stop, Move up, Move down, Step up, Step down, Go to height, Go to angle, Go to height & angle, Go to position, Unser defined 1...5, No action
  • Height (%): Height of slat position. Range: 0.00...100.00 [%]
  • Angle (%): Slat angle. Range: 0.00...100.00 [%]
  • Position number: Range: 0...4

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。
