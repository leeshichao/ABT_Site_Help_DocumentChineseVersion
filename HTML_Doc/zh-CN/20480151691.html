[DhwCrgCrt21] 生活热水、充注回路、内部热交换器

Program block, name / node subtype: [DhwCrgCrt21] Domestic hot water, charge circuit, internal heat exchanger

Library hierarchy: Heating equipment

Family: DhwCrgCrt

Configurator

程序块存储在没有 I/Os. 的库中 使用auto-create and auto-connect函数创建 I/Os 和 /or 将它们连接到接口块，例如 R_A、CMD_B。或者，从包含库中预定义 I/Os 的文件夹中取出 I/Os，并从工厂中取出 /or，并将它们连接到接口块。

Function

当生活热水储水箱需要充电时，充电电路接通。

可选泵打开，可选 PID 控制器通过将流量温度与设定值进行比较并打开和关闭混合阀来控制流量温度。

该程序块具有以下可选功能：

Option: Pump (1xBO, 4xBI)

控制泵 (Pu21)。

当充电电路打开时泵打开。

Option: Valve (1xAO, 1xAI)

Controls a valve (Vlv24).

用于流量温度控制的 PID 控制器也属于此选项。

此选项只能与可选的流动温度一起成功应用。

Option: Charge priority

当充电电路打开且无法通过减少并联用电设备的功率达到其设定点时，优先考虑充电电路。

PID 控制器将降低的流量温度设定值（例如 -5 K）与流量温度进行比较。其反相输出显示在 BACnet 上并由其他设备读取，例如用于预控制或散热器加热的加热电路。

此选项只能与可选的流动温度一起成功应用。

Option: Flow temperature (1xAI)

创建流量温度的模拟输入并读取其信号。

Option: Return temperature (1xAI)

创建回水温度的模拟输入并读取其信号。
