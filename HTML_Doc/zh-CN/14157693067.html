错误代码

输出引脚 [ErrCode] 指示功能块上次读取访问 BACnet 对象时发生的错误代码。

[ErrCode]可以测试控制程序中的Programming编辑器在线模式。在正常模式下，程序可以使用 [ErrCode] 进行特定的故障排除异常，例如高于范围、低于范围。

  • [ErrCode] = 0 indicates no fault.
  • [ErrCode] > 0 indicates a fault.

ErrCode < 20 and >= 256

值 < 20 和 >= 256 的错误代码是根据 BACnet 对象的可靠性属性的评估得出的。错误代码可能表明现场设备存在问题。

ErrCode >= 20 and < 256

错误代码 >= 20 且 < 256 表示函数和 BACnet 对象（数据点）之间存在问题，例如，访问对象和 /or 所需属性有困难。功能块和/or数据点配置值可能设置不正确。

Error codes derived from function block error message or return value from the system function chart (SFC)

错误代码

定义

描述

20

对象不可访问

未找到或无法访问引用的 BACnet 对象。

21

对象类型缺少匹配

引用的 BACnet 对象类型与功能块支持或期望的类型不匹配。原因：

  • Present value of BACnet target object is not accessible.
  • Present value of the BACnet target object does not match the data type expected by the function block.

22

对象引用已解析

如果支持，错误代码 22 表示以下内容：

临时状态， BACnet 对象引用所引用的 BACnet 对象不可访问。解析期间无法确定 VAR OUTPUT。如果解决时间超过超时，错误将转换为“ErrCode 20：对象不可访问”。

23

无效的对象引用

未设置 BACnet 对象引用。

24

对象未更新

BACnet 对象处于启动阶段，例如，在打开或下载之后。

在开始阶段，BACnet 对象尚未通过数据采集进行更新。

25

财产不可访问

无法访问属性或 BACnet 属性数据类型与功能块支持的属性数据类型不匹配。

26

找不到有效的现值

功能块“Read-Multiple”无法从由聚集类型视图节点对象聚合的成员对象中找到有效的当前值属性。

27

<保留>

N/A

28

配置参数超出范围

BACnet 属性 ID 或数组索引值超出范围。

29

不支持评价功能

该功能块不支持已配置的 EvlFnct。

30

内部错误

内部错误或系统功能图（SFC）错误。这些错误会导致 SFC 查询中断。典型的支持请求。

31

未知组数据标签

固件中不知道要命令的组数据标签。

32

组数据列表错误

命令组数据列表错误。名单的分发被取消。

33

群组成员溢出

聚集的组成员数量超过了功能块支持的最大数量。

40

没有定义属性

没有为引用的 BACnet 对象定义属性。

41

属性不匹配

引用的 BACnet 对象中的属性与功能块属性不匹配。配置不正确。

Troubleshooting

如果错误代码表明功能块的设备 ID 或对象 ID 有问题，请确保引用的 BACnet 对象与功能块兼容。

功能块访问收集视图节点对象：

  • The object ID displays a gather view node object (must be the same device).
  • The referenced BACnet object must be compatible with the function block type.
