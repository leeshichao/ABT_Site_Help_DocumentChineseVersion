FILTER_H：间隙

FILTER_H (FB428) 块根据设置的滞后创建输出变量。

功能性

该块中集成了以下功能：

  • Adjustable hysteresis.
  • Input value applied to the output via reset pulse.

输出变量保持在某个值，直到输入变量在方向改变后经历了滞后。如果输入值超过了一半的滞后，则输入值会影响输出值。

Enabling and disabling the function

当[EnFnct] = 1（是）时，该功能启用。

当[EnFnct] = 0（否）时，该功能被禁用。没有获取新的输入值并且计算停止。最后一个值可在输出 [Out] 处获得。

Reset

当 [Reset] = 1（是）时，输入 [In] 在输出 [Out] 处发出。

应用

典型应用包括： 过滤信号中的噪声（来自压力传感器、温度传感器的不稳定输入信号）。其他应用：大放大级联的稳定、小开关差的 2 点开关、具有外部偏差的控制回路。

过程响应

在该过程的第一个周期中，过滤后的值使用输入值进行初始化并传输到输出。直到过程中的第二个循环才开始过滤。
