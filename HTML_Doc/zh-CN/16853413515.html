[WNOT_DW] 双字 NOT 操作

Description

该指令反转输入值字。输入值的每一位都被反转并写入相应有效位的输出值位。

Example

IN

2# 1 1 1 1_0 0 0 0_1 1 1 1_0 0 0 0_1 1 0 1_0 0 0 0_0 0 0 0_0 0 0 0

OUT

2# 0 0 0 0_1 1 1 1_0 0 0 0_1 1 1 1_0 0 1 0_1 1 1 1_1 1 1 1_1 1 1 1

Parameters

参数

宣言

数据类型

描述

默认

IN

输入

DWORD

输入值

0

OUT

输出

DWORD

产值
