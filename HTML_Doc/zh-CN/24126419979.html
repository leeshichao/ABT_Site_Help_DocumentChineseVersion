创建趋势日志对象 - 项目选项卡

在中创建趋势日志对象Projects选项卡。

  1. Go to Engineering > BACnet references.
  2. Click Projects tab.
    Create a BACnet reference from ABT Site projects.
  3. Select the required project in the Selected project field.
  4. The respective data points of the project is displayed below in the form of a table.
  5. Right-click the required data point in the table and click Add trendlog.
  2. The trend log object is created in the Plants navigation view.

设备名称、设备实例号、对象类型和对象实例号信息可以在Log device object properties财产在Properties选项卡。
