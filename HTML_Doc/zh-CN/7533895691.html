Installing HQ or RC libraries

HQ 和 RC 库使用专用设置进行安装。这些库将复制到标准库文件夹（C:\ProgramData\Siemens\Desigo\ABT\Libraries\HQ 和 ...\RC）。

 

Install a HQ or RC library

  1. Double-click setup.exe.
  2. The templates and types are copied to the standard library folders (C:\ProgramData\Siemens\Desigo\ABT\Libraries\HQ and ..\RC).
  3. Existing templates and types remain.
  4. New template and types are added.
  5. Click Refresh.
  1. The templates and types are now available in Configuration > Application selection.
