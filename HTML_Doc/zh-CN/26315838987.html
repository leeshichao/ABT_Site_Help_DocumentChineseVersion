检查节点连接

  1. The user is logged into a node.
  1. Navigate to Object view > Device > Infrastructure.
  2. Select Network port for secure connect and then .
  3. The Network port for secure connect properties work area opens.
  4. In the field Hub connection status, check the connection status.
  1. If Connected to primary hub is displayed, everything is fine and does not require further diagnosis. If a different message is displayed, more information can be displayed in the fields Primary hub connection status and Failover hub connection status. The number <5> displayed shows the amount of information available for this field.

 

Error analysis

  1. The Hub connection status does not show the Connected to primary hub information.
    Error list
  1. Select either the Primary hub connection status or the Failover hub connection status field.
  2. The Primary hub connection status work area opens.
  3. Analyze the information displayed for further troubleshooting.

中的时间条目Connect timestamp行显示最后一次尝试连接到主集线器的时间。
