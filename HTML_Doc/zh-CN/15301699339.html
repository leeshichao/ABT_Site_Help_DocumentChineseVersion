[CMDSEQ_B] 二进制命令序列

功能块 CMDSEQ_B 命令设备组件的开启和关闭顺序。

CMDSEQ_B 接收所需的操作模式并相应地命令所需的工厂组件。

CMDSEQ_B 确定互连设备组件的开启和关闭顺序以及启动和停止模式，例如延迟、操作反馈或超时。

CMDSEQ_B 可以根据另一个工厂组件的反馈来命令一个工厂组件。

Functioning

CMDSEQ_B 接收所需的自动plant operating mode输入 [ValPgm] 处为 1...16。例如，它可以通过设备开关、手动开关或调度程序来确定。

CMDSEQ_B 支持最多16 freely programmable plant operating modes.

CMDSEQ_B 可以通过输出 [Cmd1]...[Cmd16] 命令最多 16 个设备组件。

每个工厂操作模式都可以确定要打开和关闭的工厂组件、它们的相同顺序以及要考虑的启动和停止模式（例如延迟、反馈或超时）。

Switching on and off可以使序列中的每个后续设备组件取决于来自一个或多个设备组件的操作反馈。为此，输出块的状态信号从 CMDSEQ_B 返回到所需的输入。

以下启动和停止模式可用于打开和关闭每个工厂组件：

  • Immediate
  • Delay
  • Feedback or timeout
  • Feedback message
  • Feedback and delay
  • Grouping with next

异常模式的信号，例如主动火灾探测器的结果，可以互连到 CMDSEQ_B 的输入 [RpdOff]。 CMDSEQ_B 在出现活动异常模式时关闭所有设备组件。然后，所连接设备组件的输出块由异常模式直接控制。

Normal mode and exception mode with CMDSEQ_B

Innormal mode, CMDSEQ_B 由输入 [ValPgm] 处接收的操作模式控制。 CMDSEQ_B 根据定义的标准释放连接的工厂组件。

异常模式（紧急模式或保护，例如来自火灾探测器）的信号可以连接到 CMDSEQ_B 的输入 [RpdOff]。它会导致所有连接的工厂组件快速关闭。

其次是直接控制工厂组件的输出块[CMD_A]、[CMD_B]和[CMD_M]的异常模式。

活动的本地异常模式作用于特定的输出块，但也可以返回到通用异常模式。

如果仅影响特定输出块，则正常模式继续通过 CMDSEQ_B 运行。
当返回到一般异常模式时，根据本地和一般异常模式的优先级直接控制所连接的设备组件和输出块的快速关闭。

Object table

在对象表 [ObjTb] 中，最多可输入 16 个工厂组件作为对象 [Obj1] 至 [Obj16]。

Start mode and stop mode

[SttMod] 启动模式和 [StpMod] 停止模式定义命令启动或停止序列中的下一个设备组件的条件：

  • Grouping with next
  • Immediate
  • Delay
  • Feedback or timeout
  • Feedback message
  • Feedback and delay

Grouping with next

设备组件与启动或停止序列中的下一个设备组件分组。适用于序列中组中最后一个对象的条件也适用于整个组。

Immediate
下一个工厂组件会立即收到命令。

 

Delay
设置的延迟到期后发出命令。

 

Feedback or timeout
反馈后发出命令，最迟但在设置的超时到期后。
一旦请求的反馈到达，下一个工厂组件就会立即受到命令。
如果没有反馈到达，则在设置的超时到期后仍会命令下一个工厂组件。

 

Feedback message

反馈后指挥。如果没有反馈，则不会命令下一个工厂组件。

 

Feedback and delay
反馈后发出命令并在设定的延迟期满后发出命令。如果没有反馈，则不会命令下一个工厂组件。

 

Start and stop delay

必须为每个带延迟或超时的启动模式或停止模式设置 [SttDly] 启动延迟 (mm:ss) 或 [StpDly] 停止延迟。

Locks

可以根据来自前一设备组件的反馈或来自另一设备组件的反馈来启用接通和断开序列中的下一个设备组件。这可以通过 CMDSEQ_B 或通过相应的输出互连来发生。

当通过 CMDSEQ_B 锁定时，命令设备组件的每个条件都会根据启动序列或停止序列在生效时考虑。例如，如果从较早的已处理条件请求的反馈在启动或停止序列中不再待处理，则它对序列的其余操作没有影响。

Locking必须通过输出的相应互连来持续监测反馈并考虑优先事项。

Switch-on workflow (start sequence)

如果通过更改输入 [ValPgm] 处的值来请求特定的操作模式，则所需的设备组件将通过启动顺序打开。

CMDSEQ_B 中连接的设备组件的顺序（从上到下）决定了各个设备组件的开启顺序。

第一个输出 [Cmd1] 上的设备组件首先打开；接下来是第二个输出 [Cmd2]，依此类推，直到最后一个输出（最多 16）。

在打开下一个输出的设备组件之前，必须满足前一个组件的条件。

使用 [SttMod] 和 [SttDly] 下的设置在对象表 [ObjTb] 中定义接通条件。

Example: Switching on the plant with delays

  1. The supply air damper opens after a change of value on the input [ValPgm] (switch on).
  2. The fan is switched on after a delay of one minute.
  3. The heating coil is switched on after a delay of two minutes.

Switch-off workflow (stop sequence)

If the operating mode changes or the plant is switched off with a change of value at input [ValPgm], the plant components that are no longer needed are switched off with the stop sequence.下面描述关闭设备。

The sequence of the connected plant components (from bottom to top) in CMDSEQ_B determines the sequence for switching off of individual plant components.

最后一个输出上的设备组件首先被关闭；接下来是倒数第二个输出，依此类推，直到第一个输出（最多 16 个）。

在关闭下一个输出的设备组件之前，必须满足前一个组件的条件。

使用 [StpMod] 和 [StpDly] 下的设置在对象表 [ObjTb] 中定义关闭条件。

Example: Switching off the plant with delays

  1. The heating coil is switched off after a change of value on the input [ValPgm] (switch off).
  2. The fan is switched off after a delay of two minutes.
  3. The supply air damper closes after a delay of one minute.

Changeover of operating modes

如果通过更改输入 [ValPgm] 处的值来切换操作模式，则 CMDSEQ_B 首先处理停止序列，然后处理启动序列。

在停止顺序中，首先关闭不再需要的设备组件。接下来是打开启动序列中所需的任何附加设备组件。

两种运行模式所需的设备组件在停止和启动序列期间继续运行而不会中断。

因此，只有工厂组件的停止模式 [StpMod] 和启动模式 [SttMod]（例如延迟或反馈）被视为不再待处理或新的。

① 切换前的操作模式 [PgmMod1]。
② 在停止顺序中，不再需要的设备组件将被关闭。
③ 在启动顺序中，额外需要的设备组件被打开。
④ 切换后的运行模式[PrgMod2]。

Grouping

工厂组件可以分组并一起切换。来自各个团体成员的反馈也作为一个团体进行监控。

分组基于启动模式 [SttMod] 和停止模式 [StpMod] 的设置。

每次，组都以 [SttMod] 或 [StpMod] 列中的第一个设置“与下一个分组”开始，并以下一个偏离设置结束。

启动和停止序列中的分组是独立的。

Principles of control logic

以下原则对于理解内部控制逻辑非常重要：

  • A plant component connected to output [Cmd1] to [Cmd16] is switched on with signal 1 and switched off with signal 0.
  • Feedback from a plant component connected to input [OpSta1] to [OpSta16] means, with signal 1, that the plant component is switched on and, with signal 0, that it is switched off.
  • A switch-on delay "DlyOn" requires signal 1 on the input to start the internal timer. It provides value 1 after the delay expires.
  • A switch-off delay 'DlyOff' requires value 0 on the input to start the internal timer. It provides value 0 after the delay expires.
  • "AND" provides value 1, if all connected components have the value 1.
  • 'OR' provides signal 1, as soon as one or more connected components have the value 1. Additional connected plant components may be 0.

 

开启过程很容易跟踪，如以下基于超时的示例所示：

① CMDSEQ_B 接收到想要打开设备的新操作模式。

② 设备组件 1 立即收到值为 1 的开启命令。

③ DlyOn 接收值 1，输入的时间开始运行。时间到期后它提供值 1。

④ 在输入 [OpSta 1] 处接收来自第一个设备组件的反馈。该值可以是 0 或 1。

⑤ 如果反馈为 1，或者 DelayOn 到期并发送 1，或者两个值均为 1，则逻辑块“OR”提供值 1。否则，它提供值 0。

⑥ 如果设备组件 2 接收到来自逻辑块 OR 的信号 1，则设备组件 2 接通。否则它会保持关闭状态。

 

以下示例说明了基于超时的关闭过程：

① CMDSEQ_B 接收到想要关闭设备的新操作模式。

② 设备组件 2 立即收到值为 0 的关闭命令。

③ DlyOff 接收值 0，输入的时间开始运行。时间到期后它提供值 0。

④ 在输入 [OpSta 2] 处接收来自设备组件 2 的反馈。该值可以是 0 或 1。

⑤ 如果反馈为 0，或者 DelayOff 到期并发送 0，或者两个值均为 0，则逻辑块“AND”提供值 0。否则，它提供值 1。

⑥ 如果设备组件 1 从逻辑块“AND”接收到信号 0，则设备组件 1 关闭。否则它会保持打开状态。

ObjTb

对象表

对象表定义了切换到启动或停止序列中的下一步的条件。

结构

-

可以为每个对象（设备组件）定义条件，以允许在启动或停止序列中命令下一个对象。

Obj1...16：工厂组件 1...16

每个对象都有以下设置：

Enable

EnObj:如果[EnIn1]从0变为1。

Switch-on conditions (start sequence):

SttMod:启动方式
开启下一个对象的条件。

  • Group with next: The object is grouped with the next object in the start sequence. The conditions applicable to the last object apply to the entire group.
  • Immediate: The next object is immediately switched on.
  • Delay: Switch-on after the set delay expires.
  • Feedback or timeout: Switch-on after feedback, at the latest however after the set timeout expires.
  • Feedback: Switch on after feedback. The next object is not switched on without feedback.
  • Feedback and delay: Switch on after feedback and subsequent expiration of the set delay.

SttDly:启动延迟或超时
可以为启动模式设置延迟或超时的持续时间 (mm:ss)。

Switch-off conditions (stop sequence):

StpMod:停止模式
关闭下一个对象的条件。

  • Group with next: The object is grouped with the next object in the stop sequence. The conditions applicable to the last object apply to the entire group.
  • Immediate: The next object is immediately switched off.
  • Delay: Switch-off after the set delay expires.
  • Feedback or timeout: Switch-off after feedback, at the latest however after the set timeout expires.
  • Feedback: Switch off after feedback. The next object is not switched off without feedback.
  • Feedback and delay: Switch off after feedback and subsequent expiration of the set delay.

StpDly:停止延迟或超时
可以为带有延迟或超时的停止模式设置持续时间 (mm:ss)。
