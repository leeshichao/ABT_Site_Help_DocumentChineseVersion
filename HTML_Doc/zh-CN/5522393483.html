函数的属性/channels

当在设备视图中选择具有 KNX S 模式的设备时，列出的属性将显示在“属性”选项卡中。可见属性的分类取决于自动化站的程序版本。

属性在硬件和网络编辑器中配置。属性列表按字母顺序排序。

EnableInfoMUD2)
Sunblind actuator basic (SAB)

"EnableInfoMUD" defines if the blinds actuator can send information about the direction of movement of the blind.

: The blinds actuator supports the communication object "InfoMoveUpDown". The actuator sends the direction of movement when the movement starts or the direction of movement changes. The direction of movement will not be sent if the blind is in the state Stepping.

：百叶窗执行器不支持通信对象“InfoMoveUpDown”。不发送运动方向。

Note

：百叶窗执行器不支持通信对象“InfoMoveUpDown”。

Map0x00ToVoidPos2)
Sunblind actuator basic (SAB)

“Map0x00ToVoidPos”定义如何解释遮阳帘当前高度位置和板条当前角度位置的值 0 %。

: 0 % 表示以下值至少有一个无效：
- 百叶窗当前高度位置的百分比
- 板条的当前角度位置（以百分比表示）

: 0 % does not indicate invalid values.

Note
如果启用“Map0x00ToVoidPos”，则应禁用“EnableVCAP”。

: 0 % does not indicate invalid values.

映射表

“映射表”定义了 KNX 中定义的枚举值如何映射到多状态输入或多状态输出的值。

偏移 1：枚举值对于输入向上移动 1，对于输出向下移动 1。

偏移0：枚举值保持不变。

HVACModeUser：激活房间操作模式，包括自动模式。仅受 MIN8 和 MON 支持 8。

HVACModeEff：激活房间操作模式，但不激活自动模式。仅受 MIN8 和 MON 支持 8。

Move up/down1)
Sunblind actuator basic (SAB)

“向上移动/down”定义将百叶窗或百叶窗从上端位置移动到下端位置或从下端位置移动到上端位置所需的最长时间。

如果自动化站在指定时间内没有从执行器接收到有关其移动状态的信号，则假定百叶窗已停止移动并将属性“进程中”设置为 false。

范围：3...300 [秒]

180

定位台2)
Sunblind actuator basic (SAB)

定位表包含预定义位置 P0 到 P4 的值。

每个预定义位置由 2 个值定义：

  • Position, height: Range 0 – 100 [%]
  • Slat position: Range 0 – 100 [%]

P0：关闭：
正常下端位置，板条关闭。位置、高度：100，板条位置：100。

P1：视觉保护
板条的位置可以保护房间内人员的隐私，但仍然允许尽可能多的光线进入房间。
位置，高度：100，板条位置：可变

P2：防眩光，太阳位置低
板条处于低高度的遮阳位置。
位置，高度：100，板条位置：可变

P3：防眩光，太阳位置高
板条处于遮挡位置，以适应高海拔的阳光。
位置，高度：100，板条位置：可变

P4：打开
板条处于尽可能少地限制透过百叶窗的视野的位置。
位置、高度：100 %，板条位置：可变

100
