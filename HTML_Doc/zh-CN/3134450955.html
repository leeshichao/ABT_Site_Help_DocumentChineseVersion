监控 BACnet 对象

当您上线并选择要监控的目标对象时，“类型”栏左侧会显示监控栏，您可以选择一个或多个对象进行监控。

当对象被监视时，BACnet 对象编辑器框将变为橙色，监视器列中显示眼镜，并且检查器窗口中的对象属性将被停用，直到您单击检查器窗口中的对象属性。要重新激活检查器窗口中的对象属性字段，请双击监视列中的眼镜，右键单击该对象并选择Stop Monitoring Point(s），或单击Stop Monitoring Point(s)图标在BACnet objects editor工具栏。

Note

在现值可写之前，物理输入必须停止使用。物理输出通过命令优先级进行命令。

当 BACnet 对象编辑器处于在线模式时，不允许使用复制、粘贴、添加和删除功能。当 BACnet 对象编辑器处于离线模式时，这些功能将恢复。

有关详细信息，请参阅：使用自动化站上网/offline

Prerequisites

  • A project must be open with a room automation station selected.
  • The BACnet objects editor is open.

Procedure

可以通过三种方式开启监控：

  • Double-click the cell to the left of the desired object(s) in the monitor column.
  1. Monitoring is turned on for all selected data points and subordinate properties.

OR

  • Click the Monitor Target icon and click the Start Monitoring Point(s) icon in the BACnet objects editor toolbar.
  1. Monitoring is turned on for all selected data points and subordinate properties.

OR

  1. Right-click the object(s) and select Monitor Target.
  2. Select Start Monitoring Point(s) from the context menu.
  1. Monitoring is turned on for all selected data points and subordinate properties.
