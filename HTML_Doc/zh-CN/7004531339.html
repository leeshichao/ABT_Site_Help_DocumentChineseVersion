BO for DXP2 and DXR2

下表显示了信号类型为“BO 继电器”和“BO 三端双向可控硅开关元件”和“BO 脉冲开-关”（不带任何子系统特定扩展）的二进制输出 (BO) 的通道配置属性。

列出的属性显示在Hardware and network editor > Inspector window > Properties当在中选择数据点时选项卡Device view选项卡。

BO Relay and BO Triac

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。

BO Pulse On-Off

通道数

“通道数”定义数据点使用多少个通道。

如果 I/O 数据点使用多个通道，则所有属性都存储在第一个通道中。

信号类型

“信号类型”定义 DRA 信号类型。可用信号类型取决于 I/O 模块类型。可以编辑信号类型。

开机时间

“开启时间”定义了脉冲的持续时间。

范围：0.1...25.5 [秒]

关闭时间

“关闭时间”定义 ON 脉冲和 OFF 脉冲之间的暂停长度。

范围：0.0...25.5 [秒]

另存为

“另存为”将 I/O 数据点的设置参数保存为 xml 文件。
