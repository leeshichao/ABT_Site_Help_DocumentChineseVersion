命令 BACnet 对象

当您上网并选择一个数据点时，可以通过展开对象名称来命令该数据点的特定属性。您可以在相应的命令值字段中输入可命令属性的值，并使用以下方法之一更改该值。

有关详细信息，请参阅：使用自动化站上网/offline

Prerequisites

  • A project must be open with a room automation station selected.
  • The BACnet objects editor open.

Procedure

您可以通过两种方式控制数据点的值：

  • Clicking the Command icon in the BACnet objects editor toolbar.
  1. The data point is commanded to the value.

OR

  • Right-clicking on the BACnet object or objects and selecting Command from the context menu.
  1. The data point is commanded to the value.
