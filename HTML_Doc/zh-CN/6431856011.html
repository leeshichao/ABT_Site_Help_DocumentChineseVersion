时区

定义项目的项目时区。默认时区在 ABT 站点设置中定义。
Default time zone

工程单位

从下拉列表中选择要使用的单位系统。默认单位系统是International system (SI).

  • International system (SI)
  • US system of units
  • Imperial system of units
  • Canadian system of units

Note

  • All engineering units are listed. The system does not check the selected Engineering unit against the installed application types.
  • Only application types of the selected Engineering unit can be edited. Application types of other unit systems are not displayed in Configuration > Application selection > Types in library.
    Application selection

报告

从下拉列表中选择生成的报告的默认语言。

主动系统语言

从下拉列表中选择默认项目语言。这是生成项目数据所使用的语言。项目语言自动设置为运行时语言。

Note
项目语言可以与Application engineering语言，以便用户可以用他理解的语言进行设计，但为使用不同语言的客户生成数据。
这Application engineering语言设置为Project Manager > Settings.

运行时语言

下载到设备的语言列表。对于所选语言的文本数据库中不可用的任何文本，将显示英语作为备用文本。

可选择的语言数量最多为 4 种。项目语言自动设置为运行语言。

Updating text databases of devices

ABT Pro 检查中的值Runtime languages字段并以指定语言编译项目。您可以设置多种语言。
