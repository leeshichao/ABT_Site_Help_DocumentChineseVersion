[R_BG] 读取二进制组

功能块 R_BG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续采集组数据（当前值/status 标志对）。

R_BG 链接一个组管理器对象，该对象控制从特定组数据标签的多个数据点连续获取组数据（当前值/status 标志对）。此外，组管理器对象还会触发一个已配置的评估函数来计算结果值。 R_BG 以预先配置的时间间隔定期读取评估结果。读取也可以由外部源触发。

R_BG 可配置为根据可选评估函数提供多个（最多四个）评估结果值。必须至少配置一个评估函数。

专有对象对于分组基础结构是必需的：组管理器对象和一个或多个组成员对象。各个成员数据点通过组成员对象进行分组和引用，并且数据由组成员对象获取并转发到组管理器对象。

Functioning

Compatible data points:

  • Binary input [BI]
  • Binary output [BO]
  • Binary, calculated value [BCalcVal]
  • Binary configuration value [BCnfVal]
  • Binary process value [BPrcVal]

Required properties of group data points:

  • Present value
  • Status flag

取值范围

Interval

Read interval

可配置的轮询时间，指定读取计算结果的频率。
值 0 禁用计时器。在这种情况下，可以使用 [ImpRead] 从外部源触发评估结果的读取。
[UpdInd] 使用属性更新计数（如果可用）。这允许在新值等于先前值时检测值是否已更新。在没有更新计数的对象中，如果发生更改，[UpdInd] 将更改为属性当前值。

时间

15s_0ms

ImpRead

Impulse for read

可连接引脚，允许外部源提供数字脉冲来启动读取。
由于[ImpRead]可以互连，因此可以同步多个功能块的读数以在图表中进行采集。
Note
如果[Interval] = -1s，则禁用[ImpRead]。

布尔值

0

EvlFnct1…EvlFnct4

Evaluation function 1…Evaluation function 4

[EvlFnct1] 确定对来自具有公共 [GrpTag] 的已获取组数据的有效当前值执行的过程类型。
[EvlFnct1] 属于四个输入集之一，其中每个输入集都有 [EvlFnctX] 和 [ValInX]。通常，应用工程师在编程编辑器中设置它，并且在运行时不能更改。
[EvlFnct2]...[EvlFnct4] 的功能与 [EvlFnct1] 相同。

7: OR
所有有效值的逻辑运算 OR
10: Last updated

Value input 1…Value input 4

评估函数的可配置参数，为给定 [GrpTag] 的通用数据设置行进值。
仅当 [EvlFnct1] 设置为 5 (CountOfVal) 时才使用它。
[Valln1] 属于四个输入集之一，其中每个输入集都有 [EvlFnctX]、[ValInX]。通常，应用工程师在编程编辑器中设置它，并且在运行时不能更改。
[ValIn2]...[ValIn4] 的功能与 [ValIn1] 相同。

GrpTag

Grouping tag

指定功能块获取和评估的特定组数据（当前值、状态标志）。
系统提供预定义和可定制的标签。通常，应用工程师在编程编辑器中设置[GrpTag]，并且在运行时无法更改。必须设置与功能块的数据类型匹配的标签。

描述

数据类型

Val1...Val4

Value 1...Value 4

布尔值

0

基于 [EvlFnct1] 中选择的评估函数评估的结果值。

[Val1] 属于四个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。

[Val1]表示：

  • 0, if no present values in the acquired group data for the given [GrpTag] were valid. [Dstb1] = 1.
  • 0 if [EvlFnct1] remains on the default value. [Dstb1] = 1.
  • The last valid value if [Dstb1] = 0.

[Val2]...[Val4] 的功能与 [Val1] 相同。

Cnt1…Cnt4

Count 1…Count 4

整数

0

基于 [EvlFnct1] 中选择的 CountOfVal 评估函数计算的结果值。

-3.402822E38

[Cnt1] 提供：

  • The number of valid, present values from the common group data that match the selection of 1 or 0 at [ValIn1].
  • 0, if no present values in the acquired group data for the given [GrpTag] were valid. [Dstb1] = 1.
  • The last valid value if [Dstb1] = 1.

[Cnt2]...[Cnt4] 的功能与 [Cnt1] 相同。

Dstb1...Dstb4

Disturbance 1...Disturbance 4

[Dstb1]指示[EvlFnct1]上的评估选择结果是否有效。

[Dstb1] 属于五个输出集之一，其中每个输出集包含 [ValX]、[DstbX]、[CntX] 和 [UpdIndX]。

如果采集的组数据中至少有一个值有效，则 [Dstb1] = 0。

如果获取的组数据中没有有效值，则 [Dstb1] = 1。

[Dstb2]...[Dstb4] 的功能与 [Dstb1] 相同。

布尔值

0

UpdInd1...UpdInd4

Update indication 1...Update indication 4

布尔值

0

[UpdInd1] 表示评估中的至少一个值已更新为新值或相同值。

仅当 [Dstb1] = 0 时，[UpdInd1] 才设置为 1。

[UpdInd1]和[UpdInd1]的功能与[UpdInd1]相同。

Note
[UpdInd1] 不支持评估函数“CountOfVal”。
