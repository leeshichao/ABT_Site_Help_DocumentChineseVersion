Assigning I/O's (areas)

Assign I/O's for an application template

  1. Select an application template.
  2. Open Building > Application & device overview > Go to configuration.
  3. Configuration > Application configuration opens.
  4. Select Configuration > I/O assignment.
  5. The available sensors are displayed in the left table, and the actuators in the right table.
  6. Select the button in the left table.
  7. Select the corresponding button collection in the right table.
  8. Click Assign.
  9. The button is assigned to the button collection, and the I/O is assigned.
  10. Repeat steps 4 to 6, until all I/O's are assigned.
  1. The I/O's for the application template are assigned.

未分配 I/O 的房间和段继承父模板的 I/O 分配。

更改父模板时，不会删除为房间和段单独分配的 I/O。
